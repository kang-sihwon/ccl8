# 일관성과 변경 영향

설정 수정, 모순 검토, 여러 문서의 관계 정리가 필요할 때 읽는다. 결과는 현재 요청의 범위에서 확인한 충돌과 수정 후보이며 전체 세계가 모순 없다는 보증은 아니다.

## 근거와 상태

기존 항목의 이름이나 식별자, 소유 문서, 해당 시대와 적용 지역을 기록한다. 항목마다 원문 근거와 상태를 따라간다. 원문이 다른 시안 또는 보류안이면 현재 기준에 섞지 않는다. 설정 사실과 등장인물의 믿음, 선전, 독자에게 숨긴 사실도 구분한다.

자료가 충돌하면 프로젝트의 명시된 소유와 승인 범위를 먼저 따른다. 최신 파일이라는 이유만으로 승인된 설정을 대체하지 않는다. 소유나 승인 근거가 불분명하면 충돌을 드러내고 이번 초안의 임시 가정을 표시한다.

장기 작업에는 새 데이터베이스를 강요하지 않고 기존 문서에 항목과 관계를 연결한다. 구조화된 내보내기를 요청받았을 때만 ID, 유형, 상태, 출처, 시점, 관계의 방향을 보존한 형식으로 만든다.

## 변경을 전파하는 범위

변경 전·후와 변경 권한을 먼저 확인한다. 그 항목에 직접 의존하는 설정을 찾고, 결과가 다시 다른 항목의 전제를 바꾸는 동안 추적한다. 단순히 관련 있다는 이유로 모든 설정을 다시 쓰지 않는다.

도시를 옮기는 경우 위치뿐 아니라 식수·공급·통로·관할·교역 상대와 스토리 동선을 확인한다. 에너지 규칙을 바꾸는 경우 공급권·생산·유지 인력과 기존 사건의 해결법을 확인한다. 실제 영향이 없는 항목은 그대로 둔다.

| 영향받는 항목 | 기존 근거 | 깨지는 조건 | 수정 후보 | 상태 |
|---|---|---|---|---|
| 문서나 항목 링크 | 이전에 의존하던 설정 | 구체적인 충돌 또는 조건부 영향 | 최소 수정과 필요시 대안 | 반영·검토 대기·미확인 |

수정은 사용자가 요청한 범위의 초안에서 진행한다. 정본 변경은 해당 프로젝트의 승인 절차를 따른다. 채택되지 않은 대안과 이미 대체된 자료는 식별 가능하게 보존한다.

## 검토 관점

- 공간: 수계, 통로, 거주·생산 조건과 정착지 역할이 맞는가?
- 생계: 도시의 먹거리와 필수 자원을 누가 생산·운송·유지하는가?
- 권력: 세력이 주장하는 지배와 실제 집행 능력을 혼동하지 않았는가?
- 동기: 협력과 적대가 구성원들의 이해관계로 설명되는가?
- 규칙: 기술·마법의 비용과 제한이 사건마다 편의적으로 달라지지 않는가?
- 시간: 이주, 제도 형성, 사건 순서와 이동 시간이 맞는가?
- 서사: 인물이 아는 정보와 사용한 수단이 그 시점에 확보되어 있는가?

장르적 의도나 의도된 거짓말은 오류와 구분한다. 큰 판단을 바꾸는 미정에는 가능한 대안을 제시하고, 주변 장식의 미정 때문에 본문 작성을 멈추지 않는다.

검토 결과에는 문제, 근거, 영향, 수정안을 붙인다. 실제 계산 없이 기후·인구·수문·경제가 검증됐다고 보고하지 않는다. 계산을 수행했다면 사용한 모델과 가정, 검사 범위를 함께 남긴다.
