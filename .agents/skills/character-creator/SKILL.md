# Character Creator

작업 시작 전 스킬 선택·확인과 관련 스킬 안내는 [스킬 사용 안내](../../../Docs/AgentContextTools/SkillUsage.md)를 따른다. 아래 관련 스킬은 후보이며 승인 없이 작업 범위를 늘리는 지시가 아니다.

## 인물의 중심

이야기에서 맡을 역할, 이미 정한 사실, 바꿀 수 있는 범위를 읽는다. 겉으로 원하는 것, 실제로 필요한 변화, 피하려는 두려움이 서로 충돌하는 지점을 찾는다. 덕목·결함 목록마다 그것이 드러나는 행동이나 선택을 붙인다.

필요한 항목만 골라 외형, 성격, 목표, 과거, 능력, 강점·약점, 소지품, 습관·말투, 사건 연결점을 작성한다. 모든 인물에게 같은 분량의 양식을 채우지 않는다. 과거 사건은 현재의 행동·빚·비밀·의무를 만드는 원인으로 쓴다.

관계는 서로 원하는 것, 주고받는 것, 오해·갈등, 신뢰가 변하는 조건으로 설명한다. 동료나 적대자를 추가로 확정하지 말고 요청한 인물 범위에 필요한 관계 후보로 둔다. 성장 전후에 같은 압박을 받았을 때 달라지는 선택을 보여준다.

외형은 생활·역할·자기표현과 연결한다. 초상이나 참조 시트는 이미지 요청이 있을 때 제작 도구로 넘긴다. CCL의 인물 정체성을 기본·전용 무기 한 종류로 고정하지 않는다. 장비 선택, 전투 습관, 숙련의 정도를 구분한다. 수치 능력은 실제 채택한 규칙 체계가 있을 때만 그 체계에 맞춘다.

## 결과와 확인

인물 시트 또는 요청한 수정안, 상황별 말투 예시, 관계 변화의 조건을 낸다. 동기가 실제 사건을 움직이는지, 약점이 장식에 머물지 않는지, 다른 인물과 목소리가 구별되는지 확인한다. CCL의 후보 기록·승인은 [ccl8-narrative](../ccl8-narrative/SKILL.md)가 맡는다.

관련 스킬: 사건·장면은 [creative-fiction-writer](../creative-fiction-writer/SKILL.md), 시각 설계는 [concept-art-creator](../concept-art-creator/SKILL.md), 전투상의 역할은 [game-designer-assistant](../game-designer-assistant/SKILL.md)다.

## 출처와 적용

[Jenova Character Creator](https://www.jenova.ai/a/character-creator)의 공개 설명을 2026-11-04에 확인해 이 저장소의 작업 지침으로 재구성했다. 내부 프롬프트나 서비스 기능의 복제가 아니다. Jenova 계정·API·자동 기억 기능을 제공하지 않으며, 현재 세션의 도구와 파일을 사용한다. 사용자의 범위·출력 요구와 프로젝트 승인 절차를 우선한다.
