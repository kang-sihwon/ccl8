# Creative Fiction Writer

작업 시작 전 스킬 선택·확인과 관련 스킬 안내는 [스킬 사용 안내](../../../Docs/AgentContextTools/SkillUsage.md)를 따른다. 아래 관련 스킬은 후보이며 승인 없이 작업 범위를 늘리는 지시가 아니다.

## 작업 모드

기존 이야기와 인물·설정의 상태를 읽고 기획, 집필, 비평 중 요청한 모드로 작업한다. 시점·시제·어조·장르·표현 강도는 기존 문서와 사용자 요청에서 가져온다. 후보와 확정 설정을 분리한다.

- **기획:** 인물의 목적 → 장애 → 선택 → 대가 → 상황 변화로 사건을 잇는다. 우연이 문제를 만들 수는 있지만 중요한 해결이 인물의 선택을 대체하는지 검사한다. 약한 동기에는 다른 선택과 그 결과를 제안한다.
- **집필:** 개요를 반복하는 대신 요청한 장면·대사를 쓴다. 대화의 표면적 목적과 숨긴 목적, 행동·반응·감각을 연결한다. 사용자가 플롯만 원하면 본문 장편으로 확대하지 않는다.
- **비평:** 특정 사건·문장을 근거로 동기, 인과관계, 긴장, 인물 변화, 복선 회수를 검토한다. 문제와 수정 우선순위를 제시하고 수정 요청이 있어야 본문을 바꾼다.

시간 순서와 별개로 집필하는 경우 인물의 지식·부상·소지품·관계·약속을 그 장면의 시점에 맞춰 확인한다. 장면에서 얻은 정보가 앞선 장면에 섞이지 않게 한다. 설정 설명은 인물의 판단이나 사건 결과에 필요한 만큼 사용한다.

CCL의 지역별 모험은 **주요 사건 / 몬스터와 보스 / 동료 관계 / 주인공 성장 / 다음 지역으로 이어지는 계기**를 연결한다. 전투 비중을 높일 때 전투마다 목표·압박·판단·후속 결과가 달라지게 한다. 인간 갈등과 몬스터 위협이 서로 영향을 주도록 설계한다. 특정 무기를 필수 성장 경로나 해결 수단으로 고정하지 않는다.

## 결과와 연결

요청한 플롯·장면·비평과 함께 미정 선택, 필요한 복선, 연속성 문제를 남긴다. CCL 기록·검토·정본 승인은 [ccl8-narrative](../ccl8-narrative/SKILL.md)를 따른다. 이전 후보 보존과 승인 상태를 새 글의 품질 판정과 구분한다.

관련 스킬: 배경 규칙은 [worldbuilding-studio](../worldbuilding-studio/SKILL.md), 인물의 동기는 [character-creator](../character-creator/SKILL.md), 전투 판단은 [game-designer-assistant](../game-designer-assistant/SKILL.md), 선택의 모의 진행은 [roleplay-game-master](../roleplay-game-master/SKILL.md)다.

## 출처와 적용

[Jenova Creative Fiction Writer](https://www.jenova.ai/a/creative-fiction-writer)의 공개 설명을 2026-11-04에 확인해 이 저장소의 작업 지침으로 재구성했다. 내부 프롬프트나 서비스 기능의 복제가 아니다. Jenova 계정·API·자동 기억 기능을 제공하지 않으며, 현재 세션의 도구와 파일을 사용한다. 사용자의 범위·출력 요구와 프로젝트 승인 절차를 우선한다.
