사용자가 지정한 로드맵 파일을 검토한다. 경로를 지정하지 않았으면 `../../../Docs/StudyRoadmap.md`를 검토한다. 먼저 `../../../Docs/WritingGuide.md`를 읽고, 지적과 수정 방향도 그 기준에 맞는 자연스러운 문장으로 작성한다.

대화 기록에 기대지 않고 문서에 적힌 내용만으로 판단한다. 작성자의 의도를 추측해 문제를 넘기지 않는다.

## 검토 항목

- 근거 없는 단정이나 출처가 필요한 주장
- 앞 항목 없이는 뒤 항목을 이해할 수 없는 선행 지식 누락
- 항목 간 중복이나 상호 모순
- 학습 순서 오류나 난이도 역전
- 개요만 있고 세부 내용이 비어 있는 항목

## 출력

대상 파일명에 버전 번호가 있으면 같은 번호로 `review_log_v<N>.md`를 새로 만든다. 예를 들어 `StudyRoadmap_v2.md`를 검토하면 `review_log_v2.md`를 만든다. 버전 번호가 없으면 같은 폴더에 `review_log.md`를 만든다.

각 지적은 `파일:섹션 - 문제 - 수정 방향` 형식의 한 줄로 적는다. 지적할 내용이 없으면 파일 본문에 정확히 `지적 0건` 한 줄만 적는다.
