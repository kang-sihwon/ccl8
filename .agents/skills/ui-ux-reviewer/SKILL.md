# UI/UX Reviewer

작업 시작 전 스킬 선택·확인과 관련 스킬 안내는 [스킬 사용 안내](../../../Docs/AgentContextTools/SkillUsage.md)를 따른다. 아래 관련 스킬은 후보이며 승인 없이 작업 범위를 늘리는 지시가 아니다.

## 화면과 증거

원본 화면·영상·실행 환경과 사용자가 수행할 일을 확인한다. 플랫폼, 입력 장치, 시청 거리, 현재 화면 상태를 고려한다. CCL에서는 관련 [UIFoundation](../../../Docs/UIFoundation.md)과 기능별 사양을 읽는다.

정보 우선순위, 경쟁하는 강조, 글자 크기·간격·색, 아이콘 의미, 상태 피드백을 작업 목적에 맞춰 검토한다. 선택·포커스·비활성·로딩·빈 목록·오류·성공 상태와 되돌아갈 경로를 확인한다.

게임에서는 패드 포커스 이동·키 안내·마우스와 패드 전환·메뉴 닫기·일시정지·게임 입력 차단이 검토 대상인지 구분한다. 정지 화면에 상태가 보이지 않는다는 이유만으로 구현 누락이라 단정하지 말고 확인할 항목으로 남긴다.

대비·터치 영역·안전 영역 등 수치 판단에는 측정값이나 적용 규격의 출처를 붙인다. 이미지에서 정확히 추출할 수 없는 값은 근사·미확인으로 적는다. 웹 규격을 게임 HUD에 그대로 강제하지 않는다. 색만으로 구분하는 정보, 확대·자막·키 재지정 요구를 실제 사용자 흐름과 연결한다.

## 결과와 확인

지적마다 화면·위치, 관찰 근거, 사용자 영향, 우선순위, 수정안을 적는다. 관찰한 결함과 추정·추가 확인을 분리한다. 이전 버전이 있으면 개선·회귀·미해결을 비교한다. 수정 요청이 함께 있으면 승인 범위에서 고친 뒤 같은 흐름을 다시 확인한다.

관련 스킬: 시각 제작은 [graphic-designer](../graphic-designer/SKILL.md), 정보·규칙 구조는 [game-designer-assistant](../game-designer-assistant/SKILL.md), 실제 입력·플레이 확인은 [ccl8-verify](../ccl8-verify/SKILL.md), UE 구조는 [ccl8-design](../ccl8-design/SKILL.md)다.

## 출처와 적용

[Jenova UI/UX Reviewer](https://www.jenova.ai/a/ui-ux-reviewer)의 공개 설명을 2026-11-04에 확인해 이 저장소의 작업 지침으로 재구성했다. 내부 프롬프트나 서비스 기능의 복제가 아니다. Jenova 계정·API·자동 기억 기능을 제공하지 않으며, 현재 세션의 도구와 파일을 사용한다. 사용자의 범위·출력 요구와 프로젝트 승인 절차를 우선한다.
