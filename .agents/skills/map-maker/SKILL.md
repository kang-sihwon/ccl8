# 지도 제작

지도의 용도에 맞는 배치와 시각 결과를 만든다. 생성, 검토, 부분 수정 중 사용자가 요청한 작업을 수행하고, 그림에서 확인한 관계와 좌표·치수로 검증한 값을 구분한다.

## 시작과 범위

1. 지도 종류, 보여 줄 범위, 사용 목적을 대화와 기존 자료에서 찾는다. 목적을 전혀 알 수 없으면 필요한 질문 하나를 하고, 주변 세부는 가정으로 표시해 진행한다.
2. 기존 지도·설정·좌표·지명 목록을 읽고 현재 기준과 보류 시안을 구분한다. 고정할 요소, 이번에 바꿀 요소, 새로 제안할 요소를 정리한다. 생성물을 정본이나 측량 자료로 취급하지 않는다.
3. 출력 형태를 요청에서 정한다. 그림이면 이미지, 정밀 배치면 좌표 기반 도면, 검토면 지적과 수정안, 프롬프트 요청이면 실행 가능한 입력문을 낸다. 그림 요청을 프롬프트 작성만으로 끝내지 않는다.

CCL에서는 [서사 작업 현황](../../../Docs/Narrative/CurrentWork.md)에서 설정을, [지도 아트 지도](../../../Docs/ArtDirection/EtherWorldMap.md)에서 현재 이미지와 기준 자료를 찾는다. 표현은 [결정 35](../../../Docs/decisions/0035-nadir-map-presentation.md)를 따른다. 새 설정·승인·기록은 [ccl8-narrative](../ccl8-narrative/SKILL.md), 문서 배치는 [ccl8-docs](../ccl8-docs/SKILL.md)의 절차를 사용한다. 작업마다 요청 범위에 필요한 자료만 읽는다.

## 제작과 수정

**새 지도:** 주요 지형과 물길, 거점, 이동 연결부터 배치하고 시점·색·기호·지명으로 읽는 순서를 만든다. 세계·지역 지도는 지형과 수계를, 도시 지도는 생활권과 이동을, 던전·전투 지도는 통로·높이·엄폐·퇴로를 먼저 검토한다. 관련 세부 기준은 [지도 검사](references/map-checks.md)를 읽는다.

**기존 지도 검토:** 원본을 직접 보고 지리·공간 연결, 정보의 중요도, 표현 일관성, 세부 장식 순으로 살핀다. 잘 유지할 점과 문제가 있는 위치, 근거, 수정안을 제시한다. 검토만 요청받으면 수정본 생성까지 확대하지 않는다.

**부분 수정:** 기준 이미지를 참조하고 변경 영역과 유지할 해안·수계·거점·시점 등을 입력에 명시한다. 수정 후 원본과 대조해 변경 영역 밖의 이동·누락도 확인한다. 의도하지 않은 변화가 있으면 구체적으로 보정하고, 해결하지 못한 항목은 남긴다. 기존 파일과 후보는 프로젝트의 보존 규칙에 따라 유지한다.

**축척 확장:** 상위 지도에서 확대 범위와 공통 기준점을 정한다. 하위 지도는 그 위치·방향·연결을 이어받고, 상세화하면서 새로 만든 배치는 후보로 구분한다. 스타일·기호·지명 목록도 공유한다. 지도마다 따로 생성했다는 이유로 도시 위치를 다시 정하지 않는다.

## 도구와 입력문

- 사용자 지정 도구가 있으면 우선한다. 래스터 생성·수정에는 현재 세션의 이미지 도구와 관련 스킬을 사용하고, 실제 치수·정확한 표기는 좌표 기반 SVG·GIS·도면 도구 등 목적에 맞는 수단을 쓴다. 기존 래스터 이미지를 편집할 때는 이미지 편집 도구 규칙을 따른다.
- 이 스킬은 Jenova 접속이나 API를 제공하지 않는다. Jenova 사용을 요청받으면 이용 가능한 연결·브라우저를 확인한다. 실행할 수 없으면 그 한계와 사용할 입력문을 제공하고, 다른 도구로 만든 결과를 Jenova 결과라고 부르지 않는다.
- 입력문에는 용도·범위, 기준 자료, 필수 지형·거점, 유지할 관계, 시점, 화면 비율, 표기 방식, 변경 대상과 검사 조건을 담는다. 기존 비율과 좌표가 있으면 우선하고 새 비율은 용도에 맞는 가정으로 제시한다.
- 지명 정확도가 중요한 지도는 바탕과 표기를 나눌 수 있다. 무문자 바탕 뒤에 원본 지명 목록을 따라 텍스트를 배치하고 철자·위치·중복·누락을 확인한다. 인쇄·격자가 필요하면 목표 크기와 단위를 함께 정한다.
- 지도 때문에 생기는 정착·교역·국경·갈등을 작성할 때는 [worldbuilding-studio](../worldbuilding-studio/SKILL.md)를 함께 쓴다. 지형 표식만으로 국가·문화·통치권을 확정하지 않는다.

## 완료 확인

결과 이미지는 실제로 열어 목적에 필요한 내용이 읽히는지 확인한다. 위치·거리·면적·층 연결처럼 이번 요청의 핵심 조건을 원본 자료와 대조하고, 표현 확인·계산 확인·미확인을 나눠 보고한다. 읽을 수 없는 지명이나 달라진 해안선을 발견한 채 성공으로 묶지 않는다.

지도 또는 수정안과 함께 배치 이유, 가정, 남은 문제를 짧게 전달한다. 수치 정확도를 요구받았다면 계산 가능한 근거를 남긴다. 개념 지도만으로 UE 이동·전투 공간이나 실제 항행이 검증됐다고 보고하지 않는다.
