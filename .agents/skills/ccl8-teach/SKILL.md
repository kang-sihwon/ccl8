# ccl8 학습

훈련 모드(사용자가 먼저 풀고 AI가 힌트를 주는 방식)는 `../../../Docs/Mentoring.md`가 소유한다. 이 스킬은 AI가 설명을 주도하는 학습이다. 오래 남길 학습 문서를 쓸 때는 `../../../Docs/SystemExplanationGuide.md`를 따른다.

## 절차

1. **목적을 정한다.** "이 학습이 끝나면 사용자는 ...을 할 수 있다" 한 문장을 사용자와 정한다. `Docs/LearningLog.md`에서 관련 과제와 이미 확인된 이해를 읽고, 아는 것은 반복하지 않는다.
2. **지도를 그린다.** 대상 시스템의 가장 바깥 그림을 Mermaid로 그린다. 상자는 셋에서 다섯 개다. 코드 위치는 `graft`, 엔진 동작은 `graft_ue58`로 확인하고 `path:line`을 붙인다.
3. **한 번에 하나씩 더한다.** 단계마다 그림에 요소 하나(클래스, 호출, 수명 경계, 네트워크 경계)를 더하고, 더한 이유와 실제 코드 발췌를 붙인다. 처음 나오는 UE 매크로·타입·수명 규칙은 그 단계에서 설명한다.
4. **단계마다 확인한다.** "왜 이 책임이 여기 있는가", "언제 해제되는가", "다른 방식이면 무엇이 비싸지는가" 같은 질문 하나를 낸다. 사용자가 답하면 맞은 점과 고칠 점을 말하고 다음 단계로 간다. 답을 맞히게 하려고 정보를 숨기지 않는다.
5. **기록한다.** 끝나면 Mentoring의 학습 기록 양식으로 `Docs/LearningLog.md`를 갱신한다. 이해 상태는 사용자가 실제로 설명하거나 수행한 근거로만 정한다. 설명을 읽은 것만으로는 "미확인"이다.
6. **남길지 묻는다.** 이 설명을 `Docs/Learning/`의 학습 문서로 남길지 사용자에게 묻는다. 남기면 SystemExplanationGuide의 한 장 구성과 저장 전 점검을 따른다.
