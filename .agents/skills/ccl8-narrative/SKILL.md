# ccl8 서사 작업

작업 전에 [서사 작업 절차](../../../Docs/Narrative/Workflow.md)를 읽고, 그 문서의 "시작" 절이 정한 문서를 순서대로 읽는다. 파일이 없거나 읽을 수 없으면 절차를 추측하지 말고 중단 사유를 보고한다.

서사 작업 절차는 단계와 판정, 작성자·독립 검토자·승인자의 역할, 출처와 인용, 기록 위치, 승인과 정본 반영, 인계를 정하는 유일한 절차 정본이다. 서사 문서의 소유는 `../../../Docs/NarrativeConcept.md`가 정한다. 이 스킬에서 해당 규칙을 복제하거나 변경하지 않는다.

독립 검토는 세션 모델의 읽기 전용 검토 에이전트 하나에 맡길 수 있다. 시작할 때 한 줄로 알리고, 에이전트에게는 파일을 쓰지 말고 판정과 지적만 보고하게 한다. 근거는 [결정 28](../../../Docs/decisions/0028-agent-workflow-restructure.md)이다.

사용자 요청과 서사 작업 절차가 가리키는 현재 상태에 맞는 작업만 수행하고, 검토와 승인 단계를 자동으로 건너뛰지 않는다. 스킬 호출 자체를 파일 수정, 역할 변경 또는 후보의 정본 승격에 대한 추가 권한으로 해석하지 않는다. 문서의 Git 처리는 `../../../Docs/VersionControl.md`를 따른다.

콘셉트 아트·이미지 생성·편집, 시각 레퍼런스만을 위한 조사와 아트 제작 인계는 이 스킬의 범위가 아니다.
