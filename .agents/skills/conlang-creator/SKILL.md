# Conlang Creator

작업 시작 전 스킬 선택·확인과 관련 스킬 안내는 [스킬 사용 안내](../../../Docs/AgentContextTools/SkillUsage.md)를 따른다. 아래 관련 스킬은 후보이며 승인 없이 작업 범위를 늘리는 지시가 아니다.

## 필요한 깊이

명명 규칙만 필요한지, 문장을 쓸 언어가 필요한지, 문자 시안까지 필요한지 정한다. 기존 이름·언어 계통·문화 설정을 읽고 이름을 임의로 교체하지 않는다. 새로운 체계와 충돌하는 기존 이름은 방언·외래어·옛 형태 등의 설명 후보로 제시한다.

목표 인상을 음소, 음절 구조, 허용 자음 결합, 강세·성조로 구체화한다. 필요한 경우 IPA와 한국어 독자를 위한 근사 발음을 함께 적되 두 표기의 정확도를 구분한다. 발음 인상이 문화나 성격을 결정한다고 단정하지 않는다.

문장이 필요하면 어순·문법 표지·굴절·파생 규칙을 정하고 짧은 실제 예문으로 시험한다. 유형론적 경향은 선택의 참고이며 필수 법칙으로 취급하지 않는다. 어근과 파생 규칙에서 새 단어를 만들고 뜻·발음·품사·출처를 기록한다. 번역에는 형태소 분해·뜻풀이를 붙여 같은 표현이 같은 규칙을 따르는지 확인한다.

문자는 소리와 기록 재료·필기 방식에 맞춘다. 이미지로 그린 글리프 시안, 문자 대응표, 실제 폰트·입력 가능성을 구분한다. 언어 계통을 요청하면 조어에서 순서 있는 음운 변화를 적용해 딸언어 형태를 도출한다.

## 결과와 연결

요청한 이름 목록·어휘표·문법 참조·문자 시안을 만든다. 반복 어근, 금지 음절, 표기·의미 충돌을 확인하고 신조어와 기존 승인 이름을 구분한다. CCL 기록·승인은 [ccl8-narrative](../ccl8-narrative/SKILL.md)를 따른다.

관련 스킬: 화자 문화는 [worldbuilding-studio](../worldbuilding-studio/SKILL.md), 의례 문구는 [religion-creator](../religion-creator/SKILL.md), 지도 표기는 [map-maker](../map-maker/SKILL.md), 문자 시각 체계는 [graphic-designer](../graphic-designer/SKILL.md)다.

## 출처와 적용

[Jenova Conlang Creator](https://www.jenova.ai/a/conlang-creator)의 공개 설명을 2026-11-04에 확인해 이 저장소의 작업 지침으로 재구성했다. 내부 프롬프트나 서비스 기능의 복제가 아니다. Jenova 계정·API·자동 기억 기능을 제공하지 않으며, 현재 세션의 도구와 파일을 사용한다. 사용자의 범위·출력 요구와 프로젝트 승인 절차를 우선한다.
