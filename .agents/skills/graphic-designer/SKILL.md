# Graphic Designer

작업 시작 전 스킬 선택·확인과 관련 스킬 안내는 [스킬 사용 안내](../../../Docs/AgentContextTools/SkillUsage.md)를 따른다. 아래 관련 스킬은 후보이며 승인 없이 작업 범위를 늘리는 지시가 아니다.

## 메시지와 체계

사용처·독자·핵심 메시지·표시 크기를 정하고 기존 로고·색·서체·참조를 읽는다. 로고, 문장, 홍보물, 정보 그래픽 중 요청한 결과를 만든다. 브랜드나 세력의 상징이 미정이면 시각 후보와 설정 확정을 구분한다.

새 정체성 탐색은 상징·문자·배치의 서로 다른 접근을 비교한다. 이미 선택한 방향이 있으면 재선정하지 않는다. 색·서체·여백·기호 두께·로고 사용 규칙을 이후 작업에도 적용할 수 있게 남긴다.

작은 아이콘과 큰 포스터, 밝은 배경과 어두운 배경, 단색과 컬러에서 필요한 가독성을 각각 확인한다. 특정 플랫폼의 납품 규격을 요구받으면 현재 공식 규격을 확인한다. 인쇄 크기·여백·해상도는 실제 산출물과 대조한다.

래스터 그림은 이미지 도구로, 정확한 문자·치수·편집 가능한 배치는 벡터·문서 도구로 제작한다. 긴 문구·수치·표를 생성 이미지의 글자에만 의존하지 않는다. 부분 수정은 기존 시안을 참조하고 변경하지 않은 요소도 대조한다.

## 결과와 연결

결과물을 열어 철자·잘림·정보 순서·대비·목표 크기를 확인하고, 출력 파일의 형식·크기와 남은 제약을 적는다. 화면용 이미지와 인쇄 납품 파일, 시안과 실제 폰트·아이콘 에셋을 구분한다.

관련 스킬: 게임 환경·사물은 [concept-art-creator](../concept-art-creator/SKILL.md), 사용성은 [ui-ux-reviewer](../ui-ux-reviewer/SKILL.md), 문자 규칙은 [conlang-creator](../conlang-creator/SKILL.md), 세력 상징의 의미는 [worldbuilding-studio](../worldbuilding-studio/SKILL.md)다.

## 출처와 적용

[Jenova Graphic Designer](https://www.jenova.ai/a/graphic-designer)의 공개 설명을 2026-11-04에 확인해 이 저장소의 작업 지침으로 재구성했다. 내부 프롬프트나 서비스 기능의 복제가 아니다. Jenova 계정·API·자동 기억 기능을 제공하지 않으며, 현재 세션의 도구와 파일을 사용한다. 사용자의 범위·출력 요구와 프로젝트 승인 절차를 우선한다.
