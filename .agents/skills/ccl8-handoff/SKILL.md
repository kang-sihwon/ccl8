# ccl8 인계

인계의 정본은 작업 지도(`../../../Docs/Work/`)다. 대화 내용은 다음 세션에 남지 않으므로 이어받는 데 필요한 것은 모두 지도와 Git에 둔다.

## 멈추기

1. `git status --short --branch`로 상태를 본다. 끝난 단위는 `Docs/VersionControl.md`의 커밋 주체 규칙대로 커밋한다. 커밋하지 않을 변경이 남으면 파일과 이유를 적는다.
2. 진행 중인 조각 아래에 `- 중단 지점(날짜):` 줄을 붙이고 다음을 쓴다.
   - 끝낸 것과 남은 것.
   - 다음에 실행할 명령 한 줄.
   - 마지막으로 돌린 검증 명령과 그 결과. 돌리지 않았으면 "미실행".
   - 실행 중이던 프로세스(에디터, 스모크)와 그 정리 여부.
3. 이 세션에서 새로 생긴 질문은 "아직 모르는 것"에, 정한 것은 "정한 것"에 적는다.
4. 지도를 커밋하고 사용자에게 재개할 지도 경로와 다음 명령을 알린다.

## 이어받기

1. `Docs/Work/README.md`에서 지도를 열고 중단 지점을 읽는다.
2. 중단 지점의 주장을 믿기 전에 확인한다. 브랜치와 커밋은 `git log`, 파일은 실제 존재, 검증 결과는 명령을 다시 실행해 본다. 다르면 지도가 아니라 실제 상태를 기준으로 삼고 지도를 고친다.
3. 다시 확인한 상태를 사용자에게 한 문단으로 알린 뒤 다음 명령부터 이어 간다.
