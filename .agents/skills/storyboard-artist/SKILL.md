# Storyboard Artist

작업 시작 전 스킬 선택·확인과 관련 스킬 안내는 [스킬 사용 안내](../../../Docs/AgentContextTools/SkillUsage.md)를 따른다. 아래 관련 스킬은 후보이며 승인 없이 작업 범위를 늘리는 지시가 아니다.

## 숏에서 보드로

대본·장면 목적·장소·인물 참조·화면 비율과 사용자가 원하는 깊이를 읽는다. 플레이 가능한 구간과 카메라를 통제하는 구간을 구분한다. 플레이어에게 보여 줄 단서와 인물이 실제로 아는 정보를 혼동하지 않는다.

먼저 숏별 목적·크기·각도·움직임·행동·대사·예상 길이를 정한다. 중요한 위치 관계와 행동을 이해할 수 있는 커버리지를 확보한다. 사용자가 보드까지 요청했으면 숏 목록을 기준으로 이미지 도구를 사용해 진행하며, 별도 선택을 요구받지 않은 중간 단계에서 불필요하게 멈추지 않는다.

인물의 외형·소품·장소 기준을 유지하고 시선, 화면 이동 방향, 180도 축, 앞뒤 행동 연결을 검토한다. 축을 넘는 연출은 전환을 이해할 단서를 둔다. 애니메이션용이면 주요 포즈·예비 동작·타이밍도 표시한다.

보스 등장·전투 전환에서는 위협을 읽는 시간, 플레이어 조작권의 회수·반환, 실제 전투 시작 위치를 명시한다. 게임 내 카메라나 애니메이션 동작이 구현됐다고 보고하지 않는다.

## 결과와 확인

숏 목록만 요청하면 목록을, 보드 요청이면 실제 보드와 숏 식별자·행동·카메라·음향 단서를 낸다. 생성된 컷을 열어 순서·외형·위치·화면 방향을 대조하고 추정 타이밍과 실제 재생 시간을 구분한다.

관련 스킬: 장면·대사는 [creative-fiction-writer](../creative-fiction-writer/SKILL.md), 시각 기준은 [concept-art-creator](../concept-art-creator/SKILL.md), 전투로의 연결은 [game-designer-assistant](../game-designer-assistant/SKILL.md)다.

## 출처와 적용

[Jenova Storyboard Artist](https://www.jenova.ai/a/storyboard-artist)의 공개 설명을 2026-11-04에 확인해 이 저장소의 작업 지침으로 재구성했다. 내부 프롬프트나 서비스 기능의 복제가 아니다. Jenova 계정·API·자동 기억 기능을 제공하지 않으며, 현재 세션의 도구와 파일을 사용한다. 사용자의 범위·출력 요구와 프로젝트 승인 절차를 우선한다.
