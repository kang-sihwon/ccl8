# 지도 종류별 검사

[Map Maker](../SKILL.md)로 지도를 설계하거나 결과를 대조할 때 해당 지도 종류의 항목만 적용한다. 아래는 작업 검토 기준이며 지리·공학 시뮬레이션 결과가 아니다.

## 세계와 지역

- 산맥·고도·유역과 물의 흐름을 함께 본다. 물길의 합류·출구·해안 연결을 확인하고, 분류·내륙 분기·복수 유출처럼 설명이 필요한 형태는 삼각주·인공 수로·특수 지형 또는 세계의 규칙과 대조한다. 일반적인 형태를 모든 지형의 절대 규칙으로 강제하지 않는다.
- 강수·바람·고도·위도 자료가 있을 때 기후와 생물군계의 전환을 검토한다. 색만 보고 강수량과 생태가 검증됐다고 판단하지 않는다. 판타지의 예외에는 작동 조건과 영향을 남긴다.
- 거점은 식수·생산·교역·접근 조건과 연결한다. 길과 교역선이 능선이나 물길을 건너면 고개·다리·환적 등 통과 조건을 확인한다.
- 전 지구 지도는 투영법과 경도 경계, 극지 왜곡을 확인한다. 특히 정거원통도법의 그림 픽셀 면적을 그대로 구면 면적으로 사용하지 않는다. 정확한 면적이 목표면 투영법에 맞는 계산을 사용한다.

## 도시와 마을

식수·주거·생산·저장·하역·외부 진입의 관계를 확인한다. 강 양안의 길에는 실제 연결 수단이 있어야 한다. 생활 구역의 구분과 관할·성벽 경계는 각각의 설정 근거로 판단한다.

큰 지도에서 작은 지도까지 같은 거점 ID·지명·기준점을 사용한다. 상징적으로 키운 건물·나무·도시 기호는 실제 점유 면적과 구분한다. 사람이 이동할 통로와 건물 출입구는 필요 축척에서 따로 확인한다.

## 던전과 전투 지도

입구·출구, 방·문·통로의 연결과 층 사이 이동을 확인한다. 수직 통로에는 같은 식별자를 쓰고 어느 층으로 이어지는지 표시한다. 침수·붕괴·잠금으로 길을 막으면 다른 길과 탈출 가능성이 어떻게 달라지는지 함께 본다.

전투 목적에 맞춰 적의 접근 경로, 시야·엄폐, 고저차, 우회·퇴로와 안전한 위치를 읽을 수 있게 배치한다. 적·무기·이동 규칙이 미정이면 사거리와 통과 폭을 확정하지 않는다. CCL의 무기 선택 범위는 [결정 37](../../../../Docs/decisions/0037-unrestricted-protagonist-weapons.md)을 따른다.

격자는 칸당 거리와 전체 크기·출력 해상도를 맞춘다. 이미지 비율과 지도 축척은 별개다. 지도 그림의 통로가 넓어 보인다는 사실만으로 캐릭터 충돌·사거리·경로 탐색을 통과했다고 주장하지 않는다.

## 수치와 표현의 대조

| 요구 | 확인 근거 |
|---|---|
| 거점 위치와 확대도 일치 | 좌표계·확대 범위·공통 기준점과 변환 관계 |
| 거리와 이동 시간 | 직선거리와 경로 길이 구분, 경로·속도·휴식 가정 |
| 면적과 비율 | 투영법, 영역 경계, 계산 방법과 목표값 |
| 수직 평면 표현 | 수평선·원근 축소·측면 묘사 여부, 윗면 기호와 등고선 |
| 지명과 기호 | 기준 목록의 철자·개수·식별자와 실제 그림 대조 |

검사 결과는 목표별로 확인·불일치·미확인과 근거를 적는다. 생성된 등고선은 고도 자료에서 계산한 등고선과 구분한다. 자료가 없으면 그럴듯한 시안으로 표시하고 수치 일치라고 보고하지 않는다.

## 실재 지형과 역사 지도

대상 장소와 시대에 맞는 지형·경계·지명 자료를 먼저 확인하고 출처와 시점을 남긴다. 역사적 양식은 표현 선택이며 당시 실제 지형의 증거가 아니다. 설명용 그림과 항행·공간 분석용 자료를 구분하고, 후자는 검증 가능한 지리 데이터를 사용한다.
