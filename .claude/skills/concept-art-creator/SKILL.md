# Concept Art Creator

작업 시작 전 스킬 선택·확인과 관련 스킬 안내는 [스킬 사용 안내](../../../Docs/AgentContextTools/SkillUsage.md)를 따른다. 아래 관련 스킬은 후보이며 승인 없이 작업 범위를 늘리는 지시가 아니다.

## 시각 설계

용도, 현재 설정, 아트 기준과 참조 이미지를 읽는다. CCL에서는 [ArtDirection](../../../Docs/ArtDirection.md)과 해당 하위 자료가 기준이다. 이미지 제작만으로 새 역사·세력·생태를 확정하지 않는다.

캐릭터는 실루엣·의복 기능·역할, 괴물은 이동 방식·무게·관절·공격 기관, 환경은 이동 경로·크기 기준·재료·생활 흔적을 연결한다. 세력의 형태·색·재질 규칙이 기존 건물·장비와 이어지는지 확인한다.

탐색을 요청하면 카메라만 바꾼 변형보다 형태·재료·색채 전략이 다른 후보를 제시한다. 기존 방향이 확정됐으면 그 기준을 따라 요청한 부분을 정교화한다. 수정에서는 유지 요소와 변경 요소를 분리하고 원본과 대조한다.

이미지 요청은 현재 사용할 수 있는 이미지 생성·편집 도구와 관련 스킬로 실제 시안을 만든다. 입력문만 요청한 경우에만 프롬프트로 끝낸다. 도구가 없으면 미실행 상태와 실행 가능한 입력을 제공한다. 정확한 정투상·치수·반복 부품은 생성 그림만으로 일치한다고 주장하지 않는다.

## 결과와 확인

이미지를 직접 열어 형태·색·재질·기능과 요청한 변경을 확인한다. 이미지와 함께 크기 기준, 주요 재질, 의도한 기능, 구현 시 확인할 지점을 짧게 적는다. 콘셉트 이미지, 모델링 참조, 게임용 메시·리깅·텍스처 완성 상태를 구분한다.

관련 스킬: 인물 설정은 [character-creator](../character-creator/SKILL.md), 괴물 기원은 [mythology-creator](../mythology-creator/SKILL.md), 공간 배치는 [map-maker](../map-maker/SKILL.md), 연속 장면은 [storyboard-artist](../storyboard-artist/SKILL.md)다. 실제 3D 제작은 세션의 제작 도구·스킬을 별도로 제안한다.

## 출처와 적용

[Jenova Concept Art Creator](https://www.jenova.ai/a/concept-art-creator)의 공개 설명을 2026-11-04에 확인해 이 저장소의 작업 지침으로 재구성했다. 내부 프롬프트나 서비스 기능의 복제가 아니다. Jenova 계정·API·자동 기억 기능을 제공하지 않으며, 현재 세션의 도구와 파일을 사용한다. 사용자의 범위·출력 요구와 프로젝트 승인 절차를 우선한다.
