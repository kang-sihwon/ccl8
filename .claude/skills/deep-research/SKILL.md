# Deep Research

작업 시작 전 스킬 선택·확인과 관련 스킬 안내는 [스킬 사용 안내](../../../Docs/AgentContextTools/SkillUsage.md)를 따른다. 아래 관련 스킬은 후보이며 승인 없이 작업 범위를 늘리는 지시가 아니다.

## 질문에 맞는 조사

사용자가 결정하려는 것, 후보·지역·시대·기간, 필요한 깊이와 결과 형식을 기존 대화에서 정한다. 범위가 이미 명확하면 반복해서 승인받지 않는다. 자료 수·문서 길이를 채우기 위해 조사를 늘리지 않는다.

제공된 자료와 연결된 출처를 먼저 확인한다. 개요로 쟁점을 찾고, 핵심 주장에 필요한 1차 자료를 읽고, 다른 출처·반례와 대조한다. 기술 조사는 공식 문서·실제 소스·논문을 우선한다. 복제 기사 여러 개를 독립 근거로 세지 않는다.

출처별 날짜·원문 위치·적용 범위와 주장을 기록한다. 사실, 출처의 주장, 조사자의 해석·제안, 미확인을 분리한다. 상충 자료는 버전·지역·방법·가정 차이로 설명하고 풀리지 않은 차이는 남긴다. 현재 가격·규격·지원 여부처럼 변하는 정보는 현재 자료로 확인한다.

현실 자료를 판타지에 적용할 때 실제 조건과 창작 변형의 경계를 적는다. 현실의 단일 사례가 유일한 설계법이라고 결론내리지 않는다. 자료에 접근하지 못하면 읽은 척하지 않고 확인 범위와 대체 근거를 제시한다.

## 결과와 연결

질문에 대한 답부터 쓰고 비교 기준·근거·트레이드오프·남은 불확실성을 잇는다. 인용 링크는 해당 주장의 가까이에 붙인다. 문서 요청이면 결과를 저장하고 문서 지도에 연결한다. 실행 검증·실험과 문헌 조사를 구분한다.

관련 스킬: 세계관 적용은 [worldbuilding-studio](../worldbuilding-studio/SKILL.md), 규칙 설계는 [game-designer-assistant](../game-designer-assistant/SKILL.md), 신화 비교는 [mythology-creator](../mythology-creator/SKILL.md), 일반 문서 저장은 [ccl8-docs](../ccl8-docs/SKILL.md), 서사 조사 기록은 [ccl8-narrative](../ccl8-narrative/SKILL.md)다.
