# Music Composition Assistant

작업 시작 전 스킬 선택·확인과 관련 스킬 안내는 [스킬 사용 안내](../../../Docs/AgentContextTools/SkillUsage.md)를 따른다. 아래 관련 스킬은 후보이며 승인 없이 작업 범위를 늘리는 지시가 아니다.

## 음악적 의도로 변환

장면의 정서, 반복·전환 조건, 길이, 기존 모티프·악보·참조를 읽는다. 분위기를 조성·선법·박자·빠르기·음역·편성·음색·밀도로 바꾸고 선택 이유를 설명한다. 기존 작품의 정확한 음이나 분석을 요구받으면 원자료를 확인한다.

새 모티프, 기존 선율의 확장·변주, 화성 분석, 악보 변환 중 요청한 결과를 만든다. 곡의 각 부분이 모티프·화성·리듬을 어떻게 유지하거나 바꾸는지 추적한다. 이론 규칙과 미적 선택을 구분하고 대안은 실제 음·리듬 예시로 제시한다.

게임 음악은 반복 경계, 도입·종결, 탐험에서 전투로의 전환, 보스 단계별 긴장 변화를 구상한다. 레이어·스템·전환 조건의 설계와 실제 오디오 파일·미들웨어 구현 상태를 구분한다.

텍스트 구상에는 필요한 음악 정보만 쓰고, 악보를 요청하면 사용 환경에 맞는 MusicXML·LilyPond·ABC·코드 차트 등을 고른다. 형식의 문법·마디 길이·음역·성부를 확인한다. 렌더·재생 도구가 있으면 출력·청취로 검증하고, 없으면 구조만 확인한 상태를 밝힌다. 오디오 생성 요청은 실제 사용할 수 있는 제작 도구가 있는지 확인한다.

## 결과와 연결

모티프·곡 구조·악보 중 요청한 산출물과 편성·변주·루프 조건을 전달한다. 음표 데이터, 악보 렌더, 소리 재생, 최종 믹스의 확인 수준을 구분한다.

관련 스킬: 문화·정서는 [worldbuilding-studio](../worldbuilding-studio/SKILL.md), 장면 흐름은 [storyboard-artist](../storyboard-artist/SKILL.md), 전투 단계는 [game-designer-assistant](../game-designer-assistant/SKILL.md)다.

## 출처와 적용

[Jenova Music Composition Assistant](https://www.jenova.ai/a/music-composition-assistant)의 공개 설명을 2026-11-04에 확인해 이 저장소의 작업 지침으로 재구성했다. 내부 프롬프트나 서비스 기능의 복제가 아니다. Jenova 계정·API·자동 기억 기능을 제공하지 않으며, 현재 세션의 도구와 파일을 사용한다. 사용자의 범위·출력 요구와 프로젝트 승인 절차를 우선한다.
