# Religion Creator

작업 시작 전 스킬 선택·확인과 관련 스킬 안내는 [스킬 사용 안내](../../../Docs/AgentContextTools/SkillUsage.md)를 따른다. 아래 관련 스킬은 후보이며 승인 없이 작업 범위를 늘리는 지시가 아니다.

## 교리와 생활

CCL에서는 가상 종교 창작을 기본 범위로 삼는다. 기존 신화와 사회의 문제를 읽고 신앙이 지목하는 문제, 제공하는 답, 그 답에 도달하는 실천을 정한다. 세계의 실제 법칙과 신도의 믿음을 구분한다.

요청에 필요한 창세·구원·윤리·사후관·의례·교단·승계 영역을 연결한다. 믿음으로 구원받는 교리가 공적을 사는 의례와 충돌한다면 오류인지, 분파의 논쟁인지, 제도의 위선인지 설명한다. 모든 종교를 동일한 조직 틀로 만들지 않는다.

평범한 신도가 하루에 하는 일, 죽음·질병·탄생을 다루는 의례, 금기를 어겼을 때의 반응을 작성한다. 교단의 식량·재산·교육·치유·무력 같은 유지 기반과 권력의 견제를 연결한다. 창시자 사후의 권한 승계, 해석 차이, 주변 문화와의 긴장도 필요한 범위에서 다룬다.

경전·기도·장례문·서약을 요청하면 작품 안에서 사용할 실제 문구를 쓴다. 문서의 화자·작성 시기·전승 경로에 맞춰 목소리를 정하고 작품 밖의 해설은 분리한다. 실제 종교를 비교 자료로 쓸 때 출처와 창작 변형을 밝힌다. 실존 단체 설립이나 법적 등록 절차로 요청을 확대하지 않는다.

## 결과와 연결

교리·실천·권력·분파가 서로 맞는지 검토하고 의도한 긴장과 설정 오류를 구분한다. CCL의 기록·승인은 [ccl8-narrative](../ccl8-narrative/SKILL.md)를 따른다.

관련 스킬: 신화는 [mythology-creator](../mythology-creator/SKILL.md), 도시·세력은 [worldbuilding-studio](../worldbuilding-studio/SKILL.md), 성직자·신도는 [character-creator](../character-creator/SKILL.md), 의례 장면은 [creative-fiction-writer](../creative-fiction-writer/SKILL.md)다.

## 출처와 적용

[Jenova Religion Creator](https://www.jenova.ai/a/religion-creator)의 공개 설명을 2026-11-04에 확인해 이 저장소의 작업 지침으로 재구성했다. 내부 프롬프트나 서비스 기능의 복제가 아니다. Jenova 계정·API·자동 기억 기능을 제공하지 않으며, 현재 세션의 도구와 파일을 사용한다. 사용자의 범위·출력 요구와 프로젝트 승인 절차를 우선한다.
