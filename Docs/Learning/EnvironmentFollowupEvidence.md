# 자연환경 후속 학습의 비교 근거

[시간 분할 정밀도](EnvironmentTimeAccuracy.md), [세계 저장 참여자](EnvironmentRestoreParticipants.md), [환경 맵 설정](EnvironmentMapConfiguration.md)의 Git 기준과 확인 범위를 기록한다. 기존 단계 0-7의 미커밋 소스 조사 기록은 [원래 비교 근거](EnvironmentEvidence.md)에 보존한다.

## 브랜치와 고정 기준

2026-10-11 조사 시작 때 로컬 브랜치는 `main` 하나이며 작업 트리는 깨끗했다. HEAD와 로컬 원격 추적 `origin/main`은 모두 `d7782f1`이었다. 원격 서버를 fetch한 결과는 아니다. 브랜치를 전환하지 않고 `git show`와 `git diff --ignore-all-space`로 의미가 바뀐 부분을 비교했다. 들여쓰기만 바뀐 코드를 새 설계의 증거로 세지 않았다.

| 기준 | 전체 SHA | 역할 |
|---|---|---|
| `a817082` | `a817082fc8dfbbc63f2bed292a70f39cd22f8cc5` | 시간 종료 조건의 수정 전 |
| `c8816e7` | `c8816e7000a356753b3be910a1a4e8f2572aa4a8` | 환경·생태·저장 소스의 커밋 기준, 시계 수정 포함 |
| `b888b13` | `b888b132671b82511cc866e928f8cfb09458ecac` | 세계 형식 7·참여자·맵 설정 변경 |
| `d7782f1` | `d7782f19516befa70a9e8df23ce90e76da52386b` | 작성 시작 HEAD, 후속 검증 문서 |

2026-10-11 시점에는 기존 문서의 `WT-2026-10-10`을 위 커밋 이름으로 일괄 치환하지 않았다. 2026-10-31에는 해당 소스가 `c8816e7`에 커밋된 것을 확인하고, 각 발췌를 `d4888b0`와 대조한 뒤 출처를 바꿨다. 조사 사본 이후 수정된 함수가 있고, 당시 줄 번호와 해시는 당시 바이트를 식별하기 때문이다. 새 장의 발췌는 모두 Git에 저장된 코드에서 가져왔다. 파일 링크는 현재 체크아웃을 열며, 줄 번호와 코드 블록의 정본은 표시한 커밋이다.

시계 변경 이유는 [환경 계획의 정밀도 기록](../EnvironmentPlan/Integration/Clock.md#시간-분할-정밀도-구현검증), 저장·맵 설정의 변경 사실은 `b888b13` 커밋 본문과 같은 문서의 시작점 절을 사용했다. 원격 플레이어 유지 정책은 [결정 21](../decisions/0021-server-issued-player-identity.md)과 [세션 사양](../SessionFoundation.md)이 소유한다. 이번 작업은 새 게임 결정을 추가하지 않는다.

## 코드 확인과 실행 결과의 구분

아래는 기존 로컬 보고서를 이번 문서 작성 중 읽은 결과다. 두 JSON에서 `succeededWithWarnings`, `failed`, `notRun`, `inProcess`가 모두 0임을 확인했다. 새 자동화 실행 결과는 아니다.

| 기존 실행의 목적 | succeeded | 보고서 |
|---|---|---|
| 시간 분할 수정과 당시 회귀 | 144 | `Saved/Tests/Automation/20261010-232809-465/report/index.json` |
| 전체 검토 수정 뒤 최종 자동화 | 154 | `Saved/Tests/Automation/20261011-132651-391/report/index.json` |

[2026-10-11 재검증 기록](../QA/FullReviewReverification-2026-10-11.md)은 다중 플레이어 복원, 환경 Scenario Dedicated와 Playground Standalone을 포함한 기존 실행을 설명한다. 스모크 실행 뒤 형식 정리·GameplayCue 경로 설정이 추가됐고, 최종 코드에서는 생성·빌드·자동 검사를 다시 수행했다는 기록이다. 이 문서 작성에서 각 스모크를 다시 실행한 것은 아니다.

같은 기록에는 이동 Dedicated가 한 번 실패한 뒤 같은 코드의 재실행에서 통과한 사실과 원인 미확인이 남아 있다. 또한 최신 변경을 포함한 Windows 패키지는 다시 만들지 않았다. [세계 모듈 분리 후 패키지](../Packaging/Records.md#세계-모듈-분리-후-패키지)가 소유한 미확인 환경의 한계를 유지한다. 자동 검사 성공을 모든 네트워크 조건·렌더링·패키지의 성공으로 확대하지 않는다.

## 지식 노트와 문서 확인

기존 볼트의 `UE5/Gameplay/World-Time-Commit-Boundaries.md`와 `Session-Checkpoint-Validation.md`에서 끝점 보존과 여러 소유자의 알림 전 확정 원리를 참고했다. 이번에는 프로젝트별 후속 코드 비교를 저장소에 기록했다. 볼트에는 다른 작업의 변경이 있어 합치거나 커밋하지 않았다.

새 장은 실제 코드의 연속 발췌, 전후 차이, 실패·수명, 선택 비용과 이해 확인 해설을 포함한다. 문서 검사에서는 고정 커밋의 발췌 원문, 상대 링크와 제목 앵커, Guide·학습 목록 등록, 코드 블록의 닫힘과 공백 오류를 확인한다. 게임 코드·에셋·설정은 수정하지 않는다.

이번 확인에서 Guide와 학습 문서 40개의 상대 링크 497개, 새 코드 발췌 11개를 대조했다. 누락 링크·제목 앵커·발췌 불일치는 0건이었다. 후속 파일 이동으로 끊긴 GAS 전투 소스 링크는 현재 경로로 고치고 당시 커밋과 줄 번호를 유지했다. `git diff --check`도 통과했다.
