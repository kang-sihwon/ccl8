# QA 보고서

이 폴더의 문서는 실행 검증을 한 시점의 기록이다. 보고서가 적은 결함, 판정, 미확인 범위는 그 날짜와 커밋에서만 참이다. 현재 구현과 검증 상태는 [문서 지도](../README.md)의 사양 문서가, 검증을 실행하는 절차는 `ccl8-verify` 스킬이 소유한다. 근거는 [결정 28](../decisions/0028-agent-workflow-restructure.md)이다.

## 규칙

- 작성한 보고서의 내용은 고치지 않는다. 정정이나 재검증은 새 보고서로 쓰고, 앞 보고서에서 새 보고서를 가리키는 한 줄만 덧붙인다.
- 보고서의 코드 위치(`path:line`)와 커밋은 작성 당시 기준이다. 이후 코드가 바뀌었을 수 있으므로 현재 코드는 `graft`로 다시 확인한다.
- 새 보고서는 `<주제>-YYYY-MM-DD.md`로 이 폴더에 두고 문서 지도의 "QA 보고서" 표에 한 줄 등록한다.
- 보고서를 옮길 때는 본문을 그대로 두고 상대 링크의 대상만 새 위치에 맞춘다. 2026-10-26에 아래 2026-10-12 보고서 세 개를 `Docs/`에서 옮길 때도 링크 대상만 바꿨다.
- 실행 검증 기록은 QA 보고서로 남기고, 코드나 설계를 검토한 결과는 소유 사양서로 옮긴다. 2026-10-26 사용자가 날짜 붙은 문서 여섯 개 중 세 개를 QA 보고서로, `AgentReview-2026-10-08`, `UIReview-2026-10-08`, `CodeDesignFixes-2026-10-11`을 검토 보고서로 분류했다. 검토 보고서 세 개는 결과를 사양서로 옮긴 뒤 2026-10-27에 지웠다.
