# NG04 채택 설정과 문서 통합

**목표는 사용자가 채택한 내용이 결정·정본·문서 지도에서 일치하고, 남은 후보와 보류를 바로 찾을 수 있게 하는 것이다.** 첫 장·대륙 배경·전체 여정의 결과가 채택될 때마다 해당 범위로 수행한다. 현재 상태는 [CurrentWork](../CurrentWork.md), 공통 운영은 [작업군 지도](../WorkGroups.md)를 따른다.

## 시작 조건과 입력

사용자가 선택한 항목·공통 경계·대안 범위가 명확해야 정본에 반영한다. 최신 [결정 목록](../../Decisions.md), [World](../World.md)·[Scenario](../Scenario.md), 해당 작업군 선택표·독립 검토를 입력으로 삼는다. NC01-NC04와 공통 경계는 사용자 승인으로 이번 반영 대상이며 NC01이 가리키는 VR01-VR10의 흐름·경계도 포함한다.

## 첫 장 통합 묶음

승인된 NC01-NC04와 공통 경계의 정본 반영을 완료했다. [결정 58](../../decisions/0058-veles-chapter-continuity-adoption.md)·[Scenario](../Scenario.md#벨레스-첫-장의-통합-흐름과-미완료-연결)에 반영했으며 [독립 검토 PASS](../Reviews/2026-11-15-veles-chapter-adoption-review.md), 남은 지적 없음이다. 이번 묶음은 `CLOSED`이며 NG02·NG03의 미래 결과까지 통합했다는 뜻은 아니다.

| 구분 | 범위·확인 위치 |
|---|---|
| 승인 범위 | [NC 선택표](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent/2026-11-15-veles-chapter-options.md)의 NC01-NC04와 공통 경계. NC01은 기존 VR01-VR10의 흐름·강조와 장면별·공통 경계를 포함한다. |
| 미채택 대안 | 같은 선택표의 NA01-NA02와 [VR 선택표](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent/2026-11-15-veles-familiar-route-options.md)의 RA01-RA02를 보존한다. |
| 세부 보류 | NH01-NH05·RH01-RH06, BA·BH와 앞선 대안·보류를 유지한다. 정확한 표현·진행·운영·재시도·제작은 이번 채택에 포함하지 않는다. |
| 원문 보존 | NC 선택표·사례 비교, VR 선택표·장면 원문의 네 편은 상단 채택 안내만 더한다. 전체 원문·C 상태표·통합표·지도·수치를 정본으로 승격하지 않는다. |
| 삭제 후보와 실제 삭제 | 삭제 후보 없음. 네 원문은 승인 범위 대조·미채택 대안·재개할 보류의 근거로 계속 참조한다. 실제 삭제·이동도 없다. |
| 검토·증거 | [정본 반영 독립 검토](../Reviews/2026-11-15-veles-chapter-adoption-review.md)에 승인 범위·14행 대조·네 원문 보존·검사 결과를 남긴다. |
| 후속 범위 | NG02 배경 작성·검토는 완료했으며 아래 IB 묶음은 미채택이다. NG03과 미래 채택 묶음의 NG04 통합은 별도로 진행한다. 실제 플레이·UE는 미검증이다. |

아직 승인되지 않은 부분은 링크·현재 상태를 대조하고 반영 대상 목록까지 준비할 수 있다. 승인 자체를 추정하거나 다음 결정 번호를 미리 예약하지 않는다.

## 이그니스 배경의 반영 대기 범위

[NG02 선택표](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-15-ignis-background/options.md)의 IB01-IB06과 공통 경계는 독립 검토 PASS이며 아직 미채택이다. 사용자 선택 뒤 실제 승인 항목을 결정·정본과 대조한다. 배경 관계는 World, 벨레스 공급·여정 인수와 사건 시점의 구체화는 Scenario를 반영 후보로 검토한다. 이 구분이 새 설정의 채택을 뜻하지 않는다.

IA01-IA02·IH01-IH05, 정착망 좌표·정치 제도·전체 종 명부·성장 수치·기존 원문을 보존한다. 기존 지리·첫날 상황·인계 세 원문에 추가한 안내와 IC01-IC08을 읽고, 새 수계·장거리 거래 설명을 원문 전체의 승인으로 확대하지 않는다. 삭제 후보와 실제 삭제는 없다.

## 묶어서 수행할 범위

1. 실제 승인 발언과 선택표의 범위를 대조한다. 채택한 중심, 유지할 대안·보류, 전체 원문에 적용되지 않는 경계를 적는다.
2. [결정 기록 절차](../../WritingGuide/DecisionRecords.md)에 따라 새 결정과 관계를 기록하고 승인된 내용만 정본에 반영한다. 과거 결정은 새 결정으로 보완하며 기록을 지우지 않는다.
3. 원문에는 채택 안내를 더하고 본문·대안·보류를 보존한다. 최신 읽기 시작점·참조·작업 상태를 맞추고 오래된 다음 행동이 현재 지시로 읽히지 않게 한다.
4. 독립 검토로 승인표·결정·정본의 일치, 이전안 보존, 링크·번호·문자 상태를 확인한다. 문서·결정 검사를 수행하고 이번 묶음만 커밋한다.
5. 불필요해진 자료가 있으면 삭제 후보·사용 중인 참조·보존 근거를 목록으로 준비한다. 실제 삭제는 사용자가 구체 범위를 승인할 때 진행한다.

## 완료 기준과 결과물

| 결과물 | 완료 기준 |
|---|---|
| 결정과 정본 | 실제 승인 범위와 반영 내용이 일치하고 결정 번호·관계·근거 링크가 맞는다. |
| 문서 탐색 경로 | 현재 확정은 정본에서, 상세 후보는 해당 원문에서, 미채택 선택은 선택표에서 찾을 수 있다. |
| 보존·정리 목록 | 대안·보류·과거 원문이 유지된다. 삭제 후보 정리와 실제 삭제 여부를 구분한다. |
| 검토·인계 | 독립 검토 결과와 검사 결과, 완료 범위·미승인·미검증이 CurrentWork에 남는다. Git 상태와 제출 범위를 확인한다. |

승인된 묶음의 반영이 끝났다는 사실이 모든 서사 작업·게임 제작 완료를 뜻하지 않는다. 승인 없는 잔여 범위는 후보로 남긴다. 문서가 많다는 이유로 원문을 삭제하거나 전체 상세를 정본화하지 않는다.

## 스킬과 다른 작업군

ccl8-narrative·docs·writing으로 기록·검토한다. 원문 의미를 바꿀 필요가 생기면 해당 작업군으로 돌려 수정 후보를 만들고, 그 작업군의 승인된 전문 스킬 조합을 적용한다. 의미 수정이 없는 정본 반영에 새 창작 범위를 추가하지 않는다.

NG01-NG03의 결과를 한꺼번에 기다리지 않고 사용자가 고른 범위부터 완료할 수 있다. 세 작업군의 결과가 모두 선택된 뒤에는 전체 읽기 경로와 잔여 보류 목록을 다시 맞춘다. 후속 세션은 통합한 정본에서 출발한다.
