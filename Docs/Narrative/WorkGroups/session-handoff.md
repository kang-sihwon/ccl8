## 시작 순서

1. Git 상태와 [진행 중인 작업](../../Work/README.md)을 확인한다. 앞선 세션 이후 다른 변경이 있을 수 있으므로 이 문서의 커밋만 보고 작업 트리 상태를 단정하지 않는다.
2. [서사 작업 절차](../Workflow.md)가 지정한 시작 문서와 CurrentWork의 최신 항목을 읽는다. 오래된 항목에 남은 다음 행동보다 최신 상태·결정·Git을 우선한다.
3. [Scenario](../Scenario.md)와 필요한 [World](../World.md)의 확정 범위를 확인한다. 이어 선택한 작업군의 입력 문서만 읽고, 전체 후보군을 처음부터 다시 조사하지 않는다.
4. CurrentWork에 담당과 작업군을 적고 목표의 완료 기준까지 진행한다. 다른 세션이 같은 파일을 맡고 있으면 담당 범위를 먼저 구분한다.

## 되돌리지 않을 기준

주인공은 실제 관찰하거나 전달받은 것만 안다. 야외 동물·고블린·늑대 조우를 모두 거쳐야 수원 사건을 이해하는 구조로 바꾸지 않는다. 모든 무기를 선택할 수 있으며 일반 동물은 생태로 남는다. 전투와 조사는 장소의 현재 상태에서 발생하고, 이야기 단계마다 적이 자동 생성되는 흐름을 전제하지 않는다.

바르툴은 직접 싸워 외부 결박을 끊고 서로 물러난 뒤 살아남는다. 전투 승리, 실제 정비·송수, 하류 사용 점검은 별개다. 인수의 이해·동의, 현재 재고·보충, 다음 아침의 실제 점검을 설명 축약으로 생략하지 않는다. 린은 벨레스 부두에 남고 첫 장은 배에서 세계수 상층 수관을 보는 데서 닫는다. 세부 기준은 정본을 따른다.

[지도 도안 보관·사용](../../ArtDirection/EtherWorldMap/IgnisSharedTerrain.md#제작-도안-보관과-사용)에 따라 기존 그림·좌표는 참고로 보존한다. 이미지 추가 제작은 종료된 상태이며 실제 월드 제작도 별도 요청 대상이다. 이번 작업군은 플롯·세계관 문서 범위다. 채택 전 후보 정리와 기존 원문 삭제를 같은 일로 취급하지 않는다.

## 다음 세션에 전달할 요청문

VD01-VD06·공통 경계의 채택 요청은 아래 인용대로 접수해 결정 62·정본에 반영했다. 이어지는 NG07 문구도 사용자 요청으로 접수해 통합 집필을 진행했다. PR·VD의 채택과 별개로 이 문서만 읽고 후속 작업을 자동 실행하지 않는다.

> 추천한 VD01-VD06과 공통 경계를 모두 채택할게. NG04에서 해당 범위를 정본에 반영하고 검토·커밋·푸시까지 진행해줘. 기존 원문·대안·보류·도안·좌표·수치는 유지하고 실제 UE 구현·실행은 제외해줘.

> 세션 인계와 후속 작업군 지도, NG05 확정과 NG06 검증 설계를 읽고 NG07 첫 장 통합 집필과 정보 전달을 하나의 목표로 완료 기준까지 진행해줘. 확정된 PR·VD와 남은 상세 후보·실제 미검증을 구분하고 정상 원고와 C03-C06의 필요한 대체 장면·VI01-VI08 정보 대조를 작성·검토해줘. 기존 원문·대안·보류·도안·좌표·수치를 유지하고 실제 UE 구현·실행은 제외해줘.

NG02의 IB01-IB06·공통 경계는 채택됐지만 검토 묶음 전체·좌표·제도·종과 성장 수치를 일괄 채택한 것은 아니다. NG03의 JC01-JC06·공통 경계는 채택·반영을 마쳤지만 이동·전투·생태·성장 원문 전체는 승격하지 않았다. JA01-JA02·JH01-JH05·JI01-JI08과 기존 보류를 다음 범위의 입력으로 보존한다. 정확한 표현·물량·항행·성장·실패 상태·구현은 새 요청에서 정하며 자동으로 다음 목표를 시작하지 않는다. 이 문서는 후속 작업을 자동 실행하거나 다른 세션을 생성하지 않는다.

VD 채택의 소유는 [결정 62](../../decisions/0062-veles-validation-design-adoption.md)·[Scenario](../Scenario.md#벨레스-첫-장의-공간운영전투-검증-기준)다. source-audit와 NG06 작성 검토는 채택 전 기준으로 보존하며 Scenario는 이번 승인 범위의 추가로 달라진다. 기존 원천의 도안·좌표·수치와 VDA·VDH는 그대로다. GX·WC는 미실행이며 NG07 집필은 별도 요청 범위로 수행했다. NG08과 UE 작업을 자동 시작하지 않는다.

NG07 [통합 원고](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-15-veles-integrated-manuscript.md)는 MS01-MS10 정상 흐름·C03-C06 대체 장면·C03-R/C06-M 재개 차이·VI01-VI08 대조를 소유한다. IW01-IW06·공통 경계는 사용자 승인으로 결정 63·Scenario에 반영했다. 이 채택 범위는 `CLOSED`다. [반영 독립 검토](../Reviews/2026-11-16-veles-manuscript-adoption-review.md)는 지도 표현 한 곳 보완 뒤 PASS이며 잔여 지적은 없다. IWA·IWH와 기존 원문·대안·보류·도안·좌표·수치를 보존한다. 실제 인지·길·전투·재고·UE는 검증하지 않았다.

아래 IW 채택 요청은 사용자 승인으로 접수해 결정 63·정본에 반영했다. 이어지는 NG08은 사용자가 다음 목표를 선택할 때 쓸 요청 예시다.

> 추천한 IW01-IW06과 공통 경계를 모두 채택할게. NG04에서 해당 범위를 정본에 반영하고 검토·커밋·푸시까지 진행해줘. 기존 원문·대안·보류·도안·좌표·수치는 유지하고 실제 UE 구현·실행은 제외해줘.

> 세션 인계와 후속 작업군 지도를 읽고 NG08 후속 지역의 운영·인계 상세를 하나의 목표로 완료 기준까지 진행해줘. 확정된 NC·IB·JC·PR·VD·IW와 남은 상세 후보·실제 미검증을 구분하고 로덴·세르나·하르덴의 첫 연결을 다뤄줘. 기존 원문·대안·보류·도안·좌표·수치는 유지하고 실제 UE 구현·실행은 제외해줘.

IW 채택의 소유는 [결정 63](../../decisions/0063-veles-manuscript-delivery-adoption.md)·[Scenario](../Scenario.md#벨레스-첫-장의-표현과-작업-기록)다. NG07 source-audit는 채택 전 기준으로 보존하며 Scenario만 이번 승인 절의 추가로 달라진다. 여섯 원문에는 상단 채택 안내만 더하고 정확한 대사·매체 규격·조건부 성공·MS/C/VI 전체와 IWA·IWH를 보존한다. 실제 UE 구현·실행은 별도 요청 대상이며 NG08은 아래 사용자 요청으로 작성·검토했다.

## NG08 완료 인계

NG08 로덴·세르나·하르덴 운영·인계의 작성·독립 검토를 PASS로 완료했다. 잔여 지적은 없다. HO01-HO06·공통 경계는 미채택 후보인 DISCUSSION이며 HOA01-HOA02·HOH01-HOH06을 보존한다. G4·G5 상세와 실제 UE 구현·실행은 미착수다. [운영·인계 묶음](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-16-ignis-operational-handoffs.md)과 [독립 검토](../Reviews/2026-11-16-ignis-operational-handoffs-review.md)를 읽는다. SC04의 북행 조건과 로덴 적용 시험 성공을 구분하며, 수령 회신 지연·일부 물량 부족·현지 시험 미완료의 담당자와 다음 행동을 작성했다. 18개 입력의 보존 기록을 남기고 기존 원문·정본·도안·좌표·수치를 유지했다.

접수한 요청은 다음과 같다.

> 세션 인계와 후속 작업군 지도를 읽고, NG05–NG07에서 확정한 PR01–PR07·VD01–VD06·IW01–IW06과 공통 경계를 기준으로 NG08을 하나의 목표로 완료 기준까지 진행해줘. 기존 원문·대안·보류·도안·좌표·수치는 유지하고 실제 UE 구현·실행은 이번 범위에서 제외해줘.

다음은 [HO01-HO06·공통 경계](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-16-ignis-operational-handoffs/options.md)의 사용자 선택이다. 선택되면 기존 NG04에서 해당 범위만 반영한다. 정확한 수치·제도·표현·재방문·복원·실제 실행과 해외 환승·극지 운영은 보류한다. 작성 PASS를 정본 채택·실제 물류 성공으로 확대하지 않는다.
