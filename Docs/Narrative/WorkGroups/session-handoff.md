# 시나리오와 세계관 세션 인계

**NG01의 작성·검토·사용자 채택과 NG04의 첫 장 승인 묶음 반영을 완료했다. 다음 목표는 NG02를 추천한다.** [Scenario의 NC·VR 흐름](../Scenario.md#벨레스-첫-장의-통합-흐름과-미완료-연결)과 [NG04 반영·보존 목록](04-canon-consolidation.md#첫-장-통합-묶음)부터 읽는다. NA·NH·RA·RH와 원문 전체·실제 제작의 보류는 남는다. 목표·완료 기준은 [작업군 지도](../WorkGroups.md), 현재 담당·상태는 [CurrentWork](../CurrentWork.md)가 소유한다.

## 시작 순서

1. Git 상태와 [진행 중인 작업](../../Work/README.md)을 확인한다. 앞선 세션 이후 다른 변경이 있을 수 있으므로 이 문서의 커밋만 보고 작업 트리 상태를 단정하지 않는다.
2. [서사 작업 절차](../Workflow.md)가 지정한 시작 문서와 CurrentWork의 최신 항목을 읽는다. 오래된 항목에 남은 다음 행동보다 최신 상태·결정·Git을 우선한다.
3. [Scenario](../Scenario.md)와 필요한 [World](../World.md)의 확정 범위를 확인한다. 이어 선택한 작업군의 입력 문서만 읽고, 전체 후보군을 처음부터 다시 조사하지 않는다.
4. CurrentWork에 담당과 작업군을 적고 목표의 완료 기준까지 진행한다. 다른 세션이 같은 파일을 맡고 있으면 담당 범위를 먼저 구분한다.

## 되돌리지 않을 기준

주인공은 실제 관찰하거나 전달받은 것만 안다. 야외 동물·고블린·늑대 조우를 모두 거쳐야 수원 사건을 이해하는 구조로 바꾸지 않는다. 모든 무기를 선택할 수 있으며 일반 동물은 생태로 남는다. 전투와 조사는 장소의 현재 상태에서 발생하고, 이야기 단계마다 적이 자동 생성되는 흐름을 전제하지 않는다.

바르툴은 직접 싸워 외부 결박을 끊고 서로 물러난 뒤 살아남는다. 전투 승리, 실제 정비·송수, 하류 사용 점검은 별개다. 인수의 이해·동의, 현재 재고·보충, 다음 아침의 실제 점검을 설명 축약으로 생략하지 않는다. 린은 벨레스 부두에 남고 첫 장은 배에서 세계수 상층 수관을 보는 데서 닫는다. 세부 기준은 정본을 따른다.

[지도 도안 보관·사용](../../ArtDirection/EtherWorldMap/IgnisSharedTerrain.md#제작-도안-보관과-사용)에 따라 기존 그림·좌표는 참고로 보존한다. 이미지 추가 제작은 종료된 상태이며 실제 월드 제작도 별도 요청 대상이다. 이번 작업군은 플롯·세계관 문서 범위다. 채택 전 후보 정리와 기존 원문 삭제를 같은 일로 취급하지 않는다.

## 다음 세션에 전달할 요청문

> Docs/Narrative/WorkGroups.md와 WorkGroups/session-handoff.md를 읽고 NG02 이그니스 배경 정합을 하나의 목표로 완료 기준까지 진행해줘. NG01의 완료 결과와 변경 영향을 입력으로 쓰고, 확정·미채택·미검증을 구분해줘. 새 정본 반영은 승인받은 범위에 한정하고 이전안과 대안·보류는 보존해줘.

NG03을 원하면 위 요청의 목표를 바꾸고 해당 문서의 완료 기준을 사용한다. NG04는 사용자가 채택한 범위를 명시해 요청한다. 이 문서는 후속 작업을 자동 실행하거나 다른 세션을 생성하지 않는다.
