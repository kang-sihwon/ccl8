# 다음 서사 작업의 선택

NG05-NG07의 작성·채택 결과는 [완료 지도](../WorkGroups.md)에 있다. 현재는 NG08의 HO01-HO06·공통 경계가 미채택이며 [현재 상태](../CurrentWork.md)가 다음 선택을 소유한다.

## NG08 후속 지역의 운영·인계 상세

첫 범위였던 로덴·세르나·하르덴은 [운영·인계 묶음](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-16-ignis-operational-handoffs.md)의 흐름·조건·불완전 사례·권한·선택표로 작성했다. [독립 검토](../Reviews/2026-11-16-ignis-operational-handoffs-review.md)는 PASS, 잔여 지적 0이다. 상세 완료 기준은 당시 계획의 Git 이력에 남기고 현재 결과는 산출물에서 읽는다.

## 후속 범위

| 선택 | 첫 범위와 입력 | 남는 경계 |
|---|---|---|
| 현재 HO 채택 | HO01-HO06·공통 경계 중 사용자가 고른 범위를 NG04 절차로 반영한다. | HOA·HOH는 자동 해제하지 않는다. |
| G4 또는 G5 상세 | 사용자가 다음 연결 하나를 고르면 그 구간의 당사자·물자·회신·현지 권한·불완전 인계를 대조한다. | 해외 항행·극지 운영·전 대륙 수치를 한꺼번에 확정하지 않는다. |
| 벨레스 실제 제작·검증 | 채택된 PR·VD와 필요한 통합 원고를 입력으로 제한된 UE 제작·실행 범위를 정한다. | 문서 PASS는 통행·무기·정보 인지·운영의 실행 증거가 아니다. |

신상·제도·기원·후일담은 [보류 지도](remaining-holds.md)의 재개 조건에 따른다. 아직 요청하지 않은 후속 작업을 시작하거나 다른 세션·예약 작업을 자동 생성하지 않는다.
