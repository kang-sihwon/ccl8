# NG03 5대륙 여정 연결

**목표는 대륙 이동 해금, 동료의 위치와 선택, 설비·보급 인계, 생태·성장이 서로 이어지는 전체 여정 검토 묶음이다.** 이미 작성한 지역별 상세와 통합 검토를 재사용하고 최신 확정·변경 영향만 대조한다. 현재 상태는 [CurrentWork](../CurrentWork.md), 공통 운영은 [작업군 지도](../WorkGroups.md)를 따른다.

## 시작할 자료

- [Scenario](../Scenario.md)의 WP·CL·CP·FC·SC 확정과 G1-G6 조건.
- [5대륙 여정 통합](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-13-world-journey-continuity.md)의 해금·인계·생태·성장·미정 목록.
- [5대륙 메인라인](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-08-five-continent-mainline.md), [이그니스 통합](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-09-ignis-journey-continuity.md), [대표 전투와 선택 비교](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-13-regional-combat-and-choices.md).
- [세계 분포·성장](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-08-world-distribution-and-leveling.md)의 64항목·199형태와 성장 후보. 기존 수치가 있다는 사실과 정본 채택 여부를 구분한다.
- [NG02의 충돌·영향](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-15-ignis-background/options.md#충돌과-누락의-영향). 벨레스의 실재고·미완료 귀환, 하르덴·켈바 물 협의, 외곽 장거리 교환, 공공 통과와 현지 권한을 입력으로 삼는다. IB01-IB06·공통 경계는 [결정 59](../../decisions/0059-ignis-background-relations-adoption.md)·World·Scenario에서 확정했고 IA·IH와 원문 전체는 별도로 보존한다. 좌표·종·성장·해금은 바꾸지 않았다.

## 묶어서 수행할 범위

1. 기존 통합 검토 이후 확정한 전투·인물·갈등·정보 연결과 NG01·NG02의 확정 결과와 나머지 후보·보류를 구분해 대조한다. 이미 통과한 구간은 변경 영향이나 미해결 근거가 있을 때 다시 검토한다.
2. 이그니스에서 아르베나·오르다스·세라디온·니베르와 결말로 이어지는 이동의 선행 성과·계약·물자·동료 위치·현지 인수를 한 흐름으로 확인한다. 선택 왕래와 필수 본편, 준비 이동과 실제 해금을 구분한다. 니베르 귀환 조건, 귀항 후 근거 대조·준비 인수를 통한 G6 결말 접근, 실제 결말 완료도 각각 구분한다.
3. 환경과 몬스터 생활권·파생형·성장 범위가 이동 이유와 맞는지 대조한다. 고레벨 지역으로 가는 이유를 강제 처치나 자동 스케일링으로 대신하지 않는다.
4. 대표 전투의 관찰·공격·중지·철수 판단과 네 인물의 선택·남는 대가가 반복되거나 앞선 성장을 잊는 부분을 검토한다. 지역별 상세 장면·대사를 새로 쓰는 작업으로 넓히지 않는다.
5. 발견한 충돌·누락의 수정안과 미해결 선택을 모아 독립 검토와 묶음 선택표를 만든다. 변경할 필요가 없는 항목도 근거와 함께 유지로 표시한다.

## 완료 기준과 결과물

| 결과물 | 검토 완료 기준 |
|---|---|
| 이동·인계 통합표 | 각 대륙 이동의 선행 조건·주인공이 아는 것·남는 동료·인수할 사람·남은 준비가 구분된다. 계약과 실제 인수, 예정 물량과 재고를 혼동하지 않는다. |
| 전투·인물 연결 대조 | 대표 전투의 판단 차이와 주인공·린·마렌·이르의 선택 발전을 추적하고 반복·퇴행·지식 선취를 기록한다. |
| 생태·성장 대조 | 기존 분포·성장 후보와 플롯의 충돌, 합계·전이 오류 또는 미검증을 구분한다. 실제 난도를 검증했다고 쓰지 않는다. |
| 묶음 선택표·검토 기록 | 유지·추천 수정·대안·보류가 구분되고 독립 검토 지적을 처리하거나 남은 사유를 적는다. 관련 문서 검사에 통과한다. |

전체 대륙의 도시·국가사를 세세하게 늘리거나 모든 지역을 벨레스 수준의 원고로 쓰는 것은 목표가 아니다. 기존 지리·지도·종·수치를 일괄 재설계하지 않는다. 실제 항해·공학·통행·전투 난도·AI·UE 검증은 별도다.

작성·대조·독립 검토를 완료했다. 다음은 JC01-JC06·공통 경계의 사용자 선택이며, 선택된 범위만 NG04에서 정본에 반영한다. JA01-JA02·JH01-JH05·JI01-JI08과 이전 원문·지도·좌표·수치를 보존한다. 삭제 후보와 실제 삭제는 없다.

## 스킬과 다음 인계

[현재 여정 대조 묶음](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-15-world-journey-alignment.md)에 이동·인계 15구간, 전투·네 인물, 생태·성장, JC01-JC06·JA01-JA02·JH01-JH05를 작성했다. [독립 검토](../Reviews/2026-11-15-world-journey-alignment-review.md)는 PASS이며 잔여 지적은 없다. 기존 확정·좌표·종과 성장 수치를 유지하고 새 강조는 사용자 선택 전 후보로 둔다.

관련 조합은 Creative Fiction Writer·Character Creator·Worldbuilding Studio·Game Designer Assistant와 ccl8-narrative·docs·writing이다. 이미 승인한 범위는 이어 쓰고 새 범위만 확인한다. 관련 선택 스킬은 Map Maker·Mythology Creator이며 항로·전승의 실제 변경 영향이 있을 때만 추가 범위를 검토한다.

NG01·NG02의 관련 변경이 아직 후보라면 확정 전후를 섞지 않고 조건부 영향으로 기록한다. 모든 결정을 기다리느라 기존 정본 기준의 대조를 멈출 필요는 없다. 사용자 선택 이후 [NG04](04-canon-consolidation.md)로 승인 범위와 반영 대상을 넘긴다.
