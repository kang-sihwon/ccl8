# NG01 벨레스 첫 장 완성도

**목표는 도입부터 보스·복구·귀환·출항까지, 탐색 선택이 달라도 필요한 정보와 인물의 선택이 이어지는 첫 장 검토 묶음이다.** 새 지역이나 구현을 늘리지 않고 기존 상세 원고를 정리한다. 현재 담당·상태는 [CurrentWork](../CurrentWork.md), 공통 운영 기준은 [작업군 지도](../WorkGroups.md)를 따른다.

## 검토 묶음

NG01의 작성·독립 검토를 완료했다. [독립 검토 PASS](../Reviews/2026-11-15-veles-chapter-review.md)이며 미해결 수정 요구는 없다. 새 강조는 `DISCUSSION`으로 미채택이며 정본 승인과 별개다.

| 읽는 때 | 결과물 | 확인 범위 |
|---|---|---|
| 정상·조사 누락·복구 전 및 도중 귀환·인수 부족을 비교할 때 | [사례 비교와 첫 장 통합 흐름](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent/2026-11-15-veles-chapter-comparison.md) | C01-C06의 지식·수행·위협·보고, 도입부터 출항, 반복·전투 연결의 자체 보완 |
| 새로 채택할 흐름·강조를 고를 때 | [NC01-NC04 묶음 선택표](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent/2026-11-15-veles-chapter-options.md) | 확정과 추천·대안·보류, 기존 VR 범위 재사용, 승인 뒤 NG04 인계 |
| 판정·완료 기준별 근거·미검증을 확인할 때 | [독립 검토](../Reviews/2026-11-15-veles-chapter-review.md) | 서면 인과·선택 범위 PASS, 실제 인지·전투·운영·UE 미검증 |

다음 행동은 NC01-NC04·NA·공통 경계의 사용자 선택과 해당 범위의 NG04 반영이다. NG02·NG03에는 [변경 가정과 미확인](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent/2026-11-15-veles-chapter-comparison.md#다른-작업군에-넘길-영향)을 넘긴다. 아직 선택되지 않은 VR·NC와 정확한 진행 규칙·운영·실제 검증을 완료로 세지 않는다.

## 시작할 자료

- [Scenario](../Scenario.md)의 VS·VB 확정과 인물·복구·출항 조건.
- [첫 장 문서 지도](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent.md)의 현행 개요·정보 접근·VR 원문·선택표.
- [정보 접근 점검](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent/2026-11-14-veles-information-access.md)의 VI·VT와 기존 보류. 이미 다룬 정상 사례는 재작성하지 않고 비교 기준으로 쓴다.

## 묶어서 수행할 범위

1. 확정 VS·VB와 미채택 VR의 차이를 확인한다. VR 채택 여부가 없으면 후보로 계속 비교하며 정본에는 옮기지 않는다.
2. 정상 조사·익숙한 길 귀환 사례와 함께, 작업실 정보를 일부 놓친 경우, 복구 전 또는 도중에 돌아온 경우, 인수 시 설명이 부족한 경우를 비교한다. 기존 VT에 있는 내용을 재사용하고 필요한 장면 연결만 보완한다.
3. 각 사례에서 아는 사실·모르는 사실·실제 수행한 작업·남은 위협·귀환 후 전달을 한 표로 대조한다. 누락이 자동으로 해결되거나 모든 사례가 정상 출항으로 끝나지 않게 한다. 재시도 수치·저장 규칙까지 설계하지 않는다.
4. 첫 장의 연속된 흐름에 대조 결과를 연결한다. 필드 교전, 현장 조사, 직접 보스전, 실제 정비, 주민 인수, 도움 수용·여행 의사, 아침 점검이 각각 다른 일을 하는지 확인한다.
5. 자체 수정과 읽기 전용 독립 검토를 거쳐, 새로 고를 흐름·강조만 묶음 선택표 하나에 모은다. 기존 VR 선택표는 근거로 연결하고 승인 이력을 다시 만들지 않는다.

## 완료 기준과 결과물

| 결과물 | 검토 완료 기준 |
|---|---|
| 사례 비교 | 정상·조사 누락·미완료 귀환·인수 부족 사례의 정보와 작업 상태가 구분된다. 필요한 재확인 위치와 아직 정하지 않은 규칙을 표시한다. |
| 첫 장 통합 흐름 | 도입부터 출항까지 원인·전투 목표·복구 결과·인물 선택이 끊기지 않는다. 미완료 사례는 무엇이 남아 출항하지 못하는지 보인다. |
| 반복·전투 연결 검토 | 같은 설명을 다시 하는 이유가 있는지, 현재 위험을 무시하는 설명 장면이 있는지 점검하고 지적·수정·미검증을 남긴다. |
| 묶음 선택표·검토 기록 | 확정·추천·대안·보류를 구분하고 독립 검토 결과와 미해결 지적을 기록한다. 문서 검사에 통과한다. |

검토 묶음이 준비되면 이 목표의 작성·검토를 마친 것이다. 정본 채택은 별도 상태로 남기고, 승인 뒤 [NG04](04-canon-consolidation.md)에서 반영한다. 실제 재미·통행·전투 가독성·UE 검증을 완료 조건에 섞지 않는다.

## 스킬과 다음 인계

현재 승인 범위의 Creative Fiction Writer·Character Creator·ccl8-narrative·docs·writing을 이어 쓸 수 있다. 관련 선택 스킬은 Game Designer Assistant이며 실제 전투 배치·간격·진행 규칙까지 확대할 때 사용 범위를 확인한다. 단순 장면 비교를 이유로 구현을 시작하지 않는다.

완료 시 NG02에 벨레스 공급·주민 역할·동선에서 달라진 가정만 전달한다. NG03에는 주인공의 첫 신뢰 변화·린 잔류·로덴 기록 전달과 출항 조건의 변경 영향만 전달한다. 마렌·이르 합류나 출항 이후 상세 장면을 이 목표에 추가하지 않는다.
