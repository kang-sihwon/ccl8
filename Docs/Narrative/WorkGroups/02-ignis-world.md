# NG02 이그니스 배경 정합

**목표는 산·강·세계수와 정착 위치, 생계·교역, 국가·세력·몬스터의 압력이 서로 설명되는 이그니스 배경 묶음이다.** 역사 사전 수준으로 확대하지 않고, 주인공이 방문하기 전에도 사람들이 무엇을 하며 어떤 문제가 이어지는지 읽히게 한다. 현재 상태는 [CurrentWork](../CurrentWork.md), 공통 운영은 [작업군 지도](../WorkGroups.md)를 따른다.

## 시작할 자료

- [지형과 정착](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent/geography.md), [국가·세력·몬스터의 현재 상황](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent/present-world.md).
- [36곳 좌표 정합 후보](../../ArtDirection/EtherWorldMap/2026-11-07-continent-coordinate-map.md)와 [지도 도안 보관·사용](../../ArtDirection/EtherWorldMap/IgnisSharedTerrain.md#제작-도안-보관과-사용).
- [이그니스 여정 통합](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-09-ignis-journey-continuity.md), [세계 분포·성장](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-08-world-distribution-and-leveling.md), [World](../World.md)의 확정 범위.

## 묶어서 수행할 범위

1. 대도시 8곳·도시 12곳·마을 16곳의 현행 이름·위치·지형 제약·생계·교역 상대를 기존 자료에서 모은다. 이미 있는 내용을 복제하기보다 원본을 가리키는 비교표를 만든다.
2. 나라·인간 세력의 명목 영토와 실제 영향력, 자원·수원·고개·항만을 두고 생기는 갈등을 연결한다. 새로운 국가사·연표·인구 수치를 임의로 채우지 않는다.
3. 몬스터의 거점·먹이·이동·약탈과 일반 동물의 생태가 지형·사람의 생활권과 맞는지 확인한다. 기존 종·파생형·성장 후보를 재사용하며 총수를 늘리거나 확정으로 승격하지 않는다.
4. 메인 이동 축과 외곽 정착지를 함께 대조한다. 현재 배경에 후대 사건의 해결 결과가 미리 들어갔거나, 주인공이 오지 않으면 모든 활동이 멈추는 부분을 보완 후보로 남긴다.
5. 근거 있는 충돌·누락만 수정 후보로 제시하고 검토한다. 지역별로 무엇이 유지되고 무엇이 달라질지를 묶음 선택표로 정리한다.

## 완료 기준과 결과물

| 결과물 | 검토 완료 기준 |
|---|---|
| 정착망 비교 | 36곳 모두 지형·기능·의존 관계의 근거 또는 미기록 표시가 있다. 이름·좌표를 조용히 이동하지 않는다. |
| 세력·생활권 관계 | 갈등의 자원·당사자·현행 대응·방치 시 변화가 연결된다. 몬스터와 동물의 역할을 구분한다. |
| 충돌·영향 목록 | NG01 벨레스와 NG03 장기 여정에 영향을 주는 항목이 추적된다. 확정 변경이 필요한 부분은 승인 대상으로 분리한다. |
| 묶음 선택표·검토 기록 | 제안·대안·미확인을 한 묶음으로 비교하고 독립 검토·문서 검사를 마친다. |

모든 빈칸에 새 설정을 만들어 넣는 것이 완료 조건은 아니다. 현재 상황을 설명하는 데 필요하지 않은 역사·신상·수치는 보류한다. 기존 해안·도시 좌표·선택한 화풍을 보존하며 지도 이미지 재제작·실제 지형 생성·UE 블록아웃은 범위 밖이다. 자료 대조에서 공간 검증이 필요해지면 위치와 이유를 남긴다.

## 스킬과 다음 인계

관련 조합은 Worldbuilding Studio·Map Maker·Game Designer Assistant와 ccl8-narrative·docs·writing이다. 과거 승인의 적용 범위를 확인하고 새 전문 스킬·확장 범위만 작업 전에 확인한다. Map Maker는 기존 지도·좌표를 대조하는 용도로 제안하며 이미지 제작 재개를 뜻하지 않는다. 관련 선택 스킬은 Mythology Creator이며 전승의 모순을 다룰 때만 검토한다.

NG01 완료 전에도 지형·정착망 대조를 진행할 수 있다. 벨레스의 공급·동선·세력 가정이 달라지면 NG01에 전달하고, 대륙 이동·성장·갈등의 변화는 [NG03](03-world-journey.md)에 전달한다. 채택한 변경의 정본 반영은 NG04가 맡는다.
