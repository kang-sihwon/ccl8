# NG01-NG04 이후 남은 보류

**남은 일은 채택한 진행·재개 규칙의 세부 보류, 채택한 공간·운영·전투 검증 기준의 세부와 실제 검증, 채택한 집필 표현의 세부와 실제 인지 검증, 필요한 후속 구간의 운영 상세다.** 신상·신화·후일담은 해당 이야기가 필요할 때 재개한다. 이 목록은 보류를 찾는 지도이며 새 설정·수치의 채택이나 제작 약속이 아니다. 실행 순서와 완료 기준은 [후속 작업군 추천](next-workgroups.md)이 소유한다.

## 완료와 보류를 구분하는 기준

NG01-NG03의 작성·독립 검토와 NC·VR·IB·JC·공통 경계의 NG04 정본 반영은 완료했다. 근거는 [결정 58](../../decisions/0058-veles-chapter-continuity-adoption.md)·[59](../../decisions/0059-ignis-background-relations-adoption.md)·[60](../../decisions/0060-world-journey-connections-adoption.md), [세 반영 묶음](04-canon-consolidation.md), 최종 반영 커밋 `1b4bdb7b`다. 승인된 핵심을 다시 후보로 돌리거나 같은 통합 검토를 반복하지 않는다.

아래 열두 선택표에는 보류 행 79개가 있다. **79개의 독립 과제나 미해결 결함을 뜻하지 않는다.** 같은 주제가 후속 선택표에 반복되고, 일부 행의 중심은 이미 채택됐다. 행 수는 원문 추적의 범위이며 전체 문서에 흩어진 모든 미확인의 개수를 센 값은 아니다.

|---|---|
| 채택 완료 | K·WP·CL·CP·FC·SC·VS·VB·NC·VR·IB·JC의 결정 범위는 유지한다. 상세 원문 전체의 승인으로 확대하지 않는다. |
| 남은 세부 보류 | 필요한 부분만 NG05-NG08의 입력으로 연결한다. 작업군 하나를 끝내도 같은 보류 행에 남은 전 대륙·제작 범위까지 닫지 않는다. |

## NG05가 구체화한 부분

[NG05 진행·재개 후보](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-15-veles-progression-resume.md)는 첫 장의 지식·실제 작업·인수·현재 운영·아침 판단과 같은 세계의 재개·명시적 저장 복원을 구분한다. 작성·[독립 검토](../Reviews/2026-11-15-veles-progression-resume-review.md)를 PASS로 완료했으며 PR01-PR07·공통 경계도 사용자 승인으로 [결정 61](../../decisions/0061-veles-progression-resume-adoption.md)·[Scenario](../Scenario.md#벨레스-첫-장의-진행과-재개)에 반영했다. 반영 검토는 [별도 기록](../Reviews/2026-11-15-veles-progression-adoption-review.md)에서 확인한다. 아래 원문별 NG05 연결은 이 결과에 대응한다. 채택한 의미·경계만 확정했으며 기존 보류 행의 수치·입력·공간·실행·다른 지역 상세를 함께 해제하지 않는다.

[선택표](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-15-veles-progression-resume/options.md)의 PRA01-PRA02는 미채택 대안, PRH01-PRH06은 저장·전투 세부·운영 수치·공간·표현·실행의 미결이다. 기존 열두 선택표의 79행 집계에 섞지 않고 별도로 추적한다. 정확한 입력·저장 필드·시간·물량·재접근 성공은 여전히 미확인이며 NG06·NG07과 별도 제작의 입력으로 넘긴다.

## NG06이 구체화한 부분

[NG06 검증 설계](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-15-veles-validation-design.md)는 SP01-SP10·GX01-GX12·WC01-WC06·OP01-OP09와 최소 제작 인계를 작성하고 [독립 검토](../Reviews/2026-11-15-veles-validation-design-review.md)를 PASS로 마쳤다. 실제 검사 결과는 전부 미실행이며 도안·좌표·수치를 바꾸지 않았다. VD01-VD06·공통 경계는 사용자 승인으로 [결정 62](../../decisions/0062-veles-validation-design-adoption.md)·[Scenario](../Scenario.md#벨레스-첫-장의-공간운영전투-검증-기준)에 반영했다. 이 채택 범위는 `CLOSED`다. [반영 독립 검토](../Reviews/2026-11-15-veles-validation-adoption-review.md)는 PASS이며 잔여 지적은 없다. VDA01-VDA02는 미채택 대안, VDH01-VDH06은 형상·무기·운영·성장·정보 표현·실행 미결로 남는다.

아래 원문별 NG06 연결은 해당 검증 명세로 구체화됐다. 설계를 쓴 것으로 실제 통행·무기 도달·재고 지속·경험치·저장·UE가 검증되지는 않는다. 새 VDH는 기존 79행·PRH를 대체하거나 집계에 더하지 않고 각 원문의 남은 질문과 연결한다.

## NG07이 구체화한 부분

[NG07 통합 집필](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-15-veles-integrated-manuscript.md)은 정상 MS01-MS10·C03-C06의 대체 장면과 두 재개 변형, VI01-VI08 정보 대조·인물 검토를 작성했다. [독립 검토](../Reviews/2026-11-16-veles-integrated-manuscript-review.md)는 C05 표현 두 곳 보완 뒤 PASS이며 잔여 지적은 없다. IW01-IW06·공통 경계는 사용자 승인으로 [결정 63](../../decisions/0063-veles-manuscript-delivery-adoption.md)·[Scenario](../Scenario.md#벨레스-첫-장의-표현과-작업-기록)에 반영했다. 이 채택 범위는 `CLOSED`다. [반영 독립 검토](../Reviews/2026-11-16-veles-manuscript-adoption-review.md)는 지도 표현 한 곳 보완 뒤 PASS이며 잔여 지적은 없다. IWA01-IWA02는 미채택 대안, IWH01-IWH06은 정확한 매체·근거 소실·실제 인지·운영·다른 경로·후속 집필의 미결이다.

원고를 쓴 것으로 기존 정확한 대사·입력·저장·운영·공간·실행 보류가 해제되지는 않는다. 새 IWH는 기존 79행·PRH·VDH를 대체하거나 집계에 더하지 않는다. 그중 NG07 연결은 이번 원고와 대조표로 구체화됐으며 실제 정보 인지·전투 피로·UE는 계속 미검증이다.

## NG08이 구체화한 부분

NG08 로덴·세르나·하르덴 운영·인계의 작성·독립 검토를 PASS로 완료했다. 잔여 지적은 없다. HO01-HO06·공통 경계는 미채택 후보인 DISCUSSION이며 HOA01-HOA02·HOH01-HOH06을 보존한다. G4·G5 상세와 실제 UE 구현·실행은 미착수다. [운영·인계 묶음](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-16-ignis-operational-handoffs.md)에서 당사자·물량·자료·회신·인수·적용을 구분하고 조건/비용과 불완전 사례를 작성했다. [독립 검토](../Reviews/2026-11-16-ignis-operational-handoffs-review.md)는 PASS다. [HOH 보류](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-16-ignis-operational-handoffs/options.md#보류)는 물량·시간·책임·표현·경로/복원·실제 실행·다음 지역의 남은 질문을 연결하며 기존 79행·PRH·VDH·IWH를 대체하지 않는다. 정확한 값과 실제 성공은 미확인이다.
