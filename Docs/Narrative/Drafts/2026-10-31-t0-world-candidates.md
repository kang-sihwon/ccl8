# T0 세계 후보 비교

컨셉 시안 테스트 T0의 기준으로 쓸 세계와 시나리오 후보 세 개를 비교한다. 작성자는 시각 기준의 개성과 제작 부담을 함께 볼 때 후보 A를 추천한다. 세 후보 모두 사용자 승인 전의 후보이며 [World](../World.md)와 [Scenario](../Scenario.md)의 정본이 아니다. 독립 검토는 실시하지 않았다.

## 질문과 범위

- 질문: 시안 하나로 배경, 캐릭터, 몬스터의 화풍을 묶으려면 어떤 세계를 기준으로 삼아야 하는가?
- 범위: 세계의 한 줄 전제, 마을, 보스에게 갈 이유, 일반 몹 세 역할, 보스, 결말. 고유 이름과 세부 역사는 정하지 않는다.
- 제약: [Direction](../../Direction.md#확정-범위)의 마을 하나, 전투 구간, 보스 하나, 일반 몹 몇 종류, NPC 몇 명, 짧은 시나리오를 지킨다. 일반 몹 역할은 [GameDesign](../../GameDesign.md#전투제안)의 제안을 따른다. 시각 조건은 [ArtDirection](../../ArtDirection.md#시각-기준제안)의 제안을 따른다.

## 후보 A: 닫힌 수문

높은 골짜기의 강을 옛 사람들의 거대한 돌 수문이 다스렸다. 수문이 닫힌 뒤 겨울이 길어졌고 강은 바닥까지 얼었다. 양치기와 얼음 채취꾼이 사는 마을에는 장작과 식량이 줄고 있다. 안내인은 주인공을 수문으로 보낸다.

| 항목 | 내용 |
|---|---|
| 전투 구간 | 얼어붙은 강바닥과 옛 수로 |
| 빠른 근접 압박 | 굶주려 낮게 달리는 산짐승 |
| 느리고 강한 공격 | 얼음이 갑옷처럼 붙은 옛 수문 경비병 |
| 거리 유지와 견제 | 로브를 두르고 얼음 작살을 던지는 수로지기 |
| 보스 | 수문을 떠나지 못하는 문지기 |
| 결말 | 수문을 열면 물이 돌아오지만 강가의 낮은 땅은 잠긴다 |

- 기존 구현과의 연결: [깊은 눈](../../EnvironmentSnow.md)과 [물 순환](../../EnvironmentWater.md)의 결빙, 강 수위를 시나리오의 이유로 쓸 수 있다. 기능 검증 초안의 `DA_GateGuard`, `DA_GateWarden`도 그대로 어울린다.
- 제작 부담: 수문과 수로는 석조 모듈로 나눌 수 있어 부담이 가장 낮을 것으로 추정한다.
- 약점: 눈과 얼음이 화면을 채우면 색 범위가 좁아진다. "서정적인 자연"이라는 마을 제안과도 거리가 있다.
- 유사성: 끝나지 않는 겨울은 판타지의 흔한 소재다. 작성자가 기억으로 판단했고 조사하지 않았다.

## 후보 B: 물러난 바다

바다가 수평선 너머로 물러난 지 3대가 지났다. 옛 항구 마을은 좌초한 배의 목재로 집을 고치고 마른 해저에서 소금을 캐며 산다. 우물이 짜지고 밭이 말라 가자, 안내인은 곶 끝의 등대가 바다를 붙잡고 있다는 옛말을 꺼낸다.

| 항목 | 내용 |
|---|---|
| 전투 구간 | 마른 해저와 좌초선 무덤 |
| 빠른 근접 압박 | 갯벌을 낮게 달리는 갑각 짐승 |
| 느리고 강한 공격 | 소금이 껍질처럼 굳은 거구의 옛 선원 |
| 거리 유지와 견제 | 로브를 두르고 소금 가시를 던지는 등대의 제자 |
| 보스 | 침식된 등대 안의 등대지기 |
| 결말 | 등대의 불을 끄면 바다가 돌아오고 마을은 떠나야 한다 |

- 기존 구현과의 연결: [EnvironmentPlan](../../EnvironmentPlan.md)의 범위에 강과 해안 수위가 있다. 조석은 향후 입력이지만 바다가 물러난 설정은 조석을 요구하지 않는다. [ArtDirection](../../ArtDirection.md)이 ccl8에서 얼마나 쓸지 정하게 한 Orbis의 해안과 대항해 소재를 다른 방향으로 쓴다.
- 제작 부담: 좌초선처럼 큰 구조물과 소금 결정 재질이 필요해 세 후보 중 가장 무거울 것으로 추정한다.
- 약점: 물이 없는 세계라 이미 구현한 물과 눈을 덜 쓴다.
- 유사성: 말라붙은 바다의 좌초선은 실제 아랄해에서 볼 수 있는 풍경이다. Bloodborne의 어촌 구역과 겹치지 않도록 달과 어인 소재는 뺀다. 작성자의 기억이며 원문을 확인하지 않았다.

## 후보 C: 내려오는 숲

오래된 숲이 해마다 언덕 아래로 내려오고, 뿌리가 밭과 길과 집을 먹는다. 나무꾼과 직조공의 마을은 대대로 경계 말뚝을 세워 숲을 막아 왔다. 올해 경계가 무너져 뿌리가 광장의 우물까지 닿았고, 안내인은 숲 깊은 곳의 옛 석조 전당으로 주인공을 보낸다.

| 항목 | 내용 |
|---|---|
| 전투 구간 | 잠식된 옛길과 버려진 마을 |
| 빠른 근접 압박 | 사지가 길어진 숲의 사냥꾼 |
| 느리고 강한 공격 | 돌과 뿌리가 엉긴 거구 |
| 거리 유지와 견제 | 로브를 두르고 긴 지팡이를 든 숲지기 |
| 보스 | 전당에서 뿌리와 엉겨 버린 옛 사제 |
| 결말 | 뿌리를 끊으면 숲이 마르고 마을은 목재를 잃는다 |

- 기존 구현과의 연결: 생태와 영구 지형을 이유로 쓸 수 있다. 기존 T1, T2, T3, T6, T7의 피사체와 거의 같아 결과를 다시 쓸 수 있다.
- 제작 부담: 마을과 숲은 구하기 쉬운 편이지만 뿌리가 구조물을 감싼 형태는 조립이 까다로울 것으로 추정한다.
- 약점: 세 후보 중 가장 흔해서 개성이 약하다. T0의 새 시안이 기존 테스트와 비슷해진다.
- 유사성: 숲의 침식은 판타지의 흔한 소재다. 작성자가 기억으로 판단했고 조사하지 않았다.

## 비교

| 기준 | A 닫힌 수문 | B 물러난 바다 | C 내려오는 숲 |
|---|---|---|---|
| 시각 개성 | 중간 | 높음 | 낮음 |
| 재질 폭 | 좁음 | 넓음 | 넓음 |
| 기존 구현 연결 | 높음 | 중간 | 중간 |
| 제작 부담(추정) | 낮음 | 높음 | 중간 |
| 기존 테스트 재사용 | 낮음 | 낮음 | 높음 |

## 추천

후보 A를 추천한다. 시나리오의 이유가 이미 구현한 눈과 물에서 나오고, 3-4개월 제작 범위에서 부담이 가장 낮을 것으로 추정하기 때문이다. 좁은 색 범위는 마을의 양모, 가죽, 장작불과 수문 내부의 차가운 돌로 보완할 수 있다고 본다. 시각 개성을 가장 우선하면 후보 B가 낫다.
