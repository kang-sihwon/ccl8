# 현용 수원의 조사와 운영 인계

히드라의 여러 공격 방향과 마른 땅 유지, 승리·철수 판단을 비교할 때는 [키메라·히드라·빙편 정령 상세 후보](../2026-11-13-predator-and-ice-combat-arcs.md)를 읽는다. 아래 기존 사건·급수 인수·성장·귀환 조건은 보존한다.

[수원 후보](../2026-11-10-seradion-waterworks.md)는 주인공이 시설 전체를 끄는 대신, 현지 담당자가 주민 공급을 이어 갈 조건을 확보하는 이야기다. 기준은 [세라디온 전반 이야기](../2026-11-08-five-continent-mainline/continent-arcs.md#세라디온)와 [G4-G6 조건](../2026-11-08-five-continent-mainline/routes-and-unlocks.md#이동이야기-시작-조건)이다. 아래 장소·기술 절차·인물 행동은 새 후보이며 공학 검증 결과가 아니다.

## 조사에서 전투까지

| 공간 | 주인공의 행동과 갈등 | 달라지는 상황 |
|---|---|---|
| F03·F04·C01 접수 | 관리회는 하류 관측·숲 기록과 출입 명단을 대조한다. 사업단 현장 기술자는 무작정 정지하면 주민 물부터 줄어든다고 반대한다. 주인공은 운전 담당자 동행과 외부 철수 연락을 합의한다. | F04는 합의한 조사 구획만 열린다. 초청장이나 키메라 처치가 심부 조작 권한을 주지 않는다. |
| C02-C04 분기·정비길 | 주인공은 찌꺼기 웅덩이와 낡은 표식 경계를 지나 조사조의 접근을 확보한다. 마렌은 실제 분기와 원본 기록을 맞춘다. | 주민 계통과 시험 계통이 한 조절부를 공유해, 확대 운전 때 생활 급수까지 흔들릴 수 있다는 현지 가설을 얻는다. 니베르 실패 원인을 알아낸 것은 아니다. |
| C11·C17 별도 협의 | 녹석비늘 나가 집단은 지하 샘의 통과·취수 범위를 지킨다. 관리회는 이미 쓰는 주민 분기를 유지해야 하고 사업단은 시험용 물량을 늘리고 싶어 한다. | 기존 주민 취수 유지, 시험 취수 확대 금지, 샘 출입 동행을 합의한다. 나가를 죽여 통행증을 얻지 않는다. 미합의면 관측·외부 정비는 가능하지만 급수 인수는 보류한다. |
| C05-C06·C08-C09 사전 정찰, 49→50 | 히드라의 먹이 흔적·목볏·물결을 살피고 남쪽 철수로와 북쪽 다른 귀환을 먼저 확인한다. 관리자는 정비턱 점검 중단 때문에 분리 작업이 끝나지 못했다고 설명한다. | 전투의 목적은 외부 잠금부에 접근할 작업창이다. 관리실·기록실 전체가 보스 뒤에 생기는 구조가 아니다. |
| C07 녹관 사건, 50→51 | 호수에 살던 같은 개체가 정비턱에 몸을 올리는 때 대응한다. 물속 추격이나 무한 재생을 끊는 특정 무기를 요구하지 않는다. | 추천 처치 뒤 현지 정비조가 사체·미끄럼·잠금부 손상을 확인하고 작업을 인수한다. 즉시 모든 수문이 자동으로 열린 것으로 처리하지 않는다. |
| C08-C13 다른 귀환·급수 인수, 51→52 | 주인공은 북쪽 마른 둑으로 돌아온다. 관리자·나가 연락인·주민 대표가 기존 샘 계통의 운전을 확인하고, 시험 분기를 분리한다. 마렌은 빠진 운전 시간과 시험대 연락 장부를 대조한다. | 주민 공급 인수와 확대 시험 중지, 니베르 구조 요청·위치 대조를 하나의 조사 성과로 묶는다. 협의·밸브·문서마다 성장을 중복 지급하지 않는다. |

관리회는 사하르 유역의 급수 책임과 탈레아 교역도시의 개발 계약을 함께 조정한다. 사업단 기술자는 공급을 지키려는 관리자의 동료가 될 수 있고, 계약 담당자는 중지로 발생할 비용과 책임 공개를 꺼린다. 주인공은 계약 책임을 결정하는 재판관이 아니다. 현지 대표가 중지 범위·기록 보존·비용 협의를 맡고, 현장 기술자의 기술과 생활 기반은 남긴다.

## 녹관 히드라와 싸우는 방법

WG6는 [MN34-X 녹관](../2026-11-08-worldwide-monster-variants/overseas-forms.md)의 녹색 목볏·길고 가는 여러 목·넓은 뒷몸을 유지한다. 수치는 구 도감의 23-29가 아니라 [현행 배치](../2026-11-08-world-distribution-and-leveling/variant-distribution.md#세라디온-47형태)의 49-52 중 **51**을 쓴다. 하류 SG8 판갑목과는 별개 개체다.

준설·취수 운용 변화가 물고기의 머무는 곳과 사람의 정비 접근을 겹치게 했다. 이 호수의 어군을 먹는 포식자가 정비턱을 쉬는 자리로 쓰고, 낮은 물가에 접근하는 사람에게 반응한다. 신호를 받으면 나타나는 소환수나 사업단이 조종하는 병기는 아니다. 주인공이 다른 순서로 와도 목볏·물결·먹이 흔적이 남아 있다.

남쪽 C06에서는 목 하나가 먼저 낮게 훑고 다른 목이 뒤쪽 접근을 견제하는 것을 본다. C07의 마른 턱에서 싸울 때는 전방 목의 찌르기, 옆 목의 쓸기, 몸통 이동을 서로 다른 예고로 읽는다. 몸통을 돌려 한쪽 물가를 비우면 낮은 목 밑과 옆몸에 접근할 수 있다. 근접·원거리 모두 가능한 공격 창을 두되 성능이 같다고 전제하지 않는다.

압박이 커지면 두 목의 공격 사이 간격이 짧아지고 몸을 물 쪽으로 돌린다. 주인공은 공격을 한 번 피한 뒤 오래 붙어 있기보다 몸통 이동 방향을 보고 반대편으로 빠진다. C07의 두 차폐물은 목의 직선 접근과 시야를 나누며, 전신 쓸기를 무조건 막는 벽이 아니다. 젖은 물가보다 마른 턱을 유지하는 선택이 중요하다.

머리 재생에는 먹이와 시간이 든다는 기존 설정을 유지한다. 한 전투 도중 잘린 머리가 즉시 무한 증식하거나 생명력이 전부 회복되지는 않는다. 머리 절단·불속성·특정 무기를 필수 해법으로 삼지 않고 몸통과 노출 부위에 대한 전투로 해결한다. 물로 들어가면 추격하지 않고 C06으로 물러나 흔적을 다시 관찰한다. 이탈 개체의 상처·섭식·회복 상태와 재도전 저장 규칙은 아직 설계하지 않았다.

추천 처치 뒤 WG6 초기 장부는 1개체, 활동 수는 0이다. 돌아오는 길에 같은 사건 개체를 재생성하지 않는다. 일반 포식자의 재유입은 장기 관리 문제이며 보스 부활 연출로 대체하지 않는다. 실패하면 C07-C06-C05-C04 또는 사전에 확인한 C08-C09-C10을 이용한다. 보스가 잠깐 물러났다고 정비조가 즉시 위험 구역에 들어가지 않는다.

## 주민 물과 시험 장치

| 대상 | 현지 담당자의 조치 | 인수 완료 조건과 실패 시 |
|---|---|---|
| C11 기존 지하 샘 | 나가 연락인과 취수 범위를 대조하고 기존 주민 취수를 유지한다. 새 샘을 즉석에서 만들지 않는다. | 취수·수질·비축 확인이 부족하면 C12 기존 비축과 배급 계획을 사용하고 작업을 미룬다. 실제 양·시간은 미검증이다. |
| C02 공용 분기·C03 시험 격리부 | 확대 시험을 먼저 금지한 상태에서 잠정 운전을 유지한다. 기존 주민 분기를 시험 분기와 분리하고 잠금·표지를 현지 담당자 둘이 확인한다. | 역류·누설·잔류 압력 관측, 주민 급수 시험과 담당자 인수가 모두 끝나야 분리 완료다. 단순 레버 한 번으로 안전하다고 판정하지 않는다. |
| C07 외부 잠금부 | 정비조가 위협 제거 뒤 손상과 작업 바닥을 확인한다. 주인공은 접근·철수 확보를 맡는다. | 부품·인력이 부족하면 작업창을 보존하고 자재를 가져온다. 보스 재처치는 요구하지 않는다. |
| C10 운전 기록·C13 복귀 접수 | 관리회가 확대 시험 중지 범위, 일상 운전 책임자, 감시·정비·배급 연락을 서면 인수한다. | 주민 공급과 정지한 시험 계통을 분리해 기록한다. 결말 심부의 영구 정지·무휴기관 원리 해명은 아직 아니다. |

C11·C12·C02 사이 연결은 기존 시설의 배관을 상세화한 후보이며 지하 층·관경·압력·양수 동력·정수 설비를 검증한 것은 아니다. 새 도면의 호수는 기존 강 북쪽을 막거나 세계 수원의 위치를 다시 정하지 않는 국소 물자리다. 히드라가 사는 외부 물자리를 주민의 유일한 음용수로 설정하지 않는다.

## 구조 요청과 원정 인계

마렌은 C10 원본 장부에서 니베르 시험대의 연락 누락을 발견한다. 관리회가 보관한 최근 구조 요청 사본에는 시험대 식별, 마지막 정박 기준점과 철수 희망 위치가 있다. 출항지의 기존 항해 자료·발신 식별·수신 시점을 교차 대조한다. 구조 요청의 존재와 위치를 확인하는 단계이며 생존 인원·현재 상태·실패 원인은 현장 조사 전까지 미확인이다. 순간통신이나 실시간 생존 보증을 추가하지 않는다.

| G5 조건 | 이번 끝의 상태 | 다음에 확인할 것 |
|---|---|---|
| G4 뒤 현지 조사 | 기존 왕복 계약과 초청을 유지한다. | 귀환 좌석·비용의 유효 범위 확인. |
| 주민 수원 분리·시험 확대 중지 | 위 인수 조건을 충족하는 추천 플롯에서 완료한다. | 출항 전 관리회 연락으로 운영 인수를 재확인한다. |
| 최근 구조 요청·위치 확인 | 기록·발신 식별·항해 자료를 대조한다. | 남부 거점에서 출항 시점의 정보 신선도와 탐색 범위를 갱신한다. |
| 극지 개조 | 오르다스 장인회의 기술 협력과 사양 사본을 원정 담당자에게 인계한다. | 출항 전 항구에서 부품 조달·시공·선장 인수. 니베르산 재료를 요구하지 않는다. |
| 귀환 비축·피난 계획 | 왕복·예비·철수 보급과 피난 후보를 계획서에 적는다. | 실제 적재·피난 거점 수용·기상과 해빙 창 확인. |

따라서 G5는 준비 중이다. 선박 개조·적재가 문서에 적혔다는 이유만으로 완료 처리하지 않는다. 다음 구간은 기존 기항항에서 남부 출항 거점으로 이동해 준비물을 실물로 확인하고 T6 원정에 나서는 플롯이다. 남부 거점의 절대 좌표·기항 거리·항해 일수는 아직 정하지 않는다.

마렌은 주인공과 이동하며 관측 사본·관리회 확인서·구조 요청 사본·개조 사양을 휴대한다. 시설 원본·열쇠·일상 운전 권한은 현지에 남긴다. 린·이르는 기존 담당지에 남고 산림 안내인도 다시 소환하지 않는다. 수원 담당자와 나가 연락인은 인수 이후 현지에 남는다. 새 고정 동료를 추가하지 않는다.

주인공은 큰 적을 쓰러뜨리는 능력을 키우면서도, 누가 남아 물을 공급할지 확인하지 않고 떠나면 전투의 성취가 유지되지 않는다는 점을 배운다. 마렌은 모순을 발견하자마자 원인을 단정하던 태도 대신 현장 기록과 증언의 차이를 남긴다. 니베르에서 비교할 질문은 마련하지만 해답은 아직 얻지 않는다.

확대 시험은 중지되어 원정 중 숨은 실시간 파국 시계를 두지 않는다. 강경파의 시설 점거·강제 재가동·중추 방어체는 니베르 조사 결과를 공개한 뒤의 G6 결말에 남긴다. G5 준비를 중단해도 기존 G4 계약으로 돌아갈 수 있다.
