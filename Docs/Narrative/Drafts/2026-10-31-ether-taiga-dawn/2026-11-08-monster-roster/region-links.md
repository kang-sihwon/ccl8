# 몬스터 종과 지역 분포의 연결

이번 [종 기준안](../2026-11-08-monster-roster.md)을 먼저 적용한 뒤 개체 수와 순찰 범위를 상세화한다. 앞선 [지역 생태안](../2026-11-08-continent-ecology-progression/regional-ecology.md)의 먹이·물·거점·이동 구조를 유지하며 기능명을 구체적인 종으로 연결한다. 이 문서는 새 분포 후보를 소유하고 앞선 지도·JSON은 작성 당시의 v1 자료로 보존한다.

## 종별 주 생활권과 확산 범위

| 종 | 주 생활권 | 보조 생활권·등장 한계 | 기존 레벨 비교와 관계 |
|---|---|---|---|
| MN01 고블린 | S1 벨레스 숲 | S2 강변·E2 곡창의 별도 집단. 모든 대도시 내부에 배치하지 않는다. | S1의 1-5를 유지. 장비·인원·준비가 다른 집단은 별도 비교 |
| MN02 오크 | S4 서부 고갯길 | E1 서해 짐길의 일부 거점. 첫 장 벨레스에는 추가하지 않는다. | S4 일반 전투 18-23을 비교값으로 제안. 수치만 키운 고블린으로 만들지 않는다. |
| MN03 트롤 | S4 바위 골짜기·E2 깊은 늪 | E1 채석장 주변 선택 위험. 모든 다리에 고정 배치하지 않는다. | 바위형 23-28, 늪형 18-22는 공간별 도전 비교값. 서식형 전체의 고정 레벨이 아님 |
| MN04 여울턱 | S2 강바위 | S3 담수 갈대습지. 염분 높은 암초·외해는 제외 | 강형 4-8, 습지의 큰 성체 10-14 비교. 낮은 위험 개체도 남는다. |
| MN05 유리턱충 | S2 정비층 | 일부 난방 배관의 국소 군집. 전 대륙 설비마다 있지는 않음 | 7-11 기본 비교 유지. 군집 합류와 지형이 위험을 바꿈 |
| MN06 돌등게 | S3 잔해·하구 | E1·E3의 일부 바위 포구. 내륙 강 상류에는 없음 | 기존 갑각종 12-16 기준 연결 |
| MN07 수지거미 | E3 조선림 | 다른 수지 채취터는 조건부. 벨레스 현재 배치에 자동 추가하지 않음 | E3 탐색 14-22 안에서 개체·거점 위험을 후속 배분 |
| MN08 갈고리날개 | S4 절벽 선반 | E1 바람길. 큰 평야·설비 실내에는 없음 | 기존 활공종 18-23 연결 |
| MN09 칼바람비룡 | S4 상부 절벽 | E1 외곽 번식 절벽은 선택 관찰 후보 | 기존 고개 보스 25 유지. 종 전체의 단일 레벨이 아님 |
| MN10 갈퀴등해수 | S3 하구 깊은 홈 | E1·E3 연안 어장. 담수 상류 여울에 복사하지 않음 | 작은 개체 13-17·항로 보스 18 비교 유지 |
| MN11 설원아귀 | S5 눈 계곡 | 북부 목초권 외곽. 벨레스 늑대의 후반 교체물이 아님 | 기존 한랭종 24-28 연결 |
| MN12 불씨도롱뇽 | S5 난방 유적 | S2의 제한된 폐온수실에 낮은 위험 개체를 둘 수 있음 | S5 군집 27-31 비교. S2까지 이 수치로 올리지 않으며 조기 배치는 선택 후보 |
| MN13 백각거수 | S5 계절 이동로 | 북부 방목지와 인접. 성벽 안 상시 적으로 배치하지 않음 | 피난로 개체 31 비교 유지. 종 전체·순록에 적용하지 않음 |
| MN14 뿌리천공충 | S6 깊은 뿌리층 | 오래된 분해층에 국소 존재. 중앙 시장과 일반 농촌에는 없음 | 기존 뿌리굴착종 32-36 연결 |

S1-S6는 벨레스·로덴·세르나·하르덴·북부·세계수의 메인 여정 구간이고, E1-E3는 서해 교역권·남동 곡창·조선림과 동해의 선택 탐색권이다. 표의 숫자는 [기존 성장 비교안](../2026-11-08-continent-ecology-progression/route-and-levels.md)에 연결한 임시 도전 범위다. 종이 어느 지역으로 이동했다고 레벨이 바뀌는 규칙은 아니다. 조우의 몸집·장비·지형·집단 구성이 정해지기 전에는 수치를 실제 능력치로 환산하지 않는다.

## 앞선 기능명을 정리하는 방식

| 기존 표현 | 새 기준 | 반영할 변화와 보존 범위 |
|---|---|---|
| 갈대매복종·습지 매복종 | MN04 여울턱의 습지 서식형 | 별도 새 종 추가를 취소하는 비교안. 같은 장소에서 짧게 덮치는 습성과 마른 단 우회는 유지 |
| 유리턱 군체 | MN05 유리턱충의 집단 | 생물 종과 무리 이름을 구분. 기존 동력 섭취·열·정비로 사건 유지 |
| 하구 갑각종·갑각 포식종 | MN06 돌등게 | 기존 잔해·조석 생활권에 이름과 형태를 부여 |
| 산지 활공 포식종 | MN08 갈고리날개 | 작은 무리·절벽 이용 유지. 비룡 새끼로 바꾸지 않음 |
| 바위매복종·바위트롤·늪트롤 | MN03 트롤의 서식형 | 별도 바위매복종 대신 트롤로 통합. 종 수를 줄이는 대신 고원 바닥의 위협을 드문 중량 위험으로 바꿈 |
| 소형 해수 | MN10 갈퀴등해수의 작은 개체 | 기존 수중 추적 역할 유지. 별도 종·유체 사냥을 필수로 추가하지 않음 |
| 한랭 포식종 | MN11 설원아귀 | 기존 추적·계곡 생활권에 이름과 형태를 부여 |
| 열기를 좇는 생물 | MN12 불씨도롱뇽 | 외부 열 의존과 제한된 증기 능력 추가. 유리턱충의 동력 섭취와 구분 |
| 뿌리굴착종 | MN14 뿌리천공충 | 기존 분해층·굴착 흔적·설비 손상 연결 유지 |
| 고갯길 약탈단 | 인간 약탈단 또는 MN02의 특정 무장 집단 | 둘 다 존재 가능. 기존 인간 집단을 일괄 오크로 변경하지 않고 개별 거점에서 결정 |

바위매복종 통합은 이름만 바꾸는 일이 아니다. 앞선 S4의 일반 적 17-21 바위매복종 배치를 현재 기준에서 보류하고, 트롤은 기존 23-28 선택 위험에 둔다. 고원의 반복 교전은 갈고리날개 활동권과 일부 오크 무장 거점이 맡는 새 비교안이다. 그 둘을 모든 경로에 강제 배치하거나 트롤을 필수 보스로 추가하지 않는다. 구체적인 일반 전투 공백은 이후 고원 탐색 지도에서 확인해야 한다.

## 구조체와 주요 보스의 소속

| 대상 | 분류와 등장 이유 | 유지할 목표 |
|---|---|---|
| 숲·작업실 뿌리 파수꾼 | CT01 수로·시설 관리 계열. 생태적 먹이터가 아니라 작업 반경을 가짐 | 기존 오작동과 직접 전투. 정지 뒤 보수 노동이 남음 |
| 견인 수레·정비체 | CT02 산업 계열의 서로 다른 모델. 사람을 운반·수리·보조하던 설비 | 로덴 구조·대피와 정상 생활 설비의 구분 |
| 철근지기 | CT02의 대형 작업 설비 | 팔의 공격을 직접 멈춰 대피로 확보. 자체 동력통과 파손 비용 유지 |
| 겨울지기·유적 방어체 | CT03 피난 시설 보호 계열. 겨울지기는 특정 대형 설비 | 주민 구조 후 우회로의 방어체를 붙들어 동료의 분리 작업을 도움 |
| 중앙 경비·보수체 | 인간 경비는 인간 조직, 보수체는 CT01 또는 CT02의 용도별 모델 | 생물 종을 추가하지 않고 임무·출입 조건으로 구분. 모델 배치는 미정 |
| 바르툴 | 토착 곰의 특정 개체 | 외부 결박을 끊어 생존·복구·귀환·인계를 이어감 |
| 항로의 갈퀴등해수 | MN10의 대형 개체 | 구조와 배의 탈출. 최종 생사 미정 |
| 고개의 칼바람비룡 | MN09의 번식기 영역 개체 | 취수 접근로 확보. 이후 설비 재설계가 별도로 남음 |
| 피난로의 백각거수 | MN13의 무리에서 떨어진 개체 | 죽이는 대신 이동 방향을 바꿔 피난로 확보 |
| 심근룡 | MN15 보류 고대종 | 기존 최종 보스 대안·생사·존재 보류. 뿌리천공충의 성체로 연결하지 않음 |

## 이후 작업 순서

1. 이 종 기준안을 기준으로 사용자가 바꾸고 싶은 종·분위기를 비교한다. 새 종의 정본 채택은 별도로 기록한다.
2. 타르넬–로덴의 탐색 구간에서 고블린·여울턱·유리턱충과 정비체의 거점·활동권을 배치한다. 불씨도롱뇽의 조기 관찰은 선택 후보로만 비교한다.
3. 종별 기본 개체·장비 역할·큰 개체를 구분한 뒤 수량·합류·추격·귀환과 성장 보상을 검토한다. 모든 종에 같은 무리 크기·전투 간격을 붙이지 않는다.

대륙 지도 v1의 해안·36개 정착지·경로는 이 분류 때문에 바뀌지 않는다. 기능명과 새 이름의 대응은 이 문서에서 읽는다. 도면의 텍스트·JSON을 실제 분포 v2로 갱신하는 작업은 지역별 배치 검토와 함께 수행하며, v1 도면을 이미 새 14종이 모두 배치된 지도로 보고하지 않는다.
