# 남부 원정항의 공간·왕복·생활권

**주요 항만 동선은 개조·적재·승선과 피난을 서로 구분한다.** [남부 출항 후보](../2026-11-10-seradion-polar-departure.md)를 위한 국소 배치이며, SE-S01은 기존 기항항 SE-P01과 다른 좌표계다. 두 항구를 같은 평면에서 임의의 거리에 놓거나 세계 해안선을 수정하지 않는다. 수치·위치는 [JSON](../../../../ArtDirection/EtherWorldMap/Data/seradion-polar-departure-v1.json)이 소유한다.

## 장소와 토지 이용

새 기능 장소는 **16곳**, 길의 꺾임·접속을 계산하는 보조 교차점은 **7곳**이다. 지붕이 구분되는 건물 **10동**과 물탱크·작업 마당·집결지·부두 2곳을 별도로 그린다. 이 숫자는 도시 인구나 전체 항만 건물 수가 아니다. 건물·주민 추가 설정과 시공 치수는 후보로 둔다.

| ID | 장소·좌표(m) | 일상 기능과 이번 사건 |
|---|---|---|
| P01 | 연안편 도착 부두 (185, 40) | 기항항에서 온 운송편을 내려 접수한다. 귀환 연안편도 여기서 연결한다. |
| P02 | 하역·환승 마당 (185, 110) | 상업 화물과 원정 장비를 분류한다. 보행자와 하역 작업창을 나눈다. |
| P03 | 원정 접수소 (260, 140) | 계약·승선 명부·G5 인수를 대조한다. 주민 식량을 징발하는 관청은 아니다. |
| P04 | 개조 작업 마당 (470, 140) | 본선 부품을 점검·조립한다. 배 전체가 육상에 올라온 상태를 전제하지 않는다. |
| P05 | 본선 시험·출항 부두 (485, 40) | 계류 상태 시험과 승선, 외해 출발을 잇는다. 실물 인수가 먼저다. |
| P06 | 현지 수리 공방 (550, 260) | 오르다스 사양을 본선에 맞추고 결함을 수정한다. |
| P07 | 장비·귀환 비축 창고 (360, 260) | 남기는 조사 화물과 선적할 예비품을 칸별로 분리한다. |
| P08 | 급수 인수대 (280, 340) | 항만 저장·조달분을 검수한다. 주민 수원 시설 전체를 원정이 가져가지 않는다. |
| P09 | 식량 검수 창고 (180, 260) | 전진·귀환·지연·구조자 몫의 장부와 실물을 맞춘다. |
| P10 | 난방·의무 대기실 (480, 360) | 부상자·원정자의 출항 전 대기와 귀환 인계를 맡는다. |
| P11 | 원정 집결지 (350, 430) | 명부·짐·피난 연락을 확인한다. 구조자 수용 여유를 확인한다. |
| P12 | 언덕 피난소 (180, 500) | 부두를 쓰기 어려울 때 항만이 인수한 육상 대기 거점이다. 고도·침수 안전성은 미검증이다. |
| P13 | 연락·관측소 (610, 470) | 출항·미귀환 계획과 현지 관측을 남긴다. 순간통신 장치가 아니다. |
| P14 | 승선 대기장 (485, 100) | 적재 작업이 끝난 뒤 승선한다. 집결 인원을 부두 끝에 한꺼번에 몰지 않는다. |
| P15 | 서쪽 육상 출입구 (80, 370) | 주민·수리 인력의 육상 왕래와 항만 철수를 연결한다. |
| P16 | 습지 바깥 관찰길 (80, 220) | 선택 탐색. 원정 승인이나 식량 확보의 필수 경유지가 아니다. |

도면 위쪽은 북쪽이며 남쪽에 항내 수면을 둔다. y=80 경계와 부두 사각형은 접안·보행 대조용 단순 외곽이다. 실제 세계 해안선이나 방파제·수심 측량 결과가 아니다. 북쪽 완충 숲, 서북 과수·텃밭, 동남 암반 연안, 서쪽 배수 습지를 구분한다. 원정 물자는 이 작은 밭의 생산량만으로 충당하지 않고 기존 항만 거래·저장분을 계약해 사용한다.

창고와 공방은 개별 지붕·출입 연결을 표시하고 8m 주 동선 후보로 잇는다. 습지 선택길은 4m다. R01-R07은 접수소·공방·창고 둘·대기실·피난소·연락탑이며 R08-R10은 항만 숙소·주민 주택이다. 교차점 J01-J07은 길의 연결을 위한 표식이며 새 이야기 장소로 세지 않는다. 배치도는 공간 검토용이고 [결정 47](../../../../decisions/0047-map-working-drawing-detail.md)의 채택 화풍·건축 상세를 완성한 최종 제작 아트로 판정하지 않는다.

## 이동과 철수

| 동선 | 연결 | 사용할 때 |
|---|---|---|
| 도착 접수 | P01-P02-P03 | 연안편의 화물·인원 인계. |
| 개조·시험 | P03-P04-P14-P05 | 수리 검토 뒤 항내 시험으로 간다. 시험 동안 하역·승선 순서를 분리한다. |
| 장비 인수 | P04-J01-P07-P06 | 장부와 물품, 공방의 수정 결과를 대조한다. |
| 식량·급수 | P03-P02-J06-P09, P07-J01-J02-P08 | 별도 저장·검수 대상이며 같은 물품을 중복 계상하지 않는다. |
| 육상 피난 | P05-P14-P04-J01-J02-J03-P10-J03-J04-P11-J05-P12 | 부두에서 난방 대기실을 거쳐 집결·피난소로 이동한다. 하역 중이면 작업을 멈추고 통로를 비운다. |
| 최종 승선 | P11-J04-J03-J02-J01-P04-P14-P05 | 모든 실물 인수와 출항 판단 뒤 이동한다. |
| 항만을 떠나는 육로 | P11-J05-P15 | 원정 취소·육상 대기·주민 이동. 대륙 간 귀환편은 P01-A02 계약을 사용한다. |
| 선택 습지 | P15-P16-J06-P09 | 별도 생태를 관찰하거나 싸울 수 있다. 주 공급 동선과 피난로를 대신하지 않는다. |

주 동선의 중심선뿐 아니라 폭을 고려해 창고·공방 지붕 외곽과 겹치는지 대조한다. 부두 구간은 물 위에 그린 길이 아니라 별도 바닥 후보가 있는 것으로 계산한다. 실제 부두 강도·경사·난간·크레인 회전·수레 회전·들것 폭·NavMesh는 미검증이다.

피난로와 승선로 일부가 겹치므로 둘을 동시에 대규모로 사용하지 않는다. 항만 작업 책임자가 하역을 멈추고 승선자를 집결지에 남긴 뒤 부상자·피난자를 먼저 옮긴다. 이 운영 조건을 없애면 지도에 선이 두 개 있다는 사실만으로 교통이 분리되지 않는다.

## 몬스터·일반 동물·성장

| 단위 | 형태·수량·준비도 | 생활 범위·반응 |
|---|---|---|
| PG1 | MN03-A 늪트롤 1개체 / 24-26 | (75, 300) 저장처 반경 18m, 추격 여유 10m 후보. 버려진 어획 잔해·작은 먹이를 모으며 P15-P16 선택길에 반응한다. |
| PG2 | MN41-A 가는잎 식인덩굴 3개체 / 10-13 | (60, 220) 습지 가장자리 반경 20m, 추격 없음. 작은 동물을 잡는 뿌리 군락이며 P16에 가까우면 접촉한다. |

총 **2형태·2생활 단위·4개체**, 새 구조체·적대 인간조·필수 보스는 0이다. 두 형태는 [현행 SE1 범람원 분포](../2026-11-08-world-distribution-and-leveling/variant-distribution.md#세라디온-47형태)의 범위를 유지하며 남부 습지에 배치한 추가 후보다. 남부 대륙 전체의 기후가 같다는 뜻은 아니다. 더 위험한 변종으로 자동 강화하지 않는다.

물새·어류·작은 도마뱀, 숙소 지붕의 일반 새와 창고 주변 작은 동물이 생태를 이룬다. 일반 동물을 식량 인수의 필수 사냥 목표로 쓰지 않는다. 배수 습지와 생활권은 출항 조건과 무관하게 존재하며, 주인공이 계약서를 읽을 때마다 소환되지 않는다. 항만이 먹이 쓰레기 반출과 경계 관리를 맡는다.

이번 구간은 **52→52**, 선택 성장까지 얻은 경우 **54→54**다. 새로운 상승분 예산은 0·0·0이며 니베르의 3·1·2를 남긴다. 주요 준비 길의 전투가 적은 것은 의도된 인수 구간의 성격이다. 몬스터 생활권은 습지 선택길에 두고, 해상 이동마다 보스나 전투 웨이브를 강제하지 않는다. 실제 경험치·이동 시간·전투 밀도 체감은 미검증이다.
