# 남부 거점에서 니베르행 출항까지

[이번 후보](../2026-11-10-seradion-polar-departure.md)는 준비 서류를 모으는 데서 끝나지 않는다. 주인공이 선원·기술자·항만 담당자와 물건과 동선을 직접 확인하고, 출항 가능한 상태를 인수하는 흐름이다. [G5·T6](../2026-11-08-five-continent-mainline/routes-and-unlocks.md)의 조건은 유지한다.

## 기항항에서 남부로

F03에서 기존 동쪽 강둑 또는 관리교 길로 기항항 A02에 돌아간다. 앞서 해결한 개체·통행 합의를 초기화하지 않는다. 관리회는 주민 급수 담당자와 시험 확대 중지 상태를 다시 확인한 사본을 보내고, 원본·시설 열쇠·조작 권한은 남긴다. 마렌은 구조 요청과 항해 자료의 서로 다른 작성·수신 시점을 표시한다.

A02의 T5 귀환 계약과 남부행 연안 배편은 별도로 처리한다. 주인공과 마렌은 현지 항만이 연결한 연안 운송편을 타고 남부 원정항 P01에 도착한다. 같은 소형 강배가 원양선·극지선으로 바뀌지 않는다. 기항항에서 남부까지의 실제 해안 접속·거리·일수는 미정이며 항로 관계도는 배편과 인계 순서만 보여 준다.

남부 원정항은 탈레아 교역권의 기존 수리·구호 협약을 이용하는 작은 항만 후보다. 새로운 수도나 극지 제국을 만들지 않는다. 관리회 조사비·항만의 원정 계약·조사선 임차를 연결하며 주민 비축·구호품을 무상 징발하지 않는다. 오르다스의 기술 협력은 설계 사본과 질의 경로를 제공하고, 시공·운항 책임은 현지 담당자가 맡는다.

## 준비를 끝내는 사건

| 순서·공간 | 장애와 주인공의 선택 | 완료 결과 |
|---|---|---|
| P03 접수 | 사업단 물품 담당자는 과거 시험 계약을 근거로 장치 상자까지 모두 싣기를 요구한다. 선장은 구조 공간을 먼저 확보해야 한다고 반대한다. | 주인공은 현지 관리회의 구조·조사 우선 임무를 확인하고 필수 기록·소형 대조 장비만 인수한다. 계약 취소·보관비는 원정 담당자가 처리한다. |
| P04·P06 개조 | 익숙한 장인이 만든 사양이라도 다른 배에 바로 맞지 않는다. 보호 덮개가 배수 점검구를 가린 문제가 시험에서 드러난다. | 마렌이 접근 불가 지점을 기록하고 현지 기술자가 덮개를 고친다. 주인공은 운반·철수 공간을 확보한다. 기술자가 같은 점검을 다시 수행하고 선장이 인수한다. |
| P05 항내 시험 | 조타·배수·보온 시험과 구명정 내림을 동시에 하면 좁은 부두에 사람이 몰린다. | 항만 담당자가 시공 작업을 멈추고 시험 구역을 비운다. 선원들이 배수 점검, 비상 조타, 구명정 승선 동선을 순서대로 확인한다. 실패를 성공으로 넘기지 않는다. |
| P07-P09 보급 | 실제 적재 목록에는 귀환분을 조사 연장용으로 함께 표시한 묶음이 있다. 주인공은 기록보다 먼저 구조자 수용 공간과 물·식량의 분리를 확인한다. | 담당자가 전진·귀환·지연·구조자 몫을 구분하고 장부와 적재 위치를 대조한다. 여분 탐사 화물은 항만 창고에 봉인 보관하며 필수 보급은 남긴다. |
| P10-P12 피난 연습 | 부상자를 부두에서 바로 옮기려던 길은 정비 적재와 겹친다. | 주인공은 난방 대기실·집결지·언덕 피난소로 이어지는 별도 길을 걸어 보고 들것·도구를 운반한다. 항만 책임자가 수용과 재보급을 인수한다. |
| P13 연락·P03 합동 인수 | 마렌은 구조 요청의 마지막 위치가 상륙을 보장하는 좌표가 아님을 설명한다. 선장은 수색 범위·철수 기준과 최근 관측을 맞춘다. | 현지 연락 담당자가 원정 사본과 출항·귀환 예정 확인 절차를 보관한다. G5 조건을 모두 인수한 뒤에만 승선 명령을 낸다. |
| P14·P05 출항 | 기상·조석·시야·해빙 정보가 준비 당시와 같은지 최종 확인한다. | 추천 플롯에서는 출항 가능한 창이 확인된다. 주인공과 마렌이 승선하고 본선이 항내를 벗어나 T6로 나간다. 니베르 상륙 성공을 미리 기록하지 않는다. |

개조는 에테르를 무한히 만드는 장치가 아니다. 보온 구획·배수 접근·갑판 미끄럼 대책·구명정과 통신 표식·비상 조타·예비 수리품을 현지 선박에 맞추는 후보로 둔다. 닫힌 빙해를 부수고 달리는 쇄빙선으로 만들지 않는다. 선장은 열린 물길과 항해 가능한 조건을 골라야 하며, 알 수 없는 해빙을 주인공의 힘으로 해결하지 않는다.

주인공은 모든 일의 전문가가 되지 않는다. 수리 판단은 기술자, 적재·복원성·운항 판단은 선장과 담당 선원, 계약·재고·피난 수용은 항만 책임자가 맡는다. 주인공은 동선을 점검하고 현장 불일치를 찾아 위험을 줄이며, 마렌은 시험을 직접 본 뒤 사본에 결과를 남긴다. 누가 서명했는지만 모으는 반복 심부름보다 실제로 달라진 공간과 적재 상태를 보여 준다.

## 긴장과 전투의 위치

항만의 전투는 출항 조건을 채우기 위해 갑자기 등장하는 해수 보스가 아니다. 서쪽 배수 습지에는 기존 범람원형 덩굴·늪트롤 생활권을 두고, 뒤편 길을 탐색하면 접촉할 수 있다. 정문·정비동·식량 창고·승선로는 항만이 관리하는 길이다. 몬스터의 목을 가져와야 선장이 출항한다는 조건은 없다.

니베르 본편의 큰 탐색·전투를 앞두고, 이번에는 이미 배운 판단을 사람과 장비의 준비에 적용한다. 선택 습지 교전은 새 고레벨 형태나 필수 성장 목표를 추가하지 않는다. 늪트롤을 처리했다면 그 결과가 귀환에도 남고, 다른 일지를 읽었다고 같은 개체가 부두에 생성되지 않는다. 일반 물새·어류·도마뱀은 먹이망의 일부다.

## 동료·시설·계약의 인계

| 주체 | 출항 때 가져가거나 맡는 것 | 남겨 두는 것 |
|---|---|---|
| 주인공 | 조사·구조 현장 대응, 개인 장비, 배에 실을 자료 확인 | 시설 운영 권한·주민 비축 |
| 마렌 | 운전 사본·구조 요청 사본·분리 조건을 비교할 질문·수리 도구 | 실패 원인을 단정한 결론, 현지 원본 장부 |
| 원정 선장·승무원 | 새 원정 계약, 조선소 인수, 승선 명부, 출항·철수 판단 | 기존 T5 운항 계약을 마음대로 대체하는 권한 |
| 현지 기술자·항만 책임자 | 남부 거점 유지·예비 보급·피난 수용·연락 인계 | 주인공을 따라 전원 원정을 떠나는 전개 |
| 관리회·나가 연락인 | 주민 급수와 시험 확대 중지 유지 | 해외 장기 동행 |
| 린·이르 | 기존 담당지와 역할 유지 | 갑작스러운 원정 합류 |

새 고정 동료는 추가하지 않는다. 극지 운항 경험이 있는 현지 선원들은 임무 승무원이며, 마렌의 역할을 대체하지 않는다. 새 배편이 생겨도 A02에서 확보한 기존 귀환 계약은 남부 거점에서 돌아갈 연안편과 연결해 유지한다.

이번 끝에서 주인공은 돌아올 사람을 위한 빈 자리를 남겨 둔 갑판을 본다. 모든 장치를 가져가려는 욕심보다 구조·귀환 가능성을 택한 결과다. 바다로 나간 뒤의 서사는 니베르 연안 관측과 실제 상륙지 판단부터 이어진다. 실패 원인 규명·생존자 수·시험 장치 회수·G6는 다음 단계다.
