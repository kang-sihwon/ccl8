# 중앙의 조사·돌파·정지와 다른 귀환길

북부에서 얻은 기록을 실제 중앙 조건에 맞추고, 위험을 나눠 맡긴 뒤 주인공이 마지막 접근을 돌파한다. [이전 이그니스 재검토](../2026-11-08-five-continent-mainline/ignis-story-review.md)의 강제 채취 중단·지역별 인계·CT03 중앙 방어체를 구체화한다. [생활권](populations.md)의 일반 교전은 아래 사건 사이에도 일어나며, 모든 무리가 퀘스트가 시작될 때 생기거나 단서를 주지 않는다.

## 귀환에서 작전 준비까지

1. **도착·공개:** C01에서 북부 인계와 현재 연락을 확인하고 C02에서 사본을 공개한다. 주인공은 북부에서 세운 현장 대조 계획을 제시하고, 현지 담당자가 알려 준 계측 위치·배관의 차이를 반영해 조사 범위를 좁힌다. 기록만으로 즉시 정지할 수 없다는 앞선 판단을 실제 협업으로 옮긴다.
2. **비축·사람:** C03-C05에서 수령 재고와 대체 운용의 적용 범위를 확인한다. 상회의 손실과 주민의 보호 요구가 충돌한다. 주인공은 자기 신뢰만 요구하는 대신 수령·시험·담당자의 확인을 공개하고, 린의 운송 소식이 실제 인수로 이어질 때까지 예정 물량을 제외한다.
3. **바깥 조사:** C06 허가 뒤 O01-O02-O03-O04-O05-O10을 탐색한다. 분해목 굴조·경갑·잔근 정리형·낙엽형이 각 생활권에서 움직인다. O03 표본과 O04 관측으로 현재 운용이 북부 도면과 다른 지점을 특정한다. 샘과 균류 움푹터는 선택 탐색이고 돌아오는 길에는 같은 개체가 먹이 이동을 마쳤을 수 있다.
4. **안쪽 예비 조사:** 정비 담당자의 동행 허가로 F01-F03과 F05를 점검한다. F06 너머는 잔여 지휘부가 점유한다. 현재 부하·회수조·필수 분기를 최종 정지대에 들어가기 전에 확인할 수 있으므로 조사 권한과 최종 접근의 조건이 순환하지 않는다. IC1·천공충을 상대하거나 가동 틈을 읽어 관측자를 보호한다.
5. **시험·대피·명령:** F02 시험과 C03-C04의 필수 수요·재고 대조가 통과하면 시민 대표·현장 책임자가 제한 중단 명령을 낸다. 부족하면 추가 감산·비축·대피를 준비하고 O01/F01로 철수한다. 이르는 작업하지 않는 사람을 F01 밖으로 인계한다. 안전을 확인하지 않은 채 플레이어에게 정해진 제한 시간 안에 돌진하라고 요구하지 않는다.

도시에서 준비를 끝냈다가 다시 외측 조사로 나올 수 있다. 조사 자료를 전달하는 연락편·책임자를 두고 장거리 왕복을 대사 한 줄의 즉시 통신으로 바꾸지 않는다. 실제 소요 시간과 대기 기간은 미정이다.

## 잔여 지휘부와 중앙 방어체

F06 보호 경비는 새 명령과 대피 인수를 확인하고 임무를 바꾼다. 남은 지휘관 1명·경비 4명은 기록 압수와 작업문 통제를 유지한다. 사람을 설득하거나 제압해 통제를 확보하되, 지휘관을 죽여야 문이 열린다는 규칙은 두지 않는다. 무장 충돌 시 경비의 방패·측면 접근과 지휘관의 전진 명령을 읽고 정비조와 분리한다. 한꺼번에 CT03까지 같은 좁은 목으로 끌어오지 않는다. 지휘부 돌파 뒤 부상자·소모품·공급 상태를 다시 확인할 여유를 둔다.

F07의 **CT03-B 중앙 작업문 개체(24)**는 넓은 가슴판·지지다리·다중 잠금부를 갖는다. 주인공은 물리적 문과 정비 접근을 차지한 장치를 직접 제압한다. 멀리서 차단기만 눌러 끝낼 수 없지만, 필수 공급을 끊어 거대한 폭발로 해결할 필요도 없다.

| 관찰할 동작 | 압박·대응 | 빈틈과 작업 결과 |
|---|---|---|
| 관측부가 한 방향에 고정되고 지지발이 벌어짐 | 전방 밀기. 옆 6m 통로로 피하거나 선택한 방어 행동으로 버틴다. | 멈춘 뒤 지상 지지부가 노출된다. 무기 종류를 필수 열쇠로 두지 않는다. |
| 넓은 팔이 수평으로 잠긴 뒤 회전 | 측로 하나를 쓸며 몰아낸다. 벽 칸막이를 이용하되 끝 구석에 갇히지 않는다. | 팔 회수 중 가슴판 아래 연결과 반대 지지부가 열린다. |
| 지지부 일부가 멈추고 잠금 순서를 바꿈 | 빠른 재정렬·짧은 전진으로 빈틈이 달라진다. 같은 정면 공격 반복을 피한다. | 주인공이 장치를 묶어 두는 동안 마렌과 기술자가 방어 전용 축적부를 분리한다. |
| 공격이 멎고 작업문 잠금이 해제됨 | 장치 움직임과 잔류를 다시 확인한다. 즉시 보상창 뒤로 사람을 밀어 넣지 않는다. | 정비조가 F08로 들어갈 수 있다. 강제 채취 정지는 별도 절차다. |

전투는 주인공의 공격·관찰·위치 판단이 장치의 지지·잠금을 실제로 무력화하는 구조다. 기술자가 모든 전투를 대신 해결하지 않는다. 실패하면 F06-F04-F03-F02-F01로 후퇴하고, 대피·비축·부상·방어 잔류를 다시 확인한다. 이야기의 재진입을 새 위기나 무한 자원 초기화로 설명하지 않는다. 실제 체크포인트·보스 체력 리셋·멀티플레이 사망 처리와 무기별 패턴은 별도 제작 사양이다.

## 정지·귀환 상태

| 상태 | 닫힌 연결 | 가능한 행동 |
|---|---|---|
| 조사 단계 | F06-F07, F07-F08, F08-F09 | F03·F05 예비 관측, F10-F09 외부 확인, F01 철수. 서쪽 문으로 정지대를 먼저 차지할 수 없다. |
| 공급·대피·명령·지휘 확보 | F07-F08, F08-F09 | F07 전투 접근. 이전 조사·퇴로는 유지한다. |
| 방어 격리 확인 | F08-F09 | F08 작업 접근, 강제 채취 감산·정지·재가동 잠금. 방어체 정지만으로 강제 채취가 꺼지지는 않는다. |
| 정지 확인·안쪽 수동 해제 | 없음 | F08-F09-F10-F01의 다른 귀환길. 필요하면 진입로로 돌아간다. |

표의 ‘닫힘’은 작업문·통제 구획을 통한 이동 상태다. F06의 명령 확보와 공급·대피 준비를 모두 만족해야 다음 상태로 간다. 정지 조건이 무너졌을 때는 문이 마법처럼 다시 잠기는 대신 작업을 중지하고 이미 열린 퇴로로 철수한다. F08-F09의 안쪽 해제는 필수 공급 전원과 독립된 수동 장치다.

F08에서는 F05의 회수 여유와 F03의 감산 관측을 다시 확인한 뒤 강제 채취만 멈춘다. 정상 공급·비축·감산 배정은 남는다. 회복은 곧바로 초록빛 숲이 되는 연출이 아니라 확대 가동 소음의 감소, 남은 서리·분해목, 정비조의 다음 교대와 주민의 배급 확인으로 보여 준다. 같은 생태의 몬스터를 전부 제거한 결말도 아니다.

## 왕복과 성장·해외 연결

| 동선 | 중심선 길이 | 역할 |
|---|---:|---|
| 도시 준비 C01-C02-C03-C04-C05-C06 | 3,766.7m | 조사·재고·필수 공급·작업 인계. 도시 전투를 강제하지 않는다. |
| 뿌리권 조사 O01-O02-O03-O04-O05-O10 | 2,799.6m | 일반 생활권을 거쳐 현재 설비의 차이를 읽는다. |
| 뿌리권 귀환 O10-O05-O04-O09-O01 | 3,126.6m | 일부 공유 구간 뒤 건조 둔덕으로 돌아온다. 다른 길이라고 같은 개체를 새 적으로 복제하지 않는다. |
| 안쪽 조사 F01-F02-F03-F04-F06 | 1,749.5m | 부하·명령·통제 목을 확인한다. F03-F05-F06의 별도 배출 점검 1,518.2m도 가능하다. |
| 최종 접근 F06-F07-F08 | 919.2m | 잔여 지휘 확보 후 방어체를 돌파하고 정지대에 접근한다. |
| 정지 뒤 귀환 F08-F09-F10-F01 | 3,237.3m | 잎몸 수호령·균류군이 남은 외벽 길. 위험하면 기존 진입로로 철수한다. |

거리와 생활권 접촉은 [계산 데이터](../../../../ArtDirection/EtherWorldMap/Data/central-exploration-v1.json)의 투영 평면 비교다. 실제 이동·전투 시간이나 체감 난도는 계산하지 않았다. 도시·연결 회랑·확대도 거리를 합쳐 전부 하나의 도보 임무로 강제하지 않는다.

성장은 **야외 탐색·교전 +1, 인간 통제·중앙 방어체·정지 목표 합산 +1, 조사·공급·관계 인계 +1**로 21→24다. 주요 상대마다 +1씩 더하지 않는다. 교섭·우회로 같은 목표를 해결했을 때 공통 보상을 중복 지급하지 않는다. 선택 수피형·일반 동물·반복 사냥은 본편 성장의 필수 조건이 아니다.

C07로 돌아와 현장 관측·재가동 잠금·부품·교대 책임을 인수한다. 린의 운송 인계와 로덴·하르덴 협력은 각 지역에 돌아갈 책임을 남긴다. 이르는 북부와 중앙의 피난 연락을, 마렌은 현지 정비조의 다음 작업을 정리한다. 주인공은 다시 모든 수리를 자기 몫으로 붙들지 않는다.

[G2](../2026-11-08-five-continent-mainline/routes-and-unlocks.md)의 조건은 G1과 중앙 강제 채취 중단·필수 운용 인계, 가공장 조합의 기술 교류·사고 조사 계약 수락이다. 레벨 24나 방어체 처치만으로 해외 본편이 열리지 않는다. G1을 앞서 하지 않았다면 세르나의 반출·로덴 수령·수리 인계·왕복편 조건을 함께 확인한 뒤 G2를 이어간다. 이그니스의 성과를 남긴 짧은 후일담 뒤 아르베나 정식 조사로 연결하며 원양선은 계약 선박이다. 린의 작은 강배를 그대로 대양에 띄우지 않는다.
