# 하구·항만의 몬스터 생활권과 일반 생태

[현행 S3 분포](../2026-11-08-world-distribution-and-leveling/variant-distribution.md)의 **5항목·7형태를 12생활 단위·33개체**로 배치한다. 하구 17, 항만·연안 16개체이며 청등 사건 개체와 선택 능갑 개체를 포함한다. 일반 동물·선원·경비·구조체는 이 수에 포함하지 않는다. 이번 구간에 새 구조체 모델이나 몬스터 종을 더하지 않는다.

상위 문서는 [세르나 탐색 후보](../2026-11-08-roden-serna-exploration.md)다. 외형은 [기존 형태 원문](../2026-11-08-monster-variants/field-forms.md)과 [청각형](../2026-11-08-worldwide-monster-variants/overseas-forms.md), [수침형](../2026-11-08-worldwide-monster-variants/ignis-completion.md)을 보존한다. 원문의 옛 대륙·수치는 현행 분포표로 읽는다. 피부색만으로 강함을 결정하지 않고 크기·장갑·동작·서식 조건의 차이를 쓴다.

## 생활 단위와 교전

| 단위·수량 | 형태·준비도 | 생활·흔적·전투·회피 |
|---|---|---|
| EC1 4 | 자갈등 MN06-A 4, 8-11 | C05의 조수 배수로·작은 그물 잔해에서 먹이를 수거한다. 자갈 등판·짧은 집게·옆걸음이 특징이다. 물결과 긁힌 발판으로 읽고 열린 쪽을 선택한다. |
| EC2 3 | 자갈등 A 2, 8-11 / 판석등 MN06-B 1, 11-14 | C11의 오래된 잔해가 큰 먹이를 붙잡는다. 판석등은 넓은 회색 층판·굵은 한쪽 집게로 길을 민다. 뒤쪽 관절·회수 동작을 노리거나 C10 상단으로 물러난다. |
| EU1 4 | 청각 MN05-X 4, 5-9 | C06의 폐보온관 유기 피복·남은 온기를 이용한다. 푸른 투명 턱과 긴 촉각이 틈에서 먼저 보인다. 남은 공급을 정지하면 열린 벽면으로 나온다. 공급이 끝난 뒤에도 무한 번식하지 않는다. |
| EH1 3 | 갈매깃 MN21-A 3, 10-14 | 숲 가장자리 휴식처에서 C07·C10의 버린 어획물 운반대까지 오간다. 1마리 경계·2마리 수거 후보지만 고정 직업은 아니다. 짧게 날아 공격한 뒤 낮은 턱에 내리므로 근접·원거리 모두 접근 창이 있다. |
| ED1 3 | 수침 MN45-A 3, 10-14 | C09 옛 매장처의 제한된 의식 연결이 세 사체를 움직인다. 사체 자체·감염·검은 결정의 무한 동력을 원인으로 쓰지 않는다. 연결 범위 안에서 느리게 붙잡고 몸을 다시 세운다. 선택 조사로 연결을 끊고 기록·매장을 인계한다. |
| HC1 3 | 자갈등 A 3, 8-11 | H05 서쪽의 방치 그물·연안 잔해에 산다. 정상 부두의 모든 인부를 상시 공격하는 포위 상태가 아니다. 폐어획물 치우기와 수거 시간 변경으로 충돌을 줄인다. |
| HC2 4 | 자갈등 A 2, 8-11 / 판석등 B 2, 11-14 | H07 좌초선 아래 엉킨 물고기를 먹는다. 구조 때 사다리로 올라오지만 한꺼번에 4마리가 같은 발판을 차지하지 않는다. 아래 갑판을 내주고 높은 선미를 지키며 부상자를 옮긴다. |
| HU1 3 | 청각 X 3, 5-9 | H04의 인양된 보온관 잔재와 유기물에 붙는다. EU1과 별도 개체다. 정상 창고를 감염시키는 적이 아니라 격리 검사뜰의 생활권이다. |
| HH1 2 | 갈매깃 A 2, 10-14 | H11 바깥 절벽에서 남은 어획물과 인양 바구니를 나른다. 울음·날개 그림자로 예고하며 공공길 경계 밖에서 돌아간다. 돌아올 때 처음 본 두 개체가 남아 있을 수 있다. |
| HD1 2 | 수침 A 2, 10-14 | H12 동쪽의 격리 인양 매장물에 붙은 별도 유한 연결이다. C09와 같은 원격 군단이 아니다. 최근 구조 선원이 죽으면 자동으로 이 무리에 추가되는 규칙은 없다. |
| HS1 1 | 청등 MN10-A 사건 개체, 14 | 푸른 회색 등·짧은 갈퀴·빠른 측면 충돌. 어군과 좌초선 먹이 주변을 오가며 선저 양쪽을 바꿔 접근한다. 암반 돌진 뒤 옆구리가 드러나는 순간 직접 공격해 구조 시간을 만든다. 최종 생사는 보류한다. |
| HS2 1 | 능갑 MN10-B, 16-20 | H13 깊은 홈의 큰 성체. 짙은 등·높은 갈퀴·굵은 목과 큰 파문이 경고다. 구조 항로와 겹치지 않는 선택 위험이며 청등 뒤의 필수 2차 보스가 아니다. |

수침형의 의식 연결 범위·유한 소모는 이번 국소 후보이며 신화·종 전체의 기원을 확정하지 않는다. 두 매개를 없애도 세계 모든 언데드가 사라지지 않는다. 검은 결정의 정본 규칙과 다른 현상을 편의상 같은 원인으로 묶지 않는다.

## 거점·이동·추격 범위

| 단위 | 거점 반경 / 이동 띠 반폭 m | 역할·연락·추격 종료 |
|---|---|---|
| EC1·EC2·HC1·HC2 | 120·135·120·35 / 없음 | 먹이·물기·잔해 안에서 최대 25-40m 반응한다. 큰 원은 먹이권이지 집게 사거리다. HC2는 갑판 가장자리에서 돌아가며 수상 구조 배까지 계속 증원되지 않는다. |
| EU1·HU1 | 110·85 / 없음 | 피복·잔류 온기 근처에서 35m 이내 추격. 격리판·마른 뜰 경계에서 돌아간다. 인양한 한 관에서 도시 전체 군체가 생기지 않는다. |
| EH1 | 140 / 65 | 거점↔C07↔C10↔C07↔C08 바깥의 어획물 이동. 동시에 모든 점에 서 있지 않는다. 반응 지점 80m 안·활동 띠 안에서만 추격하며 창고 지붕 너머까지 자동 경보를 보내지 않는다. |
| ED1·HD1 | 85·70 / 없음 | 매개와 연결된 범위에서만 움직이고 반응 지점 25m 안에서 붙잡는다. 대피로 밖 매개를 먼저 조사할 수 있지만 모든 교전을 공짜로 건너뛴다고 보장하지 않는다. |
| HH1 | 130 / 55 | 절벽↔잔여물 수거턱↔제방 바깥 이동. 70m 이내 추격과 공공 관리선에서의 이탈을 함께 둔다. |
| HS1 | 85 / 25 | 어군·좌초선·수중 홈을 따라 이동한다. 원과 띠는 수중 잠재 활동권이다. 바위 윗면까지 평면 원을 채워 적이 걷는 것으로 해석하지 않는다. H09에서 승선하더라도 린의 항로 이탈 판단까지 필요하다. |
| HS2 | 180 / 없음 | 깊은 홈의 먹이권이며 실제 추격은 120m 이내·깊은 수로 안의 후보. 구조 수로로 자동 합류하지 않는다. |

모든 추격은 반응 지점 거리와 활동권·지형·목적 조건 중 먼저 끝나는 조건을 따른다. 근거리 적은 보통 2-3개체 대응을 목표로 하되, 구체적인 동시 공격·합류·패턴·회피 폭은 미검증이다. HC2와 HS1이 같은 평면에 가깝더라도 갑판의 갑각류와 수중 해수를 같은 지상 적 5마리로 계산하지 않는다. 남아 있는 갑각류는 그물 쪽으로 물러나게 유도하고 선미 진입을 관리한다.

## 일반 동물과 인간 세력

갈매기·도요새·갈대새·어류·일반 패류는 먹이와 조수 변화를 보여 준다. 하구 상단에는 작은 설치류·토끼, 한적한 연안 바위에는 물개류를 둘 수 있다. 정상 부두에는 고양이·쥐·일하는 말이 있고 먹이·쓰레기·운반과 연결한다. 몬스터 돌등게와 일반 작은 게·패류를 외형 크기·행동으로 구분하며 일반 동물 사냥을 성장의 필수 재료로 삼지 않는다.

도시 배정소는 계약·필수품 우선 배정권을, 선주들은 배·운항 판단을, 부두 노동자는 하역 지식과 인력을 가진다. 연맹 현장 책임자는 실종선 출고 보고를 숨기고 일부 상인은 물량을 붙잡지만, 모든 상인·도시 경비가 공모한 것은 아니다. 별도 인간 사건의 지휘관 1명·경비 5명, 준비도 10-14를 후보로 둔다. 일부는 명령을 따르고 일부는 봉인 확인 뒤 물러나거나 계류 해제를 돕는다. 이 6명을 몬스터 도감이나 상시 필드 스폰에 넣지 않는다.

작업자는 인양품·폐어획물·배수 관리로 생활권 충돌을 줄이고, 선주들은 구조 신호·회항 부표·대체 배편을 공유한다. 구조 성공이 계약·생계 손실을 전부 없애거나 해수를 모두 퇴치해 바다를 비우는 결과로 이어지지 않는다.
