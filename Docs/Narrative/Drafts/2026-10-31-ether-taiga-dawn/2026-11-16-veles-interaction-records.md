# 벨레스 첫 장 상호작용·작업 기록 상세

**VI01-VI08의 관찰·질문·기록을 현재 장면에 연결한 후보 묶음이다.** NG09의 [완료 기준](../../WorkGroups/next-workgroups.md#ng09-첫-장-상호작용작업-기록-상세)을 따른다. NG01-NG08의 확정은 유지하며 정본·기존 원고를 수정하지 않는다. 현재 단계와 검토 결과는 [CurrentWork](../../CurrentWork.md)가 소유한다.

| 읽는 때 | 문서 |
|---|---|
| 장면의 실제 행동·정보·피드백을 대조할 때 | [상호작용](2026-11-16-veles-interaction-records/interactions.md) |
| 정상·작업 전 귀환·부분 수행·인수 부족의 기록을 비교할 때 | [기록 예문](2026-11-16-veles-interaction-records/records.md) |
| 누락된 사실을 묻고 현재 근거를 찾는 짧은 표현을 볼 때 | [누락 대응](2026-11-16-veles-interaction-records/repairs.md) |
| 채택 추천 IR01-IR06·대안 IRA·보류 IRH를 고를 때 | [선택표](2026-11-16-veles-interaction-records/options.md) |

## 입력과 새 후보의 차이

| 기존 확정·입력 | 유지할 의미 | 이번에 비교할 새 상세 |
|---|---|---|
| [PR](../../Scenario.md#벨레스-첫-장의-진행과-재개), 결정 61 | 실제 정보·작업·인수·현재 운영과 저장 복원을 구분한다. | 행동 뒤 어떤 결과를 짧게 알려 주고 무엇을 미확인으로 남길지 쓴다. |
| [VD](../../Scenario.md#벨레스-첫-장의-공간운영전투-검증-기준), 결정 62 | 문서·실제 실행, 공간·전투·운영 검사를 나눈다. | 가시성·읽힘·인지의 가정과 후속 확인 질문을 붙인다. |
| [IW](../../Scenario.md#벨레스-첫-장의-표현과-작업-기록), 결정 63 | 휴대 기록, 계획/수행 구분, 부족한 내용만 보완한다. | 현재 사실과 전달 출처를 붙인 실제 기록 예문·짧은 문답을 쓴다. |
| [VI](2026-11-15-veles-integrated-manuscript/information.md), [MS](2026-11-15-veles-integrated-manuscript/manuscript.md), [C](2026-11-15-veles-integrated-manuscript/variants.md) | 기존 정상·불완전 사례의 시작 상태를 유지한다. | 같은 시점에 비교할 행동·표현을 추가한다. 옛 원문 전체를 교체하지 않는다. |
| [완료 지도](../../WorkGroups.md)의 NC·IB·JC·HO와 공통 경계 | 첫 장 끝·역할·후속 전달과 실제 인수는 각각 유지한다. | 로덴용 기록은 전달할 자료이며 수령·적용·회신 성공을 미리 적지 않는다. |

이 문서의 대사·기록은 새 예문이며 원문의 직접 인용이 아니다. 예문에 적힌 성과는 지정한 사례에서 실제 확인·수행했을 때만 성립한다. 예문을 선택하거나 읽은 행위 자체는 그 성과를 만들지 않는다. 사실이 없는 칸은 비어 있다는 이유로 성공 처리하지 않고 ‘미확인’ 또는 ‘미수행’이라고 드러낸다.

## 문서 검토와 실행의 경계

검토할 것은 VI 여덟 항목의 출처·주체·행동·피드백·다음 행동, 기록 사례의 차이, C03-C06·C03-R·C06-M의 현재 근거와 미완료 유지다. 실제 게임의 입력·자동 판정·기록 보존·공간 가시성·플레이어 이해·전투 중 읽기·음성 접근성은 검증하지 않는다.

원문·대안·보류·도안·좌표·수치를 유지한다. 기존 외부 블록아웃 증거를 지하·전투·정보 인지 검증으로 확대하지 않는다. 진행 조건을 바꾸는 제안은 없으며, 정확한 문구와 UI·매체 제작은 추천 범위의 자동 채택 대상이 아니다.
