# 이그니스 S1-S6 전체 여정 연결 점검

후속 [세르나 출항·아르베나 첫 탐색](2026-11-09-serna-arvena-passage.md)은 G1 선택 왕래·G2 최초 방문과 재방문, 계약선 환승·동료와 설비 인계·공개 탐색·조사 구획을 연결한다. 기존 사건·분포·해금은 유지하며 원문은 비교 자료로 보존한다.

벨레스의 수원 복구에서 시작해 로덴 구조, 세르나 운송, 하르덴 수리, 북부 기록 회수, 중앙의 강제 채취 정지로 이어지는 흐름을 유지한다. 지역을 떠날 때마다 **현지에 남을 담당자·운영 조건·다음 목적지로 가져갈 자료**를 나눠 인계한다. 문제를 발견하는 즉시 다음 보스를 찾아가는 흐름보다, 탐색 중 만난 위험과 사람의 선택이 다음 이동을 만드는 방향이다.

상태는 `DISCUSSION`이며 독립 검토는 수정 후 PASS다. 이번 문서는 기존 S1-S6 후보를 대조한 연결 보완이며 정본 승인이 아니다. 첫 장의 벨레스 출항, 36정착지, 64항목·199형태, G0-G6와 모든 무기 사용을 유지한다. 각 지역의 상세 배치 기준은 아래 소유 문서에 남긴다.

## 점검 결과와 반영

| 항목 | 판단과 보완 |
|---|---|
| 사건 인과 | S2에서 연결 확인 전 성급히 차단한 실수를 인정하는 경험이 S3에서 린의 철수 판단을 따르는 선택으로, S4의 제한 운전과 S6의 공급을 보존하는 정지로 이어진다. 흐름 유지. |
| 첫 화물과 후속 화물 | S3 첫 허가 화물은 로덴 수령·회신까지 끝낸다. S4에서 함께 타는 것은 **후속 정기 상행편의 일반 화물**로 명시했다. |
| 로덴 설비 책임 | S4 종료 때 현지 담당자의 인수 동의·축소 운영·다음 보충을 확인한다. 담당자 지정과 로덴의 실제 적용 성공은 별개다. 버틸 조건이 없으면 북행을 늦춘다. |
| S1 파생형 | 기존 고블린 14명의 위치·활동조를 유지하고 잎빛 9명·회등 5명을 배정했다. 피부색이 직업·적대성·정확한 레벨을 결정하지 않는다. |
| S2-S6 분포 | 현행 분포표의 형태 집합·구간 범위와 각각 일치한다. 수량은 국소 설계 개체이며 지역 전체 개체 수나 필수 처치 수가 아니다. |
| 성장 | 기본 여정 1→6→10→14→18→21→24 유지. G1 선택 탐색의 추가 성장은 유지하며 적 자동 스케일링이나 복귀 시 레벨 초기화를 넣지 않는다. |
| 이동과 권한 | 공공 환적장·도시 통과와 S6 안쪽 설비 출입권을 분리한다. 하르덴 복귀와 북부 왕복은 실제 R4·R3·B03·B04·고개 회랑을 따른다. |
| 동료 | 린의 벨레스 잔류→후속 회차 타르넬 합류→세르나 잔류, 마렌의 로덴 대체 담당자, 이르의 북부 대체 담당자를 연결했다. 순간 합류·즉시 회신은 없다. |
| 읽기 경로 | 이전 대륙 플롯의 ‘린 합류 추후 작성’ 안내에 이미 작성된 S2 상세 링크를 보충했다. 옛 원고는 보존했다. |

추천은 기존 경로를 유지하고 인계와 선택 분기를 보완하는 안이다. 로덴을 S4 뒤 필수 재방문으로 바꾸는 대안은 직접 결과를 확인할 수 있지만 장거리 왕복과 S5 진입 지연이 늘어난다. 따라서 기본은 담당 운송자를 통한 인계, 재방문은 선택으로 둔다. 세계 전역에서 같은 시각에 위기가 끝나는 설정도 넣지 않는다.
