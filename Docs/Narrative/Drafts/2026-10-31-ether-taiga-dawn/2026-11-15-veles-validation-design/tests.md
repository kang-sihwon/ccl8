# 통행·전투 검사 명세

2026-11-15 사용자 승인으로 VD01-VD06과 공통 경계를 [결정 62](../../../../decisions/0062-veles-validation-design-adoption.md)·[Scenario](../../../Scenario.md#벨레스-첫-장의-공간운영전투-검증-기준)에 반영했다. 이 채택 범위는 `CLOSED`다. [반영 독립 검토](../../../Reviews/2026-11-15-veles-validation-adoption-review.md)는 PASS이며 잔여 지적은 없다. VDA01-VDA02·VDH01-VDH06과 아래 원문·도안·좌표·수치는 보존한다. SP·GX·WC·OP 및 상세 표·실행용 가정 전체는 일괄 정본화하지 않았고 실제 GX·WC 검사는 모두 미실행이다. 아래 후보·미채택·다음 선택 표현은 작성 당시 기록이다.

**검사는 시작 조건과 실제 관찰을 함께 남겨야 통과 여부를 판단할 수 있다.** GX01-GX12는 경로·미완료 사례, WC01-WC06은 각 무기의 공격·대응·이격 검사다. 아래 통과·실패는 후속 실행의 판정 기준이며 현재 결과는 모두 **미실행**이다. [공간 SP](spatial.md)·[운영 입력](operations.md)·[실행 인계](handoff.md)를 함께 사용한다.

## 공통 실행 입력과 기록

각 기록은 빌드·맵·콘텐츠 버전, 원천 참조·배치 변환, 선택 경로, 실제 무기/행동 정의·장비·체력·회복·탄약, 현재 적의 식별자·위치·성과, 실제 관찰한 정보·미완료 작업·인수·재고·시각, 실행 모드·참가자·입력 조건을 가진다. 같은 세계에서 이은 것인지 새 비교용 초기 상태인지 명시한다. 시험 시작용 상태 주입을 허용한 경우 그 구간 이전의 실제 플레이·복원 성공까지 증명한 것으로 쓰지 않는다.

판정은 `미실행`, `선행 미결`, `통과`, `실패`, `판정 불가`로 나눈다. 기능·배치가 없으면 선행 미결이며 실행한 뒤 관찰을 얻지 못했으면 판정 불가다. 실패는 원인과 해당 조건을 붙인다. 실행 한 번의 성공은 지정한 초기 상태·무기에 한정하고 모든 경로·적 위치·숙련·접속 환경의 보장이 아니다. 반복 횟수·시간·난도 목표는 사전 선택한 실행 계획에 기록하며 이번에 숫자를 만들어 넣지 않는다.

## 모든 무기 선택을 검사에 반영하는 법

현재 [무기 목표](../../../../decisions/0037-unrestricted-protagonist-weapons.md)는 모든 무기 선택이며, 실제 지원 종류·행동은 별도다. 따라서 이름 몇 개를 예시로 검사하고 전체 무기를 통과했다고 쓰지 않는다. 후속 실행 전에 **실제 지원하려는 모든 무기 정의·사용 손·행동·탄약/매개·장비 조건**을 한 명부에 열거하고 각 항목을 아래 WC에 연결한다. 미구현 종류·목록 자체의 빈칸은 누락으로 남긴다. 해당 없음은 이유와 소유 근거가 있을 때만 쓰며 무기 목표를 축소하는 면제로 쓰지 않는다.

| WC04 투사·원거리 | 실제 지원하는 발사·조준·장전 행동과 탄약/자원으로 두 단계 결박을 검사한다. | 눈에 보이는 표적과 발사 원점의 가림을 구분하고 실제 발사체가 닿는다. 사거리 밖 안전 지대에서 전투·이격을 생략하는 방식으로 정상 성공을 대체하지 않는다. | 조준 시야·총구/발사점·탄도·비행시간·명중/소모·재장전·적의 실제 대응. 무한 탄약으로 자원 통과를 주장하지 않는다. |
| WC05 지속·범위·매개 행동 | 실제 지원 목록에 있을 때만 지속·범위·자원 의존 행동을 같은 표적에 검사한다. | 표적 선택·중복 적중·소모가 실제 정의와 맞고 곰 사망·정상 설비 파괴로 해방을 대신하지 않는다. 속성 하나를 필수 해법으로 만들지 않는다. | 범위·차폐·유효 접촉 시점·유지 비용·중단·해제된 연결의 재적중. 해당 무기 구현이 없으면 미검증이다. |
| WC06 전 무기 공통 이격·재개 | 각 명부 항목에서 결박 전/부분 해제/생존 이격, 실내·G04 접근, 철수·재접근을 비교한다. | 해당 장비가 제공하는 실제 행동으로 위협을 읽고 공격·대응·이격을 연결한다. 모든 무기에 같은 가드·패링·에테르 행동이 있다고 가정하지 않는다. | 장비·손 조합, 공격/방어 비용, 실제 이격 경로·카메라·현재 곰 상태·보존 성과. |

각 실제 무기는 관련 WC와 GX01·GX02·GX04·GX05·GX06·GX09에 연결한다. 무기별 지원 동작이 다른 경우 검사 행동도 그 정의를 따르며 최종 정상 진행의 요구는 유지한다. 한 특성의 대표 무기로 먼저 문제를 찾을 수 있지만 다른 무기의 통과로 대체하지 않는다. 첫 예비 검사를 한 동작 세트로 시작하더라도 나머지는 계속 미검증이다.

공격 창은 화면상 빈틈만으로 판정하지 않는다. 실제 선택한 행동의 준비·이동·접촉(발사체면 비행)과 유효 표적 시간이 겹치는지, 그 전후에 접근·대응·이격이 가능한지 기록한다. 난도·피해량·모든 사용자 숙련의 적정성은 별도 플레이 검증이다. 새 초 단위 목표나 표적 크기를 이 문서에서 확정하지 않는다.
