# 운영·성장의 가정과 판정 입력

2026-11-15 사용자 승인으로 VD01-VD06과 공통 경계를 [결정 62](../../../../decisions/0062-veles-validation-design-adoption.md)·[Scenario](../../../Scenario.md#벨레스-첫-장의-공간운영전투-검증-기준)에 반영했다. 이 채택 범위는 `CLOSED`다. [반영 독립 검토](../../../Reviews/2026-11-16-adoption-summary.md#결정-62)는 PASS이며 잔여 지적은 없다. VDA01-VDA02·VDH01-VDH06과 아래 원문·도안·좌표·수치는 보존한다. SP·GX·WC·OP 및 상세 표·실행용 가정 전체는 일괄 정본화하지 않았고 실제 GX·WC 검사는 모두 미실행이다. 아래 후보·미채택·다음 선택 표현은 작성 당시 기록이다.

**현재 재고와 예정 거래, 작업 비용과 성장 보상을 각각 기록한다.** [PR06](../../../Scenario.md#벨레스-첫-장의-진행과-재개)이 요구하는 근거를 수치·단위·발생 시점으로 바꿀 입력 명세다. 이번에는 실제 비축·시간·경험치를 산출할 데이터가 없어 성공 일수나 적정 도착 레벨을 계산하지 않는다.

입력마다 `원문 근거`, `실측`, `실행용 가정`, `미확인`을 표시한다. 임시 실험값을 쓴다면 별도 실행 사본에 값·선정 이유·단위·적용 구간을 기록하고 원본 수치·정본은 고치지 않는다. 가정값으로 통과한 결과는 그 가정 범위의 결과다.

## 시간별 운영 판단

자원 종류 k에 대해 사용 시각 t까지의 잔량은 `초기 사용 가능량 + 실제 인수 완료한 보충량 - 생활 소비 - 완료/진행 작업의 실제 소모 - 운반·손실·예약으로 사용 불가해진 양`으로 대조한다. 항목은 같은 자원·단위에서만 더하고 뺀다. 각 사용 시점에 필요한 양과 접근 가능성이 있어야 하며, 마지막 잔량이 양수여도 도중 고갈이 있으면 정상 지속을 인정하지 않는다.

미래 보충은 필요한 시각 전에 실제로 받을 조건이 있을 때만 계획 입력에 사용하고, 실제 도착과 계획을 장부에서 구분한다. 도착 지연·길 차단이 있으면 영향을 받은 작업·인수·출항 판단을 갱신한다. 기계 손실·사람 노동·부피·무게처럼 서로 다른 제약을 하나의 에너지 수치로 환산하지 않는다. 시간 단위·소비 곡선·동력 용량이 없으면 충분/부족을 계산할 수 없다.

| 운영 비교 | 입력을 바꿀 지점 | 기대 판단·측정 |
|---|---|---|
| 정상 한 번 왕복 | 확인된 초기량·실제 이동·작업·인수 | 필요 시점별 사용 가능량과 완료 작업을 대조한다. 현재 데이터를 채우기 전 성공으로 쓰지 않는다. |
| 복구 전 철수·재출발 | 현장 성과 없음, 왕복·비상 운반의 추가 시간과 소모 | 남은 자원으로 재작업 가능한지 다시 판단한다. 비축 고갈을 숨기거나 정해지지 않은 파국을 추가하지 않는다. |
| 부분 복구 후 재접근 | 끝낸 작업·사용량은 유지, 남은 작업과 접근 비용만 추가 | 이미 지불한 비용의 이중 청구·회수한 파편의 복제·무상 동력 재충전을 검사한다. |
| 보충 지연·일부 부족 | 실제 인수량/시각·담당자 여력 변경 | 공급 전 소비 구간의 부족을 드러내고 영향을 받은 작업·인수만 재판단한다. |
| 아침의 새 이상·출항 지연 | 새 소비·재작업·배편 조건 | 과거 성과와 현재 출항을 분리한다. 추가 시간·운항 대응을 모르면 판정 불가로 남긴다. |

## 성장 비교의 기준과 제한

[현행 성장 원문](../2026-11-08-world-distribution-and-leveling/progression.md)의 S1 `1→6`, 야외 3·주요 목표 1·조사/관계 1은 **레벨 상승분 환산 예산 후보**다. 그대로 보존하며 실제 XP 공식·최고 레벨·바르툴 도전 자격으로 쓰지 않는다. [S1 파생형](../2026-11-09-ignis-journey-continuity/s1-variants.md)의 잎빛 9·회등 5, 고블린 14명과 기존 활동 단위도 새로 배정하지 않는다. [NG03 대조](../2026-11-15-world-journey-alignment/ecology-and-growth.md)가 남긴 적은 조우 경로의 실제 경험치·장비 미확인을 유지한다.

두 비교를 나눈다. **경로 비교**는 같은 출발 장비·자원에서 GX01과 GX02를 진행하고 실제로 얻고 쓴 결과를 유지해 도착 준비도·소모·시간을 비교한다. **무기 도달성 비교**는 명시한 고정 시험 상태에서 무기별 표적 접촉·공격 창을 분리해 본다. 후자의 장비/자원 통제는 실험 조건이며 플레이 중 무료 보정이나 같은 피해량 보장이 아니다.

실제 경험치·드롭·숙련·업그레이드 입력 없이 야외 조우가 적어도 레벨 6이 된다거나 같은 난도라고 결론 내리지 않는다. 진행이 어렵다면 도달 불가·자원 부족·학습/가독성·공격 창·성장 보상의 원인을 먼저 구분한다. 필수 사냥·자동 레벨 보정·보상 증액·적 자동 스케일링은 별도 후보와 승인 없이 해결책으로 넣지 않는다.
