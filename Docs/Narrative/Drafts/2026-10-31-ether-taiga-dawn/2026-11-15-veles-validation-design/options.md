# 검증 설계의 추천·대안·보류

**VD01-VD06과 공통 경계를 함께 추천한다.** 첫 범위를 줄이면서도 통행·전투·운영·재개의 서로 다른 실패를 구분하는 안이다. 새 배치나 난도 수치를 채택하는 안이 아니며 PR01-PR07의 확정을 유지한다. [상위 문서](../2026-11-15-veles-validation-design.md)와 아래 상세는 아직 미채택 검증 설계 후보다.

## 공통 경계

- PR01-PR07·공통 경계와 NG01-NG04의 확정을 유지한다. 같은 세계의 실제 해방·작업 성과를 보존하고 명시적 저장 복원은 결정 5·21의 기존 계약과 구분한다.
- 동쪽 왕복은 첫 비교 사례다. 모든 플레이의 필수 길, G04·GB03·선택 캠프·일반 동물 처치·레벨 6·새 무기/동료/보상 요구로 승격하지 않는다. 실내 직접 대응·바르툴 직접 전투·생존·이격·실제 정비는 유지한다.
- 기존 원문·대안·보류·도안·좌표·수치는 보존한다. 새 위치·층 구조·길·치수가 필요하면 원본을 유지한 별도 후보와 영향·선택 범위를 먼저 낸다. 이미지 제작을 재개하거나 v5 전체를 실제 플레이 공간으로 확정하지 않는다.
- 과거 평면 거리·시야·픽셀·문서 검사와 실제 통행·추격·전투·사용·원경을 구분한다. 서면 검토 PASS를 GX·WC 실행 통과로 기록하지 않는다.
- 입력이 없는 운영·성장·재접근 가능성은 미확인이다. 무한 자원·순간 이동·자동 수리·숨은 파국 시간표·자동 레벨 보정·강제 사냥으로 빈칸을 채우지 않는다.
- 현재 프로토타입의 수치·무기·처치/승리·저장 지원을 첫 장 전체의 지원으로 읽지 않는다. 새 구현·UI·스키마·전체 다인 플레이·전 대륙 검증은 별도 요청 범위다.

## 대안과 선택 비용

| 선택 | 얻는 것 | 잃거나 남는 것 | 추천 판단 |
|---|---|---|---|
| 권장: 제한된 연결 + 무기별 분리 검사 | 연속 통행·운영과 개별 전투 실패를 함께 찾고 첫 장 인계를 추적한다. | 최소 연결과 상태·자원 계측이 필요하다. | VD01-VD06 묶음 추천 |
| VDA01 공동·작업실 시험장 우선 | 짧은 도달·큰 궤적·표적 가림·생존 이격 문제를 먼저 좁힐 수 있다. | 마을·동쪽 귀환·실제 재고·출항 원경은 미검증이다. 시험장 통과를 첫 장 완료로 쓸 수 없다. | 제작 여건이 제한된 경우의 실행 순서 대안 |
| VDA02 기존 동쪽·서쪽 귀환을 함께 비교 | 같은 길과 다른 길의 위험·경험치·소모 차이를 처음부터 볼 수 있다. | 서쪽 가림·생활권·R04 상세와 추가 경로 측정까지 필요해 초기 범위가 커진다. 새 필수 서쪽 길을 만들 수 없다. | 다른 길 선택이 첫 제작 목표에 필요할 때만 별도로 선택 |

세 안 모두 기존 좌표·수치를 보존한다. 원본을 그림에 맞춰 옮기거나 바르툴을 처치 보스로 바꾸는 안은 승인된 경계와 충돌하므로 동등한 대안으로 제시하지 않는다.

## 다음 작업으로 넘기는 것

NG04에는 VD01-VD06·공통 경계를 선택 대상으로 넘긴다. 사용자가 선택할 때만 해당 범위를 정본·결정과 대조하며, 검사 ID·실행용 가정·좌표·표 전체를 설정으로 복사하지 않는다. 실제 제작 요청이 없다면 선택만으로 UE 작업을 시작하지 않는다.

다음 문서 목표는 NG07 첫 장 통합 집필과 정보 전달을 추천한다. PR 확정과 SP별 제약·미확인, C03-C06·GX03/04/06/07의 달라지는 근거를 입력으로 정상 원고와 차이가 필요한 장면을 쓴다. NG06 실행이 끝나야만 초안을 쓸 수 있는 것은 아니지만 실제 관찰·안전한 귀환·재고 충분성·모든 무기 성공을 이미 검증한 것처럼 쓰지 않는다. 실제 제작을 먼저 원하면 [최소 제작 인계](handoff.md)에서 필요한 범위를 별도 목표로 선택한다.
