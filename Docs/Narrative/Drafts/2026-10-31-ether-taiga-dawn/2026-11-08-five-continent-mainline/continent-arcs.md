# 대륙별 이야기와 대표 세계관

각 대륙은 **현재 주민이 살아가는 문제와 몬스터의 생활권**을 함께 가진다. 이그니스의 국가·세력은 [기존 정치 후보](../2026-11-01-ignis-political-relations.md)를 사용한다. 해외 국가·조직·사건은 이번에 만든 가칭·창작 후보다. 대표 둘을 적었다고 그 대륙에 나라가 두 개뿐이라는 뜻은 아니다. 국경·수도 위치·면적·민족·상세 역사는 미정이다.

대표 몬스터는 [199형태 도감](../2026-11-08-worldwide-monster-variants/catalog.md)에서 골랐다. **대표 선정은 종의 최종 분포나 개체 수 확정이 아니다.** 기존 형태의 수치는 보존하며 이 여정 전체의 레벨은 후속 작업에서 다시 구성한다. 일반 늑대·곰·새·토끼·사슴은 몬스터 도감의 새로운 종으로 세지 않는다.

## 이그니스 타이가

숲과 하천을 따라 생활 현장에서 출발해 고원·북부·세계수로 범위를 넓힌다. 주인공의 목적은 고향 기록을 전달하고 배우는 것에서, 지역들의 협력을 얻어 강제 채취를 멈추는 것으로 발전한다. [재검토한 지역 순서](ignis-story-review.md)를 따른다.

| 항목 | 대표 후보 |
|---|---|
| 지형 | 북방 혼합림·큰 강과 하구·서부 고원·북부 눈 계곡·세계수와 뿌리층 |
| 국가·정치권 | 테른 도시연합(로덴·세르나·관리도시), 서부 계곡동맹(하르덴·서안항), 동부 평야왕국(농경·동안항), 북부 계곡자치회(비축·구조·고개) |
| 인간 세력 | 에테르 연맹의 현장 정비조·배정 담당자·강경 책임자, 도시 의회, 장인 조합, 선주·운송인. 연맹은 대륙 정부가 아니다. |
| 몬스터·비인간 세력 | 숲 고블린 거점, 광산 코볼트 집단, 바위트롤, 여울턱·칼바람비룡·설원아귀, 제한 시설의 파수꾼·방어체 |
| 대표 충돌 | 거목의 휴식과 공급 계약, 사람의 수리·채취 길과 생물의 물·먹이 접근이 겹친다. |
| 큰 전투 | 바르툴 결박 해방, 철근지기 구조전, 갈퀴등 해수 대응, 칼바람비룡 토벌 후보, 백각거수 유도, 겨울지기·중앙 CT03 돌파 |
| 마무리 | 공급 협력과 정지 절차를 갖춰 중앙 강제 채취를 멈춘다. 해방·복구·회복은 구분하고 심근룡은 보류한다. |

첫 대륙의 전체 성취를 보여 준 뒤 아르베나의 가공 기술 교류 초청에 응한다. 세르나에서 구조한 선주가 연결해 준 항로는 그보다 먼저 선택 왕래로 사용할 수 있다.

## 아르베나

주인공은 정상적인 기술 교류와 바다 여행을 기대하고 도착한다. 선단 실종으로 항만의 생계와 식량 반입이 흔들리고, 수색 도중 탐사 물자를 빼돌린 흔적이 드러난다. **해양 모험·구조·항만 내부의 이해관계**가 중심이다.

| 항목 | 대표 후보 |
|---|---|
| 지형 | 동해안의 만·반도·해식 절벽, 얕은 하구, 배후 과수원·곡창·낮은 숲 |
| 국가·정치권 | **메리온 항만연합**: 항만 자치도시가 공동 호송·통관을 맡는다. **에스텔 곡창왕국**: 배후 농업과 비축을 지탱하며 항만과 곡물 가격·반출을 협상한다. |
| 인간 세력 | 자유선주회(배·항로와 구조 인력), 가공장 조합(수입 에테르 규격·수리), 항만연합 호송대. 외부 계약 조직인 상시가동 사업단이 탐사 물자를 조달한다. |
| 몬스터·비인간 세력 | 모래귀 고블린의 운반·채집 집단, 백깃 하피 둥지, 백석 돌등게, 부표껍질 미믹, 돛갈퀴 갈퀴등해수. 배후에는 청목 코카트리스·유리막 요정이 있다. |
| 대표 충돌 | 신설 부두가 둥지와 어획 폐기 지점을 바꾸고 포식자의 먹이가 특정 수로에 몰린다. 선단 사고를 감춘 계약 담당자가 물량을 빼돌린다. 자연 포식자의 이동과 은폐 범죄는 서로 다른 원인이다. |
| 큰 전투 | 외해 난파선·암초의 수색 돌파, 돛갈퀴 해수의 특정 개체를 상대로 구조 선단이 빠져나갈 길 확보. 항만 전역을 점령하는 전쟁은 아니다. |
| 마무리·다음 이유 | 생존 선원과 화물 계약을 대조해 물량이 오르다스 내해로 향했음을 확인한다. 정상 호송을 재개하고 선주회가 오르다스 배편·안내인을 제공한다. |

세르나와 다른 점은 주인공이 선원의 철수 판단을 처음부터 존중한다는 것이다. 연안 바위턱의 일대일 대응을 반복하지 않고 여러 난파 지점·먹이터·출입 수로에서 길을 고르는 탐색으로 구성한다. 해수의 최종 생사는 미정이며 항로 확보를 종 전체의 제거로 삼지 않는다.

## 오르다스

물자 추적은 내해의 봉쇄와 고원의 물 분쟁에 막힌다. 한쪽 나라의 통행 허가만으로 목축 공동체의 길까지 사용할 수 없다. **육상 탐험·대형 포식자와의 전투·나라와 공동체 사이의 협상**이 중심이다.

| 항목 | 대표 후보 |
|---|---|
| 지형 | 북동부 만과 좁은 해협, 내해 연안·암반섬, 배후 고원 초지·수로·바람목·마른 돌밭 |
| 국가·정치권 | **바라크 내해왕국**: 해협 관세·연안 항만·저수 시설의 권한을 갖는다. **오르문 고원연합**: 목축·수로 공동체가 물 사용과 고개 개방을 합의한다. 왕국의 영유권 주장과 실제 고원 통제는 다르다. |
| 인간 세력 | 내해 수로청, 고원 수로장인회, 고개 안내인, 상시가동 사업단의 계약 경비. 사업단은 국가 전체를 지휘하지 못한다. |
| 몬스터·비인간 세력 | 황토 오크의 운반·목축 집단, 적점 코볼트 배수굴, 붉은갈기 켄타우로스 공동체, 염갈기 트롤, 흰침 만티코어·동막 비룡. 지성 집단은 자동 적대가 아니다. |
| 대표 충돌 | 새 양수·통행 계약이 하류의 물과 기존 목축로를 제한한다. 봉쇄를 피해 간 피난·운송 행렬이 포식자의 사냥권으로 들어간다. |
| 큰 전투 | 강제 점거 수로의 호위·돌파, 흰침 만티코어가 차지한 고개에서 안내인과 통로 확보. 가시 보충과 착지 등 생태 단서를 이용한다. |
| 마무리·다음 이유 | 물 사용 협약과 통행을 회복한다. 물자의 최종 발주처가 세라디온의 수원 개발 사업임을 확인하고 현지 관리자의 조사 초청을 받는다. 고원 장인회는 원양선 운용·극지 개조에 필요한 기술 협력을 약속한다. |

사업단의 전부를 악으로 단정하기보다 주민 공급을 개선할 계획에 기대를 건 사람과 계약을 악용한 사람을 구분한다. 주인공은 새로운 국가 질서를 세우지 않고 당사자가 지속할 수 있는 통행·물 사용 합의를 돕는다.

## 세라디온

긴 해안과 큰 내륙을 가진 대륙에서 일부 범람원·숲·현용 수원만 메인 여정에 넣는다. 현재 나라와 기술자가 고대 시설을 쓰며 살고 있다. **살아 있는 숲과 수계의 탐험, 옛 기술을 둘러싼 기대와 선택**이 중심이다.

| 항목 | 대표 후보 |
|---|---|
| 지형 | 적도 양쪽에 걸친 큰 대륙의 일부 범람원·호수·관개 경작지, 큰 숲과 열린 분지, 지하 수원·석조 시설. 대륙 전체의 기후를 하나로 묶지 않는다. |
| 국가·정치권 | **사하르 수로왕국**: 농경 유역·제방·식량 비축을 관리한다. **탈레아 자유도시연맹**: 하구와 해안 도시의 교역·기술 협약을 맡는다. 양쪽은 함께 쓰는 수원의 개발 권한을 나눈다. |
| 인간 세력 | 현용 수원관리회(주민 물 공급·보수), 기록 해독가 집단, 상시가동 사업단(발굴·설비·개발 계약). 수원관리회에는 여러 정치권의 현장 대표가 참여한다. |
| 몬스터·비인간 세력 | 청관 리자드맨의 어장·알자리, 적수피 트리엔트와 나무에 맺인 드라이어드, 줄무늬 키메라, 녹관 히드라, 녹석비늘 나가, 국소 의식의 도편골 해골병. |
| 대표 충돌 | 준설과 시험 가동이 물높이·둥지·보호림 이용을 바꾼다. 사업단은 ‘무휴기관’이 공급을 안정시킨다고 주장하고 주민은 일자리·물을 기대하지만 실패 자료가 공개되지 않는다. |
| 전반의 큰 전투 | 숲 우회로의 줄무늬 키메라 돌파와 범람 수로의 히드라 대응. 나가는 수원 이용권을 협상할 수 있는 지성 존재이며 필수 토벌로 두지 않는다. |
| 전반의 결과 | 주민 수원과 시험 장치를 분리하고, 빠진 니베르 시험 기록과 구조 요청의 존재를 확인한다. 현지 관리자가 확대 운전을 중지한 상태에서 원정을 떠난다. |
| 결말의 큰 전투 | 귀환 뒤 사업단 강경파가 점거한 작업 통로를 돌파한다. **수문 중추 방어체(CT03 해외 운용 개체 후보)**의 큰 동작·경계 명령을 읽으며 현지 정비조의 분리 작업을 지킨다. 사람 지휘부의 강제 재가동도 저지한다. |
| 결말 | 에테르를 새로 만드는 기적을 얻지 않는다. 비축·회복·중단 조건을 공개하고 필수 물 공급과 위험한 비상 운용을 나눈다. 기록·책임·운영 권한은 현지 공동체가 이어받는다. |

수문 중추 방어체는 기존 CT03 계열을 해외에 적용하는 **새 개체·운용 후보**다. 종 도감의 새 MN 항목이나 기존 구조체 16모델에 자동 추가하지 않는다. 실루엣·모델·레벨·해외 제작 기원은 후속 검토 대상이다. 최종 전투 공간을 UI 조작만 하는 설비 퍼즐로 만들지 않고 직접 전투로 접근·방어·돌파를 수행하는 방향을 둔다.

## 니베르

세계 최후의 비밀이 숨은 대륙으로 고정하지 않고, 이번 여정에서는 실패한 시험대와 구조 대상이 있는 극지로 사용한다. **탐사·생존·구조와 낯선 환경의 전투**가 중심이며 주요 교역권 밖이다.

| 항목 | 대표 후보 |
|---|---|
| 지형 | 남극 육지의 빙설·해안과 계절 해빙, 국소 온수·바람그늘, 탐사 피난지. 북극 해빙과 구분한다. |
| 국가·정치권 | 이번 방문권에는 국가를 새로 두지 않는다. 탐사 협약과 기지 관리권만 제안하며 대륙 전체의 주권·원주민·고대 국가 여부는 미정이다. |
| 인간 세력 | 여러 항구가 지원하는 합동극지탐사단, 상시가동 사업단의 소규모 시험대, 계약 선원·구조 인력. 모두 유한한 보급에 의존한다. |
| 몬스터 | 흰배 설원아귀, 온수 주변의 유백 불씨도롱뇽·냉막 슬라임, 빙편 정령, 탐사 물건에 묶인 빙무 망령. 진주비늘 용은 매우 희귀한 관찰·선택 위험 후보로 남긴다. |
| 대표 충돌 | 피난지의 잔열·먹이·보급이 좁은 곳에 모여 사람과 생물의 길이 겹친다. 시험대의 정보 은폐와 현지 자연 위험을 동일한 원인으로 합치지 않는다. |
| 큰 전투 | 연안 구조로의 포식자 돌파와 온수 경계를 차지한 큰 빙편 정령 현현에 대응한다. 정령을 물리쳐도 추위와 바다 전체가 잠잠해지지 않는다. |
| 마무리·다음 이유 | 살아 있는 시험 담당자의 증언, 소모·중단 기록, 잔존 장치의 실제 상태를 맞춰 본다. 비상 운용의 실패와 시험대의 분리 조건을 확인하고 세라디온 현지 적용을 검토할 기록을 확보한다. 같은 원정의 귀환편으로 세라디온에 돌아간다. |

새 도시나 거대한 극지 제국을 필요 조건으로 만들지 않는다. 신화급 크라켄·불사조·심근룡을 극지 보스로 우회 채택하지 않는다. 일반 동물은 먹이망을 구성하며 전투 레벨표를 채우는 대상이 아니다.

## 대륙을 잇는 조직과 주인공의 역할

**상시가동 사업단**은 이번 해외편의 새 조직 후보다. 선박·가공 부품·발굴 기술·개발 계약을 가진 여러 출자자와 현장 조직의 사업 연합이며 국가·종교·에테르 연맹 전체와 같지 않다. 아르베나에서는 물자를 모으고, 오르다스에서는 물길·운반 계약을, 세라디온에서는 현용 수원과 개발권을, 니베르에서는 소규모 시험대를 갖는다. 인력·보급·현지 허가가 필요한 유한한 조직이다.

안정 공급을 원하는 기술자와 투자금을 회수하려는 출자자, 실패를 감추는 책임자가 함께 있다. 니베르에서 얻은 근거가 공개되면 일부는 조사에 협력하고 강경파만 점거·재가동을 택한다. 전쟁 능력이나 초대륙 통치권을 부여하지 않는다. 이그니스 수원 사고의 숨은 범인으로 연결하지도 않는다.

주인공이 필요한 이유는 현장 기록을 비교하고 낯선 생물과 싸워 접근·구조·철수를 직접 수행할 수 있기 때문이다. 모든 나라를 대신해 통치하거나 현지 전문가의 지식을 무효화하는 선택받은 인물로 만들지 않는다. 각 대륙의 사람에게 배운 판단이 후반 전투와 운영 인계를 가능하게 한다.
