# 장면별 상호작용과 피드백

**실제로 본 것·들은 것·한 일에만 짧은 응답을 붙인다.** [VI01-VI08](../2026-11-15-veles-integrated-manuscript/information.md)의 정보 의미와 [정상 원고](../2026-11-15-veles-integrated-manuscript/manuscript.md)를 유지한 후보이며, 공통 경계는 [선택표](options.md#공통-경계)를 따른다. 여기서 행동은 인물이 장면에서 하는 일이다. 버튼·시선 고정·트리거·완료 플래그를 정하지 않는다.

## 열람과 지식의 구분

예를 들어 플레이어가 R01을 열었다고 해도 주인공이 현장 대조를 하지 않았다면 수행·관찰 칸을 채울 근거가 없다. 반대로 실제 대조 장면에서 인물이 확인한 사실이 있어도 플레이어가 읽고 이해했는지는 별도다. 자료를 닫거나 다시 읽지 않았다는 이유만으로 실제 성과를 취소하지 않는다.

주민에게 자료를 건네는 행동 역시 이해·동의를 보장하지 않는다. 실제 질문과 근거 있는 응답, 맡을 부담의 확인을 장면으로 보여 주는 후보이며 정답 선택 시험을 요구하지 않는다. 기록의 자동 작성·열람 권한·개인별 인지 상태를 저장하는 방식은 [IRH](options.md#보류)에 남긴다.

## 놓친 정보의 안내 강도

기본 후보는 **현재 행동에 필요한 차이를 짧게 말하고 상세 기록은 요청할 때 살펴보는 조합**이다. 예를 들어 송수 보고 직후에는 마을 점검이 남았다는 한 문장만 전하고 우회 원인의 전체 설명은 반복하지 않는다. 이미 실제 전달된 같은 내용은 상시 재생하지 않되, 누가 무엇을 들었는지 모르는 상태에서 ‘이미 알 것’이라고 생략하지 않는다.

전투 중에는 움직임·현재 결박의 변화가 우선이다. 과거 해제 동작 재생, 기록 창을 열었을 때 위협 정지, 보이지 않는 연결의 자동 강조를 가정하지 않는다. 자막·재열람·시각 대체 표현이 필요한지는 별도 접근성·인지 검증 질문이다. 이 후보는 그 수단이 이미 구현됐다고 주장하지 않는다.
