# 상호작용·작업 기록의 선택 후보

채택 범위: IR01-IR06·공통 경계는 사용자 승인으로 [결정 65](../../../../decisions/0065-veles-interaction-records-adoption.md)·[Scenario](../../../Scenario.md#벨레스-첫-장의-상호작용과-기록-상세)에 반영했다. 현재 반영 검토 상태는 [CurrentWork](../../../CurrentWork.md)가 소유한다. 아래 본문은 작성 당시 후보 기록으로 보존한다. IRA01-IRA02·IRH01-IRH06·정확한 예문·매체 세부와 실제 검증은 일괄 채택하지 않았다.

**IR01-IR06과 공통 경계를 함께 추천한다.** 아래 추천은 NG09의 새 표현 방식·적용 범위다. NG01-NG08의 확정에 대한 재승인이나 전체 원고·정확한 대사의 일괄 채택을 요청하는 표가 아니다. 사용자 채택 전에는 후보이며 NG04 반영을 시작하지 않는다.

## 채택 추천

| 항목 | 추천할 범위 | 이점 | 비용·자동 채택하지 않는 것 |
|---|---|---|---|
| IR01 행동에 붙는 짧은 현재 피드백 | [VI01-VI08](interactions.md)의 실제 관찰·전달·작업에 현재 확인한 범위와 다음 부족한 일을 짧게 붙인다. 전투에서는 현재 움직임·결박 변화를 우선한다. | 정보의 근거와 시점이 분명하고 장면 전체를 반복하지 않는다. | 적은 표현을 놓칠 수 있다. 버튼·강제 시청·자동 강조·안전 정지·VI 완료 플래그는 정하지 않는다. |
| IR02 출처와 완료 범위를 드러내는 기록 | [R01-R06](records.md)처럼 관찰/전달 출처·미확인·계획·실제 수행·남은 확인을 구분한다. 같은 사실도 현장 수행자와 전달받은 사람을 구분해 쓴다. | 계획을 작업으로, 보고를 직접 관찰로 오인하는 일을 줄인다. | 기록량이 늘어날 수 있다. 정확한 칸·양식·자동 작성·아이템·저장 구조는 별도다. |
| IR03 불완전 결과를 먼저 알리는 보고 | 작업 없음·해방/분리까지만 수행·송수 후 하류 미확인·하류 확인 후 인수 부족을 서로 다른 기록과 첫 보고로 표현한다. | 남은 일을 보여 주면서 이미 이룬 성과를 보존한다. | 실제 상태에 맞는 문장을 골라야 한다. 예문 선택만으로 상태를 바꾸거나 정상 성공을 보장하지 않는다. |
| IR04 현재 근거에 한정한 누락 보완 | C03은 빠진 연결만, C03-R은 해방 뒤 남은 현재 자료만 대조한다. 자료·접근이 없으면 미확인 이유와 다음 확인 후보를 드러낸다. | 재결박·과거 재연·전지적 답변 없이 공백을 설명한다. | 자료가 부족하면 해결 예문으로 합류할 수 없다. 새 자료·증언·안전 접근은 별도 제안이며 존재를 보장하지 않는다. |
| IR05 상대가 맡을 일 중심의 문답 | C06에서 질문한 점검·부담만 실제 근거로 보완한다. C06-M은 현재 아침의 인수·영향받은 새 점검·운영·배편으로 잇는다. | 주민의 역할과 이해·동의를 보여 주고 시간 소급을 피한다. | 근거와 담당 범위를 보여 줄 부담이 있다. 고정 시험·서명 자동 완료·저녁 재연·추가 하루는 정하지 않는다. |
| IR06 짧은 안내와 요청 시 상세 열람 | 현재 필요한 차이는 짧게 알리고, 실제 보유·전달된 상세 기록은 필요할 때 다시 살펴보는 조합을 우선한다. 저녁에는 마을 운영용과 로덴 전달용의 목적을 보여 주고 아침에는 새 결과만 묻는다. | 전면 반복을 줄이면서 상세 확인 기회를 남긴다. | 읽기 접근성과 재열람 발견성을 검증해야 한다. UI·입력·자동 팝업·자동 지식 공유·읽기 의무를 확정하지 않는다. |

IR06의 ‘요청 시’는 인물이 기록을 펼치거나 아는 당사자에게 필요한 부분을 다시 묻는 표현 방향이다. 구체적 요청 입력과 시스템 제공 방식은 미정이다. 현재 없는 자료나 현장에 없는 사람에게 즉시 접근하게 한다는 뜻이 아니다.

## 표현 대안

| 대안 | 적용하면 달라지는 것 | 이점 | 비용·추천과의 관계 |
|---|---|---|---|
| IRA01 매 결과를 자동으로 자세히 표시 | 실제 확인한 내용에 한해 작업·기록 상세를 매번 전면에 제시한다. | 누락 사실을 눈에 띄게 보여 주기 쉽다. | 반복·시선 분산·전투 방해 우려가 크고 읽기 완료를 지식으로 오인하기 쉽다. 강제 열람·세계 정지는 추가하지 않는다. 기본안으로 추천하지 않는다. |
| IRA02 요청할 때만 안내 | 현장 행동 외의 부족 안내와 기록 설명을 모두 요청 시 제공한다. | 장면의 흐름을 덜 끊고 재방문 시 반복을 줄인다. | 무엇을 모르는지 모르면 요청하기 어렵다. 송수/인수 혼동이 남을 수 있어 기본안으로 추천하지 않는다. |
| 추천 조합 IR01·IR06 | 현재 판단에 필요한 차이는 짧게, 근거 상세는 실제 접근 가능한 기록·당사자에게서 필요할 때 본다. | 부족을 알 기회와 반복 억제를 함께 둔다. | 언제 짧게 안내할지와 재열람 수단의 실제 읽힘은 미검증이다. 우수성이 입증된 UI로 표현하지 않는다. |

대안의 비교 기준은 반복량·행동 중 시선 분산·완료 오인·누락을 알아차릴 기회다. 실제 사용자 시험 결과가 아닌 문서 분석이며, 미열람 감지나 플레이어의 이해를 자동으로 판정하는 조건은 없다.

## 공통 경계

- NG01-NG08의 NC·VR·IB·JC·PR·VD·IW·HO와 공통 경계를 유지한다. 현재 확정의 소유는 [완료 지도](../../../WorkGroups.md)와 정본이다. 새 진행 조건·보상·의무 교전·도착 레벨·강제 동쪽 왕복을 만들지 않는다.
- 플레이어의 열람·이해, 인물이 실제로 안 내용, 물리 작업, 주민 인수, 현재 운영과 실제 출항은 서로 다르다. 장소 방문·처치·기록 열람·대화 종료·서명만으로 나머지를 완료하지 않는다.
- 실내 직접 대응·바르툴 직접 전투·모든 무기 선택·해방·생존 이격을 유지한다. 설명 때문에 위협을 멈추거나 이미 해제된 결박·과거 동작을 재연하지 않는다. 현재 조사 접근과 귀환의 안전은 보장하지 않는다.
- 같은 세계에서 실제 이룬 성과를 보존하고 현재 변화는 별도로 확인한다. 명시적 저장 복원은 결정 5·21의 기존 계약을 따른다. 새 저장 형식·자동 되감기·미저장 기록 영속·다인 지식 공유는 정하지 않는다.
- 미확인 정보·물량·시간을 자동 충족시키지 않는다. 실제 자료 없는 답·무한 자원·주민 대리 수리·무상 회복·숨은 파국 시한·자동 보충은 넣지 않는다. 미래 보충과 현재 사용 가능량은 구분한다.
- 주인공의 스승과 마렌을 구분하고 린은 첫 출항의 부두에 남는다. 마렌·이르의 현장/원격 합류·새 신상·가족사·연애·후일담은 추가하지 않는다. 첫 장은 실제 출항 뒤 상층 수관에서 닫는다.
- 정확한 대사·기록 규격·도식·UI·입력·음성·카메라·코드·에셋·전체 원고는 자동 채택하지 않는다. 기존 원문·대안·보류·도안·좌표·수치는 보존한다.
- 문서 PASS는 실제 읽힘·인지·공간·전투·운영·재미의 검증이 아니다. 이번 범위는 실제 UE 구현·실행을 제외한다.

## 보류

| 항목 | 남는 질문 | 재개 조건·기존 연결 |
|---|---|---|
| IRH01 표현·제작 세부 | 정확한 문장·지면·도식·입력·UI·자동 갱신·음성·번역·재열람 접근성 | 표현 범위 채택 후 실제 제작을 따로 요청할 때. PRH05·VDH05·IWH01을 일괄 해제하지 않는다. |
| IRH02 근거 소실 | 도면·기록·연결이 실제로 없거나 닿지 못할 때의 새 자료·증언·접근 수단 | 해당 소실 사례와 기존 보유 근거를 먼저 정한 뒤 새 후보의 존재·비용을 검토할 때. IWH02를 유지한다. |
| IRH03 실제 인지 | 누락을 알아차리는지, 완료 범위를 구분하는지, 전투·이동 중 부담과 재열람 발견성 | 별도 사용자 관찰·접근성·UE 검증 범위를 고를 때. IWH03·GX/WC는 미실행이다. |
| IRH04 운영·시간 | 실제 재고·소비·운반·작업 시간·늦은 보완과 배편 영향 | NG10 등 별도 입력·측정 범위에서 다룰 때. 숫자가 없는 충분성은 미확인이다. |
| IRH05 복원·다른 경로 | 다중 누락·다인 지식·저장 손상·재접속·다른 귀환로의 조합 | 실제 지원·저장 계약을 확인할 별도 설계·검증 요청 때. PRH01·PRH02·PRH06·VDH06·IWH05는 유지한다. |
| IRH06 후속 지역 | 로덴에서 기록을 실제 수령·질문·대조하는 장면과 이후 집필 | 해당 구간 집필을 요청할 때. HO의 인수 조건은 유지하고 IWH06·HOH03을 자동 해제하지 않는다. |

IRH는 기존 보류에 연결하는 새 색인이다. 과거 보류나 대안을 삭제·기각·채택하는 표가 아니다. 채택 추천과 공통 경계만 선택할 수 있으며, 예문 전체의 고정 대사화는 별도 선택이다.
