# 로덴·세르나·하르덴의 운영과 인계

**실제 수령·회신·인수 동의·현지 적용을 구분해 한 연결의 운영 조건을 작성한 후보 묶음이다.** 로덴의 축소 운영을 출발점으로 세르나 첫 허가 화물, 하르덴 자료·부품, 로덴 적용과 북행 판단까지 다룬다. 전 대륙 물류나 새 제작 목표를 만들지 않는다.

작성·[독립 검토](../../Reviews/2026-11-16-ignis-operational-handoffs-review.md)를 PASS로 완료했고 잔여 지적은 없다. 후보 단계는 `DISCUSSION`이다. [NG08 완료 기준](../../WorkGroups/next-workgroups.md)에 따라 당사자·물자·정보, 조건·비용, 불완전 인계, 권한·책임, 선택·다음 구간을 구체화한다. 새 추천 HO01-HO06은 미채택이며 정본은 변경하지 않는다.

## 확정 입력의 적용 범위

[World의 IB](../../World.md#이그니스의-공급권한생활권), [Scenario의 JC](../../Scenario.md#여정-연결과-현재-인수)·[FC·SC](../../Scenario.md#장면-연결과-정보-공개)가 지역 관계·이동 조건을 소유한다. 아래 표는 벨레스에서 확정한 판단을 이번 후보에 사용하는 범위다. 첫 장의 개별 사건을 후속 지역에 복사하지 않는다.

| 확정 입력 | 이번 적용 | 유지할 경계 |
|---|---|---|
| PR01·PR02 | 성과·현재 조건·실제 전달받은 지식을 나누고 누락·변경만 묻는다. | 화물의 현지 도착과 멀리 있는 주인공의 인지는 다르다. |
| PR03·PR04 | 같은 세계에서 구조·분리·수리 성과와 이미 쓴 자원을 보존한다. | 명시적 저장 복원은 결정 5·21의 기존 계약이다. 새 저장 필드·자동 저장·복원 지원을 설계하지 않는다. |
| PR05·PR06 | 이해·동의와 현재 자원·실제 보충 여건으로 운영 판단을 작성한다. | 후임 이름·예정 거래·서명이 수행을 대신하지 않는다. |
| PR07 | 첫 장 출항 조건은 그대로 둔다. 후속 이동은 해당 SC02-SC04·JC의 조건으로 판단한다. | 벨레스의 새 아침·수관 종료·하류 점검을 모든 지역의 필수 반복으로 확대하지 않는다. |
| VD01·VD02·VD03 | 기존 공간 참조·무기 자유를 유지하고 정상·불완전 시작 상태를 구별한다. | 벨레스 동쪽 왕복·GX·WC를 이 지역의 검증 완료나 새 필수 경로로 가져오지 않는다. |
| VD04·VD05·VD06 | 필요한 순간의 운영 수지와 문서/실행 증거를 구분한다. 성장 예산과 실제 준비도를 섞지 않는다. | 실제 물량·거리·운항·전투·성장·UE 결과는 미검증이다. |
| IW01·IW06 | 첫 장 출발·저녁·아침의 표현과 인물 역할을 유지한다. | 린의 첫 출항 잔류를 이후 세르나 운송 잔류와 혼동하지 않는다. 후속 지역에 같은 대사·식사·일과를 강제하지 않는다. |
| IW02 | 벨레스의 접어 휴대하는 기록과 마을용/로덴용 구분을 유지한다. | 모든 항만·공방에 같은 서식·아이템·UI를 도입하지 않는다. |
| IW03·IW04·IW05 | 남은 차이를 근거로 묻고 미완료의 종류를 먼저 보고하는 방식을 후보에 사용한다. | 정확한 대사·매체 규격·필수 문답·자동 갱신을 확정하지 않는다. |

근거: [PR·공통 경계](../../Scenario.md#벨레스-첫-장의-진행과-재개), [VD·공통 경계](../../Scenario.md#벨레스-첫-장의-공간운영전투-검증-기준), [IW·공통 경계](../../Scenario.md#벨레스-첫-장의-표현과-작업-기록). 기존 NC·VR·VB·CP·IB·JC와 유한 자원·성과 보존이 우선한다.

## 완료 범위와 남길 것

결과물은 흐름 OF01-OF09, 판단 입력 OV01-OV10, 사례 HC01-HC08, 추천 HO01-HO06·대안 HOA01-HOA02·보류 HOH01-HOH06이다. 식별자는 문서 추적용이며 런타임 상태나 새 퀘스트 단계가 아니다.

기존 원문·대안·보류·도안·좌표·수치를 유지한다. 정량 근거가 없는 운영 기간·물량·운임·시험 한계는 계산 결과로 채우지 않는다. 정본 반영은 사용자 선택 후 기존 NG04에서 별도로 수행한다. 다음 G4 연안·원양 환승과 G5 극지 준비·귀환은 모두 미착수다. 실제 UE 구현·실행, 이미지·음성·스토리보드, 코드·설정·에셋 변경은 제외한다.
