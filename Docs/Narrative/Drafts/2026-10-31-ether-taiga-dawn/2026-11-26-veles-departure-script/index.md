# 벨레스 첫 장 제작 대본 · 장면표

[본편을 처음부터 읽기](script.md) · [마을 생활 대화](village.md) · [미완료 귀환과 재개](returns.md)

배우는 장면과 굵은 화자명으로, 연출자는 같은 장면의 동작과 소리로 발화를 찾는다. 한 장면 안에서는 적힌 순서대로 읽는다. 선택 대화의 ‘돌아오면’은 자리를 떴다 같은 상황에 돌아온 대사다. 아래 표가 정상 진행과 대체 발화의 위치를 연결한다.

| 본편 / 정본 | 통합 원고 | 발화자와 대사를 찾을 행동 | 이어 읽을 곳 |
|---|---|---|---|
| [01 물통 안쪽](script.md#01-물통-안쪽) / VS01 | MS01 | 린과 주인공의 내일 배, 주민의 젖은 통 | 물이 끊기면 02 |
| [02 빈 통이 가는 쪽](script.md#02-빈-통이-가는-쪽) / VS02 | MS01 | 린의 본류 확인, 스승의 샘 조사, 보관인의 배분, 주인공의 귀환 약속 | 마을 자유 대화 또는 03 |
| [03 황금안개숲의 길손](script.md#03-황금안개숲의-길손) / VS03 | MS02, 선택 관찰 | 주인공의 결빙 관찰 한 줄. 직행·교전은 무언 | 현재 접근에 따라 04 또는 05 |
| [04 물가와 작업 구역](script.md#04-물가와-작업-구역) / VS04 | MS02, 선택 관찰 | 주인공의 발자국 반응. 늑대와 바깥 파수꾼은 현장음 | 실내 작업실 05 |

| [06 곰이 물러서려는 자리](script.md#06-곰이-물러서려는-자리) / VS06 | MS04 | 발톱과 결박 소리. 위협 앞에서 무언 | 07 또는 [전투 전 귀환](returns.md#조기) |

| [08 첫 물은 이쪽으로](script.md#08-첫-물은-이쪽으로) / VS08 | MS06 | 주인공의 작업 발화 둘, 송수 기록 | 09 또는 [부분 복구](returns.md#부분) |

## 경로별 통독

| 읽을 경로 | 끝에서 맞춰 볼 것 |
|---|---|
| 01부터 12까지, 동쪽 왕복 | 등불과 생활 급수는 따로 보인다. 곰의 호흡 뒤에 장치 소리가 남는다. 주민이 일을 맡은 저녁과 그 결과를 믿는 아침이 떨어져 있다. |
| 생활 대화 전부 생략, 야외 단서 최소, 익숙한 길 귀환 | 경첩 이야기는 01과 11 안에서 이어진다. 사고 원인은 05에서 알 수 있다. 야외 물길을 못 봤다는 09의 보고로도 하류에서 점검한다. |
| 숲에서 실제로 관찰하고 서쪽으로 귀환 | 들어올 때 본 흔적은 결박의 원인을 확정하지 않는다. 나갈 때 실제 물을 본 지점만 린에게 말한다. |
| 05의 대조 누락 후 전투 전 보완 / 해방 뒤 보완 / 현장 근거 소실 | 보완 시점부터 현재 위협과 자료를 쓴다. 해방 뒤에는 곰을 다시 묶지 않는다. 근거가 없으면 성공 문장으로 넘어가지 않는다. |
| 전투 전 귀환 / 부분 복구 귀환 뒤 재접근 | 실제 마친 작업만 보고한다. 재고·통행 등이 허용할 때 미완료 작업에서 잇는다. 첫 물을 보내기 전 성공한 저녁이 열리지 않는다. |
| 하류 미확인 / 담당자 미동의 / 현재 재고 미확인과 부족 | 각각 물 사용·맡을 일·현재 몫을 확인한다. 대화 종료나 예정 보충만으로 인수가 끝나지 않는다. |
| 아침 인수 보완 / 다시 언 물턱 / 새 결정 / 운영 변경 / 배편 연기 | 달라진 항목이 해결될 때까지 짐은 주인공 곁에 있다. 저녁을 재연하지 않고 현재 조건과 실제 운항이 일치할 때 12의 승선으로 합류한다. |
