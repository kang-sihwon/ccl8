# 이그니스 통치 지역과 생산·교역 배치

도시 주변의 생활권과 연결 통로를 중심으로 정치권을 표시하고, 주요 생산·가공·비축 거점과 교역로를 겹쳐 놓았다. 테른 도시연합은 중앙 수계, 서부 계곡동맹은 고원과 서해안, 동부 평야왕국은 남동 평야와 동해안 항구, 북부 계곡자치회는 관문도시 주변 계곡을 맡는 배치안이다.

2026-11-01 사용자가 [세력과 국가 관계](2026-11-01-ignis-political-relations.md)를 지도 작성 기준으로 사용하라고 요청했다. 이 문서는 그 관계의 공간 배치 후보를 소유한다. 새 경계와 생산지·경로의 정확한 위치는 미승인 제안이며, 지도 작성 요청을 서사 정본 전체의 반영 승인으로 해석하지 않는다. 성장 배경은 [도시 성장 문서](2026-11-01-ignis-city-origins.md), 기존 도시 표식은 [주요 도시 배치](2026-11-01-ignis-major-cities.md)를 따른다.

## 통합 지도

이 이미지는 통치·생산·교역 관계를 보는 개념도다. 이후 세계수 실제 치수에 맞춰 [관리도시·로덴과 중앙 정착망](2026-11-01-ignis-settlement-network.md)을 조정했다. 중앙의 실거리와 배후 거점은 새 지역도를 우선하며, 아래 PNG의 도시 표식 간격이나 P1·P3·R1-R4 세부 선형을 새 좌표로 간주하지 않는다. 정치권 소속과 품목·교역 연결의 의미는 유지한다.

![이그니스 통치 지역과 생산·교역 배치안](../../../ArtDirection/EtherWorldMap/Images/ignis-governance-production-trade-v2.png)

지도의 도시와 세계수는 위치를 읽기 위한 과장된 기호다. 영역의 넓이나 경로 길이를 실제 면적·거리로 환산하지 않는다. 생성 이미지의 해안·수계·지형은 픽셀 단위로 고정되지 않았으며 정확한 대륙 면적·위경도는 [세계지도 기준](../../../ArtDirection/EtherWorldMap.md)이 유지한다. 입력·출력과 프롬프트는 [지도 제작 기록](../../../ArtDirection/EtherWorldMap/2026-11-01-ignis-governance-prompts.md)에 있다.

## 통치와 협약 범위

| 표시 | 뜻 |
|---|---|
| 색이 채워진 실선 내부 | 해당 정치권의 구성 도시·공동체 또는 왕실이 일상 과세·경비·시설 관리를 집행하는 핵심 생활권 후보 |
| 색 사선과 점선 주변부 | 지역 자치와 통행·수로·방어 협약으로 연결되는 주변권. 일괄적인 직접 통치를 뜻하지 않음 |
| 무색 | 이번에 관할을 설계하지 않은 지역. 무인 지대나 주인 없는 땅을 뜻하지 않음 |
| 동안항의 이중 원 | 동부 평야왕국에 속하면서 항만 운영의 자치를 인정받는 항구 |
| 교역선 | 물자의 교환 방향을 잇는 경로 후보. 영유권이나 군사 점령선이 아님 |

사선은 협약·자치 주변권을 나타내며, 경제적 영향은 교역선으로 별도 표현한다. 왕국의 영유권 주장과 실제 점령 범위를 따로 확정한 지도는 아니다. 각 정치권의 법적 경계와 조약 문구는 다음 설계에서 정한다.

| 정치권 | 이번에 표시한 범위 | 통치가 유지되는 근거와 경계 |
|---|---|---|
| 테른 도시연합, 청록 | 관리도시와 중앙 분지의 생산 취락, 로덴 강변, 세르나 하구를 잇는 낮은 생활권 | 구성 도시의 자체 경비와 조세, 공동 수로·호송 협약. 연합 중심에 속한다고 모든 마을이 관리도시의 직접 통치를 받지는 않음 |
| 서부 계곡동맹, 황토 | 하르덴 주변의 계곡·공방과 서안항 배후지, 그 사이 교역 접근로 | 수로 공동체·공방·항구가 각 구역을 관리. 능선 밖과 남서 반도의 숲 전체를 동맹 영토로 칠하지 않음 |
| 동부 평야왕국, 보라 | 남동 평야도시의 농경 배후지와 동안항까지의 계곡·연안 생활권 | 왕실 비축·간선로·관세와 지역 관할의 결합. 산지의 사선 구역은 지역 공동체와의 협약권이며 항구에는 자치 특허가 있음 |
| 북부 계곡자치회, 분홍 | 북부 관문도시와 인접한 산맥 남쪽 계곡 | 관문이 공동 비축과 협상의 중심이고 주변은 자치 공동체의 협약권. 지도는 사선이 많은 권역으로 표현하며 북부 산맥·북쪽 해안 전체를 통치한다고 보지 않음 |

에테르 연맹에는 별도 영토색을 주지 않았다. 세계수 설비의 위탁 관리와 각 지역 계약으로 활동하며, 공급 계약이 있다는 이유로 해당 생산지의 통치권을 갖지는 않는다. 벨레스의 과세·가입 관계와 세부 위치는 이번 지도에서 확정하지 않는다.

## 주요 생산·공급 거점

P1-P8은 각 품목의 대표 거점이다. 생산량·실제 경작 면적을 측정한 표식이 아니며 대륙의 모든 생산지를 열거하지 않는다. P7의 비축과 P3·P6의 가공 기능을 원료 생산과 구분한다. 이웃 생활권도 자체 식량과 저장 시설을 갖는다.

| 표식 | 배치 | 주요 산물·기능 | 연결과 유지 조건 |
|---|---|---|---|
| P1 | 로덴 북쪽·북동쪽의 낮은 산림과 거목 관리 취락 | 정상 에테르·목재 | 로덴의 검사·수리·거래망에 연결. 거목의 휴식과 선별 검사가 필요하며 모든 에테르의 독점 산지가 아님 |
| P2 | 세계수 관리도시 서쪽 중앙 분지의 경작 배후지 | 곡물·채소 | 관리도시와 인근 취락에 먼저 공급. 급수·종자·지역 소비를 남긴 잉여분을 교역 |
| P3 | 로덴의 강변 공방권 | 정밀 부품 가공·수리 | 목재와 외부 금속 부품을 받아 작업. 원광 산지나 새 광산을 뜻하지 않음 |
| P4 | 하르덴의 계곡 공방·목초지 | 수력·풍력 설비, 목축 | 로덴의 정밀 부품과 서안항의 물자를 들여옴. 계절 수량·바람·현장 설치 인력에 제약 |
| P5 | 서안항 주변 연안과 가공장 | 어획·수산 가공 | 항구와 고원으로 공급. 소금은 수입 물품이며 이 표식은 소금 산지를 추가하지 않음 |
| P6 | 동안항 배후의 낮은 산림과 조선소 | 조선용 목재·선박 제작 | 평야의 식량과 외부 부품에 의존. 벌채·재생·목재 운송을 고려해야 함 |
| P7 | 북부 관문 주변 낮은 계곡과 도시 창고 | 지역 목축·겨울 비축 | 중앙에서 들여온 식량·부품·에테르를 저장. 북부가 곡물 수출 중심지가 된다는 뜻이 아님 |
| P8 | 남동 평야도시 남쪽의 경작·저장 생활권 | 곡물·종자 | 주민의 먹거리와 다음 파종분을 남겨 동안항·세르나로 반출. 모든 도시의 식량을 혼자 공급하지 않음 |

생산지의 구체 위치는 기존 역할에서 확장한 새 제안이다. P1과 P6의 작은 나무 그림은 세계수의 분신이나 새로운 초대형 세계수를 뜻하지 않는다. 표식에서 가까운 도시까지의 집하 지선과 작은 정착지는 대륙 지도에서 생략했으며 후속 지역 지도에서 설계한다.

## 주요 교역로

파란 실선은 수운, 적갈색 짧은 점선은 육로, 남색 긴 점선은 연안 해로다. 노선은 양방향 교역 후보이며 지도에는 경로 종류만 표시한다. 아래 R 번호는 문서에서 연결을 추적하기 위한 번호로 이미지에 별도 인쇄하지 않았다.

| 번호 | 연결 | 방식 | 주로 움직이는 물자와 검토 조건 |
|---|---|---|---|
| R1 | 로덴, 중앙 강변 환적장, 세르나 | 테른 강 수운 | 부품·목재·에테르·비축품. 하류·상류 운항 조건이 다르며 여울·수위·결빙·견인 여부는 미검증 |
| R2 | 세계수 관리도시와 중앙 강변 환적장 | 짧은 접속 육로 | 관리 물자·생활 식량. 세계수 남쪽 생활 공간을 돌아 본류 서안의 네모 표식에 닿고 강을 건너지 않음 |
| R3 | 세계수 관리도시와 북부 관문도시 | 중앙 저지·산기슭 육로 | 겨울 식량·에테르·수리품, 안내·현장 지원. 통행 가능한 고개와 계절 저장 거점은 후속 검토 |
| R4 | 관리도시와 하르덴 | 분지와 고원 접근 육로 | 설비·기술자·정밀 부품. 경사·교량·운송 수단과 실제 우회선 미정 |
| R5 | 하르덴과 서안항 | 서부 계곡 접근 육로 | 설비·가공품, 수입 소금·해외 물품. 계곡 하천 전체를 항행하는 노선으로 그리지 않음 |
| R6 | 세르나와 남동 평야도시 | 남쪽 만 동측의 육로 | 잉여 곡물·부품·수입품. 바다를 가로지르는 육로를 두지 않으며 지선 하천의 도하 지점은 미정 |
| R7 | 남동 평야도시와 동안항 | 동부 낮은 계곡·고개 접근 육로 | 곡물·선박 재료·수입품. 직선 최단 도로가 아니며 실제 지형을 통과할 경로는 검증 전 |
| R8 | 서안항과 세르나 | 남서 반도 외곽을 도는 연안 해로 | 서부 가공품·선복·비축품. 반도를 가로지르는 운하를 만들지 않음 |
| R9 | 세르나와 동안항 | 남동 반도 남단과 동해안을 도는 연안 해로 | 선박·가공품·화물 재배치. 남쪽 만에서 반도 바깥으로 나가 동안항에 닿음 |

R1은 세계수 동쪽의 기존 본류를 따른다. R2의 환적장은 새 소규모 시설 후보이며 도시가 하나 더 생겼다는 뜻은 아니다. 세르나에서는 강배와 바닷배가 화물을 바꾸므로 같은 배가 모든 노선을 연속 운항한다고 가정하지 않는다. 연안의 기항지·피항지, 강변 창고, 중간 시장과 관문은 이후 필요에 따라 설계한다.

육로가 지류를 건너는 곳은 교량·나루가 필요하지만 이 단계에서는 위치나 방식이 검증되지 않았다. 연안 해로의 굽이는 반도 우회 관계를 보여 주며 안전한 항로·수심·바람·해류·항해 시간이 확인된 선이 아니다. 이 지도에 그린 연결을 벨레스에서 시작하는 첫 장 플레이 경로로 사용하지 않는다.

## 확인 범위와 다음 판단

화면 대조에서는 도시 8곳의 번호·이름·대략적인 상대 위치, 정치권 4곳의 색과 사선·자치항 표시, P1-P8 범례 대응, R1-R9 연결을 확인했다. 세르나와 동서 항구 사이의 해로는 반도 바깥 바다를 돌고, 관리도시의 접속 육로는 중앙 환적장에 닿는다. 이는 시각적 확인이며 지형·수문·통치 면적·국경·물류 수치 검증이 아니다.

다음은 통치 범위와 생산 거점의 구성을 검토한 뒤 수계·고개·도하 지점을 계산 가능한 지형에 맞추는 일이다. 경로별 거리·계절 통행·운송량을 정하기 전에는 인구·비축 기간·국가별 면적을 수치로 고정하지 않는다. 기존 후속 여정과 첫 장 제작 범위는 유지한다.
