# 공간과 동선

[구간 개요](../2026-11-09-arvena-fleet-search.md)는 기존 AR-P01의 A12 조사 작업장과 A13 조사 잔교에서 이어진다. **기존 26장소를 옮기지 않고 같은 국소 좌표에서 28장소를 확장한다.** 새 그림의 해안 직선·수심·저수터·높이는 지형 후보이며 세계 해안의 특정 위치나 실제 항행 가능성을 뜻하지 않는다.

## 세 탐색권

W03은 작은 현지 저장·급수 후보이며 바다와 연결한 새 대륙 강이 아니다. 농지·정착지의 관할 경계도 새로 확정하지 않는다. AR2의 숲을 조사한다는 이유로 에스텔의 모든 농지에 들어갈 권한을 얻지 않는다.

길이는 [좌표 데이터](../../../../ArtDirection/EtherWorldMap/Data/arvena-fleet-search-v1.json)의 평면 선형이다. 도보 속도·파도·고도·운항 소요일로 환산하지 않는다. 각 탐색권의 전투와 장거리 연결을 끊임없는 한 전장으로 만들지 않는다. 근처 무리를 모두 제거하거나 같은 보스를 다시 잡아야 돌아가는 조건도 없다.

## 구조·전투 상태별 접근

G2 계약과 현지 허가는 기존 도착 문서에서 이어받는다. 난파선 상륙은 선장과 구조조가 갑판·파도·탑승 공간을 확인해야 한다. 두 난파선을 오가면서 주인공은 갑판 위, 구조조는 옮길 사람, 선장은 선박 위치를 맡는다. 한쪽이 불안정하면 C06 인수 또는 선내 보호 대기로 바꾸고 해당 장소의 진입만 보류한다.

C11은 C04·C05와 별개의 무인 인양 잔해다. 전투용 갑판은 **60×24m**, 두 작업 위치는 중심에서 좌우 20m 떨어진 후보로 둔다. 짐 고정 줄·통행 띠·낮은 엄폐를 분리하고 실제 캐릭터·모든 무기 사거리·회피 폭은 추후 검증한다. 해수는 같은 개체가 C12-C11 먹이 접근선을 왕복한다. 두 작업 위치마다 보스를 복제하지 않는다. C10-C11 사이 이동도 배편이며 갑판 밖 바다를 걸어 건너는 전투가 아니다.

전투가 열리기 전에 C11-C10-C06 후퇴를 준비한다. 싸움 중 선장이 접선할 수 없으면 갑판의 확보한 면에서 신호를 기다리거나 접근을 중지한다. 무한 대기 안전을 보증하지 않으므로 날씨·선체가 악화되면 전투를 시작하지 않는다. 최종 회수 뒤 C14 육상 연결, 북쪽 조사선, 승객 귀환 해선은 서로 다른 단계다. 조사선 실패가 G1 왕복 계약의 자동 취소로 이어지지 않는다.
