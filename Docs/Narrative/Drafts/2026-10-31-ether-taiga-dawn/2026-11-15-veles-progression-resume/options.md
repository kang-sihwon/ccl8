# 추천·대안·보류와 다음 작업

2026-11-15 사용자 승인으로 PR01-PR07과 공통 경계를 [결정 61](../../../../decisions/0061-veles-progression-resume-adoption.md)·[Scenario](../../../Scenario.md#벨레스-첫-장의-진행과-재개)에 반영했다. 이 채택 범위는 `CLOSED`다. PRA01-PRA02·PRH01-PRH06과 아래 원문을 보존하며 TR·C·RT 및 상세 표 전체·실제 UE 구현은 함께 채택하지 않았다. 아래 후보·미채택·다음 선택 표현은 작성 당시 기록이다. 반영 검토는 [별도 기록](../../../Reviews/2026-11-15-veles-progression-adoption-review.md)에서 확인한다.

**PR01-PR07과 공통 경계를 한 묶음으로 추천한다.** 진행 판단에 필요한 사실, 중단 뒤 보존할 성과, 현재 다시 확인할 조건을 함께 선택해야 정상 흐름과 C03-C06이 다른 규칙을 쓰지 않는다. 이는 NG05의 새 후보이며 사용자 채택 전이다. [상위 문서](../2026-11-15-veles-progression-resume.md), [조건·전이](conditions.md), [사례 추적](cases.md), [재개·저장 대조](resume.md)가 상세 근거다.

PR04의 저장 시점 복원은 같은 세계에서 성과를 무효화하는 새 사건이나 필수 실패 루프가 아니다. 현재 [결정 21](../../../../decisions/0021-server-issued-player-identity.md)의 늦은 참가자 처리처럼 명시된 예외도 보존한다. 첫 장의 상세 성과가 실제 저장·복원된다는 주장은 하지 않는다. 구현 데이터가 없거나 형식이 맞지 않으면 정상 완료를 추정하지 않고 지원 불가·이전 형식 처리의 선택을 남긴다.

## 함께 적용할 경계

- NC·VR·IB·JC, 기존 VB·CP와 무기 선택을 유지한다. 첫 장 조건을 위해 필수 사냥·레벨 6·G04·GB03·서쪽 방문·새 동료·보상을 붙이지 않는다. 야외 조우의 선택성과 실내 직접 대응·바르툴과의 실제 전투를 구분한다.
- 결박에서 해방된 살아 있는 바르툴과 일행의 이격을 보존한다. 설명 누락을 이유로 다시 묶거나 죽이지 않으며, 이미 무력화한 구조물을 대사를 위해 되살리지 않는다. 지식 누락이 물리적 방어나 실제 성과를 금지하는 입력 잠금이 되지 않는다.
- 해방·설비 복구·첫 물·하류 사용·마을 인수·숲 전체 회복은 서로 다르다. 시작한 작업과 끝낸 작업, 예정 물량과 현재 물량도 다르다. 새 상시 피해·강제 실패·무적 연출·자동 수리를 넣지 않는다.
- 주인공이 실제 접한 정보와 플레이어의 이해를 구분한다. 주인공이 보지 못한 일을 스승이 자동으로 아는 것으로 쓰지 않는다. 린은 벨레스 선착장에 남고, 스승과 마렌은 별개이며 원격 설명을 위해 마렌·이르를 옮기지 않는다.
- 조건 표는 결과를 판단하는 묶음이다. 전역 퀘스트 잠금·고정 대화 순서·확인 시험·UI·데이터 스키마로 자동 채택하지 않는다. 진행을 미뤄야 하는 이유와 물리적으로 이동할 수 없는 이유를 구분한다.
- 재접근은 안전이나 무상 회복을 보장하지 않는다. 재고·부상·통행·시간의 실제 조건이 없으면 가능 여부를 미확인으로 남긴다. 새로운 재고 수치·실패 시한·운항 일정·날짜 전환 입력은 이번에 정하지 않는다.
- 원문·대안·보류, 정본·결정, 기존 지도·좌표·분포·성장 수치를 유지한다. 서면 후보·검토 완료와 사용자 채택·실제 UE 지원·실행 검증은 각각 따로 기록한다.

| PRA02: 사실 분리는 유지하되, 중단 후 해당 작업 묶음의 현재 조건을 한 번에 재확인 | 이미 끝낸 작업은 반복하지 않는다. 예를 들어 인수 뒤 변화가 있으면 관련 운영 묶음 전체를 다시 확인해 세부 영향 누락을 줄인다. | 세부 변경 원인을 추적할 부담은 줄지만 변하지 않은 조건도 다시 살펴 지연·반복 설명이 늘 수 있다. 과거 조사 내용 전체를 다시 말하게 하지는 않는다. | 영향 범위를 세밀하게 표현하기 어려울 때의 재확인 방식 대안. PR02·PR05의 관련 조건만 확인하는 권장 방식과 구별해 선택 |

장소·처치에 따른 일괄 자동 완료, 사망 때 세계 전체 초기화, 고정 시간 뒤 근거 없는 파국은 기존 확정이나 이번 목표와 충돌하므로 채택 가능한 동등 대안으로 제시하지 않는다. 미확인 운영 조건을 해소하지 않고 모든 경우의 복귀를 보장하는 방식도 제외한다.

## NG04·NG06·NG07 인계

NG04의 선택 대상은 PR01-PR07과 공통 경계다. 사용자가 선택하면 해당 범위만 현행 정본·결정과 대조해 반영한다. 표의 기호·TR·RT·PRH 전체를 정본 상태나 구현 사양으로 복사하지 않는다. PRA01·PRA02는 대안으로 보존하고, 미선택 부분은 보류로 남긴다.

다음 작업은 NG06을 추천한다. [조건 표](conditions.md)의 미확인 변수를 시작 조건으로, [C01-C06·RT01-RT12](cases.md)를 검증 명세의 입력으로 사용한다. 먼저 조우를 적게 거친 정상 경로, 복구 전 귀환, 부분 복구 후 재접근, 인수 부족을 기존 도안과 비교한다. PR이 미채택이면 가정임을 표시하고 실제 공간·운영 성공이나 새 위치 승인을 선언하지 않는다.

NG07은 정상 흐름과 C03-C06에서 달라지는 장면, VI01-VI08의 최초 확인·재전달 근거를 작성한다. 원고가 쓰는 PR과 공간 조건 중 미선택·미검증 부분을 표시한다. 안전한 귀환·대체 출처·추가 재고를 대사 하나로 보장하지 않는다. NG06·NG07의 실행은 이번 NG05에 포함하지 않는다.
