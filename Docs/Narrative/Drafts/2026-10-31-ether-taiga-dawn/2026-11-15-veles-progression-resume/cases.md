# 사례와 반례의 진행 추적

채택 범위·보류·검증 상태는 [상위 문서](../2026-11-15-veles-progression-resume.md)를 따른다. 본문은 작성 당시 후보 기록이며 원문 전체를 정본화한 것이 아니다.

**C01-C02는 원문이 가정한 실제 확인·작업을 모두 마친 경우에만 출항으로 이어지고, C03-C06은 각각 남은 조건부터 재개한다.** 아래는 [조건·전이 후보](conditions.md)를 대입한 서면 추적이다. C·VI·VT의 실제 게임 지원, 통행·안전·인지를 검증한 결과가 아니다.

## C01-C06의 마지막 충족 조건과 다음 행동

[원문 C01-C06](../2026-11-06-opening-and-continent/2026-11-15-veles-chapter-comparison.md#정보와-작업-상태의-대조)의 비교 시점을 그대로 쓴다. 성공 사례의 가정을 다른 사례에 복사하지 않는다.

| 사례 | 입력과 마지막 충족 조건 | 아직 없는 근거·현재 판정 | 다음 행동과 재개 후 남는 조건 |
|---|---|---|---|
| C01 정상 조사 | 원문상 조사·직접 전투·정비·송수·하류·인수·현재 재고·이번 아침 점검을 마쳤다. TR10까지 충족한 성공 가정이다. | 미방문 생활권·숲 전체 치유는 모른다. 필요한 실제 배편·여행 준비까지 갖췄을 때 TR11을 판단한다. | 기존 배편 승선·출항·상층 수관으로 닫는다. 별도 야외 장소를 다시 방문하거나 남은 생태를 전멸할 이유는 없다. |
| C02 적은 야외 관찰 | 작업실·공동·복구·마을·아침의 근거는 C01과 같다. 야외 파편·발자국·서쪽 풍경은 모른다. | G04 등이 남을 수 있고 전체 경험치·통행 성공은 미검증이다. 야외 관찰·처치 부재는 TR11의 누락 조건이 아니다. | 실제 귀환까지 했다는 원문 가정에서 C01과 같은 출항 판단을 한다. 다른 길·GB03·G04 처치·특정 레벨을 추가하지 않는다. |
| C03 작업실 일부 누락 | 조사 공간과 물·얼음·곰 결박만 보았다. VI02의 우회·보존 회로·차단 순서가 미확인이다. | TR03의 관찰이 TR02 전체를 채우지 않는다. 해방·정비·마을 인수·출항은 미완료다. | 현재 위협에 대응하며 여건이 있으면 기존 작업실의 빠진 대조를 한다. 계획을 얻은 뒤 현재 공동·직접 전투·실제 정비로 잇는다. 조사 보완만으로 TR04-TR11을 완료시키지 않는다. |
| C04 복구 전 귀환 | 현장 계획과 접근 방해를 확인하고 조사·보고를 마쳤다. 곰 해방·채취 해제·분리·송수는 하지 않았다. | TR06은 미완료 상태로 성립한다. 비상 공급·재접근 여유가 미확인이고 정상 출항은 불가하다. | 스승·보관인·린이 기존 역할에서 현재 비상 운영·재고·운반을 확인한다. 실제 재접근 가능성이 확보되면 현재 위협·전투·정비를 잇고 그 뒤 하류·인수·아침을 별도로 수행한다. |
| C05 복구 도중 귀환 | 곰 해방·이격, 채취 해제·손상 연결 분리는 실제 완료했다. 파편 회수·정상 동력·송수는 미완료다. | 해방·분리 성과는 남지만 하류 사용·운영 인수·아침은 충족되지 않았다. 잔류 파편·미확인 연결·귀환로 위험도 남는다. | 완료와 미완료를 보고하고 현재 공급·재접근을 판단한다. 돌아오면 현재 연결·파편을 확인하고 미완료 정비부터 잇는다. 곰을 다시 묶거나 완료 분리를 반복시키지 않는다. |
| C06 인수 설명 부족 | 현장 정비·송수·하류 점검은 완료했다. 담당자의 이해·동의와 현재 재고 충분성 확인이 남았다. | TR08 미완료이며 TR10의 이번 아침 결과도 없다. 밤이 지났다고 출항할 수 없다. | 담당자의 부족한 질문에 실제 근거로 답한다. 답이 없으면 해당 사실을 확인한다. 운영·동의와 남은 준비를 보완하고 이번 아침·실제 배편 조건을 확인한다. 이미 아침이면 현재 시각에서 관련 새 점검을 하며 저녁 재연·하루 추가 대기를 강제하지 않는다. 과거 인수로 소급하지 않는다. |

C04·C05의 귀환 성공은 원문의 조건부 사례다. 이 표는 귀환 불가·소모 고갈 상태에 새 순간 이동·자동 구조를 추가하지 않는다. C03에서 전투가 먼저 진행된 실제 상태는 아래 RT03처럼 이미 생긴 세계 변화와 아직 없는 지식을 나눠 처리한다.

## 반례와 재개 검사

RT01-RT12는 PR 후보가 자동 완료·불필요한 되감기·판정 누락을 만드는지 보기 위한 **설계 검사 사례**다. 판정은 명시한 입력에서 도출한 예상 처리이며 실행 PASS가 아니다.

| 사례·입력 | 기대하는 처리 | 막아야 할 잘못된 처리 | 남는 확인 |
|---|---|---|---|
| RT01 C02에서 야외 조우 수만 0으로 바꿈 | 다른 실제 필수 조건을 마쳤다면 같은 출항 판단. 실제 물자·경험치는 별도 상태다. | 모든 적 처치·레벨 6을 출항 조건으로 추가. | NG06의 실제 통행·성장. |
| RT02 작업실 진입·실내 대응만 완료 | VI02는 실제 현장 대조 전까지 미확인. 안전한 여건이 생기면 빠진 사실의 확인 기회를 잇는다. | 위치 트리거나 적 사망으로 지식 자동 지급. | PRH05의 관찰 인정 입력·가독성. |
| RT03 계획 일부를 못 봤지만 실제 전투에서 해방·이격 완료 | 해방 성과와 현재 곰 상태는 유지한다. 부족한 설비 계획은 현재 관찰 가능한 자료·연결에서 확인한 뒤 남은 정비를 한다. 사라진 과거 동작을 볼 의무는 없다. | 해방 취소·곰 재결박·자동 설비 지식·같은 보스 재처치. | 변화 후에도 필요한 근거가 남아 있는지 NG06·NG07에서 확인. 없으면 새 수단이 필요한 설계 미결이다. |
| RT04 앞다리 해제 뒤 중단 또는 개인 사망 | 같은 세계에서는 실제 해제된 연결·다른 플레이어의 성과를 되감지 않는다. 재스폰 후 현재 위협·남은 연결·접근을 판단한다. | 개인 재도전을 전 세계 초기화로 처리. | 곰 체력·공격 주기·현재 위치 등 전투 세부는 PRH02. |
| RT05 C05에서 파편 회수 시도만 하고 중단 | 실제 회수한 범위만 보존하고 시도 중인 부분은 완료로 세지 않는다. 현재 파편·연결을 확인해 남은 일을 잇는다. | 애니메이션 시작·기록 작성만으로 정비 전체 완료. | 회수 단위·중단 가능한 시점·위험은 PRH01·PRH04. |
| RT06 현장 첫 물만 확인하고 하류에 가지 않음 | 현장 송수 성과는 남지만 하류·인수·아침은 아직 필요하다. | TR05 완료를 곧바로 TR11 완료로 매핑. | 주민의 실제 사용 확인 수단은 NG07. |
| RT07 담당자 지정·기록 배부만 함 | 전달한 내용과 아직 이해·동의하지 않은 범위를 나누고 해당 질문·대조부터 재개한다. | 담당자 이름이 있으면 인수 완료로 처리. | 새 신상·직책을 만들지 않고 기존 역할 유지. |
| RT08 인수 후 실제 공급·분담이 달라짐 | 이전 인수 사실은 남긴다. 영향을 받은 운영 조건·동의·사용 확인을 다시 판단한다. | 모든 이전 작업 초기화 또는 과거 동의로 현재 변경 자동 승인. | 변화 종류·유효성 판정 세부는 PRH01·PRH03. |
| RT09 다음 아침이 됐지만 점검 결과가 없음 | 이번 아침 결과는 미확인. 담당자의 실제 점검·전달 이후에 출항 판단. | 시간 경과·휴식·메뉴 닫기로 자동 통과. | 시간 표현과 이상 시 배편 재조정은 PRH03·PRH05. |
| RT10 거래 약속만 있고 현재 재고·작업 시간은 모름 | 재고와 일정의 판정 불가를 표시하고 현재 보유분·실제 인수·소모를 확인한다. | 약속 물량을 즉시 재고로 계산하거나 곧바로 고갈 사망을 확정. | 필요한 단위·기간·손실·운반은 NG06. |
| RT11 같은 세계에서 해방 후 사망 또는 재접속 | 현재 세계의 완료 성과를 유지하고 개인 상태·접근·지식을 각 소유 규칙에 따라 확인한다. 다른 사람이 한 일을 자동으로 본 사실로 바꾸지 않는다. | 개별 재스폰으로 월드 로드, 재접속자에게 모든 조사 지식·보상을 자동 부여. | 다중 플레이 지식·기여·보상 병합은 PRH01·PRH06. |
| RT12 명시적으로 이전 저장을 불러오거나 복원 자료가 불완전함 | 유효한 선택 저장과 기존 복원 계약에 따라 재개한다. 결정 21의 늦은 참가자 유지 예외를 포함하며, 그 밖에 저장 후 성과를 임의로 섞지 않는다. 필수 상태가 빠진 기록은 완료를 추정해 적용하지 않는다. | 현재 해방 사실과 과거 재고만 골라 합치기, 누락 필드를 전부 참으로 채우기, 개인 사망마다 자동 과거 로드. | 지원 버전·거부/이관·원본 보존의 구현은 PRH01. 기존 복원 계약과의 연결은 [재개 대조](resume.md). |

## 서면 추적의 결론과 한계

명시된 여섯 C 입력에서는 C01·C02만 성공 가정의 나머지 배편 준비와 연결되고 C03-C06은 부족한 근거·작업·인수에서 재개한다. 반례 열두 개에는 각각 다음 확인 또는 미결 소유가 있으며, 전이표에서 위치·적 수·시간 경과만으로 출항을 인정하는 경로는 두지 않았다.

이 결론은 대표 입력의 수동 추적이다. 모든 상태 조합에 대한 도달성 증명·모델 검사·UE 자동화 테스트를 수행하지 않았다. 특히 실제 고갈·부상·통행 불가·근거 소실·동시 플레이·손상 저장의 회복 가능성은 미검증이다. 필요한 다음 행동이 서면으로 정해졌다는 사실을 그 행동이 실제로 가능하다는 보장으로 쓰지 않는다.
