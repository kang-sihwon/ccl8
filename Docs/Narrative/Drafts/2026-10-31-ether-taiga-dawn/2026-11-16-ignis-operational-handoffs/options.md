# 운영·인계의 추천과 남은 선택

**HO01-HO06을 공통 경계와 함께 추천한다.** 기존 SC02-SC04·IB·JC의 인계를 판단 근거와 불완전 사례로 구체화하는 후보이며 아직 채택되지 않았다. [전체 묶음](../2026-11-16-ignis-operational-handoffs.md)의 모든 표·정확한 문장·변수명·사례를 함께 정본화하는 선택은 아니다.

## 추천

|---|---|---|---|

HO01·05는 [흐름·권한](flows.md), HO02는 [조건·비용](conditions.md), HO03·04·06은 [HC01-HC08](cases.md)에 적용했다.

## 공통 경계

- PR01-PR07·VD01-VD06·IW01-IW06과 공통 경계, 기존 NC·VR·VB·CP·IB·JC·FC·SC의 확정을 유지한다. 벨레스의 새 아침·휴대 기록·수관 종료·동쪽 비교 경로를 후속 지역의 의무 절차로 복제하지 않는다.
- 실제 구조·분리·수리·인수의 성과와 현재 지식·운영 조건을 구분한다. 같은 세계에서는 끝낸 일을 보존하고, 명시적 저장 복원은 결정 5·21의 기존 계약을 따른다. 새 저장 필드·전 경로 지원·자동 복원·다인 정보 공유는 포함하지 않는다.
- 세르나 첫 화물은 기존 예비선·허가 범위와 실제 로덴 수령 회신을 따른다. 린의 수리 중인 배나 좌초선을 즉시 쓰지 않으며 후속 S4 일반 화물·G1 해외 선실을 같은 운송으로 세지 않는다.
- 북행은 SC04의 현지 협의·제한 시험·정비 인수·북부 출처와 로덴 인수 동의·운영 여유를 따른다. 발송은 적용 성공이 아니며 로덴 시험 완료를 새로운 일괄 북행 조건으로 만들지 않는다. 운영이 버티지 못하면 출발·지원을 조정한다.
- 현지 권한·유한 자원·실제 전달과 남은 비용을 유지한다. 하르덴 상류 취수·켈바 하류 영향·윗샘의 추가 공급/보수는 구분하며 새 수로·원격 조작·직접 갈수 인과를 만들지 않는다. 부족한 근거를 순간 통신·자동 보충·무한 대기·숨은 파국 시간표로 채우지 않는다.
- 린은 세르나·로덴 운송에 남고 마렌은 로덴 현지 인수 뒤 동행하며 이르는 북부에서 합류한다. 스승과 마렌을 구분한다. 새 인물·신상·혈통·연애·재합류·보상·처분·새 필수 전투를 추가하지 않고 일반 생태·생활권·모든 무기 선택을 유지한다.
- 기존 원문·대안·보류·도안·좌표·수치와 상세 표를 보존한다. 추천 채택은 OF·OV·HC 전체·정확한 대사·매체·수치·계약·UI·제작 사양의 일괄 승격이 아니다. 문서 검토는 실제 인지·운송·재고·시험·전투·성장·UE의 증거가 아니며 구현·실행은 별도다.

## 대안

| ID | 비교안 | 얻는 것·잃는 것 | 권고 |
|---|---|---|---|
| HOA01 실제 답변을 짧게 묶는 전달 | 현지 상세 기록을 유지하되 주인공에게는 수령·남은 차이·다음 담당의 핵심 답변만 드러낸다. | 설명 반복을 줄이지만 지연/부족 원인과 비용 부담이 덜 보일 수 있다. 실제 답변·수령을 생략해서는 안 된다. | 상세를 추적하는 HO 중심을 추천하고 표현 축약은 비교 자료로 둔다. 정확한 대사·매체는 후속 집필에서 고른다. |
| HOA02 선택 재방문을 자세히 다루는 전달 | 원격 인계의 기본 여정은 유지하면서, 사용자가 재방문을 택했을 때 로덴 현장 차이·시험과 인수 장면을 더 쓴다. | 현장 책임을 구체적으로 볼 수 있으나 왕복·부재 비용과 추가 집필·검증 범위가 커진다. 방문이 자동 성공을 보장하지 않는다. | 지금은 운송망을 통한 한 연결을 완료한다. 재방문 상세는 실제 필요가 확인되면 별도 범위로 고른다. |

두 대안은 기존 정본을 번복하는 선택지가 아니다. 재방문 강제·모든 회신 생략·적용 성공 전 일괄 북행 금지는 기존 SC04·JC와 어긋나므로 추천 대안에 넣지 않는다.

## 검토와 다음 선택

독립 검토에서는 SC04의 북행 조건, 물자/회신의 비동시성, 비용 중복 계상, 현지 권한, 기존 성과·원문 보존을 우선 대조한다. 작성·검토 완료와 HO의 사용자 채택, 정본 반영, 실제 실행은 따로 기록한다.

이 묶음의 다음 선택은 HO01-HO06·공통 경계다. 사용자가 채택하면 기존 NG04에서 해당 범위만 정본·결정으로 옮긴다. 해외 환승·극지 운영과 실제 제작을 자동 시작하지 않는다.
