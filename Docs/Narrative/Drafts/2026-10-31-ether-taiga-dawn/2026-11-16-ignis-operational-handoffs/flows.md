# 운송·자료·운영 책임의 연결

**세르나에서 보낸 첫 허가 화물과 하르덴에서 보내는 적용 자료는 목적·담당·완료 근거가 다르다.** 아래 OF01-OF09는 [전체 묶음](../2026-11-16-ignis-operational-handoffs.md)의 상세 후보다. 기존 사건은 [이그니스 인계 원문](../2026-11-09-ignis-journey-continuity/story-and-handoffs.md), 이동 판단은 [SC02-SC04](../../../Scenario.md#장면-연결과-정보-공개)와 [JC01-JC04](../../../Scenario.md#여정-연결과-현재-인수)를 따른다.

## 당사자와 책임

새 직책·대표권을 만들지 않고 원문의 역할을 구분한다. 한 사람이 여러 역할을 맡더라도 수령·운영·시험 동의를 같은 사실로 처리하지 않는 후보를 추천한다.

| 당사자 | 맡은 일과 확인할 범위 | 대신 결정하지 못하는 것 |
|---|---|---|
| 로덴 현지 후임·공급 담당자 | 축소 운영·사용 가능량·보충·치료 지원과 미완료 작업을 인수하고 현재 조건을 답한다. | 세르나 반출 허가, 선장의 운항, 하르덴의 물 배정 |
| 로덴 실제 수령자·적용 담당자 | 도착 화물의 품목·상태·인수량을 확인하고, 기술자는 자기 현장 측정·제한 시험과 적용 결과를 맡는다. | 운송 확인만으로 시험 성공·완전 복구·책임 면제 선언 |
| 세르나 배정소·창고 담당 | 허가된 제한 품목과 봉인·규격·반출 내역을 확인한다. | 허가 밖 물량 제공, 구조 공로에 따른 무제한 반출 |
| 첫 화물의 운송 선주·선원 | 다른 선주의 예비선을 인수해 허가 화물을 운송하고 로덴 인계 사실을 운송망에 남긴다. | 손상된 린의 배·좌초선의 즉시 재사용, 로덴 설비 적용 판정 |
| 린·수리 담당·비용 인수 당사자 | 배 수리·시험 운항·운송 조건을 나눠 맡는다. 린은 자기 배의 운항 판단과 이후 세르나·로덴 운송에 남는다. | 구조자의 일방적 출항 결정, 첫 화물 선주 역할과의 자동 합병 |
| 하르덴 장인·공방·현지 운용 담당 | 조건부 도면·측정 방법·정비 교육·현지 제한 시험과 남은 한계를 제시한다. | 같은 장치를 로덴에 꽂으면 된다는 보증, 로덴 대신 내리는 적용 승인 |
| 켈바 경작·수로 당사자와 윗샘의 공급·보수 당사자 | 자기 물 배정·하류 영향·추가 공급과 보수 부담을 협의한다. | 한 대표의 동의로 모든 이용자 권한 대체, 윗샘으로 하르덴 원격 조작 |
| 주인공·마렌 | 실제 자료를 전달하고 현장 차이를 대조하며 도움이 필요한 범위를 요청한다. 마렌은 로덴 후임 인수 뒤 동행한다. | 모든 공방·운송·주민을 대표하는 계약, 현지 시험 없이 적용 완료 선언 |

권한 근거는 [IB02·IB04](../../../World.md#이그니스의-공급권한생활권)·[FC02-FC04](../../../Scenario.md#지역-갈등과-선택의-대가)다. 실제 수령자와 적용 담당자의 이름·겸임 여부·정확한 직책은 미정이며 새 조직을 필수로 만들지 않는다.

## 물자·자료·답변의 흐름

| ID·시점 | 발송·수행 주체 → 실제 상대 | 이동하는 것·선행 조건 | 완료로 인정할 근거·남는 일 |
|---|---|---|---|
| OF01 로덴 출발 준비 | 주인공·마렌·현지 후임 → 로덴 운영 담당 | 구조·분리 성과, 손상·부상, 축소 공급과 부품 요청을 나눈다. 후임이 실제 맡을 범위와 버틸 조건을 확인한다. | 후임의 이해·동의와 현재 운영 여건. 성립 전 세르나행을 미루며 구조를 되풀이하지 않는다. |
| OF02 세르나 반출 준비 | 마렌·배정소·창고 → 운송 선주 | 필요한 정상 동력·부품의 제한 반출, 봉인·품질·운임과 지연 부담의 인계. 품목별 실제 확보·허가·적재 가능성을 구분한다. | 허가·선적·운송 인수. 이것은 로덴 도착이 아니다. 린의 배 수리는 병행될 수 있으나 첫 화물은 예비선이다. |
| OF03 첫 화물의 로덴 수령 | 첫 화물 선주 → 로덴 실제 수령자 | 도착 물량·상태·허가 내역을 대조한다. 부족·손상·사용 불가분을 따로 남긴다. | 현지 인수 완료량만 현재량으로 옮긴다. 수령은 설비 수리·적용 성공과 다르다. |
| OF04 수령 회신과 세르나 출발 | 로덴 수령·운영 담당 → 운송망 → 세르나 일행 | 실제 받은 내역·남은 차이·그 시점 운영 정보를 전달한다. 린의 수리·시험 운항과 비용 인수도 별도로 확인한다. | 세르나에서 실제 회신을 받은 뒤 첫 운송 완료를 판단한다. 부족이 있으면 후속 대응 인수를 별도로 남기고 무조건 전량 성공으로 합치지 않는다. |
| OF05 후속 정기 상행편 | 해당 편 선장 → 공공 환적장·로덴 화물 수령자 | 주인공·마렌은 환적장에서 내리고 일반 화물은 로덴으로 간다. | 하르덴행 여객 이동과 일반 화물 인계는 서로 다르다. OF03 첫 허가 화물이나 G1 해외 선실로 중복 계산하지 않는다. |
| OF06 하르덴 협의·제한 시험 | 공방·물 이용자·현지 운용 담당, 주인공·마렌 | 현지 취수·하류 영향·교육·정비 부담을 협의하고 제한 시험·정비 인수를 한다. | 현지 조건에서의 결과와 한계. 처치가 협의를 대신하지 않으며 이 결과를 로덴 성공으로 복사하지 않는다. |
| OF07 자료·부품 발송과 인수 동의 | 하르덴 장인·마렌 → 운송자 → 로덴 적용 담당 | 현지 조건표·차이·측정/정비 절차·부품·남은 질문을 전달한다. 로덴 담당자가 맡을 범위와 부족한 도움을 실제 답한다. | 발송, 실제 수령, 이해·인수 동의는 각각 근거를 남긴다. 동의는 미리 전달된 구체 범위에 대해 가능하며 미래 부품이 이미 도착했다는 뜻은 아니다. |
| OF08 북행 전 판단 | 로덴 담당의 답변 → 실제 전달망 → 주인공·마렌 | 인수 동의·현재 축소 운영·다음 보충 조건을 확인한다. 현지 시험 미완료라도 SC04 조건을 충족할 수 있다. | 운영이 버티지 못하면 북행을 미룬다. 정보가 부족하면 충족으로 승인하지 않고 필요한 답변·지원을 조정한다. 새 보이지 않는 통행벽은 만들지 않는다. |
| OF09 로덴 현지 적용·결과 회신 | 로덴 적용 담당 → 현지 운영 담당·전달망 | 자기 현장 측정·제한 시험·중지 조건·정비 인수를 수행한다. 결과를 당사자에게 전달한다. | 성공은 실제 현지 시험 근거로만 판단한다. 북행 뒤 실패가 확인되면 가능한 제한 운영·재시험·추가 운송·선택 재방문을 검토한다. |

OF02-OF05는 [세르나 원문](../2026-11-08-roden-serna-exploration/story-and-roundtrip.md)의 허가·봉인·예비선·수령·수리와 후속 인계 순서를 따른다. OF06-OF09는 [하르덴 원문](../2026-11-08-serna-harden-exploration/story-and-roundtrip.md)의 현지 차이·교육·조건부 대체 운용과 북행 기준을 따른다. 표의 세분화와 근거별 기록은 새 추천이며 원문 전체를 정본화하지 않는다.

## 정보가 도착하는 때

각 전달에는 발신 시점·관찰 시점·도착 여부·답할 범위를 남기는 후보를 둔다. 시각 체계·서식은 아직 정하지 않는다. 로덴에서 수령이 끝났어도 회신이 오기 전의 세르나 일행은 그것을 안다고 말할 수 없다. 회신이 늦으면 이전 관찰의 범위와 이후 조건 변화를 확인한다. 주인공의 추측으로 재고·운항을 갱신하지 않는다.

로덴 담당은 원거리 답변을 기다리는 동안에도 자기 현장 운영을 맡는다. 가능한 제한 운전을 유지하고 여건이 무너지면 영향받는 작업을 조정할 책임이 남는다. 이 책임이 무제한 재량·무한 비축·자동 대체 공급을 뜻하지 않는다. [HC 사례](cases.md)에서 실제 근거가 있는 분기와 없는 분기를 구분한다.

## 성과와 책임을 함께 남기는 인계

로덴의 붕괴는 주인공 조작보다 먼저다. 주인공의 확인 생략과 마렌의 우회 승인·기록 누락, 실제 구조·분리 성과를 함께 유지한다. 이후 시험 실패를 이유로 과거 구조를 취소하거나 같은 사고를 필수로 반복하지 않는다.

세르나의 구조·부두 방어는 정상 배정·선주 권한과 다르다. 린의 배 손상·수리·놓친 일감과 후속 책임은 남는다. 협조에 대한 비용 인수가 모든 손실 정산·일방적 용서·법적 면책으로 바뀌지 않는다.

하르덴의 협력에는 물 배정·교육·정비 부담과 미합의 항목이 남는다. 도면 제공이 무상 희생·독점 전체 폐지·무조건적 성능 보증이 되지 않는다. 정확한 계약·처분·세율·대표권은 [HOH 보류](options.md#보류)로 남긴다.
