# 운영 조건과 비용의 판단 입력

**현재 사용 가능한 자원과 미래 보충 계획을 별도로 대조하고, 필요한 순간의 부족을 확인한다.** [흐름 OF01-OF09](flows.md)에 적용할 문서 후보이며 실제 수급 계산 결과는 아니다. [PR06](../../../Scenario.md#벨레스-첫-장의-진행과-재개)·[VD04](../../../Scenario.md#벨레스-첫-장의-공간운영전투-검증-기준), [NG06 운영 입력](../2026-11-15-veles-validation-design/operations.md)을 재사용한다.

## 판단의 구분

| 판정 | 뜻 | 다음 행동 |
|---|---|---|
| 충족 근거 있음 | 해당 시점·범위에 실제 확인·인수·자원과 접근 근거가 있다. | 그 판단에 필요한 다음 일을 진행한다. 미래 조건까지 보장하지 않는다. |
| 부족 확인 | 필요한 품목·시간·동의·작업 여유 중 빠진 것이 실제로 확인됐다. | 영향을 받은 운송·작업·이동 판단을 조정한다. 이미 끝낸 다른 성과는 유지한다. |
| 미확인 | 값·단위·시점·현재 답변 또는 관측이 없다. | 확인할 당사자와 막힌 판단을 남긴다. 충분도 재난도 추정하지 않는다. |
| 조건 변경 | 과거 확인 뒤 사용량·운항·담당·공급 조건이 바뀌었다. | 영향받는 부분만 다시 확인한다. 모든 인계를 처음부터 반복하지 않는다. |

이는 서면 판단 분류다. 고정 대화 순서·UI 표시·퀘스트 상태·전역 이동 잠금의 확정이 아니다. 실제 실패·시간 경과·플레이어의 자유 이동을 어떻게 다룰지는 별도 설계다.

## 변수와 단위·출처

현재 확인한 원문에는 아래 값의 정량 범위가 없다. 단위를 고르는 것도 입력 작업이며, 표의 단위 예시는 새 세계 수치나 통화 체계를 정하는 것이 아니다.

| ID | 필요한 변수와 단위 | 근거·값을 확인할 상대 | 값이 없을 때 막히는 판단 |
|---|---|---|---|
| OV01 사용 가능량 | 자원 k별 실재고·위치·확인 시점, 손상·이미 예약된 양. 물은 부피, 동력은 정의된 용량 또는 동일 규격 개수, 부품은 규격별 개수 | 로덴 공급·보관 담당. [로덴 축소 운영](../2026-11-08-tarnel-roden-exploration/story-and-roundtrip.md) | OF01·08의 현재 버팀 조건. 서로 다른 규격을 개수만으로 합치지 않는다. |
| OV02 생활·제한 운영 소비 | 자원 k별 소비율, 같은 시간 단위, 사용자·필수 공급·가동 범위 | 로덴 현지 운용 담당, World 유한 자원 | 대기·운송·재작업 사이 지속 가능성. 축소 운영이 소비 없음은 아니다. |
| OV03 운송 묶음 | 첫 허가 화물·S4 일반 화물·하르덴 자료/부품을 구분한 실제 확보·허가·선적·도착·인수량 | 배정소·선주·로덴 수령자, 이그니스 인계 원문 | 아직 없는 물량을 현재 재고에 넣는 오류와 같은 화물 중복 계산. |
| OV04 이동·회신 시간 | 대기·하역·각 운송 구간·회신 전달의 경과, 실제 경로·짐·접안·운항 조건 | 해당 편 선장·운송 담당·수령자 | 수령 회신 예상과 다음 보충까지의 운영 여유. 원문 평면 거리를 속도 없이 기간으로 환산하지 않는다. |
| OV05 적재·접근 | 실제 배·적재 무게/부피·보관·하역 여력, 품목 규격·손상·선적 허용 조건 | 첫 예비선 선주, 후속 상행편 선장, 각 수령자 | 허가 물량이 실제 옮겨질 수 있는지. 정원과 화물 능력, 강배와 원양선을 혼동하지 않는다. |
| OV06 수리·시험 자원 | 작업별 남은 시간·품목·공구·교육·인력 작업량, 실제 완료/소모 내역 | 린과 수리 담당, 하르덴 장인, 로덴 기술자 | 배 수리·시험 운항과 설비 시험의 각각의 완료. 한쪽 성공이 다른 쪽을 대체하지 않는다. |
| OV07 현지 물·설비 조건 | 로덴 수두·유량·부하·정비 능력, 하르덴과의 차이·측정 단위·제한 시험의 허용/중지 범위 | [하르덴 원문](../2026-11-08-serna-harden-exploration/story-and-roundtrip.md)의 조건표와 로덴 실측 | 현지 적용·시험 성공. 범위 밖이면 중지·보완하며 임의 수치를 넣지 않는다. |
| OV08 비용·부담 인수 | 운임·수리·교육·지연·놓친 일감의 각각의 근거, 지급/미지급·부담 합의 범위. 기존 거래 단위가 확인된 경우만 금액 사용 | 로덴 부담 회신, 선주·린·공방·비용 당사자 | 누가 남은 비용을 맡는지. 현금·물자·노동을 환산 근거 없이 총액으로 더하지 않는다. |
| OV09 인수 범위·정보 시점 | 담당자가 이해·동의한 일, 빠진 질문, 관찰·발신·수신 시점, 그 뒤 바뀐 조건 | 로덴 후임·적용 담당·운영 담당, 실제 전달자 | OF04의 수령 인지와 OF08의 북행 판단. 이름·서명·발송만으로 동의를 만들지 않는다. |
| OV10 다음 대응 가능성 | 확인된 다음 보충의 양·도착 조건, 재시험·추가 운송·선택 재방문의 접근·인력·소모 | 현재 운영·운송·시험 당사자 | 시험 미완료 상태의 운영 여유와 문제 발생 후 대응. 원거리 대기나 무상 회복으로 채우지 않는다. |

## 시점별 수지와 민감도

다음 식은 값이 들어왔을 때 사용할 분석 틀이다. 수치가 없으므로 이번에 충분한 물량·일수·허용 지연 범위를 산출하지 않는다. 가상 숫자로 통과 사례를 만들지도 않는다.

자원 k의 기준 시점 사용 가능량을 U_k라 두고, 그 뒤 시점 t까지 **실제 인수해 사용 가능해진 보충**을 A_k(t), 생활·운영의 실제 소비를 C_k(t), 작업 소비를 W_k(t), 이후 새로 사용 불가해진 손실·예약분을 X_k(t)로 나눈다. 그러면 잔량 대조식은 `B_k(t) = U_k + A_k(t) - C_k(t) - W_k(t) - X_k(t)`다. 기준 시점의 손상·예약은 이미 U_k에서 제외하므로 X_k로 다시 빼지 않는다. 작업비·운반 손실도 한 항목에만 반영해 이중 차감하지 않는다.

각 사용 시점에 그때 필요한 양과 접근 조건을 충족해야 한다. 마지막 잔량이 남아도 중간에 필수 공급이 끊기면 지속 근거가 없다. 식이 음수가 되면 실제로 음수 재고가 생겼다는 뜻이 아니라 그 소비 계획을 이행할 수 없다는 뜻이다. 비축의 실제 하한·필수 공급량은 현지 입력으로 정하며 새 비상 기준을 발명하지 않는다.

예정 보충은 별도 계획 항목 P_k(t)로 둔다. 확보·운송·인수 가능성의 근거와 도착 불확실성을 표시하고, 도착 전 실제 B_k에 더하지 않는다. 인수 때 같은 묶음을 계획에서 이행으로 표시해 중복 계상하지 않는다. **북행 판단은 미래 보충을 전부 무시하는 것도, 약속을 현재량으로 세는 것도 아니다.** 확인된 현재 운영과 다음 보충 조건으로 계획 구간을 검토하되 실제 현지 시험 성공은 별도로 남긴다.

| 변동 조건 | 필요한 대조 | 결론의 한계 |
|---|---|---|
| 도착/회신 지연 Δt | 추가 대기 구간의 자원별 소비와 실제 가능한 대응을 더한다. 해당 구간의 소비율이 일정하다는 근거가 있을 때만 추가 소비를 소비율 × Δt로 계산한다. | 회신 지연과 물자 도착 지연은 다르다. 회신만 늦으면 로덴 실제 재고를 임의로 줄이지 않는다. |
| 허가 물량 일부 미도착 | 품목별 실제 인수량을 사용하고, 부족 품목이 필수 운영·시험·여분 중 어디에 필요한지 나눈다. | 총 상자 수가 같아도 품질·규격이 다르면 대체할 수 없다. 부족이 모든 운영의 즉시 실패를 뜻하지 않는다. |
| 시험 한 번 추가 | 이미 끝낸 수리·소모는 보존하고 이번 재시험의 추가 자원·교육·시간만 넣는다. | 같은 성과의 비용을 다시 청구하거나 재시험을 무상으로 처리하지 않는다. |
| 담당자/운항 변경 | 새 담당의 이해·여력과 바뀐 구간의 시간·하역·비용만 갱신한다. | 기존 완료 사실을 취소하지 않지만 옛 동의가 새 담당에게 자동 승계되지 않는다. |

자료의 관찰 시점 이후 변화에 대한 근거가 없으면 오래됐다는 이유만으로 임의 유효시간을 적용하지 않는다. 관련 변경 여부와 현재 계획에 쓸 수 있는 범위를 묻는다. 운송 중 최신 현황을 자동으로 알 수 없으며 범위를 확인할 수 없으면 북행 조건은 미확인으로 남는다.

## 비용을 부담하는 선택

| 선택 | 얻는 것 | 실제 남는 비용과 확인 |
|---|---|---|
| 현지 담당과 운송망을 통한 기본 인계 | 로덴을 다시 방문하지 않아도 역할을 나누고 북부 조사를 준비할 수 있다. | 왕복 전달·교육·추가 운송과 현지 시험 책임이 남는다. OF08의 근거가 필요하다. |
| 선택 재방문 | 주인공·마렌이 실제 현장 차이와 필요한 작업을 직접 대조할 수 있다. | 왕복 이동·부재·보충·운항 비용이 추가된다. 방문 자체가 전문 판단이나 물량 부족을 해결하지 않는다. |
| 관련 이동·시험을 미루고 지원을 재합의 | 현재 부족한 조건을 숨기지 않고 피해를 줄일 대안을 찾는다. | 대기 소비·놓친 일정·추가 작업을 부담한다. 자동 실패 타이머·강제 하루 대기를 만들지 않는다. |

운영·손실의 인수는 구조 공로에 대한 보상이나 모든 책임의 최종 정산이 아니다. 실제 입력·정량 범위·비용 합의가 마련되기 전에는 특정 선택이 항상 싸거나 안전하다고 결론 내리지 않는다.
