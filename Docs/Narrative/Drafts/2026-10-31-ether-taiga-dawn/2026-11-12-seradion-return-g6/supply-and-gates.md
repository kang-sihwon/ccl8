# 현지 적용·급수·대피와 G6 인수

**G6는 니베르 기록을 가져오는 것만으로 완료되지 않는다. 현지 적용 조건·대피·필수 수원 운용 준비를 각각 담당자가 인수해야 한다.** 기준은 [기존 G6](../2026-11-08-five-continent-mainline/routes-and-unlocks.md#이동이야기-시작-조건)다. 아래 항목은 추천 플롯에서 확인하는 사건이며 실제 설비 검증·운영 승인서가 아니다.

## 이미 확보한 것과 다시 확인할 것

| 구분 | 이번에 유지하는 성과 | 추가 확인 |
|---|---|---|
| 니베르 근거 | 생존자 8명의 인계, 동의받은 진술, 소모·중단 기록, 잔존 공통 연결의 현장 관찰 | 현지 도면과 같은 부품·같은 차단 순서라고 단정하지 않는다. 빠진 기록과 진술 차이를 남긴다. |
| 주민 공급 | C11 기존 샘·C12 비축·C02 주민 분기는 앞서 인수했다. WG6 재처치 없이 C07 잠금부 점검 결과를 이어받는다. | 현재 누설·역류·비축·교대와 나가 협의 유효 범위를 관리회가 다시 본다. |
| 시험 확대 중지 | 원정 중 확대 운전 중지와 일상 책임자는 유지됐다. | 정지한 심부의 잔류 공통 연결·재가동 명령 권한은 별도 과제다. 주민 분리 성과와 혼동하지 않는다. |
| 주민·정비 인력 보호 | 기존 주민·현지 운영자가 책임을 나눈다. | 작업 영향 구역의 명부와 Q04/Q05 대기 장소, 정비조 Q07, 비상 연락·철수 기준을 확인한다. |

니베르에서 가져온 분리 원리는 관찰 순서의 참고 자료다. 현지의 공통 연결·정지 확인·파편 냉각 위험과 정상 자원 공급을 실제 도면·표식·담당자의 관측으로 대조한다. 주인공의 정비 경험이 현지 기술자의 권한과 지식을 대체하지 않는다. 검은 결정은 정상 비축처럼 사용하지 않고 분리 뒤에도 냉각 위험을 남긴다.

## 주민 공급과 작업 여력

C11-C12-C02의 지하 배관은 기존 도식 그대로다. 새 보행로를 그렸다는 이유로 급수 배관·압력·용량이 생기지 않는다. Q02는 주민 분기 관측 마당, Q03은 배급 준비 공간이며 새 물 생산 시설이 아니다. 현지 관리자는 기존 샘 취수와 정상 비축의 실제 여유를 대조하고, 급수가 불안정하면 배급·작업 축소를 먼저 선택한다.

남부항의 귀환 비축과 구조자 몫은 Q03 주민 비축으로 옮겨 계산하지 않는다. 비용·물자 책임은 수원관리회와 기존 배급 담당자가 맡는다. 현지 확인량이 알려지지 않았으므로 인구·일수·수량을 새로 확정하지 않는다. 이야기에서는 필요한 작업창과 지연 여유를 확보했다는 담당자의 인수 장면을 두며, 현실 검증을 끝냈다고 보고하지 않는다.

G6 전에는 심부를 건드리지 않고 접근 가능한 관측 지점과 기존 도면으로 **작업 준비**를 인수한다. 실제 심부 잔류 연결 확인·분리는 다음 전투 이후다. 준비에 필요한 정보가 부족하면 G6를 보류하고 외부 관측·기술자 질의를 보완한다. 결말 전투를 끝내야 G6를 얻는 순환 조건을 만들지 않는다.

## 대피 인계와 실패 시 행동

| 장소·책임 | 준비와 인수 조건 | 부족할 때 |
|---|---|---|
| C13 정비 인수 마당 | 관리회가 영향 범위·남을 운전 인력·나갈 주민 및 비필수 작업자를 명부로 나눈다. | 영향 범위가 미확인이면 작업 구역을 줄이고 관측한다. 모든 도시 주민을 일괄 강제 이주시킨 것으로 쓰지 않는다. |
| Q04 주민 집결·Q05 임시 대피 | 주민 대표가 실제 수용 공간·물·휴식·안내 담당과 인수 명부를 확인한다. | 정원 미확인 공간에 인원을 무한히 채우지 않는다. 추가 분산 장소를 확인하기 전 G6 준비 완료로 처리하지 않는다. |
| Q06 연락·Q14 뒤쪽 연결 | 현지 안내 담당자가 주 대피로와 우회 귀환을 직접 확인하고 연락 인수 시점을 정한다. | 시야·통행이 나쁘면 안전하다고 처리하지 않고 관측·인력 배치를 보완한다. 실시간 통신을 추가하지 않는다. |
| Q07 정비조 집결 | 현지 정비 책임자가 정상 공구·대체 공급·인력·철수 신호·접근 범위를 확인한다. | 전투가 시작됐다는 이유로 미준비 정비조를 투입하지 않는다. |

주민 대피는 C13-Q06-Q04-Q05, 북쪽 보조 연결은 Q04-Q14-Q03-C12 후보를 쓴다. 기존 C12-C13 운영길과 이어지며 호수·괴물 선택 구역을 건너지 않는다. 실제 통행 폭·경사·군중 이동은 별도 검증 대상이다. Q05는 새 대피 장소 후보고 남부항 P12와 다른 공간이다. 남부항에 남은 생존자 8명을 이 명부에 중복 계수하지 않는다.

## 추천 플롯의 상태

| 시점 | G6 | 완료한 것 | 아직 남은 것 |
|---|---|---|---|
| 남부항 귀항 | 미완료 | 24명 귀항·구조자 인수 | 현지 적용·대피·필수 공급 준비 |
| C10/Q01 대조 | 미완료 | 니베르 근거와 현지 관측·도면 비교 | 준비 인수의 실제 완료 |
| C13 인수 | 완료 | 현지 적용 범위·대피·필수 수원 운용 준비 | 기록 공개 후 결말 사건 |
| 공개 뒤 점거·Q08 정찰 | 유지하되 준비 조건 재확인 | 결말 사건 시작·접근 판단 | 강제 재가동 저지·중추 방어체·실제 심부 분리·운영 인계 |

점거가 대피로·필수 공급·연락 조건을 침범하면 준비를 다시 확인하고 돌파를 미룬다. G6 완료 표시가 이후 모든 상황의 안전을 보장하지 않는다. 니베르 귀환과 T5 귀환 계약은 G6와 별개이며, 결말 전투 실패를 이유로 대륙 밖 배편을 몰수하지 않는다.

기준 성장 58·선택 +2를 유지한다. [결말 예산](../2026-11-08-world-distribution-and-leveling/progression.md)의 주요 목표 1과 조사 1은 다음 강제 재가동 저지·운영 인계에 남긴다. 이번 계약·대피 확인·문서 전달마다 별도 메인 레벨을 더하지 않는다. 일반 교전 경험의 실제 분배는 미정이며 완전 무보상이라고 확정하지 않는다.
