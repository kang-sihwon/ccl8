# 여정 연결의 추천·대안·보류

2026-11-15 사용자가 JC01-JC06과 공통 경계를 모두 채택했다. 해당 강조·효과·제한은 [결정 60](../../../../decisions/0060-world-journey-connections-adoption.md)·[Scenario](../../../Scenario.md#여정-연결과-현재-인수)에 반영해 `CLOSED`다. 아래 미채택·선택 예정은 승인 전 기록이며, JA01-JA02·JH01-JH05·JI01-JI08과 기존 원문·표·사례·수치·지도·좌표는 보존한다. 원문 전체를 일괄 확정하지 않는다.

**JC01-JC06과 공통 경계의 연결 강조를 묶어 채택하는 안을 추천한다.** 기존 G1-G6·주민 성과·인물 변화·생활권은 유지하고, 인계가 어디까지 끝났는지 독자가 구분하도록 한다. 기존 확정을 다시 승인받는 항목이 아니라 그 확정을 여정 연결에서 어떻게 강조할지 고르는 후보다. 상태는 사용자 선택 전이며 [전체 묶음](../2026-11-15-world-journey-alignment.md)이 검토 결과를 소유한다.

공통 경계는 다음과 같다. WP·CL·CP·FC·SC·NC·VR·IB의 확정과 유한 자원·성과 보존을 우선한다. 실제 관찰·전달·동의·작업·인수가 판단에 앞서야 한다. 일반 필드의 생활권·탐색·우회·왕복 교전과 모든 무기 선택을 유지하며, 전 개체 처치·특정 무기·강제 피격·필수 실패를 새 조건으로 넣지 않는다. 린·이르의 잔류와 마렌의 동행, 조건 없는 구호, G1 선택·G2 첫 방문·G4/G5 준비 이동·귀환과 G6·결말의 구분을 유지한다. 새 즉시 통신·자동 복구·무한 재고·숨은 파국 시간표·대륙 전체 스케일링은 만들지 않는다. 기존 원문·대안·보류·지도·좌표·수치·개체 상태를 보존하고 정확한 표현·구현은 별도로 둔다. 여섯 강조를 채택해도 이 묶음의 모든 통합표·사례·숫자·정치 제도를 일괄 승인하는 뜻은 아니다.
