# 생태와 성장의 현재 대조

**기존 성장 28지점의 전이와 30·14·15 예산 합계는 일치하지만, 탐색을 달리한 플레이어의 실제 레벨과 난도는 미검증이다.** 수치는 계속 창작 후보다. [IB05](../../../World.md#이그니스의-공급권한생활권)의 생태 구분을 적용해도 종·형태·경험치 예산을 새로 늘릴 근거는 없다. 상태와 후속 선택은 [여정 묶음](../2026-11-15-world-journey-alignment.md)을 따른다.

## 다시 계산한 범위

원천은 [통합 JSON](../../../../ArtDirection/EtherWorldMap/Data/world-journey-continuity-v1.json)의 `checkpoints`, `sources_sha256`, `placements`와 [현행 분류](../2026-11-08-world-distribution-and-leveling/species-distribution.md)·[형태 표](../2026-11-08-world-distribution-and-leveling/variant-distribution.md)·[성장 소유 문서](../2026-11-08-world-distribution-and-leveling/progression.md)다. Python으로 원문을 읽어 다음을 대조했다. 기존 검증 JSON의 PASS를 이번 실행 결과로 복사하지 않았다.

| 검사 | 결과 | 계산·한계 |
|---|---|---|
| 성장 원천과 전이 | 28지점 일치, 인접 시작·끝 불일치 0건 | 각 `source`·`pointer`의 기준·예산과 통합 행을 대조했다. 첫 시작 1, 마지막 60, 각 상승분=세 예산 합. 원천별 필드명을 맞춰 비교했다. |
| 예산 합계 | 필드 30·주요 목표 14·조사/관계 15, 합계 59 | 1+59=60. 필드와 목표의 합 44는 전투 시간 비율이 아니다. |
| 0상승 구간 | T345·G5P·G6P | 44 유지 환승, 52 유지 극지 준비, 58 유지 귀항 준비. 실제 인수가 없어도 된다는 뜻이나 교전 무보상 규칙이 아니다. |
| 기본 분류 | 고유 ID 64, 공통 44·고유 20 | 형태의 소속 대륙이 기본 항목의 배치 대륙에 포함되는지 확인했다. 생물학적 종 수로 해석하지 않는다. |
| 형태 분포 | 고유 형태 ID 199, 이그니스 59·아르베나 32·오르다스 44·세라디온 47·니베르 17 | 59+32+44+47+17=199. 전체 명부를 정본화하거나 메인 경로 필수 조우로 바꾸지 않는다. |
| 저장된 MN 배치와 현재 형태 표 | 189기록의 대륙·준비도 범위 일치, 양수 개체 수 | 기존 추출 `placements`를 현행 형태 표와 다시 대조했다. S1 고블린 A 1-4·B 3-5 예외도 확인했다. 이번에 모든 지역 JSON에서 배치를 다시 추출하거나 모든 권역·좌표를 재검증한 것은 아니다. |
| 원천 변경 확인 | 24개 해시 중 22개 일치, World·Scenario 2개 변경 | 원본 또는 LF 정규화 바이트의 SHA-256을 비교했다. 정본 둘은 후속 채택이 있어 현행 내용을 별도 서면 대조했다. 옛 해시를 갱신해 옛 검토를 새 검토처럼 만들지 않았다. |

189는 형태·수량·준비도 배정 기록 수다. 무리 수·개체 합계·고유 형태 수가 아니며 CT 구조체·사람·일반 동물·바르툴은 이 검사 밖이다. 원천 해시 일치는 자료가 같다는 증거이며 실제 생태나 새 정본과의 의미 일치를 보장하지 않는다.

## 성장의 집계와 탐색 선택

| 구간 | 기준 후보 | 필드·주요 목표·조사/관계 | 이번 판정 |
|---|---|---|---|
| 이그니스 S1-S6 | 1→24 | 11·6·6 | 유지. NC·VR의 야외 관찰 생략·익숙한 길 귀환을 필수 조우·자동 경험치로 보정하지 않는다. |
| 아르베나 | 24→34 | 6·2·2 | 유지. G1 선행 방문 없이도 G2 가능. 이미 얻은 발견은 재보상하지 않는다. |
| 오르다스 | 34→44 | 6·2·2 | 유지. 외항 조사·수로 회수·고개 인수는 별도 목적이며 레벨을 입항 허가로 쓰지 않는다. |
| 세라디온 전반 | 44→52 | 4·2·2 | 유지. 환승·원양 계약은 0상승 준비, 하구 조사·숲·수원은 기존 예산. |
| 니베르 | 52→58 | 3·1·2 | 유지. 구조와 별도 조사의 목표 보상을 구분하고 미완료 조사를 귀환 조건으로 만들지 않는다. |
| 세라디온 결말 | 58→60 | 0·1·1 | 유지. 중추 전투와 실제 분리·인수에 한 번씩 배분하는 비교안이다. G6 준비는 그 보상에 선행한다. |

G1 선행 탐색 +1/+2를 더한 비교 종점은 61/62다. 넓은 선택 탐색 +4-8의 비교 종점 64-68에는 G1도 포함되며 대륙마다 +2를 더하는 규칙이 아니다. 선택을 생략한 서사 연결이 성립해도 실제 경험치·장비·숙련이 이 기준에 도달하는지는 확인하지 않았다. 특히 NC01 사례는 전 개체 처치나 늑대전이 필요 없으므로 S1의 필드 3 예산을 어떤 행동으로 얻는지는 미검증이다. 오류를 고치겠다며 강제 사냥·레벨 맞춤·보상 증액을 추가하지 않는다.

## 생태와 이동 이유

| 생활권 | 기존 유지 조건과 이동의 이유 | 막아야 할 혼동·남은 확인 |
|---|---|---|
| 이그니스 숲·하구·고원·설선·세계수 | 동물·고블린 생활권·정비 시설을 구분하며 수원 기록·구조·수리·북부 기록·중앙 현지 대조로 이동한다. | IB05의 E1-E3를 모든 외곽 마을에 복제하지 않는다. 새로 채택한 교역 관계가 적 배치나 전투 수를 늘리지 않는다. |
| 아르베나 공공 항만·곡창·깊은 연안 | 선행 방문 때도 생물·생활은 존재한다. G2는 조사 계약·작업선·현장 정보의 조건이다. | G2가 몬스터를 강화·생성하는 스위치가 아니다. 낮은 위험과 선택 심부가 함께 남는다. |
| 오르다스 물길·목축 고원 | 인간의 점거·배정과 포식자의 먹이·둥지·이동을 구분한다. 외항 조사 후 현지 합의가 필요하다. | 종 전체를 점거조로 취급하지 않고 전투 승리가 물 사용권을 주지 않는다. |
| 세라디온 하구·성숙림·현용 수원 | 주민·나가·관리회와 생물의 생활권이 겹친다. 현지 관측과 합의가 수원 조사로 이어진다. | 전 대륙 생물을 사업단의 장치로 연결하지 않는다. 숲과 수원을 한 연속 보스방으로 압축하지 않는다. |
| 니베르 해양 먹이·국소 열·시험 잔류권 | 구호가 우선이며 별도 조사는 귀환 여력 안에서 한다. 생물·현현·계약 존재의 유지 조건을 구분한다. | 용 처치·현지 사냥·새 자원 획득을 귀환 필수로 두지 않는다. 실제 먹이 수지·열·보온·생산성은 미검증이다. |
| 세라디온 재방문 | 앞선 생존·처치·주민 수원 분리는 유지하고 별도 점거 심부를 다룬다. | 일반 생물 전부가 후기 수준으로 오르지 않는다. 강경파를 전 세계 사건의 단일 배후로 만들지 않는다. |

근거는 [현행 지역 생태](../2026-11-08-world-distribution-and-leveling/regional-ecology.md)와 [이전 전체 생태 대조](../2026-11-13-world-journey-continuity/ecology-and-growth.md)다. 생활권의 서면 이유와 실제 AI·동시 합류·접근 창·통행 안전은 다른 검증 대상이다.

## 후속 검증의 입력

JC06은 탐색·선행 방문의 차이를 서사 완료·후보 성장·실제 경험치로 나누어 설명하는 강조 후보다. JH04에 같은 무기·장비·회복 조건에서 선행 방문 없음/있음, 야외 조우 적음/많음, 재방문 경로를 비교할 과제를 남긴다. 입력이 정해지기 전 특정 도착 레벨·전투 횟수·시간·재고 지속을 보장하지 않는다. 이번에는 성장 수치·원천 JSON·게임 보상 규칙을 수정하지 않았다.
