# 전투 판단과 인물 변화의 누적

채택 범위·보류·검증 상태는 [상위 문서](../2026-11-15-world-journey-alignment.md)를 따른다. 본문은 작성 당시 후보 기록이며 원문 전체를 정본화한 것이 아니다.

**첫 장에서 생긴 작은 신뢰는 이후의 잘못을 없애지 않으며, 하르덴 이후에는 배운 협력을 먼저 실행한다.** [Scenario의 CL·CP·FC·SC](../../../Scenario.md#전투-판단의-연결)를 유지하면서 [대표 전투 비교](https://github.com/kang-sihwon/ccl8/blob/2a95af4c674f816fdc3f55796714def2936abfd8/Docs/Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-13-regional-combat-and-choices.md)에 남은 반복 위험을 현재 확정과 대조했다. 새 동작·공격 순서·필수 실패·종 명부는 추가하지 않는다. 전체 상태는 [여정 묶음](../2026-11-15-world-journey-alignment.md)을 따른다.

## 전투에서 무엇이 달라지는가

| 비교 구간 | 관찰·공격·중지·철수의 차이 | 인물·후속 인수와 연결 | 판정과 남은 위험 |
|---|---|---|---|
| 바르툴 → 로덴 | 결박을 끊을수록 살아 있는 곰의 이동이 커지는 상황과, 구조 통로를 침범하지 않게 기계의 공격을 유도하는 상황을 나눈다. 해방 뒤 상호 이탈과 구조 작업의 직접 방해 종료는 다르다. | 벨레스의 실제 복구·주민 인수, 로덴의 들것 이송·축소 운영을 전투 결과와 따로 확인한다. | 유지. 둘을 장치 약점 파괴 하나로 요약할 위험은 남는다. 무기별 거리·구조 동선은 미검증이다. |
| 세르나 → 아르베나 | 세르나는 부상자의 이탈·린의 승선 신호, 아르베나는 구조자를 항만에 둔 뒤 별도 회수 작업의 접근면·공격 방향을 읽는다. 공격 중지와 목표 미완료 철수·목표 달성 이탈을 구분한다. | 린의 판단 침해·손실을 겪은 뒤 해외 선장의 판단을 처음부터 받아들인다. 구조자를 보스전 동행자로 되돌리지 않는다. | 유지. 해수 이름만 바꾸는 반복을 피하되 아르베나에서 신뢰를 다시 실패시키지 않는다. 실제 두 전투의 체감 차이는 미검증이다. |
| 하르덴 비룡 → 오르다스 흰침 | 사건 개체·착지·재상승의 판단을 바탕으로 측풍·사선·엄폐 변화를 읽는다. 정상 둥지·모든 개체를 사냥 목표로 확대하지 않는다. | 물·통행 협의와 시험 인수는 직접 위협 제거 이후에도 남는다. 하르덴의 협의가 오르다스 권한을 주지 않는다. | 유지. 이름은 기존 후보 식별용이며 실제 패턴·처치 수·필수 원거리 무기를 확정하지 않는다. |
| 북부 → 중앙 → 결말 방어체 | 북부의 고유 재잠금 종료, 중앙의 현재 측로·잠금 변화, 결말의 필요한 접근 판단을 구분한다. 이전 패턴을 전부 누적하거나 체력 증가로만 차별화하지 않는다. | 북부 기록은 가설, 중앙은 현지 공급 보호, 결말은 별도 심부 분리의 작업창이다. 준비를 보스 뒤 설명으로 미루지 않는다. | 유지. 같은 계통을 읽는 숙련과 반복 피로의 경계는 미검증이다. 세 구간의 실제 공간·실행 검증이 필요하다. |
| 키메라 → 히드라 → 빙편 정령 | 남은 부위 공격, 여러 방향 속 마른 땅, 낙하 뒤 접근·퇴로의 변화로 관찰 중심을 나눈다. | 숲의 합의 범위·주민 급수·구조자 본선 인수를 각기 지킨다. 정령 조사는 구조 뒤 귀환 여력이 허용할 때다. | 유지. ‘피하고 측면 공격’이라는 공통 문장만으로 차이를 증명할 수 없다. 실제 판정·공간·카메라는 보류다. |
| 북부 → 아르베나 → 니베르 구조 | 들것 길·통행 기회, 여러 현장의 구조와 별도 회수, 책임자에 대한 조건 없는 구호를 구분한다. | 북부 지연·이르의 추가 협력, 아르베나 자료 지연 가능성, 니베르 강요 수단 포기가 서로 다른 대가다. | 유지. 매 구조마다 사망·배신·자료 손실을 강제하지 않는다. 구조 인원을 추가하거나 기존 수량을 정본화하지 않는다. |

지역별 이름과 구조체 분류는 [기존 전투 연결 후보](../2026-11-13-combat-learning-continuity.md)의 비교 표식이다. 정본에서 채택한 판단 중심과 후보의 패턴·종·레벨을 구분한다. 대표 전투 사이에도 생활권에 따른 필드 교전·우회·왕복은 가능하며 모든 일반 교전에 핵심 단서나 새 인물 실수를 붙이지 않는다.

## 네 인물의 이어지는 선택

| 인물 | 출발점 → 누적 변화 | 이후에도 남는 것 | 이번 연결에서 강조할 후보 |
|---|---|---|---|
| 주인공 | 벨레스에서 실제 인수를 믿고 떠남 → 로덴에서 확인 생략 인정 → 세르나에서 알고도 침해한 판단의 책임 → 하르덴부터 먼저 도움 요청 → 해외의 현지 판단·니베르의 무조건 구호 → 다음 교대 수용 | 호기심·직접 전투·책임감과 서두를 가능성. 처음 신뢰한 경험이 모든 약점의 소멸은 아니다. | JC04: 낯선 현장에서 이미 맡길 줄 아는 행동을 먼저 보이고, 새 질문은 그 현장의 관측·권한 차이에서 생기게 한다. 새 실패로 성장을 증명하지 않는다. |
| 린 | 벨레스 역할 유지 → 자기 운송 일로 합류 → 세르나의 배 손실·판단 침해 → 시험 운항에서 업무 신뢰 회복 → 운송 잔류 | 배와 운항 결정권·놓친 일감·친밀감 회복의 속도. 주인공의 여행을 위해 삶을 포기하지 않는다. | JC04: 이후 실제 도착한 운송 결과로 역할을 잇는다. 린의 짧은 소식이 현재 재고·계약 전체·친밀감 회복을 대신하지 않게 한다. |
| 마렌 | 로덴 우회 승인·기록 누락 인정 → 현지 후임 인수 → 하르덴·해외의 상호 검토 → 니베르에서 자기 과거와 책임자의 사실 분리 → 다음 교대 수용 | 책임·불편함·확인을 붙잡는 성향. 고백이 면책·사제 관계가 되지 않는다. | JC04: 새로운 관측과 이미 확인한 사실을 나눠 주인공과 서로 검토한다. 모든 지역에서 같은 죄책감 고백을 반복하거나 새 은폐 사실을 만들지 않는다. |
| 이르 | 북부에서 협력 범위·우려 설명 → 통행 지연을 주민 탓으로 돌리지 않은 행동에 추가 정보 공유 → 중앙의 시민 인수 → 북부·중앙 연락 잔류 | 경계와 주민 우선, 대표권 없는 협력자라는 한계. 한 번 구조했다고 전적 신뢰가 되지 않는다. | JC04: 해외의 선택은 이르의 즉시 승인 대신 이미 배운 현지 권한 존중으로 잇는다. 해외 재합류·린과의 새 친분은 만들지 않는다. |

근거는 [CP01-CP12](../../../Scenario.md#네-인물의-개인-동기)와 [SC01-SC13](../../../Scenario.md#장면-연결과-정보-공개)다. 위 화살표는 고정 플레이 단계나 내면 수치가 아니다. JC04는 기존 변화의 순서를 바꾸지 않는 표현 강조이며, 표 전체의 모든 문장을 새로운 정본으로 승격하지 않는다.

## 지식과 성과가 앞당겨지는지 확인

| 확인 대상 | 유지할 선후 | 이번 대조 |
|---|---|---|
| 벨레스의 사고 원인 | 현장·도면에서 현재 고장과 차단 계획까지만 안다. | 곰 해방·고블린 약탈을 변경자·공모의 증거로 쓴 새 연결 없음. |
| 북부 기록·하르덴 기술 | 현지 시험·기록을 현재 장소의 조건과 다시 맞춘다. | 발송·사본 보유·기술 협력을 적용 성공으로 바꾸지 않음. JC01 강조 대상. |
| 아르베나·오르다스·세라디온 | 불일치 → 수색·행선지 → 현지 수령·물 배정 → 초청 → 현용 수원 관측. | 다음 지역의 원인·권한을 이전 계약 하나로 미리 얻지 않음. |
| 니베르·결말 | 본선 구호 → 별도 조사 → 귀항 후 대조·준비 → 공개·점거 대응 → 직접 전투·분리·인수·다음 교대. | 구호를 협조의 대가로 쓰거나 니베르 관찰을 즉시 원격 적용하지 않음. |

문서상 차이는 확인했으나 독자의 피로·전투 체감·선택의 가독성을 측정하지 않았다. 정확한 대사·장면 길이·공격 연출·실제 인지 검증은 보류한다.
