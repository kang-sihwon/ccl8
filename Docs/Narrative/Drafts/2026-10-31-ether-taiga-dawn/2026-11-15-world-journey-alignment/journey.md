# 이동과 인수의 현재 조건

2026-11-15 사용자가 JC01-JC06과 공통 경계를 모두 채택했다. 해당 강조·효과·제한은 [결정 60](../../../../decisions/0060-world-journey-connections-adoption.md)·[Scenario](../../../Scenario.md#여정-연결과-현재-인수)에 반영해 `CLOSED`다. 아래 미채택·선택 예정은 승인 전 기록이며, JA01-JA02·JH01-JH05·JI01-JI08과 기존 원문·표·사례·수치·지도·좌표는 보존한다. 원문 전체를 일괄 확정하지 않는다.

**해금은 앞선 성과·계약·현지 인수가 갖춰진 상태이며, 실제 승선·작업 가능성은 그 자리의 조건으로 확인한다.** 아래 표는 [Scenario](../../../Scenario.md)의 확정 WP·FC·SC·NC·IB를 기존 상세와 대조한 결과다. 지역별 미정 수치·장소 ID·정확한 사건 표현까지 확정하지 않는다. 선택과 상태는 [전체 묶음](../2026-11-15-world-journey-alignment.md)이 소유한다.

## 구간별 인계

| 구간 | 앞에서 성립한 것·주인공이 아는 범위 | 현지 인수·남는 사람 | 다음 이동 전 확인·아직 모르는 것 |
|---|---|---|---|
| 벨레스 → 타르넬 | 수원 현장·도면을 실제 대조하고 외부 결박 해방·정비·송수·하류 사용을 구분한다. 사고 변경자·대륙 공모는 모른다. | 주민 담당자의 이해·동의·현재 재고·보충·다음 아침 점검. 린은 벨레스에 남는다. | NC02 조사 누락·NC03 미완료 귀환·NC04 인수 부족은 실제 확인 전 정상 출항이 아니다. 이상 시 연기하고 예정 운송 배편의 세계수 상부 수관에서 첫 장을 닫는다. IB01의 거래망은 실재고가 아니다. |
| 타르넬·로덴 → 세르나 | 수원 기록 전달 중 붕괴·구조를 겪고, 주인공의 확인 생략과 마렌의 우회 승인·기록 누락을 각자의 사실로 밝힌다. 붕괴는 주인공 조작 전이다. | 작업자의 구조·치료·축소 공급을 현지 후임이 인수한다. 마렌은 인수 뒤 동행한다. 린은 자신의 화물·하역 일로 후속 회차에 합류한다. | 구조 성공과 부품·운송 문제 해결은 다르다. 기록 비교와 남은 수리 필요가 세르나행의 이유다. 인계자 이름만 정하고 떠나지 않는다. |
| 세르나 → 하르덴 또는 G1 | 린의 계획을 이해한 뒤 구출 집착으로 판단을 침해한 대가와 실제 구조 성과가 함께 남는다. 해수 대응은 종 전체 제거가 아니다. | 허가 화물의 로덴 실제 수령 회신, 린의 배 수리·시험 운항·비용 인수를 확인한다. 린은 세르나·로덴 운송에 남는다. | S4 상행과 G1 해외 왕복 선실은 다른 조건이다. G1 선택 방문 뒤에는 귀환·부재 중 업무 인수와 현재 배편을 확인해 S4에 잇는다. 왕복 기간·물량은 미정이다. |
| 켈바·하르덴 → 북부 | 현지 시험·제작 표식·대조 기록이 북부 기록 조사로 이어진다. 하르덴 H02 상류 취수와 윗샘 H09→켈바 기여를 구분한다. | 공방·경작·수로 당사자가 물·교육·보수 부담과 제한 시험을 협의한다. 로덴 적용 담당자의 인수 동의·운영 여유를 확인한다. | 윗샘 수문으로 하르덴을 원격 조절하지 않는다. 자료 발송은 수령·현지 적용 성공이 아니다. 북행 전 운영이 못 버티면 지원·출발 조정, 북행 뒤 실제 실패 회신은 당시 현지 조건으로 대응한다. |
| 북부 → 중앙 | 구조를 택해 통행 기회를 놓친 뒤 별도 기록 접근으로 사본·발견 조건을 확보한다. 기록은 중앙의 현재 연결에 관한 가설이다. | 부상자·난방·구조 업무·원본은 현지에 인수한다. 이르는 인수 뒤 중앙까지 동행하되 주민 배정권을 대신하지 않는다. | 현재 부하·공급·대피를 중앙에서 다시 대조한다. 옛 설계와 현재 설비를 같은 장치로 단정하거나 기록 회수를 자동 정지 권한으로 쓰지 않는다. |
| 중앙 → 세르나·G2 | 필수 공급·대피·명령을 준비하고 직접 돌파·강제 채취 중단·현지 인수를 이룬다. | 이르는 중앙·북부 연락에 남고 마렌은 동행한다. 린의 소식과 예정 운송을 실제 준비 물량으로 세지 않는다. | G1 준비와 조사 계약을 함께 갖춰 G2로 간다. 첫 해외 방문도 출항지 위임 접수로 가능하다. 선행 방문·레벨 24·보스 재처치를 조건으로 더하지 않는다. |
| 아르베나 도착·본편 → G3 | 첫 대조는 입출고·명령 기록 불일치까지다. 현지 수색·증언·계약 행선지를 얻은 시점에만 다음 판단에 쓴다. | 생존자를 항만에 먼저 인수하고 별도 무인 잔해 회수에 나선다. 구조자는 이후 원정 승객으로 자동 합류하지 않는다. 마렌과 현지 선장이 협력한다. | 통행·행선지·선주회 배편을 갖춰 오르다스 외항으로 간다. 구조가 회수 성공을, 계약서가 목적지의 모든 조사권을 대신하지 않는다. |
| 오르다스 외항 → 내해·고원 | 외항에 들어간 뒤 현지 수령·수위·배정·생활권 증언을 대조한다. 내해 봉쇄 해결은 첫 입항 조건이 아니다. | 수로청·물 이용자·목축 공동체·운송인의 권한을 나눠 협의한다. 전투 뒤 실제 하중·도선·고개 운반 시험과 운영 인수가 필요하다. | 내해와 고원 통행 회복·인수·실제 초청 회신을 확인한다. 요청 발송만으로 초청을 받았다고 하지 않는다. 세라디온 발주처 지식은 실제 대조 이후다. |
| 오르다스 → T3/T4 → 동안항·G4 | 현지 성과와 초청·항해 자료를 가지고 연안 환승한다. 준비 이동 자체가 원양 해금 완료는 아니다. | 오르다스 운영자는 현지에 남고 각 선장은 자기 구간을 인수한다. 루세아의 상업용 급수와 주민·구호 몫을 나누며 동안항에서 선박·선원·실제 적재·귀환 계약을 인수한다. | IB03의 청그물·루세아·동안항 관계는 장거리다. 가까운 마을이 즉시 보충하거나 같은 배로 원양을 건넌다고 쓰지 않는다. G4 준비 뒤 당일 운항 판단이 남는다. |
| T5 → 세라디온 하구·숲 | 초청의 조사 범위 안에서 하구 관측을 대조한다. 원인 전체나 보호림 개방을 미리 얻지 않는다. | 현지 도선사·관리회·어민·나가와 관측·작업 범위를 합의한다. 마렌은 현지 관측을 잇고 주인공은 직접 위협에 대응한다. | 키메라 뒤에도 현용 수원 조사·합의는 따로 성립한다. 무휴기관의 유한 설비 성격은 실제 관측으로 드러내되 모두에게 새 상식인 반전으로 만들지 않는다. |
| 현용 수원 → 남부항·G5 | 히드라 대응으로 작업창을 확보하고 주민 수원 분리·시험 확대 중지를 실제 인수한다. 구조 요청의 발신·시점·위치를 확인한다. | 기항항에서 별도 연안편으로 남부 원정항에 간다. 극지 개조·귀환 비축·피난·승선 여유를 선장·보급·항만 담당자가 인수한다. | 기술 협력 약속은 시공 완료가 아니다. 자리 확보는 생존자 수의 확증이 아니다. 식량 계획 예시는 현재 잔량이 아니며 귀환분을 조사 연장용으로 세지 않는다. |
| 니베르 접근·구조 → 본선 | 상륙 관측 뒤 흔적·회수로·실제 생존 현황을 확인한다. 장부 요구만으로 범행을 단정하지 않는다. | 협조·장부 제공·조사 참여를 조건으로 삼지 않고 생존자를 본선에 먼저 인수한다. 본선 인력은 보온·구호·운항을 맡는다. | 실제 회수·보온 전에는 구조 완료가 아니다. 원문 인원 배분은 비교 후보이며 명목 정원만으로 구조 성공을 보장하지 않는다. |
| 본선 인수 → 별도 조사 또는 귀환 | 구조 성과와 미완료 조사를 구분한다. 잔량·기상·회수 여력이 허용할 때만 기존 조사조가 재상륙한다. | 구조자는 본선에 남는다. 선장은 귀환 운항, 마렌은 증언·사본, 주인공은 현장 관찰을 맡는다. | 조사 미완료·자발적 철수라도 귀환은 G6와 독립이다. 귀환 협약은 즉시 운항 보장이 아니며 안전 섬·순간 구조선을 추가하지 않는다. |
| 세라디온 귀항 → G6 | 니베르 증언·기록·관찰을 들고 돌아온다. 그곳의 잔류 연결을 세라디온에 바로 복사하지 않는다. | 생존자·승무원은 남부항·본선 업무에 남고 주인공·마렌은 별도 연안편으로 이동한다. 현지 운영자가 적용·대피·필수 공급 준비를 인수한다. | 주민 수원 분리 성과는 유지한다. 미확인 자료·적용 조건이 남으면 G6는 미완료이며 귀환·구호 성과를 취소하지 않는다. 준비 뒤 공개·점거 대응으로 잇는다. |
| G6 → 결말 | 준비 인수와 공개 뒤 강경파 점거에 대응한다. 주인공의 해외 체류 일수가 자동 점거 타이머가 되지 않는다. | 직접 전투 뒤 현지 기술자가 위험 심부를 실제 분리하고 주민 운영·다음 교대 결과를 인수한다. 주인공·마렌이 이를 받아들인다. | 전투 승리만으로 결말이 끝나지 않는다. 손상·손실·책임·생활권은 남으며 전 세계 해결·새 G7·실제 귀향·린과 이르의 재합류는 추가하지 않는다. |

이 표의 유지 근거는 Scenario의 [대륙 이동](../../../Scenario.md#대륙-이동과-귀환-조건)·[FC](../../../Scenario.md#지역-갈등과-선택의-대가)·[SC](../../../Scenario.md#장면-연결과-정보-공개), World의 [IB 관계](../../../World.md#이그니스의-공급권한생활권)다. 세부 원문으로는 [이그니스 인계](../2026-11-09-ignis-journey-continuity/story-and-handoffs.md), [G1/G2 첫 방문](../2026-11-09-serna-arvena-passage/story-and-gates.md), [오르다스 첫 조사](../2026-11-09-ordas-arrival-investigation/story-and-handoffs.md), [환승·G4](../2026-11-10-seradion-arrival/story-and-handoffs.md), [G5 준비](../2026-11-10-seradion-polar-departure/readiness-and-return.md), [니베르 인수](../2026-11-12-niber-expedition-rescue/rescue-and-handoffs.md), [귀항](../2026-11-12-seradion-return-g6/story-and-handoffs.md), [결말 인수](../2026-11-13-seradion-finale/separation-and-ending.md)를 대조했다. 작업용 인원·수치·장소 ID는 원문에 남긴다.

## 연결을 확인한 비교 사례

| 사례 | 적용 결과 | 유지·보완·미확인 |
|---|---|---|
| 첫 장 야외 관찰·선택 조우를 적게 거침 | 실제 작업실 조사·전투·복구·인수·아침 확인이 성립하면 출항 인과가 이어진다. | NC·VR 유지. 같은 경로로 기준 레벨 6을 얻는지는 별도 미검증이며 자동 보정하지 않는다. |
| G1 방문 없음 / 방문 뒤 G2 재진입 | 최초 방문도 출항지 위임 계약으로 성립한다. 재진입은 이미 얻은 발견·성과와 현재 승선 조건을 구분한다. | 기존 원문 유지. 강제 선행 방문·재보상·적 강화 없음. |
| 하르덴 자료 발송 후 로덴 시험 미완료 | 발송·인수 동의·운영 여유와 현지 적용 성공을 나눠 보고한다. | JC01의 전달 강조 후보. 북행 전 운영 부족은 출발 조정, 북행 뒤 실패는 실제 회신 뒤 대응. 즉시 원격 지식 없음. |
| 루세아 환승에서 다음 선박·물량 미인수 | 초청·이전 통행 성과는 보존하되 현재 원양 준비는 미완료다. | JC03의 현지 인수 강조 후보. 새 기항지·같은 양의 우회·무료 비축 없음. |
| 니베르 구조 후 조사 중단 | 구조자의 본선 인수와 귀환 협약은 유지하고 자료 미확인만 남긴다. | JC05의 귀항 보고 강조 후보. 물리적 회수·운항 가능성과 사망·저장 규칙은 미검증·보류. |
| G6 준비 또는 중추 전투만 완료 | 준비·직접 위협 종료·실제 분리·운영·다음 교대는 다른 시점이다. | 기존 확정 유지. 결말 보상·완료 선언을 앞당기지 않는다. |

이 비교는 가능한 서사 연결의 서면 점검이다. 실패 시 자동으로 선택지를 실행하는 게임 상태 전환이나 모든 귀환로의 안전을 증명하지 않는다.
