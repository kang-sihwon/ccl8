# CHANGES_REQUESTED: 세계관·정착지·모험 플롯·지도 재검증

세계관과 여섯 지역 플롯의 골격은 이어지지만, 전투 강화 요청이 현행 플롯에 반영되지 않았고 아트 안내 일부가 보류 좌표를 현재 배치로 가리킨다. 두 항목을 우선 수정해야 한다. 대표 정착지 36곳의 설정과 지도 표기는 존재하며, 세계지도 면적과 주요 지역 거리의 재계산은 기존 결과와 일치했다. 후보 수정과 정본 반영은 수행하지 않았다.

## 검토 범위와 판정 기준

2026-11-04 사용자가 승인한 스킬 조합으로 현재 소유 문서, 연결된 후보와 이미지 원본을 대조했다. Codex가 정착지·세력·지도·수치·아트와 문서 간 연결을 검토하고 보고서를 작성했다. 세션 모델의 읽기 전용 독립 검토 에이전트 한 명은 기본 후보·첫 장·모험 플롯 지도·주인공·지역별 상세·벨레스→로덴 현행안 전체를 검토했다. 독립 검토자는 파일을 수정하지 않았다. 지도·수치·아트 부분은 작성자의 재검증이며 별도 독립 검토라고 보고하지 않는다.

| 사용 스킬 | 적용한 기준 |
|---|---|
| Creative Fiction Writer | 사건의 원인·선택·대가·성장·다음 지역 진입, 복선과 결말 |
| Game Designer Assistant | 일반 조우·보스의 역할, 전투 방식의 변화, 모든 무기 선택과 직접 전투 |
| Character Creator | 주인공의 욕망·약점, 동료의 개인 목적·권한·관계 변화 |
| Worldbuilding Studio | 생활 공급·통치·세력·정착지의 상호의존, 변경이 다른 문서에 미친 영향 |
| Mythology Creator | 세계수·에테르의 규칙, 몬스터 기원과 전승·기록의 연결 |
| Map Maker | 축척별 기준 분리, 정착지 수·방향·거리, 세계지도 면적과 시각 표기 |
| Concept Art Creator | 기존 이미지와 설정의 일치, 상태 변화·색·재질·실루엣, 제작 목록과 실제 산출물의 구분 |
| ccl8-narrative·ccl8-docs·ccl8-writing | 검토와 승인 구분, 증거·미검증 범위·문서 등록과 표현 |

스킬의 적용 범위와 연결은 [스킬 사용 안내](../../AgentContextTools/SkillUsage.md)를 따른다. 외부 자료 조사나 신규 이미지 생성은 하지 않았다. 문서 관계 그래프 조회는 오래된 그래프 경고와 일치 항목 없음으로 끝났으므로 원문 링크와 내용을 직접 확인했다.

심각도는 **BLOCKER**(다음 작업을 진행할 수 없는 오류), **WARNING**(수정하지 않으면 재작업이 예상되는 문제), **OBS**(해석·재현성 개선을 위한 관찰)로 구분한다. BLOCKER는 없다. 현재 확인된 문제는 WARNING 2건과 OBS 2건이다. 이미 문서가 인정한 지도 오차와 미완성 후보는 별도 절에 둔다. 판정은 후보의 품질 검토 결과이며 사용자 승인이나 정본 승격이 아니다.

기준은 [무기 선택 결정 37](../../decisions/0037-unrestricted-protagonist-weapons.md), [플롯 작업·이전안 보존 결정 36](../../decisions/0036-narrative-plot-drafts-and-retention.md), [수직 지도 표현 결정 35](../../decisions/0035-nadir-map-presentation.md)다. 장기 여정의 규모를 첫 게임의 제작 범위 위반으로 판정하지 않았다.

## 수정이 필요한 항목

### R1 · WARNING · 전투 강화 요청의 반영과 작업 추적이 빠졌다

사용자는 벨레스→로덴 상세 작성 뒤 “좋은데 전투의 비중을 많이 높여줘”라고 요청했지만, 현행안에는 그 요청에 따른 개정이 없고 재검증 시작 시 작업 지도도 바로 세르나 구체화를 다음 일로 지정하고 있었다.

- 근거: [벨레스→로덴](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-03-adventure-plot/2026-11-03-veles-roden.md) 58-64행의 군체전, 86-103행의 철근지기전, 161행 이후의 다음 검토. 검토 기준 커밋 `e1c71c3`의 [서사 현황](../CurrentWork.md) 10행은 다음 작업을 세르나 해수전·화물 반출·배 수리로 두었다.
- 영향: 전투는 사건 해결에 필요하지만, 강화 요청을 처리했다는 근거가 없다. 장면별 시간이나 전투 반복 수가 없어 전투 비율을 숫자로 계산하거나 기존 비중을 단정할 수는 없다.
- 수정 제안: 기존안을 보존하고 벨레스→로덴 전투 강화 개정을 먼저 작성한다. 진입전, 구조 중 조우, 보스전이 각각 다른 판단과 후속 사건을 만들도록 연결한다. 사람 간 갈등을 전부 전투로 바꾸거나 특정 무기를 강제할 필요는 없다.
- 확신도: 높음. 이번 기록에서는 남은 작업 순서만 바로잡았으며 플롯 본문은 수정하지 않았다.

### R2 · WARNING · 현행 아트 안내가 보류 배치안을 현재 좌표로 연결한다

벨레스 지리·아트 안내 세 곳이 보류된 옛 공간 배치를 현재 참조처럼 가리켜 최신 지역 설계와 혼용될 수 있다.

- 위치: [벨레스 지리](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-veles-geography.md) 9행의 “현재 지역 좌표·평면도·동선”, [벨레스 공간 참조](../../ArtDirection/EtherFirstChapter/VelesReferences.md) 34행의 “현재 평면 배치 후보”, [첫 장 시안 안내](../../ArtDirection/EtherFirstChapter.md) 16행의 “세계지도 v3에 연결한” 안내.
- 상충 근거: 세 링크의 대상인 [옛 공간 배치](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-first-chapter-spatial-layout.md) 3행은 보류 자료임을 명시하고, 25행은 공동 급수대를 원점 `(58.5°N, 4.8°E)`으로 둔다. 최신 [벨레스 지역 배치](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-veles-region-layout.md)는 나루를 원점으로 쓰며 세계지도 위경도에 아직 고정하지 않았다.
- 영향: 이후 아트 작업에서 오래된 원점·방위·세계지도 연결을 재사용할 수 있다. 파일 링크가 열리므로 일반 링크 검사만으로는 발견되지 않는다.
- 수정 제안: 현행 참조를 최신 지역 배치로 연결하고, 옛 문서는 비교 자료라는 설명과 함께 유지한다. 세계지도와 정합됐다는 표현도 현재 검증 범위에 맞춘다. 옛 파일을 지우는 방식은 쓰지 않는다.
- 확신도: 높음. 이번 검토에서는 대상 문서를 수정하지 않았다.

### R3 · OBS · 세르나가 참조하는 선행 전투 경험의 장소가 모호하다

[지역별 상세](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-03-adventure-plot/2026-11-03-regional-arcs.md) 65행의 “강의 전투 경험”은 주인공이 이미 강 위에서 싸운 것으로 읽힐 수 있지만, 현행 로덴 상세에서 주인공은 시설 발판에서 싸우고 린이 수상 구조를 판단한다.

- 대조 위치: [벨레스→로덴](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-03-adventure-plot/2026-11-03-veles-roden.md) 80-82행, 94-101행.
- 영향: 세르나에서 무엇이 처음 겪는 전투 조건인지 흐려진다. 강변 시설전까지 넓게 부르는 표현이라면 설정 모순으로 단정할 사안은 아니다.
- 수정 제안: “강변 시설과 육지에서 쌓은 전투 경험”으로 좁히거나, R1 개정에서 실제 수상 조우를 채택했다면 해당 경험에 연결한다.
- 확신도: 중간 이상. 독립 검토자가 연속성 문제로 제시했고 작성자는 표현의 모호성으로 분류했다.

### R4 · OBS · 지도 검증 해시의 정규화 설명이 저장값과 다르다

[세계지도 검증 JSON](../../ArtDirection/EtherWorldMap/Data/ether-world-map-land35-precise-v3-validation.json) 99행은 텍스트를 LF로 정규화한 SHA-256이라고 설명하지만, 101-102행의 JSON·SVG 해시는 현재 CRLF 원본 바이트의 해시와 일치한다.

- 재확인: CRLF 원본 JSON·SVG 및 PNG 세 파일의 해시는 모두 저장값과 일치했다. JSON·SVG의 CRLF를 LF로 바꾸면 저장값과 일치하지 않았다.
- 영향: 다른 기기에서 문서대로 LF 정규화를 적용하면 내용이 같아도 검증 실패로 보인다. 현재 지도 파일의 손상이나 면적 계산 오류를 뜻하지 않는다.
- 수정 제안: 기존 검증 기록을 보존하고 후속 검증 기록에서 LF 정규화 해시를 새로 계산해 설명과 맞춘다. 원본 바이트 해시를 유지할 경우 줄바꿈까지 포함한 해시라고 명시한다.
- 확신도: 높음. 이번에 해시 값을 덮어쓰지 않았다.

| 정치권과 연맹 | 정치권 4곳의 통치와 에테르 연맹의 계약·검사·금융 권한이 분리된다. 교역 관계를 영유권으로 취급하지 않는다 |
| 공급과 갈등 | 세르나 재고를 전량 해외 수입으로 가정하지 않고, 하르덴을 무한 대체 동력의 낙원으로 만들지 않는다. 주민 식량·종자·거목 휴식과 채권·납기 사이의 비용이 남는다 |

36곳은 대표 정착지 목록이다. 대륙의 모든 정착지나 필수 방문 지역을 뜻하지 않는다. 현행 수직 지도는 **36곳을 한 대륙도와 중앙 확대도에 표시한 한 장의 시안**이며, 36개 도시 각각의 내부 평면도를 완성한 상태는 아니다.

### 플롯·전투·인물·신화

[기본 후보](../Drafts/2026-10-31-ether-taiga-dawn.md), [첫 장](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-first-chapter.md), [모험 플롯 지도](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-03-adventure-plot.md), 주인공·지역별 상세·로덴 상세의 독립 검토와 작성자의 아트 지침 대조에서 다음을 확인했다.

- 벨레스의 성공을 취소해 여행을 강요하지 않는다. 기록 전달에서 시작한 여정이 로덴의 증거, 세르나의 임시 물량, 하르덴의 대안, 북부의 정지 기록을 거쳐 중앙의 선택으로 이어진다.
- 모든 무기를 사용할 수 있다는 목표와 무기별 숙련을 구분한다. 장면·아트 지침도 선택한 무기를 참조하며 도끼나 근접전으로 다시 고정하지 않는다. 실제 무기별 전투 성립은 별도 검증이다.
- 주인공은 역할을 나누면서도 직접 공격하고 위험을 감수한다. 로덴 보스는 동료의 작업이 끝날 때까지 기다리는 것만으로 승리하지 않는다.
- 린은 운송 계약·항행 판단·개인 여행 목적이 있고, 마렌은 과거의 책임과 현장 인계 의무가 있다. 주인공의 성장을 설명하는 대사만 맡는 동료가 아니다.
- 몬스터를 검은 결정 하나로 설명하지 않는다. 바르툴의 해방, 군체의 생물 활동, 구조체 정지, 비룡 토벌, 거수 유도가 구분된다. 인간의 공급·정비 선택이 생물 위협을 키우지만 협상만으로 난동 중인 구조체가 멈추지는 않는다.
- 세계수의 초자연적 기원을 무한 에너지나 즉시 회복으로 확장하지 않는다. 심근룡은 검은 결정의 원흉으로 확정되지 않았으며 인간의 과도한 채취 책임을 대체하지 않는다.

### 지도 수치 재계산

[v3 해안 JSON](../../ArtDirection/EtherWorldMap/Data/ether-world-map-land35-precise-v3.json)과 [SVG](../../ArtDirection/EtherWorldMap/Images/ether-world-map-land35-precise-v3.svg)를 각각 읽고, 위경도 선분의 `sin(위도)` 적분을 심프슨 구적법으로 다시 계산했다. 기존 생성 코드나 저장된 면적 결과를 계산 입력으로 쓰지 않았다. 행성 둘레 40,000km와 선분 해석은 [제작 기준표](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-map-production-basis.md), [기존 검증 기록](../../ArtDirection/EtherWorldMap/2026-11-01-precision-validation.md)을 따른다.

| 대상 | 이번 재계산 결과 |
|---|---:|
| JSON 전체 육지 비중 | 34.99999999999996% |
| SVG 전체 육지 비중 | 34.99999999999628% |
| 이그니스 육지 면적 | JSON 20,000,000.000000km², SVG 19,999,999.999995km² |
| 아르베나·오르다스·니베르 | 각각 40,000,000·35,000,000·10,000,000km²와 계산 정밀도 안에서 일치 |
| 세라디온 | 약 73,253,536.262923km² |
| SVG 대륙별 목표 차이 | 모두 0.001km² 미만 |

지역 수치는 [세계수·정착지 입력 JSON](../../ArtDirection/EtherWorldMap/Data/worldtree-settlement-basis-v1.json)의 좌표·높이·선분에서 다시 계산하고 저장된 `computed` 값과 비교했다. 방위정거도법 원점으로부터의 반경, 구면 점 사이 거리, 지역 도면의 평면 선분 길이를 구분했다.

| 대상 | 이번 재계산 결과 |
|---|---:|
| 세계수와 관리도시 중심 | 21.6333km |
| 세계수와 로덴 | 145.3444km |
| 세계수와 벨레스 | 208.6265km |
| 벨레스→로덴 구면 최단 거리 / 설계 강선 | 64.0311km / 73.3882km |
| 공방→수원 공동 보행선 | 1,464.3523m |
| 출항→공개 지점 강선 | 1,772.9904m |
| 나루에서 세계수 최상부 / 수관 하단 고도각 | 1.19744° / -0.17339° |
| 설계 강 중심선과 가림 능선 중심 최소 거리 | 295.3528m |
| 능선 반경·도면 강 반폭을 제외한 여유 | 41.4242m |

모든 표 항목은 기존 계산값의 표시 정밀도와 일치했다. 높이 8km·수관 너비 18km·상주 제한 반경 12km는 여전히 설계 후보이며, 거리 재계산으로 수목의 생물학적 성립이나 안전을 증명한 것은 아니다. 능선의 다섯 시선 표본 전체, 대륙 중첩·해협·교역선 교차·격자·래스터 면적은 이번에 전수 재실행하지 않았다. 해당 항목의 기존 PASS와 이번 재계산 범위를 구분한다.

## 검증하지 않은 범위와 다음 작업

[World](../World.md)와 [Scenario](../Scenario.md)의 확정 영역은 비어 있다. 이번 검토는 기존 후보 전체의 채택, 최종 보스 결정, 전투 강화 개정, 시안 수정·재생성, UE 실행, 무기별 판정·밸런스, 실제 수문·기후·생태·항행·경제 시뮬레이션을 수행하지 않았다. 과거 폐기·보류 이미지와 모든 생성 프롬프트의 전수 대조, 외부 작품과의 유사성 조사도 범위 밖이다.

후속 작업의 추천 순서는 다음과 같다. 이번에는 검토 보고서와 작업 현황만 기록했다.

1. 벨레스→로덴의 전투 강화 개정을 먼저 작성한다. 기존안은 결정 36에 따라 보존하고 전투 경험의 연결도 함께 정리한다.
2. 보류 좌표를 현재 참조로 소개하는 안내를 수정한다. 지도 해시 설명은 후속 검증 기록에서 바로잡는다.
3. 세르나의 판단 실패·배 수리·반출, 북부의 선택 비용, 후반 전투 차이와 동료 개인 사건을 구체화한다.
4. 지도 작업을 재개할 때 최신 좌표로 표식과 확대도를 보정한다. 심근룡은 채택 여부를 정한 뒤 지역별 복선을 배치한다.

작업 상태는 [서사 작업 현황](../CurrentWork.md)이 소유한다. 기존 PASS 보고서와 후보 원문은 보존하며, 이 재검증 결과가 앞선 검토의 제한된 통과 사실을 소급해서 지우지는 않는다.

## 기록 검증

보고서와 작업 지도 등록 후 `node Tools/Agent/docs.cjs check`는 문서 337개에서 오류 0건이었다. `preserve.cjs`로 기존 현황·작업 지도를 새 현황·지도·보고서와 대조한 결과 결정·숫자·경로·링크 누락은 0건이었다. `git diff --check`도 통과했다. 독립 검토자가 자신의 서사 지적과 검토 범위가 보고서에 반영됐는지 확인했으며, 아트 검토 주체를 구분하라는 관찰 한 건을 반영했다.
