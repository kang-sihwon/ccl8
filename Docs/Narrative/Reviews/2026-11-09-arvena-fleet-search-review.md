# 아르베나 실종 선단 수색·G3 후보 검토

**PASS. WARNING 2건과 표기 OBS 1건을 보완했으며 미해결 지적은 없다.** [수색 후보](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-09-arvena-fleet-search.md)와 사건·공간·생활권 문서, [지도 3장](../../ArtDirection/EtherWorldMap/2026-11-09-arvena-fleet-search-map.md)을 작성자와 별도 읽기 전용 검토자가 대조했다. 판정은 후보 문서와 국소 좌표의 정합에 한정하며 정본 승인이 아니다.

BLOCKER는 진행을 막는 충돌, WARNING은 반영 전 수정할 결함, OBS는 후속 판단·검증 사항이다. 최종 미해결 BLOCKER·WARNING은 없다.

## 지적과 반영

| 분류 | 근거·문제 | 반영 결과 |
|---|---|---|
| WARNING, 높음 | 구조 사건 표는 돌등게를 난파선 갑판에 배치했으나 CO1 좌표·반경은 북쪽 얕은 패류대다. | 돌등게는 북쪽 패류대·접안, 먹깃 하피는 난파선 갑판의 전투로 분리했다. 수량·형태·좌표는 유지한다. |
| WARNING, 중간 | C11 ‘견인 난파선 갑판’이 C04·C05와 어떤 관계인지 없어 세 번째 구조 대상이나 이동한 선체로 오해할 수 있다. | 별개의 무인 인양 잔해임을 사건·공간·JSON에 명시하고 진입 전 잔류 인원 확인을 추가했다. 구조 대상 7명과 두 선체는 유지한다. |
| OBS, 낮음 | 전체 지도 A06 글자와 A15의 무표기 점이 겹쳤다. | A06 글자를 왼쪽으로 옮겼다. 지점 좌표는 바꾸지 않았으며 수정 PNG를 재확인했다. |

| 접근·귀환 | 기존 항만의 두 교량과 새 육상·잔교·배 이동을 연결했다. 최종전 없이 구조·북쪽 항만 인수가 가능하다. C11-C10-C06 후퇴와 대응 후 남쪽 회수·높은 길 귀환은 사용 조건이 다르다. |

작성자 [계산 검사](../../ArtDirection/EtherWorldMap/Data/arvena-fleet-search-v1-validation.json)는 **116/116 PASS**다. 원본 해시, 도착항 객체 보존, 형태·범위·수량, 성장 몫, 이동 수단·경로 길이·연결, 구조자 고유 상태, SVG 지점·반경·갑판 확대를 대조했다. 북쪽 구조 이송선은 돛갈퀴 먹이터 중심에서 최소 2,163.3m, 활동 중심선에서 최소 1,484.1m 떨어져 있다. 후보 반경·추격 상한과의 평면 비교이며 실제 인식·수영·추격 검증이 아니다.

독립 검토자는 **313개 검사**를 통과했고 이 중 SVG **230요소**의 좌표·경로·생활권을 역산 대조했다. PNG 3장과 수정된 전체 지도 표기도 확인했다. 작성자 검사 결과를 읽었으나 116개 검사 전체를 별도로 재실행한 것은 아니다.

기존 후보에는 후속 링크를 추가하고 원문·정본·세계 분포·해금표를 유지했다. 문서 검사 467문서·오류 0건을 확인했다. 새 내용은 `DISCUSSION`이며 사용자의 상세화 요청을 새로운 고유 설정의 정본 채택으로 취급하지 않는다.

## OBS: 남은 범위

세계 해안의 절대 접속·정밀 지형·수심·조석·선박 용량·접안·들것 운반·항해 시간은 미검증이다. 갑판 충돌·무기별 공격 창·회피·실제 전투 밀도·AI·공급량·경험치·UE 실행도 검증하지 않았다. 이번 수량은 국소 배치 후보이며 실제 생태 수지나 모든 적의 필수 처치 수가 아니다.

다음 상세화는 G3·T2에 따른 연안 환승과 오르다스 외항 진입, 현지 인계와 내해 봉쇄 조사의 연결이다. 이번 문서만으로 오르다스 내부 탐색권·국가 관할·항로 좌표를 확정하지 않는다.
