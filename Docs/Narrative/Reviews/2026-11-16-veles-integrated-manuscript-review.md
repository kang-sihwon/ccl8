# PASS: 벨레스 첫 장 통합 집필과 정보 전달

NG07 [통합 집필 묶음](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-15-veles-integrated-manuscript.md)은 C05 표현 두 곳 보완 뒤 독립 검토 PASS다. 잔여 BLOCKER 0·WARNING 0·OBS 0, 지적 없음이다. 문서의 인과·정본 정합·정보 전달·보존에 대한 판정이며 실제 플레이어 인지·공간·전투·운영·UE 검증은 아니다.

## 요청과 역할

2026-11-15 사용자는 NG05·NG06에서 확정한 PR01-PR07·VD01-VD06과 공통 경계를 기준으로 NG07을 하나의 목표로 완료 기준까지 진행하도록 요청했다. 기존 원문·대안·보류·도안·좌표·수치를 유지하고 실제 UE 구현·실행은 제외했다. 작성은 2026-11-15에 시작했고 검토 마감은 2026-11-16이다.

Codex는 Creative Fiction Writer·Character Creator·ccl8-narrative·docs·writing으로 정상 원고와 대체 장면·정보 대조·인물 점검·선택표를 작성했다. 세션 모델의 읽기 전용 `ng07_review`가 본문 여섯 편·원천 기록을 [NG07 완료 기준](../WorkGroups/next-workgroups.md#ng07-첫-장-통합-집필과-정보-전달), Scenario·World·VR·VI 원문·NG05 사례와 대조했다. 검토자는 파일을 쓰지 않았고 작성자가 지적을 수정하고 이 기록을 남겼다.

BLOCKER는 정본 충돌·승인 범위 위반·근거 없는 주장, WARNING은 필수 장면·정보·인계의 누락, OBS는 경미한 문장·순서의 모호성이다. 최초 검토는 BLOCKER 0·WARNING 0·OBS 2였다. 아래 두 표현을 고친 뒤 검토자가 재확인해 잔여 지적 없이 PASS로 판정했다.

## 완료 기준 대조

| 기준 | 독립 확인 결과 |
|---|---|
| 통합 원고 | MS01-MS10을 실제 장면·대사로 작성했다. VR의 정상 흐름과 PR·VD를 유지하며 도입·조사·직접 전투·정비·귀환·인수·저녁·아침·출항이 이어진다. 새 정확한 문장과 조건부 성공은 후보로 구분한다. |
| 차이가 있는 장면 | C03-C06에서 시작 지식·수행·미완료·보고·현재 대응과 다시 이을 조건이 다르다. C03-R은 해방 뒤 조사 공백, C06-M은 아침의 인수 보완을 현재 성과·시각에 맞춰 잇는다. |
| 정보 전달 | VI01-VI08의 최초 확인·누락 기회·재전달·현재 지식·미확인을 원고 위치에 연결했다. 캐릭터 지식과 플레이어가 이해했다는 주장을 구분했다. |
| 인물·설명 | 주인공·스승·린·보관인·담당 주민·선장의 역할과 말의 근거를 구분했다. 첫 신뢰와 후속 약점, 설명 때문에 전투를 멈추는 위험·마을의 첫 보고와 반복 해설의 차이를 검토했다. |
| 추천·인계 | IW01-IW06·공통 경계, IWA01-IWA02·IWH01-IWH06으로 새 표현·매체·적용 조건과 나머지 보류를 구분했다. 원고 전체·정확한 대사·실제 성공을 일괄 승인 대상으로 삼지 않는다. |

## 지적과 처리

| 최초 지적·위치 | 수정과 재확인 |
|---|---|
| OBS·확신 높음. [C05](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-15-veles-integrated-manuscript/variants.md#c05)의 ‘회수하고 현재 연결부터 다시 봐야 해’는 이어지는 재접근 서술과 작업 순서가 어긋나 보인다. | 현재 연결을 먼저 확인한 뒤 남은 파편을 회수하는 문장으로 바꿨다. 이미 끝낸 분리와 남은 회수를 구분하며 독립 재검토에서 해소했다. |
| OBS·확신 높음. 같은 C05의 ‘복구 완료를 기다리며 비축 몫을 풀지 않았다’는 필요한 비상 배분까지 중단한 것으로 읽힐 수 있다. | 현재 남은 비축분과 비상 운영에 필요한 몫을 대조하는 문장으로 바꿨다. 비상 공급의 현재 조건을 확인하는 원래 경계를 유지하며 독립 재검토에서 해소했다. |

문장 두 곳의 모호성을 고쳤으며 새 수치·현장 상태·사건·게임 규칙을 추가하지 않았다. 실제 해방·분리 성과를 보존하고 조사·송수·하류·인수·새 아침을 자동 완료시키지 않는 점이 유지됐다.

## 보존과 검사

기준 커밋은 `5f4cb678`이다. [원천 기록](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-15-veles-integrated-manuscript/source-audit.json)의 32개 파일은 현재 SHA-256과 일치하며 검토자가 기준 커밋의 본문 보존도 확인했다. 기존 Scenario·World·결정·원고·대안·보류·도안·좌표·수치는 바뀌지 않았다. 이전 NG06 참조는 보존 대조 대상이며 새 지리·수치 검증을 했다는 뜻이 아니다.

새 문서는 정상 장면 10개, C03-C06 네 사례와 재개 변형 두 개, VI 여덟 행, IW 여섯 행·IWH 여섯 행을 갖춘다. 작성자는 ID를 대조하고 진행 문서 일곱 편의 결정·숫자·경로·링크 보존 검사에서 누락 0건, `git diff --check` 통과를 확인했다. 이 검토 기록을 포함한 작성자·독립 검토자의 최종 문서 645개·결정 62개 검사도 오류 0건이었다.

같은 검토자는 진행 문서 일곱 편·상위 문서·이 검토 기록의 완료 상태, IW 미채택, 실제 미검증, NG08 별도 요청, 현재 담당 없음을 최종 대조했다. 검토 기록의 ‘전투 중 설명을 멈추는 위험’이라는 표현은 ‘설명 때문에 전투를 멈추는 위험’으로 바로잡아 OBS 한 건을 해소했다. 최종 판정은 PASS, 잔여 BLOCKER 0·WARNING 0·OBS 0이다. 대상 아홉 문서의 로컬 파일 링크 473개를 확인해 누락 0건이었으며 앵커는 문서 검사로 확인했다.

코드·설정·에셋·정본의 수정, 이미지·음성 제작, UE 구현·실행은 하지 않았다. Graft의 제한된 검색 결과는 이번 서사 근거로 사용하지 않았다. 프로젝트 고유 집필만 다뤄 개인 Obsidian 볼트에 새 기술 기록을 남기지 않았다. 삭제 후보와 실제 삭제는 없다.
