# 인물 동기·관계 변화 정본 반영 독립 검토

**PASS. 지적 세 건을 수정하고 재확인했으며 잔여 지적은 없다.** 작성자와 다른 읽기 전용 검토자 `combat_learning_continuity_review`가 2026-11-13 [결정 51](../../decisions/0051-core-character-motivations-adoption.md)과 [Scenario](../Scenario.md#네-인물의-개인-동기)의 CP01-CP12 반영을 사용자 승인·[선택표](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-13-core-character-options.md)에 대조했다. 판정은 승인 범위와 정본 정합성에 한정하며 실제 플레이 검증은 아니다.

BLOCKER는 승인·근거·필수 규칙 위반, WARNING은 논리·상태 보완 필요, OBS는 경미한 모호함이다.

## 수정한 지적

| 심각도·위치 | 문제와 근거 | 수정·재확인 |
|---|---|---|
| BLOCKER · Scenario의 CP01-CP03 표 · 최초 확신도 중상 | ‘돕는 기쁨’, ‘출항·중지를 판단하는 자부심’, ‘꼼꼼함과 작업자 보호’는 상세 후보에는 있지만 승인한 선택표·결정의 채택 문장에 직접 포함되지 않는다. | 호기심·용기 유지, 운항 판단 유지, 우회 승인·기록 누락 책임 유지로 좁혔다. 추가 성격 표현은 기존 상세 후보에 남겼다. 해결됨. |
| WARNING · 선택표 도입 상태 · 확신도 높음 | 선택표의 미채택 안내가 현재 승인 사실과 달랐다. | 상단에 채택일·결정 51·CLOSED·채택 범위와 아래 표현이 작성 당시 기록임을 덧붙였다. 상세 후보에도 핵심만 채택됐다는 안내를 추가했다. 기존 본문·표는 보존했다. 해결됨. |
| OBS · Scenario의 CP07 표 · 확신도 높음 | ‘놓친 일감은 남고’는 일감 손실이 유지된다는 원문 의미를 흐린다. | ‘일감 손실은 남고’로 고쳐 선택표·결정과 맞췄다. 해결됨. |

재검토는 수정 문장·상태 안내·보존 diff에 한정하며 해결 판단 확신도는 높다. 앞선 전체 검토 결과는 유지한다.

## 확인 결과

CP01-CP12와 CE01-CE12의 연결, 직접 관계 다섯 쌍과 린·이르의 미확정 경계를 확인했다. 린의 후속 합류·S3 잔류, 마렌 H03, 이르의 북부·중앙 역할, 로덴 붕괴 선행·즉시 인정, 니베르 구조와 후속 조사, 결말 순서를 유지한다.

결정 51의 `refines`·`lifts_hold`는 결정 48·49를 가리키며 본문이 WH04·CH05 가운데 채택한 중심만 해제한다. PA01-PA06·PH01-PH08 표와 기존 후보 본문을 보존했다. 과거 결정 본문·World의 법칙·제작 범위·무기 자유·필드 전투는 바꾸지 않았다. NarrativeConcept와 Scenario의 기존 개인 서사 보류 표현도 새 채택 범위와 대조했다.

## 확인 범위와 미검증

선택표 전문·결정 51·Scenario의 이번 변경·NarrativeConcept를 대조하고 후보 두 편의 안내 추가를 확인했다. 검토자는 파일을 쓰지 않고 판정과 지적만 보고했으며 작성자가 수정·결과 기록을 맡았다.

작성자는 결정과 Scenario 표에서 CP01-CP12가 각각 빠짐없이 등장함을 확인했다. 후보 두 편은 상단 안내를 제외한 본문을 Git의 이전 버전과 비교해 동일함을 확인했다. 문서 도구 검사는 독립 서사 검토와 별도로 수행한다. 실제 플레이·독자 반응·동료 AI·UE 실행·정확한 대사와 연출·외부 작품 유사성 조사는 미검증이다.
