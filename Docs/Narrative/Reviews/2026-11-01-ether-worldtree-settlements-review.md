# PASS: 세계수 규모와 정착지 배치 검토

2026-11-01 읽기 전용 독립 검토에서 강선과 능선의 교차, 예방 구역의 단정적인 표현을 발견했다. 두 항목과 좌표 재현성 권고를 반영한 뒤 재검토에서 `PASS`를 받았다. 실제 지형·기후·항행·UE 실행 검증이나 사용자 정본 승인은 아니다.

## 대상과 역할

- 작성자: Codex. 수치와 좌표는 신규 설계 후보이며 도면은 Python 계산과 Pillow·SVG로 작성했다.
- 검토자: 읽기 전용 독립 검토 에이전트 `review_worldtree_settlements`. 파일을 수정하지 않았다.
- 대상: [세계수 규모](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-worldtree-scale.md), [정착망](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-ignis-settlement-network.md), [벨레스 지역](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-veles-region-layout.md), [도면 3종과 계산 데이터](../../ArtDirection/EtherWorldMap/2026-11-01-worldtree-settlement-plans.md), 로컬 생성 코드.
- 대조: 기존 첫 장, 벨레스 지리, 도시·정치 관계, 통치 배치, 보류 좌표안과 서사 정본.

## 지적과 수정

| 항목 | 최초 지적 | 수정과 재검토 |
|---|---|---|
| 강선과 능선 | 필수 수정. 강선과 능선 중심의 최소거리 207.73m가 반경 220m보다 작아 도형 내부를 통과 | 굽이를 남쪽으로 조정. 중심 최소거리 295.3528m, 그려진 강안과 능선 사이 여유 41.4242m, 출항 강선 1,772.9904m를 독립 재계산. 문서·JSON·PNG 일치 |
| 예방 구역 | 필수 수정. 도면의 반경 12km 밖 위험권 제외 표현이 본문의 안정성 미검증과 충돌 | 관리 정책상의 예방 구역이며 실제 뿌리·낙하물 위험 한계는 미검증이라는 문구로 수정. PNG 직접 확인 |
| 좌표 재현성 | 권고. 지역 원점 연결과 관측 높이 등의 입력이 JSON에서 빠짐 | 나루 원점=(150,145)km, 변환식·평면 근사 범위·눈높이·능선·샘 입력을 명시. 공개 지점=(149,144)km 확인 |

## 확인 범위와 한계

초기 검토에서 PNG 3개를 직접 확인하고 중심 거리, 구면 거리, 강선·보행 길이, 구면 고도각을 독립 재계산했다. 재검토에서는 바뀐 문서·JSON·계산 코드와 변경 PNG 2개를 확인했다. 최종 필수 수정 사항은 없다.

- 대도시 8곳의 판정, 대표 일반 도시 12곳·마을 16곳과 기존 정치 소속 유지.
- 이전 보류 위경도 미재사용, 큰 강과 식수 샘 분리.
- 일반 적 3종·곰 보스 1종, 복구·귀환·식사·출항 및 제작 범위 보존.
- 도면에서 읽기를 막는 라벨 상호 겹침 없음. 일부 강선과 글자의 교차는 식별 가능.

세계지도와의 위경도 정합, 실제 분수계·수문·항행·안개·일조·기후·원경 렌더링·전투는 검사하지 않았다. 부모 링크와 작업 현황 갱신은 작성자가 문서 검사로 확인한다.
