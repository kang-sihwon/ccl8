# 벨레스 출항 제작 대본 독립 검토

**PASS.** 작성자와 별개의 읽기 전용 검토자가 [본편](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-26-veles-departure-script/script.md), [생활 대화](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-26-veles-departure-script/village.md), [분기 대본](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-26-veles-departure-script/returns.md), [장면표](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-26-veles-departure-script/index.md)를 [시나리오 정본](../Scenario.md)과 기존 통합 원고에 대조했다. 초회 판정은 CHANGES_REQUESTED였고 수정 원고를 같은 경로로 다시 읽어 통과했다. 남은 지적은 없다.

BLOCKER는 정본과의 충돌이나 진행 단절, WARNING은 제작자가 잘못된 발화를 고르거나 사건의 근거를 잃는 문제, OBS는 경미한 표현 문제다. 첫 검토에서 WARNING 세 건이 나왔다.

| 초회 지적 | 수정 후 같은 경로를 읽은 결과 |
|---|---|
| 11의 로덴행 온도 기록에 실제 잰 장면이 없었다. | 08의 안쪽 수로에서 측정하고 도면의 접힌 자리에 위치를 남긴다. 작업 도중 돌아오면 실제 잰 부분만 보존한다. 그 기록이 저녁 짐에 들어간다. |
| 10에서 하류 점검이 지연되면 린과 첫 보고를 또 했다. | 빈 통을 받은 다음부터 분기를 읽는다. 인수도 주민이 동의하기 전에 대체 첫 대사로 들어간다. |
| 12에서 새로 언 물턱을 보고하기 전에 정상 점검 대사를 읽을 수 있었다. | 아침에 인수가 빠졌거나 새 이상이 생기면 주민의 첫 발화부터 바꾼다. 운항만 바뀐 경우에는 마을 점검을 유지하고 선장 호명을 바꾼다. 정상 출항에서만 수관을 본다. |

선택 대화를 모두 생략하는 정상 진행, 실제 관찰 뒤 서쪽 귀환, 조사 누락과 해방 뒤 보완, 조기·부분 귀환과 재개, 하류 사용과 주민 인수, 다음 아침 점검과 배편 연기를 서면으로 따라갔다. 본편 12장면과 생활 장소 여섯 곳, 직접 전투 중 조작, 조건에 따른 승선 연결을 확인했다. 재검토 결과는 BLOCKER 0, WARNING 0, OBS 0이다. 대사·연출은 사용자 승인 대기이며 녹음과 실제 게임에서의 시야·음향·길이는 제작 검증에 남는다.
