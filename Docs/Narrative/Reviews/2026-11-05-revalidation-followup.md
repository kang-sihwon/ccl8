# PASS 벨레스·로덴 전투 개정과 지도 기록 정정

2026-11-04 통합 검토에서 지적한 R1부터 R4까지 수정하고 읽기 전용 독립 검토에서 통과했다. 판정은 네 지적의 해소에 한정된다. [최초 검토 보고서](2026-11-04-creation-skills-revalidation.md)와 [11월 3일 구간 상세](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-03-adventure-plot/2026-11-03-veles-roden.md)는 당시 상태로 보존했다.

| 지적 | 수정과 확인 결과 |
|---|---|
| R2 배치 참조 | [벨레스 지리](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-veles-geography.md), [공간 참조](../../ArtDirection/EtherFirstChapter/VelesReferences.md), [첫 장 아트 안내](../../ArtDirection/EtherFirstChapter.md)가 [나루 원점의 지역 배치](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-veles-region-layout.md)를 가리킨다. 세 곳 모두 옛 좌표 링크에 보류·비교 용도를 표시했다. 세계지도 위경도 연결은 후속 작업이다. |
| R4 파일 해시 | [검증 JSON](../../ArtDirection/EtherWorldMap/Data/ether-world-map-land35-precise-v3-validation.json)의 현행 값은 JSON·SVG의 UTF-8 텍스트를 LF로 통일하고 PNG는 원본 바이트를 사용해 계산했다. 이전 세 값은 같은 파일의 별도 필드에 보관했다. 독립 대조에서 현행 해시 세 개와 기존 체크아웃 해시 세 개가 모두 일치했다. |
| R1 전투 강화 | [현행 개정안](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-03-adventure-plot/2026-11-05-veles-roden-combat.md)에서 두 전투를 다섯 조우로 늘렸다. 여울에서 린의 선회를 지키고, 나루에서 화물과 인부를 분리하고, 정비로의 군체를 돌파한다. 차단 실수 뒤에는 부상자를 호위하고 철근지기의 팔을 멈춘다. 조우마다 필요한 위치·공격 시점·전투 후 바뀌는 상황을 대조했다. |
| R3 세르나 선행 경험 | [지역별 상세의 세르나 구간](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-03-adventure-plot/2026-11-03-regional-arcs.md)에서 여울턱의 고정된 도약점과 갈퀴등 해수의 선체 밑 이동을 구분했다. 강에서 성공한 한쪽 뱃전 방어가 하구에서 반대편을 노출하는 이유를 추적할 수 있다. 이전 표현은 개정안 끝에 인용했다. |

Codex가 작성하고 세션 모델의 독립 검토자가 현행·이전 구간, 첫 장 결말, 세르나 개요, 배치 안내와 해시 자료를 읽기 전용으로 대조했다. 최초 판정은 들것 호위전의 광원과 작업자 행동이 모호하다는 수정 요청이었다. 뜨거운 비상등은 고정하고 작업자는 손등불로 이동할 발판을 비춘다. 큰 개체는 주인공이 맡고 마렌은 마지막 들것과 주인공이 건넌 뒤 격자를 닫는다. 검토자가 이 문단과 세르나의 선행 경험 문장을 다시 확인한 뒤 PASS를 보고했다.

다음 플롯 작업은 세르나에서 린의 경고를 듣고도 주인공이 개입하는 결정, 배 손상·수리 비용, 정상 화물의 반출 권한과 하르덴으로 향할 조건을 구체화하는 일이다. 지도 확대도의 거리·방향, 실제 전투 시간·무기별 판정·UE 플레이와 정본 승인은 별도 과제로 남는다.
