# 이그니스 S1-S6 연결 검토

검토 대상은 [전체 여정 연결 후보](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-09-ignis-journey-continuity.md), 하위 인계·성장·S1 배정표, 수정한 S4 문장과 [지도 3장](../../ArtDirection/EtherWorldMap/2026-11-09-ignis-journey-map.md)이다. 작성자 Codex와 별도의 읽기 전용 검토 에이전트가 원문·그림·좌표를 대조했다. 최종 판정은 수정 후 **PASS**, 미해결 BLOCKER·WARNING은 없다. 후보 상태는 `DISCUSSION`이며 정본 승인은 포함하지 않는다.

## 지적과 반영

| 구분 | 근거와 문제 | 반영 |
|---|---|---|

작성자 보완으로 로덴 담당자 인수와 현지 적용 성공을 구분하고, 축소 운영·보충 조건이 없으면 북행을 늦추도록 했다. G1 선택 탐색의 성장 보존과 S4의 독립적인 진행 조건도 인계표·그림에 함께 기록했다.

## 확인한 범위

- [계산 검사](../../ArtDirection/EtherWorldMap/Data/ignis-journey-continuity-v1-validation.json) **302/302 PASS**: S2-S6 형태 집합·개체 범위·수량·구조체, S1 A9/B5·기존 위치·생활권·경로, 성장 몫 23과 연결, 선택 성장, 실제 SVG 좌표, 원본 해시, S4 옛 문장 복원 가능성을 확인했다.
- 독립 검토는 원본 10개 해시·경로 17개·성장 6단계·GB01-05 배정과 좌표·SVG 선형 등 108항목을 별도 대조하고 PNG 3장을 직접 열어 확인했다. 수정된 S1 범례도 그림을 다시 열어 확인했다. 작성자 302개 검사를 독립 재실행한 것은 아니며 계산과 눈으로 읽는 범례 검토를 구분했다.
- 문서 검사 454문서·오류 0건, S4 보존 검사 누락 0건을 확인했다. 이 결과는 문서·링크·이전 내용 보존의 검사다.
- S2의 책임 인정→S3의 구조 선택·린 판단 존중→S4 제한 시험→S5 과거 기록→S6 현재 부하 대조·공급 시험의 인과가 이어진다. S6 F03/F05 관측, F07 통제, F08 전투, 수동 F09 귀환의 선행조건에 순환이 없다.
- 린의 잔류·후속 합류·항만 잔류, 마렌의 로덴 대체 담당자, 이르의 구조·난방 인계가 이동과 연결된다. 공공 통과와 최종 설비 출입권은 분리된다.
- 정본 World·Scenario, 원본 지리·해안, 기존 S1-S6 JSON, 64항목·199형태와 G0-G6 기준은 변경하지 않았다. Graphify의 오래된 그래프는 문서 탐색 단서로만 사용하고 원문으로 확인했다.

## 미검증과 다음 판단

실제 여행 시간·정기편 회차·보급과 저장량·설비 용량·기상 지속시간은 미정이다. 문서의 담당자 인계만으로 실제 공급이 버틴다고 입증한 것은 아니다. 원본 생활권의 실제 시야·동시 전투·AI·난도·경험치·UE 실행도 검증하지 않았다. 이그니스 전체를 상세 제작하기로 확정한 것이 아니며 해외 상세화는 별도 요청 범위다.

다음은 사용자가 이 연결 후보를 검토하는 일이다. 이후 해외 첫 진입을 상세화할 때 G1 선택 탐색과 G2 본편 조건을 구분하고, 세르나의 계약 선박·동료 업무 인계에서 아르베나 도착으로 이어가면 된다.
