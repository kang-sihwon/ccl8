# 벨레스 NPC 개인사 독립 검토

최종 판정은 **PASS**, 잔여 지적은 0건이다. 작성자와 별도의 읽기 전용 검토자가 [개인사 16편](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-26-veles-resident-histories.md)을 [주민표](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-26-veles-residents.md), [시나리오 정본](../Scenario.md), [출항 제작 대본](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-26-veles-departure-script/script.md)과 대조했다. 인물 구성과 가구 관계, 첫 장의 역할이 일치했다.

1차 검토에서 두 일화에 수정을 요청했다. 세브린의 공방에서는 교대자가 궤짝을 선반 밑으로 끌어온 뒤 뚜껑을 밟도록 위치를 바로잡았다. 토르마의 가마에서는 조카가 덜 마른 독에 이름을 새기고, 구운 뒤 장날에 그 이름을 보여 주도록 순서를 고쳤다. 검토자가 두 대목을 다시 읽고 수정 사항을 확인했다. 개인사 채택 여부는 사용자 논의 단계에 있다.

## 생애 증보본 검토

연령별 개인사 증보본의 독립 재검토는 **PASS**, 잔여 지적은 0건이다. 16명의 이름과 나이를 주민표와 대조했다. 같은 과거를 각자의 나이에서 검산했다. 12년 전 베사가 여관을 물려받았을 때 베사는 31세, 켈은 16세, 오델은 36세다. 린이 16세에 배를 혼자 붙들던 날 에다는 37세였다. 울모가 10세에 그물을 놓쳤을 때 목격한 토르마는 24세였다.

베사의 장부에 그림이 남은 기간을 21년에 맞췄고, 켈이 그때 알 수 있었던 첫 품삯으로 밥값을 내려는 마음을 살렸다. 판재 납품자들이 라우트의 딸을 두고 아버지에게 먼저 값을 묻던 일, 울모의 딸이 고기 전부를 소금과 바꿔 현금 없이 돌아온 일도 다시 대조했다.
