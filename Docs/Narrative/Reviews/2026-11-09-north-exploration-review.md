# 북부 탐색·구조·기록 회수 검토

PASS. 독립 검토의 WARNING 2건을 수정하고 구조·보관소의 상태별 연결과 최종 그림을 재확인했다. 남은 BLOCKER·WARNING 없음.

2026-11-09 작성자 Codex와 별도의 읽기 전용 검토자가 [후보](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-09-north-exploration.md)와 하위 공간·생태·사건, [지도 4장](../../ArtDirection/EtherWorldMap/2026-11-09-north-exploration-map.md), 좌표 JSON을 현행 세계 분포·성장·기존 북부 플롯·지리와 비교했다. BLOCKER는 진행 불가, WARNING은 수정 필요, OBS는 명료화 권고다. 실제 플레이 검증·정본 승인은 포함하지 않는다.

## 지적과 보완

| 심각도·확신도 | 결함 | 보완·재확인 |

| WARNING·높음 | 구조자의 초기 우회로가 거수를 피하므로 거수 유도가 구조 완료에 필요한 이유가 부족했다. | 들것 경로를 R04→R05→R07→R08→R01로 고쳤다. 거수가 R05 분기에서 서쪽 R06으로 먼저 빠져나가고 구조자는 이후 남쪽 길로 이동한다. 독립 계산 거리 2,436.6967m이며 최대 5m 표본에서 초기 RG1만 교차하고 이동 완료 뒤 다른 생활권 교차는 없다. |
| WARNING·높음 | 보관소 뒷길로 기록실에 먼저 들어갈 수 있어 겨울지기의 방어가 진행을 막지 못했다. | 초기 A02–A03·A06–A07·A07–A08을 닫는다. 방어 격리 뒤 A06–A07이 열리고 A07 안쪽의 수동 해제 뒤 A07–A08 귀환길이 열린다. 외부 A08 탐색은 가능하되 초기 A07 진입은 불가능함을 독립 그래프 검사로 확인했다. |

작성자의 추가 점검에서는 R02–R03 파손턱의 정찰자 이동과 들것 통행을 구분했다. 45m 구간·최소 1.2m 틈·최대 1.4m 단차·손잡이는 후보 수치이며 현재 구조 장비·인력으로 들것을 운반할 수 없다. 독립 검토에서 정찰자 귀환은 가능하고, 들것 귀환은 거수 이동 전 불가능·이동 후 가능함을 확인했다. 실제 통행·운반 가능성은 미검증이다.

작성자의 [191항목 계산 검사](../../ArtDirection/EtherWorldMap/Data/north-exploration-v1-validation.json)는 원본·정본 보존, 형태·수량·레벨, SVG 좌표·축척, 경로 길이·생활권 표본, 남북 사면, 구조·보관소 상태별 연결을 통과했다. PNG는 파일 바이트, SVG는 UTF-8/LF 정규화 해시를 기록했다. 독립 검토자는 최종 결과와 핵심 연결을 별도로 확인했으며 191항목 전체를 다시 실행한 것은 아니다.

문서 검사(`node Tools/Agent/docs.cjs check`)는 437문서·오류 0건이며 Git 공백 검사도 통과했다. 연결 안내를 추가한 기존 문서 9개의 제출본에서 이전의 비어 있지 않은 모든 행이 원래 문구·순서대로 남는 것을 대조했다. 현재 상태 지도 두 개는 이번 결과와 다음 행동으로 갱신했다. 공유 지도 입구 문서의 다른 세션 변경은 이번 제출 범위에 포함하지 않는다.
