# 5대륙 플롯 채택 반영과 전투·선택 비교 검토

**PASS. 수정본에서 남은 지적 없음.** 작성자와 다른 읽기 전용 검토자 `world_plot_adoption_review`가 2026-11-13 [결정 48](../../decisions/0048-five-continent-core-plot.md)의 승인 반영과 [대표 전투·인물 선택 비교](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-13-regional-combat-and-choices.md)의 근거·논리를 검토했다. WP01-WP10의 사용자 채택과 후속 비교안의 검토 통과를 구분한다.

BLOCKER는 승인·정본·근거 충돌, WARNING은 수정이 필요한 서사·범위 오류, OBS는 표현의 모호성이다. 실제 전투 차별화나 재미를 확인한 판정은 아니다.

## 지적과 재확인

초기 OBS는 비교표 ‘인물 선택과 대가’의 로덴 행에 원문에서 확인되지 않는 ‘조작을 숨기고 해결하려는 충동’이 들어간 점이었다. [로덴 원문](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-08-tarnel-roden-exploration/story-and-roundtrip.md)은 조작 직후 바로 사실을 밝힌다고 명시한다. 권고는 확인을 생략한 행동과 즉시 공개한 선택으로 바꾸는 것이며 확신도는 높음이다. 작성자는 ‘혼자 빨리 해결하려고 확인을 생략한 뒤, 자기 조작을 바로 밝히고’로 수정했고 검토자가 직접 재확인했다.

## 범위와 다음 행동

결정 48, World·Scenario, 선택표와 비교 문서 전문, 결정 39·40 변경분, 첫 장 선택표의 H07 설명을 읽었다. 비교 문서가 연결한 지역 원문 11개의 관련 사건·전투·인물 절과 통합 인계·생태 관련 절을 대조했다. 선택표 보존과 과거 결정 본문 보존은 Git HEAD와 직접 비교했다.

전체 상세 원고·파생형·수치를 재검증하지 않았고 실제 전투·항해·지형·UE 실행도 미검증이다. 다음으로 방어체 세 구간의 접근·판단·압박 변화·승리·철수·인수를 나란히 구성하는 것을 추천한다. 후속 행동·공간 상세는 별도 후보로 유지한다.
