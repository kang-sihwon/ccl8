# PASS: 벨레스 집필 표현과 정보 전달 채택 반영

IW01-IW06과 공통 경계의 [결정 63](../../decisions/0063-veles-manuscript-delivery-adoption.md)·[Scenario 반영](../Scenario.md#벨레스-첫-장의-표현과-작업-기록)은 지도 표현 한 곳 보완 뒤 독립 검토 PASS다. 잔여 BLOCKER 0·WARNING 0·OBS 0, 지적 없음이다. 판정은 승인 범위·정본·결정·보존·인계의 일치에 한정하며 실제 정보 인지·전투·공간·운영·UE 검증은 아니다.

## 승인과 역할

2026-11-16 사용자는 [IW01-IW06과 공통 경계](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-15-veles-integrated-manuscript/options.md)를 모두 채택하고 NG04의 정본 반영·검토·커밋·푸시를 요청했다. 기존 원문·대안·보류·도안·좌표·수치를 유지하고 실제 UE 구현·실행은 제외했다.

Codex는 ccl8-narrative·docs·writing으로 반영했다. 세션 모델의 읽기 전용 검토자 `iw_adoption_review`는 기준 커밋 `f05af8e9`와 변경 내용을 대조했다. 검토자는 파일을 쓰지 않았고 작성자가 지적을 수정하고 이 기록을 남겼다. [NG07 집필 검토](2026-11-16-veles-integrated-manuscript-review.md)와 이번 채택 반영 검토는 별개다.

BLOCKER는 승인 범위 위반·정본 충돌·근거 없는 주장, WARNING은 필수 내용 누락·보존 또는 인계 결함, OBS는 경미한 모호성이다. 최초 반영 검토에서 BLOCKER 0·WARNING 0·OBS 1이었으며 수정 뒤 잔여 지적 없이 PASS로 판정했다.

## 채택 범위 대조

| 항목 | 독립 확인 결과 |
|---|---|
| IW01 출발 질문·분담 | 여행 질문에 남은 일을 먼저 답하고, 스승·린의 분담과 못 한 일도 보고하겠다는 확인을 채택했다. 원인·곰을 출발 전에 알려주지 않으며 정확한 대사·강제 순서는 별도다. |
| IW02 휴대 작업 기록 | 접어 휴대하는 기록에서 관찰·미확인·계획과 실제 수행·남은 확인을 나누고 마을용·로덴용의 용도를 구분한다. 규격·도식·필수 읽기·UI·자동 갱신·아이템화는 미확정이다. |
| IW03 조사 공백 보완 | 이미 본 내용 전체를 되풀이하지 않고 현재 근거에서 빠진 연결을 대조한다. 해방 뒤 근거 잔존·접근이 없으면 미결이며 자동 지식·재결박을 추가하지 않는다. |
| IW04 미완료 보고 | 작업 전과 해방·분리 뒤 송수 전의 차이를 먼저 말하고 현재 비상 운영·재고·운반을 확인한다. 문구의 의미를 채택하며 고정 대사·자동 복구·성공 출항으로 확대하지 않는다. |
| IW05 주민 질문·현재 인수 | 실제 질문에 근거로 답하거나 확인할 자리에 남긴다. 아침 누락은 그 시각에서 보완하며 전날 소급·저녁 재연·하루 추가 대기를 정하지 않는다. |
| IW06 저녁·아침 | 도움·기록·개인 여행 의사를 저녁에, 이번 점검과 달라진 조건·선장의 짐 안내를 아침에 둔다. 첫 신뢰만 보여 주며 린 동승·완성된 성장·항해 일정은 채택하지 않는다. |
| 공통 경계 | PR·VD와 앞선 확정, 실제 지식·작업·인수, 선택적 야외 조우·직접 전투·무기 자유·생존 이격, 기존 복원 계약·인물 역할·상층 수관 종료, 원문 보존·실제 미검증을 유지한다. |

선택표 여섯 행의 표현·수단·적용 조건·이점·비용과 Scenario 여섯 행, 공통 경계 일곱 항목은 문자 단위로 일치한다. 결정 63은 결정 57·58·61·62를 구체화하며 기존 확정·보류의 나머지를 번복하지 않는다. World의 법칙·관계도 변경하지 않았다.

## 지적과 처리

OBS·확신 높음. [작업군 지도](../WorkGroups.md)의 ‘전체 원고·정확한 대사·매체·조건부 성공·실제 플레이 지원은 함께 확정하지 않는다’에서 ‘매체’는 IW02의 휴대 작업 기록까지 제외하는 것으로 읽힐 수 있었다. 작성자는 이를 ‘매체 규격’으로 좁혔고 독립 검토자가 수정 후 정본·결정과 일치함을 확인했다. 채택한 기록 사용과 남은 규격·세부의 차이를 명확히 한 수정이며 새 내용을 추가하지 않았다.

## 보존과 검사

통합 묶음·원고·대체 장면·정보·인물·선택표 여섯 문서는 상단 채택 안내만 더했다. 안내를 제거한 기존 본문은 기준 커밋과 완전히 일치한다. Scenario도 새 절을 제거하면 이전 전체와 일치한다. IWA01-IWA02·IWH01-IWH06과 기존 79행·PRA/PRH·VDA/VDH·BA/BH·NA/NH·RA/RH를 보존했다. 정확한 대사·매체 규격·MS/C/VI 전체·조건부 성공·실제 게임 지원은 일괄 승격하지 않았다.

[원천 기록](../Drafts/2026-10-31-ether-taiga-dawn/2026-11-15-veles-integrated-manuscript/source-audit.json)의 32개 중 승인 절을 추가한 Scenario만 달라졌고 나머지 31개 SHA-256은 일치한다. 원천 기록 자체와 과거 집필 검토도 변경하지 않았다. NG04에 기존 앵커를 남겨 이전 검토의 링크를 그대로 유지했다. 채택 전 해시를 현재 정본의 해시로 덮어쓰지 않는다.

작성자와 독립 검토자는 이 검토 기록을 포함한 최종 문서 647개·결정 63개 검사에서 오류 0건을 확인했다. 작성자는 기존 문서 16편의 결정·숫자·경로·링크 보존 검사에서 누락 0건, `git diff --check` 통과를 확인했다. 독립 검토자는 후보 여섯 편의 안내와 지도 일곱 편의 CLOSED 상태·검토 링크·보존 경계·NG08 미착수를 다시 대조해 PASS, 잔여 BLOCKER 0·WARNING 0·OBS 0으로 판정했다.

코드·설정·에셋 변경, 이미지·음성·상세 스토리보드, 실제 UE 구현·실행은 없다. 삭제 후보와 실제 삭제도 없다. 프로젝트 고유 채택만 기록하므로 개인 Obsidian 볼트에는 새 기록을 남기지 않았다.
