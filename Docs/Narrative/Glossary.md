# 서사 용어

확정한 세계 법칙은 [World](World.md), 인물·사건은 [Scenario](Scenario.md)가 소유한다. 이 문서는 서사 항목의 상태 용어를 정한다. 게임 용어의 별도 사전과 ID 체계는 아직 작성하지 않았다.

| 상태 | 뜻 |
|---|---|
| 탐색 | 질문과 자료를 확인 중 |
| 후보 | 비교·검토할 초안 |
| 승인 대기 | 사용자 선택이 필요한 상태 |
| 확정 | 사용자가 명시적으로 승인해 정본에 반영한 내용 |
| 보류 | 재개 조건을 기다리는 항목 |
| 폐기 | 채택하지 않은 후보 |
| 대체됨 | 새 승인 항목으로 바뀐 과거 내용 |

작업 단계, 검토 판정, 단계와 항목 상태의 대응은 [Workflow](Workflow.md#단계와-판정)가 소유한다.
