# 서사 작업 현황

확정된 고유 서사가 없다. 사용자가 T0 컨셉 시안의 기준으로 세계 후보 A를 골랐다. 정본 승인은 아니며 사용자가 정할 때까지 후보로 둔다(`DISCUSSION`).

- 상태: `DISCUSSION`
- 담당: Claude Code
- 작성자: AI
- 검토자: 미정. 독립 검토는 미실시
- 승인자: 사용자
- 질문·범위: T0 시안의 기준이 될 세계, 마을에서 보스에게 갈 이유, 일반 몹 세 역할, 보스, 결말의 후보
- 완료·승인 내용: 제작 범위와 AI 주도 역할 분담, [결정 1](../decisions/0001-production-scope.md)·[결정 2](../decisions/0002-ai-led-production.md). 고유 서사는 미확정
- 미승인 후보: [T0 세계 후보 비교](Drafts/2026-10-31-t0-world-candidates.md)
- 장애 요인: 없음
- 다음 행동: 사용자가 T0과 T8 결과를 보고 후보 A를 정본으로 올릴지 정한다. NPC 역할과 사건·결말 초안은 그 뒤에 이어 간다.

단계, 판정, 역할은 [Workflow](Workflow.md#단계와-판정)가 소유한다.
