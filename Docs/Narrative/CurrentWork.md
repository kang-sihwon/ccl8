# 서사 작업 현황

확정된 고유 서사가 없다. 다음 항목인 NPC 역할과 사건·결말 초안은 범위만 정했고(`SCOPED`) 담당이 없다.

- 상태: `SCOPED`
- 담당: 없음
- 작성자: AI
- 검토자: 미정. 독립 검토는 미실시
- 승인자: 사용자
- 질문·범위: 마을에서 보스에게 갈 이유, NPC 역할과 간단한 결말의 초안
- 완료·승인 내용: 제작 범위와 AI 주도 역할 분담, [결정 1](../decisions/0001-production-scope.md)·[결정 2](../decisions/0002-ai-led-production.md). 고유 서사는 미확정
- 미승인 후보: 없음
- 장애 요인: 없음
- 다음 행동: AI가 [GameDesign](../GameDesign.md#npc시나리오제안)의 흐름에 맞는 NPC 역할과 사건·결말 초안을 제시한다.

단계, 판정, 역할은 [Workflow](Workflow.md#단계와-판정)가 소유한다.
