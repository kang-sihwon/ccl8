# 서사 작업 현황

사용자가 2026-10-31 [에테르 시나리오 후보](Drafts/2026-10-31-ether-taiga-dawn.md)를 "기본 시나리오는 이걸로 할게"라고 골랐다. 첫 장 세부 시나리오와 사용자 제공 지리 원고 두 편을 기존 후보에 연결했다. 고유 서사의 정본 반영 범위는 아직 승인 전이다.

- 상태: `DRAFTING`
- 담당: 없음
- 작성자: 기본 후보는 AI이며 원문의 출처와 생성 도구는 미확인. 첫 장 세부 원고는 사용자가 작성해 제공했으며 생성 도구는 미확인. 지리·스토리 배치와 5대륙 배치 원고는 사용자가 제공했으며 작성자와 생성 도구는 미확인. 문서 정리는 Codex가 수행했다.
- 검토자: 읽기 전용 검토 에이전트. [기존 후보 검토](Reviews/2026-10-31-ether-taiga-dawn-review.md)는 통합 전 원문에 대한 `CHANGES_REQUESTED` 판정이다. [통합본 의미 보존 검토](Reviews/2026-11-01-ether-first-chapter-merge-review.md)는 `PASS`이며, 전체 서사 재검토와 정본 승인을 뜻하지 않는다.
- 지리 원고 검토: [의미 보존 검토](Reviews/2026-11-01-ether-geography-merge-review.md)는 `PASS`다. 원고 두 편의 전체 본문과 정리본을 대조했으며 실제 지도나 지리·기후 타당성 검증은 아니다.
- 지도 제작 기준 검토: [육지 35% 개정본 검토](Reviews/2026-11-01-ether-land-35-review.md)는 `PASS`다. 수치·외곽 분리·입력문·지역 좌표의 적용 범위를 확인했으며 최종 해안선과 생성 이미지의 검증은 아니다. [기존 수치·프롬프트 검토](Reviews/2026-11-01-ether-map-basis-review.md)의 `PASS`는 육지 약 21.05%였던 이전 기준에만 적용된다.
- 승인자: 사용자
- 질문·범위: 행성 크기와 투영법을 유지하고 육지 비중 35%, 이그니스 약 2,000만 km²로 면적 목표·외곽·기준점·Jenova 입력문을 맞춘다. 니베르를 남극점이 있는 실제 육지와 그 위 빙설로 구분하고, 이그니스 내부 좌표는 확대된 외곽에 그대로 적용하지 않는다.
- 완료·승인 내용: 제작 범위와 AI 주도 역할 분담, [결정 1](../decisions/0001-production-scope.md)·[결정 2](../decisions/0002-ai-led-production.md). 첫 장 세부 원고의 통합과 부모·하위 문서 분리는 완료했으며 고유 서사는 미확정이다.
- 미승인 후보: [첫 장 상세 시나리오](Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-first-chapter.md), [에테르 시나리오 후보](Drafts/2026-10-31-ether-taiga-dawn.md), [T0 세계 후보 비교](Drafts/2026-10-31-t0-world-candidates.md). T0의 후보 A 선택과 T0 프롬프트는 아직 갱신하지 않았다.
- 지리 후보: [5대륙 배치](Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-world-map.md), [이그니스 타이가 지리와 여정](Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-ignis-taiga-geography.md), [벨레스 주변 지리](Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-veles-geography.md). 정리와 독립 의미 보존 검토를 마쳤으며 정본·최종 지도·아트는 미승인이다.
- 지도 제작 기준: 사용자가 행성 둘레 40,000km와 2:1 정거원통도법에 더해 육지 35%와 이그니스 약 2,000만 km²를 작업 목표로 요청했다. [기준표](Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-map-production-basis.md)와 [Jenova 프롬프트](Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-jenova-world-map-prompt.md)의 나머지 면적 배분·외곽 치수·이동 좌표는 설계 제안이다. 이 개정본으로 지도 생성은 아직 실행하지 않았다.
- 기존 Jenova 결과: 2026-11-01 이전 기준의 문서 세 본문과 요청문을 [열린 대화](https://www.jenova.ai/a/map-maker/s/01m6armv247jmetgymkm5m3v9n)에 입력해 [지도 한 장](https://www.jenova.ai/f/file_01m6ayvmsjynvapz4rj0kdz36f.jpeg)을 생성했다. 첨부 권한 문제로 파일 대신 전체 본문을 전달했다. 대륙 위치·외곽·격자와 오르다스 해협에 오류가 남았고, 이용 한도 안내로 보정이 중단됐다. 이 결과는 새 35% 기준을 적용한 이미지가 아니다.
- 남은 판단: [통합본의 검토할 사항](Drafts/2026-10-31-ether-taiga-dawn.md#10-정본-반영-전에-검토할-사항)에 전투, 멀티플레이, 재도전, 잊힌 기술, 공급 관계, 제작 가능성, 시각 기준을 모았다. 전투, 렌더링, 첫 장 제작 구조의 사용자 방향은 아직 결정 파일에 기록되지 않았다.
- 다음 행동: 35% 기준의 좌표를 고정한 배치도를 준비한 뒤 해안 시안을 만들고 실제 배치·연결 구조를 검토한다. Jenova 재실행 전에는 이용 가능 여부를 확인한다. 이후 이그니스 내부 거점과 벨레스 주변을 재배치한다. 로덴·세르나의 인간 전투 시점, 위도와 식생, 실제 육지 면적, 항구·기항지·항해 시간과 세계수 원경 가림은 미결이다. 기존 서사 판단도 구체화해 전체 재검토 후 정본 반영 범위를 정한다. 체간 채택은 확정 요구와 구분한다.

단계, 판정, 역할은 [Workflow](Workflow.md#단계와-판정)가 소유한다.
