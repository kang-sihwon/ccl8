# 서사 작업 현황

## 현재 결과와 다음 선택

담당: 없음. NG01-NG08 완료 뒤 남은 보류와 후속 작업군 추천을 정리하고 [독립 검토](Reviews/2026-11-16-post-ng08-workgroups-review.md)를 PASS, 잔여 지적 0으로 완료했다. **NG08 로덴·세르나·하르덴 운영·인계**의 작성과 [독립 검토](Reviews/2026-11-16-ignis-operational-handoffs-review.md)는 PASS, 잔여 지적 0이다. 사용자가 [HO01-HO06과 공통 경계](Drafts/2026-10-31-ether-taiga-dawn/2026-11-16-ignis-operational-handoffs/options.md)를 모두 채택해 NG04 절차로 정본 반영·검토를 완료했다. 해당 범위는 `CLOSED`다.

[운영·인계 묶음](Drafts/2026-10-31-ether-taiga-dawn/2026-11-16-ignis-operational-handoffs.md)이 당사자·물자·정보의 흐름, 조건·비용, 불완전 인계, 권한·책임을 소유한다. HOA01-HOA02·HOH01-HOH06은 남겨 둔다. 실제 UE 구현·실행, 운항 시간·비축량·운송량·요금 계산은 수행하지 않았다.

HO01-HO06·공통 경계는 [결정 64](../decisions/0064-ignis-operational-handoffs-adoption.md)·[Scenario](Scenario.md#로덴세르나하르덴의-운영과-인계)에 반영했다. [반영 독립 검토](Reviews/2026-11-16-ignis-handoffs-adoption-review.md)는 PASS, 잔여 지적 0이다. 이후 [후속 범위](WorkGroups/next-workgroups.md)는 별도 사용자 선택으로 시작한다. G4·G5 상세는 미착수다. 완료된 NG01-NG07과 NG08의 결과·채택 범위는 [작업군 지도](WorkGroups.md), 원문별 미채택 범위는 [남은 보류](WorkGroups/remaining-holds.md)에서 확인한다.

## 상세화할 범위와 순서

[NG09-NG12 추천](WorkGroups/next-workgroups.md#ng01-ng08-이후의-우선순위)은 첫 장 상호작용·작업 기록, 운영·성장 계산 입력, G4 환승, G5 극지 준비·구조·귀환 순서다. 기본 추천은 NG09이며 후속 여정 확장이 우선이면 NG11을 먼저 선택할 수 있다. 네 작업군은 모두 미착수이고 이번 정리는 새 설정 채택·보류 해제·실제 UE 구현·실행을 포함하지 않는다.

[별도 벨레스 블록아웃](../Work/VelesBlockout.md)의 외부 순환로 PIE 기록은 그 경로·조건의 증거다. 지하·바르툴·정보 인지·재고·저장·다인·서사 통합 GX/WC까지 통과한 것으로 보지 않는다.

첫 장의 상세화와 플레이 대륙 배경은 [결정 39](../decisions/0039-opening-scenario-and-continent-context.md), 출항 이후 핵심 여정은 [결정 48](../decisions/0048-five-continent-core-plot.md)을 따른다. 정본은 [World](World.md)·[Scenario](Scenario.md)가 소유한다. 새 작업의 구체 범위는 현재 요청으로 정하고, 후보 작성·정본 채택·실제 제작을 구분한다. 검토를 마친 문서를 다시 작업 중으로 되돌리거나 전체 대륙 제작을 자동 시작하지 않는다.
