# 서사 작업 현황

사용자가 2026-10-31 [에테르 시나리오 후보](Drafts/2026-10-31-ether-taiga-dawn.md)를 "기본 시나리오는 이걸로 할게"라고 골랐다. 기본안과 사용자가 제공한 첫 장 세부 시나리오의 통합은 완료했으며, 고유 서사의 정본 반영 범위는 아직 승인 전이다.

- 상태: `DRAFTING`
- 담당: 없음
- 작성자: 기본 후보는 AI이며 원문의 출처와 생성 도구는 미확인. 첫 장 세부 원고는 사용자가 작성해 제공했으며 생성 도구는 미확인. 문서 통합은 Codex가 수행했다.
- 검토자: 읽기 전용 검토 에이전트. [기존 후보 검토](Reviews/2026-10-31-ether-taiga-dawn-review.md)는 통합 전 원문에 대한 `CHANGES_REQUESTED` 판정이다. [통합본 의미 보존 검토](Reviews/2026-11-01-ether-first-chapter-merge-review.md)는 `PASS`이며, 전체 서사 재검토와 정본 승인을 뜻하지 않는다.
- 승인자: 사용자
- 질문·범위: 기존 세계관과 후속 대륙 구상을 유지하면서, 도입부터 첫 보스전·복구·귀환·출항까지의 세부 전개를 정리한다. 세계관·전체 구상은 기존 후보에 두고, 첫 장 상세 전개와 제작 범위는 같은 이름의 폴더 아래 하위 문서로 분리한다.
- 완료·승인 내용: 제작 범위와 AI 주도 역할 분담, [결정 1](../decisions/0001-production-scope.md)·[결정 2](../decisions/0002-ai-led-production.md). 첫 장 세부 원고의 통합과 부모·하위 문서 분리는 완료했으며 고유 서사는 미확정이다.
- 미승인 후보: [첫 장 상세 시나리오](Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-first-chapter.md), [에테르 시나리오 후보](Drafts/2026-10-31-ether-taiga-dawn.md), [T0 세계 후보 비교](Drafts/2026-10-31-t0-world-candidates.md). T0의 후보 A 선택과 T0 프롬프트는 아직 갱신하지 않았다.
- 남은 판단: [통합본의 검토할 사항](Drafts/2026-10-31-ether-taiga-dawn.md#10-정본-반영-전에-검토할-사항)에 전투, 멀티플레이, 재도전, 잊힌 기술, 공급 관계, 제작 가능성, 시각 기준을 모았다. 전투, 렌더링, 첫 장 제작 구조의 사용자 방향은 아직 결정 파일에 기록되지 않았다.
- 다음 행동: 남은 판단을 구체화하고 전체 서사를 재검토한 뒤 정본 반영 범위를 사용자와 정한다. 체간 채택은 확정 요구와 구분한다.

단계, 판정, 역할은 [Workflow](Workflow.md#단계와-판정)가 소유한다.
