# 서사 작업 현황

확정된 고유 서사가 없다. 사용자가 2026-10-31 [에테르 시나리오 후보](Drafts/2026-10-31-ether-taiga-dawn.md)를 "기본 시나리오는 이걸로 할게"라고 골랐다. 독립 검토 판정이 `CHANGES_REQUESTED`여서 정본 반영 범위는 아직 승인 전이다.

- 상태: `DRAFTING`
- 담당: Claude Code
- 작성자: AI. 후보 원문의 출처와 생성 도구는 미확인
- 검토자: 읽기 전용 검토 에이전트. [검토 결과](Reviews/2026-10-31-ether-taiga-dawn-review.md)
- 승인자: 사용자
- 질문·범위: 대륙 규모의 세계와 전체 이야기, 실제로 제작할 첫 장의 인물, 사건, 적, 보스, 결말
- 완료·승인 내용: 제작 범위와 AI 주도 역할 분담, [결정 1](../decisions/0001-production-scope.md)·[결정 2](../decisions/0002-ai-led-production.md). 고유 서사는 미확정
- 미승인 후보: [에테르 시나리오 후보](Drafts/2026-10-31-ether-taiga-dawn.md), [T0 세계 후보 비교](Drafts/2026-10-31-t0-world-candidates.md). T0의 후보 A 선택과 T0 프롬프트는 아직 갱신하지 않았다.
- 장애 요인: 전투, 렌더링, 첫 장 제작 구조의 사용자 방향이 결정 파일에 기록되지 않았다.
- 다음 행동: 사용자가 체간 통합, 일반 몹 구성, 멀티플레이 서술, 세계수 외형의 방향을 정한다. 작성자가 후보를 고치고 방향을 결정 파일로 남긴 뒤 정본 반영 승인을 요청한다.

단계, 판정, 역할은 [Workflow](Workflow.md#단계와-판정)가 소유한다.
