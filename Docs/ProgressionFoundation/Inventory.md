# 인벤토리 화면과 일관성

인벤토리 화면, 입력, 서버 검증, 복제와 저장 경계를 바꿀 때 읽는다.

## 화면

인벤토리·장비 화면은 공용 UI의 `UCCLInventoryScreen`이다. `UCCLInventoryContext`가 선택 상태와 캐릭터 캡처를 소유하고, 컨트롤러는 화면 핸들과 서버 RPC를 쓴다. 공용 관리자가 화면을 닫으면 드래그와 캡처도 해제한다. 본문은 Slate 슬롯을 `UNativeWidgetHost`에 넣었다. 구현과 실행 근거는 [기능 연결](../UIFoundation/Features.md#기능-연결)과 [인벤토리·메뉴 이전 기록](../UIFoundation/Migration.md#2026-10-08-인벤토리메뉴-이전)이 소유한다.

장비 패널은 캐릭터 캡처를 중앙에, 장착 슬롯을 양옆에 둔다. 가방은 오른쪽 4×4 격자이며 아이템 이름·수량을 표시한다. 빈 슬롯으로 드래그하면 이동하고 점유 슬롯이면 교환하며 창 밖 드롭은 취소한다. 슬롯 간 드래그로 장착·해제한다. GUID와 슬롯 번호는 서버가 검증하고 Fast Array로 소유자에게 복제한다. 마우스 조작 중 게임 입력을 막고 닫을 때 돌려준다. NPC 대화와 인벤토리는 동시에 열지 않아 하단 영역이 겹치지 않는다.

HUD의 기본 글자 배율은 2026-10-07 사용자 요청으로 기존의 2배다. ACCLHUD가 로컬 화면 크기에 맞춘 배치·줄바꿈을 맡고, 긴 문구는 영역 안에서 줄바꿈한다. 훈련 영역은 스크롤로 나머지 항목을 볼 수 있다.

| 입력 | 동작 |
|---|---|
| E | 가까운 보급품 획득 |
| I | 인벤토리 열기·닫기 |
| 위·아래 | 선택 이동 |
| F | 선택 항목 장착 |
| G | 장비 해제 |
| H | 선택한 회복품 사용 |
| 1, 2 | 각 훈련 습득 요청 |

성공·거부 결과와 남은 포인트를 표시한다. 화면은 기능 검증용이며 최종 시각 디자인이 아니다. 검·방패·양손 지팡이의 장착 메시는 임시 도형이다.

## 계약과 일관성

서버 진입점은 `UCCLInventoryComponent`의 `Add`, `Remove`와 `UCCLLoadoutComponent`의 `Equip`, `Unequip`, `Use`, `Learn`이다.

서버는 실제 보유 GUID, 수량, 중첩 한도, 슬롯 수를 확인한다. 획득 요청은 원하는 수량이나 가격을 받지 않고, 월드 픽업의 서버 데이터를 쓰며 거리·시야·생존 상태를 검증한다. 클라이언트가 보낸 효과 수치나 스킬 비용은 믿지 않는다. 공격 중·사망 상태에서는 장착과 사용을 거부한다. 가득 찬 체력에서는 회복품을 소비하지 않는다. 장착 효과는 중복 적용하지 않고 이전 핸들을 제거한다.

`UCCLLoadoutComponent::Use`는 아이템을 먼저 소모하고 회복 효과를 적용한다. 효과가 거부되면 사용 전 항목 배열로 되돌린다. 인벤토리 트랜잭션 안에서 실행하므로 중간 상태의 알림은 나가지 않는다. 자동 검사 `CCL.Items.Loadout.EquipAndUse`가 이 순서를 확인한다.

능력치는 GAS AttributeSet에 두고, 전투 정책은 공격 보너스 세트가 없는 공격자도 처리한다. 장비·학습 효과에는 생명 단위 제거 태그를 붙이지 않아 개별 재스폰 뒤에도 유지된다. Avatar가 바뀌면 장비 정의를 다시 연결하고 회복된 최대 체력까지 초기화한다. 아이템 삭제와 장비 참조가 어긋나지 않도록 보관 변경을 구독한다. 컴포넌트가 종료되면 소유 효과를 정리한다.

Fast Array의 항목별 복제를 쓴다. 전체 배열 복제도 가능하지만 수량·항목의 변경을 명시적으로 표시하는 엔진 계약을 재사용한다. 이 계약은 `<Engine>/Source/Runtime/Net/Core/Classes/Net/Serialization/FastArraySerializer.h`의 `MarkItemDirty`·`MarkArrayDirty` 설명에서 확인했다. 가방은 16칸이고 장착 항목은 별도로 유지한다. 무게·내구도·정렬·거래 기능은 없다. 저장은 정의 ID·GUID·수량·장비·학습 상태를 대상으로 하며 UI와 Actor 참조를 담지 않는다. 슬롯 배치와 장착 상태의 저장 형식은 [개인 체크포인트](../SessionFoundation/Checkpoint.md)가 소유한다.
