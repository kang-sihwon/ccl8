# 초기 구성 기록

## 범위

2026-10-04 승인한 계획에 따라 ccl8을 독립 Git 저장소로 구성했다. 기본 브랜치는 `main`이고 GitHub 원격은 미연결이다. `Config/`, `Content/`, `Docs/`, `Source/`, `Tools/`와 프로젝트 AI 설정을 관리한다.

Codex·Claude Code의 스킬·작업 방식·도구를 기존 Orbis에서 이전했다. 공통 스킬과 라이선스는 보존하고, 전용 스킬·운영 문서는 ccl8에 맞췄다. 게임 코드·에셋·기획·과거 결정·학습 기록은 이전하지 않았다. UE 프로젝트와 게임 모듈은 아직 없다.

엔진 소스와 외부 엔진 인덱스는 읽기 대상으로 연결한다. 전역 에이전트 설정과 Orbis 원본을 수정하지 않는다. Graft 패치의 출처 이름과 표식은 보존하지만 실행에 Orbis 디렉터리를 요구하지 않는다.

## 검증

| 항목 | 확인 결과 |
|---|---|
| 런타임 경로·실패 처리 | Node 테스트 4개 통과. 미설정 경로, 환경변수 우선순위, 관리 가드 누락을 검사 |
| 스킬·문서 | 공통 스킬 양쪽 사본 일치, 이름·YAML frontmatter·참조·문서 링크 검사 통과 |
| 설정·스크립트 | JSON, Node 구문, PowerShell 파서 검사 통과 |
| Graft 훅 | session-start·prompt 정상 종료, 상태 표시는 미생성 그래프로 표시 |
| 엔진 Graft | 13개 샤드 인식, `UObjectBase GetFName` 검색에서 실제 엔진 소스 위치 반환 |
| MCP 프로토콜 | 두 서버의 initialize·tools/list 통과. 미생성 프로젝트는 도구 0개, 엔진은 6개 |
| 프로젝트 그래프 | 미생성. CLI map의 no graph 메시지와 종료 코드 1은 예상 상태 |
| Graphify | 도구·양쪽 스킬 확인. canonical·research 그래프는 미생성 |
| Git·LFS | main 초기화, LFS 로컬 훅 설치, 바이너리 속성 및 엔진·산출물·로컬 설정 제외 확인 |
| 보존 | Orbis 도구·스킬과 전역 에이전트 설정 156개 파일의 이전 전후 SHA-256 일치 |

Graft 설치 중 Python 탐색에 실패해 UE에 포함된 Python으로 프로젝트 로컬 의존성을 빌드했다. 기존 패치는 CRLF/LF 문맥 차이를 허용하도록 적용기를 보정했다.

세션 훅의 자동 설정 갱신은 전역 설정 변경 가능성 때문에 자동 승인 검토에서 거절됐다. ccl8 로컬 런타임에 자동 갱신을 차단하는 관리 가드를 추가하고, 적용 확인 후 재검증을 승인받아 통과했다.

실행 중인 Codex·Claude 세션의 새 설정 로딩은 별개다. 재시작 후 프로젝트 MCP 설정을 로드해야 한다. 게임 코드가 없으므로 UE 빌드·에디터 실행은 수행하지 않았고, GitHub 원격 생성·연결·push도 수행하지 않았다.
