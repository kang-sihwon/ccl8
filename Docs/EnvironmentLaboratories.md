# 기능별 환경 실험장 사용법

`/Game/Maps/Tests`의 전용 레벨에서 시험 하나를 골라 실행한다. 생태계·식생·생애·부패는 종류 하나와 표본 수를 정한 뒤 새로 배치한다. 레벨마다 세계 시간과 초기 상태를 새로 만들고 0배속에서 시작한다. 기존 통합 실험장은 여러 기능을 함께 비교할 때 사용한다.

레벨 선택과 설정은 `Source/CCL/Environment/CCLExperimentLaboratoryScreen.cpp`, 서버 검증·이동은 `CCLExperimentLaboratory.cpp`, 레벨·종류 목록은 `CCLLaboratoryConfiguration.cpp`가 소유한다.

## 시작과 조작

### 관찰 방법과 표시 범위

메뉴에서 환경 조건과 시간 배율을 정하고 장면의 변화를 관찰한다. 자동 검사는 별도 계산으로 즉시 결과를 내는 항목도 있으므로 장면의 시간 진행과 구분한다.

- 메뉴와 사용법 본문의 글씨를 확대했으며 긴 영역은 스크롤한다.
- 시간 조작과 천체 관측은 Celestial에서 사용한다. Clock 레벨과 쿠킹 항목은 제거했고 기존 구역 번호와 자동 검사 식별자는 보존했다.
- 물·지형 전용 레벨은 미리 채운 물 없이 시작한다. 비 버튼은 18 mm/h이며 높은 세계 배율에서는 누적 강수도 빨라진다. 눈 레벨의 초기 적설은 보행·압축 시험용이다.
- 날씨·눈·물·지형·식생·순환·화재·차폐 레벨에는 강수 표시가 있다. 식생의 겨울 입력은 강설을 지속하며 60배에서 적설·휴면 변화를 관찰한다.
- 식생 발화는 첫 표본이 마른 상태에서 가능하다. 가뭄과 60배를 적용하고 수분이 표시된 발화 기준보다 작아지면 발화한다. 젖은 표본은 실패 이유를 표시한다. 비·성장은 세계 시간을, 연소는 게임 시간을 따른다.
- 생태계 이동 관찰에는 1배를 권장한다. 물고기 수면은 내부를 볼 수 있는 반투명 진단 표시다. 동물 몸체·날갯짓과 꼬리 움직임은 임시 도형 표현이다.
- 차폐 실험은 문 쪽에서 관찰한다. 비·바람과 문을 조작하고 발화 후 실내 농도와 문 밖 연기를 비교한다. 배출 이펙트는 농도·문 개방·풍속을 나타내는 진단 표현이며 유체 해석 결과는 아니다.
- 환경 순환은 60배를 적용한 뒤 **순환 시작**을 누른다. 경사 상단의 적설·압축, 하단 유출·진흙, 결빙·건조를 두 번 진행하고 결과에 현재 단계를 표시한다.

조작 요청은 PlayerController RPC와 Director의 권한·실행 세대 검사를 거친다. 공통 환경 계산은 서버가 소유하고 표현 Actor는 복제 상태를 읽는다. 표현 전용 보간이나 이펙트는 저장 데이터에 반영하지 않는다.

1. 콘텐츠 브라우저에서 `/Game/Maps/Tests/Ecology` 등 원하는 레벨을 열고 Play를 누른다.
2. F7 실험 화면의 **전용 레벨 선택**에서 기능을 고른다. 이 조작은 새 레벨로 이동하며 이전 실험의 진행을 이어받지 않는다.
3. 생태계·식생·생애·부패는 **시험 종류**, **표본 수 (1-16)**를 정하고 **선택한 시험만 새로 배치**를 누른다.
4. 시간 배율을 입력하고 **배율 적용**을 누른다. 0은 정지, 1은 실시간, 60은 빠른 관찰이다. 천체 관측창이 열렸으면 해당 창의 관측 배율에 적용되므로 세계 시간을 바꿀 때는 관측창을 닫는다.
5. F7로 화면을 닫고 WASD로 이동해 표본을 본다. F7을 다시 열어 관측값과 조작 버튼을 확인한다.
6. **현재 실험 초기화**로 시간·표본을 시작 상태로 되돌린다. 저장 슬롯은 레벨·종류·수량별로 나뉜다.

에디터에서 기본값을 바꾸려면 `LaboratorySettings` 액터의 `LaboratoryVariant`, `LaboratoryCount`를 수정한다. 실행 중 종류·수량 변경에는 위 메뉴를 쓴다. 플레이어 바닥은 `LaboratoryFloor_BlockAll`의 충돌이 담당한다.

전용 레벨에서는 중복 구역 선택과 기존 맵 이동 메뉴를 숨긴다. 사용법·자동 검사·저장 / 불러오기는 접힌 제목을 눌러 연다. 저장·복원 레벨은 저장 버튼을 바로 표시한다. 초기화와 관찰 위치 이동은 메뉴 하단에 유지한다.

아래 이름은 모두 `/Game/Maps/Tests/` 아래에 있다.

| 레벨 | 시험 내용 |
|---|---|

| `Ecology` | 지상 생물·물고기·새·곤충 중 하나 |

| `Fire` | 연소·강수·소화 |
| `Shelter` | 문·차폐·실내 공기 |

생태계 수량은 개체군의 전체 개체 수이며 초기에는 모두 Actor로 표시한다. Actor는 개체마다 별도 몸체가 있고, Mass는 같은 개체 상태를 데이터로 처리하며 구체로 위치를 표시한다. 전환 시 개체의 위치·에너지·섭취 기록을 유지하며 숨김 상태에서도 계산은 계속된다. 이동은 세계 시간을 따르므로 동작 관찰에는 1배를 사용한다. 몸체는 종류별 색과 단순 도형을 사용한다. 표시 보간과 날갯짓·꼬리 움직임은 진단 표현이며 실제 동물 리그와 애니메이션은 포함하지 않는다.

식생 수량은 패치 수다. 살아 있는 나무는 복사한 Fab 단풍나무 메시를 사용하고 성장량에 따라 크기가 바뀐다. 나머지 종류와 고사·휴면 상태는 상태 표시 메시를 사용한다. 생애 수량은 마네킹 주민 수이며 수명 단축·보호·피해 버튼은 첫 표본에 적용한다.

부패 수량은 선택한 보관함 안의 음식 개수다. 음식 메시 하나가 해당 묶음을 나타내므로 수량만큼 메시를 늘어놓지 않는다. 신선도·부패 수·곰팡이 수로 변화를 확인한다. 다른 보관 조건과 비교하려면 종류를 바꿔 새로 배치한다.

실제로 배치한 Fab 메시·Niagara와 그 머티리얼·텍스처 의존성을 `/Game/TestResources`로 복사하고 참조를 바꿨다. 원본 `/Game/Fab`는 보존하며 `.gitignore`로 제외했다. 기존 프로젝트의 마네킹·환경 머티리얼 등은 원래 공유 경로를 유지한다.

추가 Fab 리소스 제출 대상은 `Content/TestResources/`다. 새 실험 기능을 다른 PC에서도 실행하려면 다음 변경도 함께 제출해야 한다.

- `Content/Maps/Tests/`와 변경된 기존 실험 맵·외부 액터 패키지
- 참조를 바꾼 `Content/Progression/DA_TrainingSword.uasset`, `DA_TrainingShield.uasset`
- 이번 작업의 `Source/CCL/`, `Source/CCLEditor/`, `Config/DefaultGame.ini`, `.gitignore`, `Tools/Validation/` 변경

`Tools/Validation/create_test_laboratories.py`는 누락된 전용 레벨과 리소스 사본을 만든다. `verify_test_resources.py`는 원본 Fab 참조와 복사 리소스의 누락된 의존성을 검사한다. 둘 다 에디터 Python에서 실행하며 결과는 `Saved/Laboratories/`에 남긴다. 에셋 파일은 저장소의 LFS 규칙을 따른다.

`update_laboratory_presentation.py`는 기존 전용 레벨에 강수 리소스를 연결하고 물고기 수면 재질을 만든다. Clock을 삭제하기 전에 패키지 참조가 없는지 검사한다. PIE를 종료한 에디터에서 실행한다.

## 검증 범위

### 사용성 보완 검증

2026-10-14 UE 5.8.3 작업 트리에서 GPF와 Editor 빌드를 통과했다. `CCL.Environment.*`는 140개 통과, 실패·경고 0건이다. `LaboratoryRainOnset`은 서로 다른 셀 크기에서 첫 강수의 깊이·물질 수지와 풍속 입력 검증을 포함한다. `LaboratoryVegetationFire`는 가뭄으로 건조한 뒤 세계 시간이 정지한 상태의 연소와 열 수지를 검사한다. 근거는 `Saved/Laboratories/Usability-GPF-final.log`, `Usability-Build-final.log`, `Usability-Automation/index.json`이다.

MCP PIE 기록 `usability-live.json`에는 날씨·눈·물·지형, 물고기·새, 식생, 차폐, 순환, 생애·부패의 진입 전후 상태가 있다. 확대된 메뉴와 사용법 본문을 화면에서 확인했다. 날씨·눈·식생의 강수 입자, 물고기 수면과 수중 위치 변화, 새의 공중 위치 변화를 확인했다. 환경 순환은 두 회차의 모든 단계와 물질 수지 검사를 통과했다. 최종 문 방향 시점에서는 실내 발화와 문 밖 연기 표시를 확인했다. 식생은 가뭄을 60배로 15초 진행한 뒤 세계 시간을 정지하고 발화해 불꽃과 연기를 확인했다. 화면과 이펙트 상태 근거는 `usability-final.json`, `usability-fire.json`, `usability-*.png`다.

물·지형의 초기 저수량을 제거했지만 사용자가 보고한 간헐적 수위 폭증의 재현 원인까지 확정한 것은 아니다. 이번 새 레벨 진입과 60배 강수 관찰에서는 폭증을 재현하지 못했다. 기존 저장 복원·매우 높은 배율·장시간 누적 강수의 조합은 미검증이다. 눈 레벨은 초기 적설과 추가 강설을 확인했으며 융해 중의 간헐적 수위 문제를 재현한 검사는 아니다.

생애·부패는 시간 진행과 기존 표시를 점검했고 별도의 새 환경 이펙트는 추가하지 않았다. 실제 동물 리그, 착지·군집 회피, 종류별 새 식생 메시 연결은 구현하지 않았다. Fab 표는 도입 후보 목록이다. 리소스 검사에서 공유 리소스는 진단 수면 재질을 포함해 110개이며 원본 Fab 참조와 누락된 리소스 의존성은 없었다. 기존 `LS_Attack_01` 누락은 그대로 별도 항목이다.

### 기존 전용 레벨 검증

2026-10-13 UE 5.8.3 작업 트리에서 GenerateProjectFiles와 `CCLEditor Win64 Development` 빌드가 성공했다. `CCL.Environment.*` 자동 검사 138개가 통과했다. 새 `LaboratorySelection` 검사는 생태계 4종의 1·3·16개 선택과 식생 9종의 단일 종류 배치를 검사한다. 자동 검사는 최종 시각 표시 보완 전 실행했고, 보완 후 빌드와 MCP 화면 검사를 수행했다.

MCP PIE에서 확인한 동작은 다음과 같다.

- 전용 레벨 14개의 진입·준비 상태와 표본 분리를 확인했다. 냉각·밀폐 보관을 포함한 15회 진입 기록은 `level-smoke.json`에 있다. 기존 `EnvironmentScenario`에서도 9개 표면 영역과 생태·생애·음식·식생·지형 실험 컨트롤러가 준비됐다.
- 메뉴에서 물고기 5개를 선택·배치하고 다른 시험 액터가 없는지 확인했다. Actor 몸체와 Mass 구체가 실제 화면에 보였다.
- 수중 Mass 5개의 위치·섭취량·에너지 변화가 진행됐다.
- 지상 Actor 3개를 실시간으로 진행시켜 먹이 섭취·에너지 증가와 막힘 0을 확인했다.
- 생애 4개 중 첫 표본을 수명으로 사망시킨 뒤 초기화하여 모두 복원했다.
- 나무 3개만 배치하고 시간이 흐를 때 생체량 증가를 확인했다.
- 노출 음식 6개의 부패·곰팡이 진행을 확인했다.

최종 코드 빌드 후 `LaboratorySelection`을 다시 실행해 통과했다. 날씨 레벨의 구름 머티리얼은 기존 환경 맵의 엔진 머티리얼로 연결하고 PIE 재진입을 확인했다.

메뉴 정리 후 GPF·Editor 빌드와 MCP 메뉴 조작을 확인했다. 배율 2 입력, 정지, 초기화로 0초·0배 복원, 접힌 자동 검사 실행·통과, 물고기 재배치와 생태계·생애·식생·부패 화면 전환을 검사했다. 이 검사에서는 서버 계산을 변경하지 않았다.

리소스 검사는 `Saved/Laboratories/resource-audit.json`에 기록한다. 복사 리소스는 109개, 약 1.28 GB이며 원본 Fab 참조와 복사 리소스의 누락된 의존성은 없었다. 기존 전투 애니메이션 작성용 참조 `LS_Attack_01`의 누락은 별도 항목으로 남겼으며 이번 리소스 이동의 수정 범위에는 포함하지 않았다.

이번 전용 레벨의 멀티플레이·패키지 실행·장시간 성능, 모든 종류의 시각 표현과 모든 조작 조합은 검증하지 않았다. 원본 로그·스크린샷·상태 덤프는 `Saved/Laboratories/`에 보존하며 제출하지 않는다.
