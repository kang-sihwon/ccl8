# 서사 작업 안내

장르는 소울라이크 RPG이며 마을, 보스, NPC와 간단한 시나리오의 범위는 [Direction](Direction.md)이 소유한다. 세계관, 고유 인물과 사건은 아직 미정이다. 다음 문서는 작업 절차와 기록 틀이며 세부 게임 설정을 확정하지 않는다.

| 문서 | 소유 내용 |
|---|---|
| [Workflow](Narrative/Workflow.md) | 조사·비교·초안·검토·승인 절차 |
| [CurrentWork](Narrative/CurrentWork.md) | 현재 담당자·작업·다음 행동 |
| [Glossary](Narrative/Glossary.md) | 작업 상태와 향후 정의할 용어 |
| [World](Narrative/World.md) | 사용자 승인 세계 설정 |
| [Scenario](Narrative/Scenario.md) | 사용자 승인 인물 관계·플롯 |

필요해지면 `Narrative/Research/`, `Narrative/Drafts/`, `Narrative/Reviews/`에 조사·후보·검토를 따로 저장한다. 아트 방향은 [ArtDirection](ArtDirection.md), 코드·설정·에셋의 AI 작업 범위는 [Coding](Coding.md)을 따른다.
