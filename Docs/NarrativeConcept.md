# 서사 작업 안내

세계관, 고유 인물과 사건은 아직 미정이다. 확정된 것은 장르(소울라이크 RPG)와 마을, 보스, NPC와 간단한 시나리오의 범위뿐이며, 이 범위는 [Direction](Direction.md#확정-범위)이 소유한다. 근거는 [결정 1](decisions/0001-production-scope.md)이다.

이 문서는 서사 문서의 소유를 정한다. 확정 설정은 World와 Scenario에만 둔다. Workflow, CurrentWork, Glossary는 작업 절차와 기록 틀이며 세부 게임 설정을 확정하지 않는다. 서사 작업은 `ccl8-narrative` 스킬로 시작한다.

| 문서 | 소유 내용 |
|---|---|
| [Workflow](Narrative/Workflow.md) | 조사·비교·초안·검토·승인 절차, 단계와 판정, 기록 위치 |
| [CurrentWork](Narrative/CurrentWork.md) | 현재 담당자·작업·다음 행동 |
| [Glossary](Narrative/Glossary.md) | 서사 항목의 상태와 향후 정의할 용어 |
| [World](Narrative/World.md) | 사용자 승인 세계 설정 |
| [Scenario](Narrative/Scenario.md) | 사용자 승인 인물 관계·플롯 |

조사·후보·검토는 `Narrative/Research/`, `Narrative/Drafts/`, `Narrative/Reviews/`에 기록한다. 파일 이름과 항목이 끝난 뒤의 처리는 Workflow가 소유한다. 아트 방향은 [ArtDirection](ArtDirection.md), 코드·설정·에셋의 AI 작업 범위는 [Coding](Coding.md)을 따른다.
