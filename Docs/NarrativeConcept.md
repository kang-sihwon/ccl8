# 서사 작업 안내

이 문서는 서사 문서의 소유를 정한다. 확정 세계 설정은 World, 인물·플롯은 Scenario, 승인 범위와 변경 근거는 [Decisions](Decisions.md)가 소유한다. 후보·검토 PASS를 정본 채택이나 실제 게임 검증으로 읽지 않는다.

소울라이크 RPG와 마을·보스·NPC·간단한 시나리오의 제작 범위는 [Direction](Direction.md#확정-범위)을 따른다. 서사 작업은 `ccl8-narrative`와 [Workflow](Narrative/Workflow.md)로 시작한다.

| 문서 | 소유 내용 |
|---|---|
| [Workflow](Narrative/Workflow.md) | 조사·비교·초안·검토·승인 절차, 단계와 판정, 기록 위치 |
| [CurrentWork](Narrative/CurrentWork.md) | 현재 담당자·작업·다음 행동 |
| [작업군 지도](Narrative/WorkGroups.md) | 완료 결과·채택 범위와 후속 작업의 연결 |
| [Glossary](Narrative/Glossary.md) | 서사 항목의 상태와 향후 정의할 용어 |
| [World](Narrative/World.md) | 사용자 승인 세계 설정 |
| [Scenario](Narrative/Scenario.md) | 사용자 승인 인물 관계·플롯 |

조사·후보·검토는 `Narrative/Research/`, `Narrative/Drafts/`, `Narrative/Reviews/`에 기록한다. 파일 이름과 항목이 끝난 뒤의 처리는 Workflow가 소유한다. 아트 방향은 [ArtDirection](ArtDirection.md), 코드·설정·에셋의 AI 작업 범위는 [Coding](Coding.md)을 따른다.

NG08의 HO01-HO06·공통 경계는 [결정 64](decisions/0064-ignis-operational-handoffs-adoption.md)·[Scenario](Narrative/Scenario.md#로덴세르나하르덴의-운영과-인계)가 소유한다. 반영 상태와 다음 선택은 [CurrentWork](Narrative/CurrentWork.md), 미채택 대안과 세부는 [보류 지도](Narrative/WorkGroups/remaining-holds.md)에서 읽는다.
