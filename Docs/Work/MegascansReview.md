# Megascans 우선 후보 상세 검토

전체 2,387개의 상세 페이지와 이미지를 확인해 벨레스 공방·나루·숲에 쓸 후보를 선별하는 작업이다. 사용자 요청은 전수 상세 검토이며 벨레스 용도를 먼저 진행한다. 스킬 조합은 같은 조사 범위에서 승인한 deep-research·computer-use·ccl8-docs·ccl8-writing을 유지한다.

## 현재 상태

2026-11-17 사용자가 선택한 B안 시안을 기준으로 공방·나루·숲의 리소스 선별을 재개했다. [B안 우선 배치표](../ArtDirection/QuixelMegascansReview/B-selection-2026-11-17.md)는 26개를 대조해 추천 20개, 수정 후 후보 2개, 보류 2개, 제외 2개로 나눈다. 기존 검토품 19개를 다시 보고 미검토품 7개를 새로 확인했다. 누적 추천 수와 이번 B안 우선 묶음을 구분한다.

기준은 [결정 66](../decisions/0066-veles-b-art-direction.md)의 B안과 [공방·나루·숲 콘셉트](../ArtDirection/VelesConcepts-2026-11-17/B-scenes.md)다. 장소별 배치에는 기존 지도 위치를 함께 적용한다.

후속 [벨레스 8개 구역과 전체 조감도](../ArtDirection/VelesConcepts-2026-11-17/B-village.md)의 최종 9장과 구역 계획의 원본 중심점 포함을 확인했다. 건물별 정밀 배치와 UE 검증은 남아 있다.

- 원본 대상: [2026-11-16 전체표](../ArtDirection/QuixelMegascans-2026-11-16.md)의 A 우선 검토 2,387개.
- 상세·이미지 확보 2,386개, 실제 상세·대표 이미지 판정 2,386개, 미검토 1개. 확보와 판정은 별도다.
- 누적 추천 593개, 수정 후 후보 329개, 보류 1238개, 제외 226개.
- [추천 보고서](../ArtDirection/QuixelMegascansReview.md)와 [전체 상태 데이터](../ArtDirection/QuixelMegascansReview/review.json)가 결과를 소유한다.
- UE 실행·모델 파일 다운로드·구매·실제 채택은 이 작업에 포함하지 않는다. 공개 미리보기 이미지는 증거로 저장했다. 원본 서사·에셋은 수정하지 않는다.

## 조사 종료와 적용 경계

사용자가 요청한 남은 2,096개 중 접근 가능한 2,095개의 상세 설명·대표 이미지 판정을 마쳤다. 앞선 291개와 합쳐 2,386개이며, 접근 제한 1개는 미검토다. Chrome 연결은 없어서 공개 상품 페이지를 직접 조회했다.

- [장소별 우선 배치 30개](../ArtDirection/QuixelMegascansReview/full-audit-priority.html)는 추천 29개와 대표 화물선 조건부 1개다. 장소·용도·실제 이미지·치수·포맷·가격·수정점을 함께 제공한다.
- 0316 Wooden Cigar Box는 공개 페이지가 `Mature content hidden for user`를 반환했다. 2026-11-18 사용자가 이 항목을 미확인으로 남기고 조사 마무리를 승인했다. 상세·이미지 확인 플래그와 판정은 미검토로 유지하며, 조사에 남은 작업은 없다.
- 2,387개 행의 고유 번호·URL, 수집/판정 집계, 새 판정 2,095개의 이미지·페이지 해시·근거 경로, 검색표 데이터와 추천표 수가 일치했다. 확보한 이미지 2,170개의 파일 유효성 검사도 통과했다. 모든 갤러리 각도나 3D 뷰어를 본 결과는 아니다.
- 실제 채택과 UE 임포트·충돌·LOD·성능 검증은 별도 작업이다. 원본 서사와 UE 에셋은 수정하지 않았다.
