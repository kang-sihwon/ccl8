# 진행 중인 작업

새 세션은 이 목록에서 이어서 할 작업을 고른다. 한 줄에 작업 하나를 적고, 세부와 다음 조각은 작업별 지도가 소유한다. 끝난 작업은 결과를 소유 사양서로 옮긴 뒤 이 목록과 지도에서 지운다. 근거는 [결정 28](../decisions/0028-agent-workflow-restructure.md)이다.

작업을 시작하면 아래 표에 한 줄을 더한다.

| 작업 | 지도 | 상태 |
|---|---|---|
| 에테르 모험 플롯 구성과 후보 보존 | [서사 작업 현황](../Narrative/CurrentWork.md) | 지역별 상세 후보와 이전안을 보존했다. 주인공의 욕망·성격·성장·전투 정체성 후보 작성과 해당 범위의 독립 검토 PASS. 벨레스 출항·로덴 사건과 세르나행 조건을 구체화했다. 다음은 세르나 해수전의 판단·반출 갈등·배 수리와 이동 조건이며 이후 동료를 구체화한다. 전체 플롯은 독립 서사 검토·정본 승인 전이다. 기존 일반 도시 12곳·마을 16곳 상세 후보의 독립 검토 PASS. 대도시를 포함한 36곳의 수직 평면 지도 시안 작성. 확대도 거리·방향·일부 기호 오차가 남아 좌표 정합 필요. 지도·제작 작업 재개 시 후보 검토와 수계·정착지 보정, 첫 장 블록아웃 검증이 남는다. 현재 플롯 요청은 실제 콘텐츠 제작을 포함하지 않는다. 실제 지형·인구·물류·정본은 미확정 |
