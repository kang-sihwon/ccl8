# 진행 중인 작업

새 세션은 이 목록에서 이어서 할 작업을 고른다. 한 줄에 작업 하나를 적고, 세부와 다음 조각은 작업별 지도가 소유한다. 끝난 작업은 결과를 소유 사양서로 옮긴 뒤 이 목록과 지도에서 지운다. 근거는 [결정 28](../decisions/0028-agent-workflow-restructure.md)이다.

작업을 시작하면 아래 표에 한 줄을 더한다.

| 작업 | 지도 | 상태 |
|---|---|---|
| 이그니스 연속 지역 지도 | [공통 지형 상세 배경](../ArtDirection/EtherWorldMap/IgnisSharedTerrain.md) | 대륙 공통 원본과 벨레스 상세 지형 v1을 보존하고, 반복 지붕·수관을 줄인 항공사진 화풍 v2를 제작했다. 원본 좌표·고도 파일과 외곽 픽셀을 유지했으며, 공통 합성 화면에서 나눈 24개 아트 타일의 중첩 38곳은 동일하다. v2 수치·조립 9개와 뷰어 7개 검사를 통과했다. 일부 지붕·길 윤곽의 시각적 정합은 PARTIAL이며, 상세 영역 밖의 낮은 사진 해상도도 남아 있다. 다음은 이 차이를 보정하고 같은 출구 좌표로 이웃 구역을 확장하는 일이다. 이웃 마을 중심부·대륙 전체 상세 아트·실제 통행·UE는 미완료 또는 미검증, 에테르 전체는 보류한다. |
| 5대륙 메인 여정과 생태 배경 | [서사 작업 현황](../Narrative/CurrentWork.md) | 사용자 승인 FC01-FC13의 갈등·선택·대가와 공통 경계를 결정 52·Scenario에 반영했다. 핵심은 CLOSED이며 독립 검토 PASS다. FA01-FA06·FH01-FH08과 기존 대안·보류·후보 본문을 보존한다. 다음 후보는 채택된 여정·인물·갈등의 장면 연결·정보 공개 시점·반복 점검이다. 실제 재미·독자 반응·항해·경제 수지·연출·AI·UE는 미검증이다. |
