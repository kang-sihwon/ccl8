# 진행 중인 작업

새 세션은 이 목록에서 이어서 할 작업을 고른다. 한 줄에 작업 하나를 적고, 세부와 다음 조각은 작업별 지도가 소유한다. 끝난 작업은 결과를 소유 사양서로 옮긴 뒤 이 목록과 지도에서 지운다. 근거는 [결정 28](../decisions/0028-agent-workflow-restructure.md)이다.

작업을 시작하면 아래 표에 한 줄을 더한다.

| 작업 | 지도 | 상태 |
|---|---|---|
| 이그니스 연속 지역 지도 | [정착지 상세 도안](../ArtDirection/EtherWorldMap/IgnisSettlementDetails.md) | 36개 정착지 중심부의 상세 타일 150칸(신규 138·기존 12)을 대륙 확대 뷰어에 연결했다. 조립 검사 835개·뷰어 검사 47개 통과, 신규 내부 경계 111곳 검토. 잘못된 배치 3칸과 흙길 단절 1곳을 보정했다. 1차 제작 후보이며 정착지 사이 연결 지형·외곽 전체·벨레스 정밀 정합은 남아 있다. 실제 시설 치수·UE 실행은 미검증, 에테르 전체는 다른 대륙 설정 이후로 보류한다. |
| 5대륙 메인 여정과 생태 배경 | [서사 작업 현황](../Narrative/CurrentWork.md) | 사용자 승인 CL01-CL12를 [결정 49](../decisions/0049-combat-connection-adoption.md)와 Scenario에 반영했다. 전투 판단·인물 선택·결과 9구간의 중심을 확정했고 독립 검토 PASS다. CA01-CA06·CH01-CH08과 기존 대안·보류·상세 원문은 보존한다. 다음은 사용자가 구체화할 장면·보류 항목을 선택하는 일이다. 상세 종·패턴·수치·공간·연출·제작 범위는 일괄 채택하지 않았으며 실제 플레이·난도·UE는 미검증이다. |
