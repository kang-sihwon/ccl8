# 진행 중인 작업

새 세션은 이 목록에서 이어서 할 작업을 고른다. 한 줄에 작업 하나를 적고, 세부와 다음 조각은 작업별 지도가 소유한다. 끝난 작업은 결과를 소유 사양서로 옮긴 뒤 이 목록과 지도에서 지운다. 근거는 [결정 28](../decisions/0028-agent-workflow-restructure.md)이다.

작업을 시작하면 아래 표에 한 줄을 더한다.

| 작업 | 지도 | 상태 |
|---|---|---|
| 5대륙 메인 여정과 생태 배경 | [서사 작업 현황](../Narrative/CurrentWork.md) | [하르덴 공공 복귀–북부 S5 상세](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-09-north-exploration.md)에 26장소·9형태·34개체와 구조체 6기, 18→21 성장·이르 합류·거수 유도·구조·겨울지기·다른 귀환과 지도 4장을 작성했다. 191개 계산 검사·독립 검토 PASS. 이전안·원본 지리·세계 분포·해금은 유지한다. 다음은 탐색 규모·구조 비용을 비교하고 북부 기록을 중앙의 실제 부하·공급 조건과 대조하는 S6를 상세화하는 일이다. 실제 지형·기후·통행·전투·생태·UE 실행은 미검증이다. |
