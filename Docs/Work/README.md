# 진행 중인 작업

새 세션은 이 목록에서 이어서 할 작업을 고른다. 한 줄에 작업 하나를 적고, 세부와 다음 조각은 작업별 지도가 소유한다. 끝난 작업은 결과를 소유 사양서로 옮긴 뒤 이 목록과 지도에서 지운다. 근거는 [결정 28](../decisions/0028-agent-workflow-restructure.md)이다.

작업을 시작하면 아래 표에 한 줄을 더한다.

| 작업 | 지도 | 상태 |
|---|---|---|
| 이그니스 연속 지역 지도 | [공통 지형 상세 배경](../ArtDirection/EtherWorldMap/IgnisSharedTerrain.md) | 해안선·정착지 좌표를 유지한 대륙 공통 원본과 벨레스의 첫 상세 자식 지형을 제작했다. 벨레스·숲·동굴 접근로와 주변 연결 구간 4,096×6,144m에 2m 고도, 0.5m/px 컬러 타일 24개, 건물 86개를 배치했다. 수치 21개·뷰어 9개 검사를 통과했고 내부 고도 경계 38곳과 부모 외곽 고도를 맞췄다. 다음은 출구 좌표를 상속해 이웃 구역을 확장하고 상세 지형끼리 접합을 검사하는 일이다. 이웃 마을 중심부·대륙 전체 상세 아트·실제 통행·UE는 미완료 또는 미검증이다. 기존 상세 타일 150칸과 B04 시제품은 보존하며 에테르 전체는 보류한다. |
| 5대륙 메인 여정과 생태 배경 | [서사 작업 현황](../Narrative/CurrentWork.md) | FC01-FC13의 갈등·선택·대가를 채택 추천, FA01-FA06을 표현 대안, FH01-FH08을 세부 보류로 정리했다. 독립 검토 PASS이며 선택표는 DISCUSSION이다. 다음은 사용자가 고른 핵심과 공통 경계를 결정·Scenario에 반영하는 일이다. 기존 정본·지역 원문·대안·보류는 보존하며 실제 재미·독자 반응·항해·경제 수지·AI·UE는 미검증이다. |
