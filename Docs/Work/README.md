# 진행 중인 작업

새 세션은 이 목록에서 이어서 할 작업을 고른다. 한 줄에 작업 하나를 적고, 세부와 다음 조각은 작업별 지도가 소유한다. 끝난 작업은 결과를 소유 사양서로 옮긴 뒤 이 목록과 지도에서 지운다. 근거는 [결정 28](../decisions/0028-agent-workflow-restructure.md)이다.

작업을 시작하면 아래 표에 한 줄을 더한다.

| 작업 | 지도 | 상태 |
|---|---|---|
| 이그니스 연속 지역 지도 | [공통 지형 상세 배경](../ArtDirection/EtherWorldMap/IgnisSharedTerrain.md) | 벨레스 항공사진 보정 v3에서 건물 86개 외곽을 대조하고 숲 양옆을 확장했다. 혼합 구간을 포함한 상세 이미지 범위는 2.12km²에서 4.64km²로 늘었다. 원본 좌표·고도 해시와 외곽 픽셀을 유지했으며, 저장된 24개 타일 재조립과 인접 여백 38곳을 포함한 검사 18개를 통과했다. 지붕·길의 그림 정합은 PARTIAL, v3 브라우저 조작은 미검증이다. 다음은 남은 길 윤곽과 북쪽·남쪽의 상세도 차이 보정이다. 이웃 마을 중심부·대륙 전체 상세 아트·실제 통행·UE는 미완료 또는 미검증, 에테르 전체는 보류한다. |
| 5대륙 메인 여정과 생태 배경 | [서사 작업 현황](../Narrative/CurrentWork.md) | 사용자 승인 SC01-SC13 추천안과 공통 경계를 결정 53·Scenario에 반영했다. 핵심은 CLOSED이며 독립 검토 PASS다. SA01-SA02·SH01-SH07과 기존 대안·보류·원문을 보존한다. 다음 후보는 벨레스 첫 장 상세 원고를 확정된 인물·갈등·정보 연결과 대조해 장면 개요를 다듬는 일이다. 실제 재미·독자 반응·정보 도달성·전투 비중·항해·경제·연출·AI·UE는 미검증이다. |
