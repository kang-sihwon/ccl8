# 진행 중인 작업

새 세션은 이 목록에서 이어서 할 작업을 고른다. 한 줄에 작업 하나를 적고, 세부와 다음 조각은 작업별 지도가 소유한다. 끝난 작업은 결과를 소유 사양서로 옮긴 뒤 이 목록과 지도에서 지운다. 근거는 [결정 28](../decisions/0028-agent-workflow-restructure.md)이다.

작업을 시작하면 아래 표에 한 줄을 더한다.

| 작업 | 지도 | 상태 |
|---|---|---|
| 이그니스 연속 지역 지도 | [공통 지형 상세 배경](../ArtDirection/EtherWorldMap/IgnisSharedTerrain.md) | 벨레스 v4에서 북쪽 6개·남쪽 9개 구역과 마을·숲길을 보정했다. 새 지형의 실제 정보 간격은 약 1.01m/px부터 1.13m/px이며 확대용 전체본은 4,096×6,144px다. 원본 좌표·고도와 외곽 픽셀을 유지했고, 24개 타일 재조립·인접 여백 38곳을 포함한 검사 43개를 통과했다. 도로 103개를 비교표로 검토했지만 일부 좁은 길과 지붕의 그림 정합은 PARTIAL이다. 중앙 동쪽·서쪽 외곽의 낮은 상세도도 남아 있다. v4 브라우저 조작·실제 통행·UE는 미검증이며, 이웃 마을 중심부와 대륙 전체 상세 아트는 미완료, 에테르 전체는 보류한다. |
| 5대륙 메인 여정과 생태 배경 | [서사 작업 현황](../Narrative/CurrentWork.md) | VS01-VS12의 새 행동·장면 강조를 채택 추천, VA01-VA02 표현 대안, VH01-VH06 세부 보류로 비교했다. 독립 검토 PASS이며 아직 DISCUSSION이다. 다음은 사용자가 고른 범위와 공통 경계를 결정·Scenario에 반영하는 일이다. 기존 원문·정본·지도·수치·대안·보류는 보존하며 실제 독자 반응·전투 비중·정보 접근·공학·운항·AI·UE는 미검증이다. |
