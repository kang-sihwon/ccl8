# 진행 중인 작업

새 세션은 이 목록에서 이어서 할 작업을 고른다. 한 줄에 작업 하나를 적고, 세부와 다음 조각은 작업별 지도가 소유한다. 끝난 작업은 결과를 소유 사양서로 옮긴 뒤 이 목록과 지도에서 지운다. 근거는 [결정 28](../decisions/0028-agent-workflow-restructure.md)이다.

작업을 시작하면 아래 표에 한 줄을 더한다.

| 작업 | 지도 | 상태 |
|---|---|---|
| 이그니스 연속 지역 지도 | [연속 지역 지도](../ArtDirection/EtherWorldMap/IgnisConnectedAtlas.md) | 고정 격자에 맞춘 육지 포함 39장 생성과 바다 배경 11칸, 2,048px 타일 50장·20,480×10,240px 조립본·확대 뷰어를 제작했다. 타일과 합본의 픽셀 일치, 해안 마스크 경계 85곳, 뷰어 검사를 통과했다. 사용자 검토 대기. 시설 상세 확대와 UE 실행은 미검증. 에테르 전체는 다른 대륙 설정 이후로 보류한다. |
| 5대륙 메인 여정과 생태 배경 | [서사 작업 현황](../Narrative/CurrentWork.md) | [오르다스 고원·흰침](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-10-ordas-highlands.md)에 새 26장소·15형태·32개체와 별도 구조체 4기·경비 5명, 38→44 성장·수로 인수·고원 협약·다른 귀환·세라디온 초청 확인을 작성했다. 지도 3장·계산 318/318·독립 검토 PASS. 기존안·정본은 유지한다. 다음은 요청 시 T3/T4 동안항 인계와 원양 계약, G4 충족 뒤 T5 출항이다. G4 전체는 미완료이며 실제 지형·수문·항행·전투·UE 실행은 미검증이다. |
