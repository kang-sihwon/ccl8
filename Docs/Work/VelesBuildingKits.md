# 벨레스 건축 키트 조사

## 현재 상태

2026-11-18에 사용자가 요청한 B안용 모듈형 건축 키트의 상세·이미지 비교를 마쳤다. 결과와 출처는 [건축 키트 비교](../ArtDirection/VelesBuildingKits-2026-11-18.md)가 소유한다. [이미지 비교표](../ArtDirection/VelesBuildingKits-2026-11-18/index.html)에서 공방·주택 적용안을 함께 볼 수 있다.

- 보유 라이브러리의 건물 및 건축 10개·환경 143개 목록 확인.
- 후보 16개 상세와 대표 이미지 26장 확인. 16개 모두 보유 표시 확인.
- [결정 67](../decisions/0067-veles-building-kit-exclusions.md)에 따라 K04·K05·K06·K08·K10·K12·K14·K15·K16을 아트풍·시대배경 불일치로 제외했다. 부분 부재 활용도 추천하지 않는다.
- 남은 검토 대상은 K01·K02·K03·K07·K09·K11·K13의 7개다. K01 우선 시험과 K02 별도 조립 대안을 제안하며, 나머지는 기존 조건부·보조·보류 판정을 유지한다.
- 구매·다운로드·UE 임포트·모델 수정은 실행하지 않았다. 최종 키트 채택도 미확정이다.

## 이어갈 때

K01로 S02 공방과 기본 주택 1채를 시험해 지붕·덧문·천막의 맞춤 제작량을 확인한다. 같은 조명·카메라·캐릭터로 K02와 비교하고 기존 지도 위치·골목·건물 방향을 유지한다. 실제 실행 작업은 별도 요청에서 시작한다.

## 아직 모르는 것

UE 5.8.3에서의 실제 호환성, 모듈 치수와 스냅·피벗·UV·재질 분리, 내부 동선·충돌, 성능과 최종 수정 비용은 미확인이다. 미선별 상품의 상세와 Fab 시장 전체를 전수 조사한 결과는 아니다.
