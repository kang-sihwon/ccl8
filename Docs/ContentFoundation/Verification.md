# 콘텐츠 검증

콘텐츠를 고친 뒤 무엇을 검사할지, 어디까지 확인됐는지 볼 때 읽는다. 실행 순서와 증거 기록은 `ccl8-verify` 스킬을 따른다.

## 검증 방법

프로젝트 파일 생성·빌드·에셋 생성 뒤 실제 클라이언트 요청으로 수락·구매·귀환 보상을 검사한다. 원거리 요청, 잔액 부족, 중복 보상, 보관 공간 부족을 거부하는지 본다. 원정의 AI·전투·재스폰·늦은 접속 검사와 함께 Standalone·Dedicated·Listen과 지연 구성을 실행한다. 보스 패턴 정의와 체력 전환, 재스폰 후 개인 상태, 렌더링 화면을 확인한다.

실행 도구는 `Tools/Validation/run_campaign_smoke.ps1`에 `-Content`를 붙인다. Listen 호스트 조작은 `-DriverIsHost`, 지연·손실은 `-Impaired`, 렌더링은 `-Rendered`를 더한다. 자동 검사는 `Tools/Validation/run_automation.ps1 -Filter 'CCL.'`이다.

- `UCCLCampaignSmokeSubsystem::TickContent`는 전투 행동 중이거나 경직된 플레이어의 요청을 거부하고 개인 상태를 유지하는지 본다. 재고를 소진한 뒤 잔액이 충분해도 구매가 실패하는지, 초기 재고 설정을 바꿔도 금화·아이템이 그대로인지 확인한다. 원거리·보관 공간 부족·잔액 부족·중복 보상 거부와 보스 체력별 공격 검사도 포함한다.
- 클라이언트 검사 `CheckContentReplication`은 기본값과 다른 상품 아이템·가격·초기 재고 설정이 도착하고, 조작자·관찰자·늦은 참가자 각각의 퀘스트·잔액·훈련 포인트·인벤토리가 기대 상태가 된 뒤 완료를 기록한다. 월드 승리 수신만으로 개인 콘텐츠 검사를 끝내지 않는다. 검사용 상품·재고 값은 스모크 프로세스 안에서만 바꾸고 콘텐츠 에셋을 저장하지 않는다.

## 검증 상태

전체 검토 직후의 재검증은 [2026-10-11 재검증 기록](../QA/FullReviewReverification-2026-10-11.md)이 소유한다.

### 2026-10-11 UE 5.8.3

| 검사 | 결과 |
|---|---|
| 프로젝트 파일 생성, `CCLEditor Win64 Development` | 성공 |
| CCL 자동 검사 | 161개 성공, 경고·실패·미실행·진행 중 0 |
| 콘텐츠 Standalone | 통과 |
| 콘텐츠 Dedicated | 조작자·관찰자·늦은 참가자 통과 |
| 콘텐츠 Listen 원격 조작 | 호스트 관찰자·원격 조작자·늦은 참가자 통과 |
| 콘텐츠 Listen 호스트 조작 | 호스트 조작자·원격 관찰자·늦은 참가자 통과 |
| 콘텐츠 Dedicated 지연·손실 | `PktLag 50`, `PktLoss 2` 적용과 모든 역할 통과 |
| 콘텐츠 렌더링 실행 | Standalone 전체 흐름 통과, 1280×720 NPC 이름·대사·잔액 부족 안내와 조작 안내 확인 |

렌더링 캡처는 기본 회복약의 대화 화면이며, 변경 상품의 수신은 각 클라이언트의 데이터 검사로 확인했다. Windows 패키지는 다시 만들지 않았다.

### 2026-10-07 UE 5.9.0

원본 로그가 없으므로 다시 확인한 결과로 취급하지 않는다.

생성 BAT·CCLEditor 빌드·공격 정의 3개와 NPC 저장을 통과했다. Standalone·Dedicated·Listen 원격·호스트·왕복 지연 100ms와 손실 2% 구성에서 실제 클라이언트 요청으로 수락·구매·귀환 보상을 검사했고, 각 네트워크 구성에서 늦은 접속도 통과했다. 원거리 거래, 잔액 부족, 보관 공간 부족, 중복 보상을 거부했고 재스폰 후 개인 상태를 유지했다. 보스는 절반 체력에서 휩쓸기와 강공격을 교대했으며, 정면 방어 중인 대상에게 휩쓸기 피해 24가 적용됐다. 성장·전투 회귀도 통과했다. NPC 렌더링 화면에서 안내인·이름·구매 가격·거부 결과·다음 행동을 확인했다.

같은 날 별도 패키지의 1280×720·1920×1080 캡처에서 대화 상자의 이름, 대사, 조작 안내를 확인했고 인벤토리 전환과 거리 이탈로 닫히는 검사도 통과했다.

같은 날 옮겨 온 커서 4개, 레벨 프로토타입 29개, 무기 27개, 애니메이션 관련 2개를 저장 없이 불러왔다. 62개 모두 객체 로드에는 성공했지만 `BP_WobbleTarget`은 `/Game/DemoTemplate/_Core/MI_Intro_Colorway`가 없고, `ABP_FP_Copy`와 `CtrlRig_FPWarp`에는 `/Game/FirstPerson/Anims/` 참조가 남아 있다. `ABP_FP_Copy`는 유효한 Control Rig 클래스가 없어 Blueprint 컴파일 오류도 난다. 원본 에셋은 바꾸지 않았고 대화 UI는 이 리소스에 의존하지 않는다.

### 미검증

- 전용 캐릭터 아트, 보스 휩쓸기 모션, 대사, 효과음의 최종 제작과 사용자 조작감 검토. NPC와 적은 기존 마네킹, 전투는 기존 공격 애니메이션을 재사용한다.
- 자동 검사는 기능 연결과 일관성을 확인하며 콘텐츠 분량과 최종 완성도를 보증하지 않는다.
