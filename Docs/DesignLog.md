## 2026-10-05 — 결정 1: 제작 방향과 단기 콘텐츠 범위

### 배경

사용자는 CCL 신청 계획서에 소울라이크 RPG 제작을 이미 기재했다고 설명했다. 전체 작업 방향과 그래픽 스타일은 Orbis와 같게 유지하되 장기 프로젝트가 아닌 3-4개월 내 완성을 지시했다.

### 결정

소울라이크 RPG를 유지하고 마을 하나, 보스 하나, 보스에게 가는 동안 싸울 서로 다른 일반 몹 몇 종류, NPC 몇 명과 간단한 시나리오를 만든다. 그래픽 스타일은 Orbis를 기준으로 한다. 정확한 일반 몹·NPC 수와 세부 전투 규칙은 아직 결정하지 않았다.

범위 정본은 [Direction](Direction.md)이다. CCL 프로그램 기간 3개월과 제작 목표 3-4개월은 구분하며 실제 제출일은 미확인으로 남긴다.

### 트레이드오프

제한된 공간과 보스에 제작 시간을 집중할 수 있는 대신 세계의 규모와 콘텐츠 다양성은 작아진다. Orbis의 전체 장기 시스템을 먼저 구현하는 대안은 이번 기한과 충돌할 수 있으므로 개별 필요성을 검토한다.

## 2026-10-05 — 결정 2: AI 주도 제작과 사용자 검토

### 배경

초기 구성은 사용자가 게임 코드를 작성하고 AI가 설계·예시·리뷰를 제공하는 방식이었다. 사용자는 ccl8에서는 AI가 주도해서 작업하고 자신은 검토, 수정 사항과 방향 지시를 맡는다고 명시했다.

### 결정

AI가 합의된 제작 범위의 기획, 아트 제안, 게임 코드·설정·에셋 제작, 통합, 검증과 문서화를 주도한다. 사용자는 결과를 검토하고 방향과 수정 사항을 지시한다. 이 역할 분담은 초기 Guide·Coding·설계 스킬의 사용자 직접 구현 기본값을 대체한다.

AI는 합의된 범위 안의 통상적인 구현을 위해 매 파일마다 재승인을 요구하지 않는다. 검토 가능한 작업 단위로 결과, 검증과 미확인 사항을 제시한다. 방향과 범위 변경은 사용자 검토 대상으로 남긴다. 힌트 훈련은 요청할 때 적용한다.

이번 작업은 제작 방향과 지침의 문서화이며 UE 프로젝트나 게임 구현을 완료했다는 뜻은 아니다.

### 트레이드오프

사용자의 직접 구현 시간을 줄이고 AI가 작업을 이어갈 수 있다. 반면 사용자가 코드를 작성하며 얻는 학습과 세부 통제는 줄어들 수 있다. 작은 결과물 단위의 검토와 실제 실행 검증으로 진행 상황을 확인한다.
