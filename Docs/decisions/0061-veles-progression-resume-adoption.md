# 2026-11-15 — 결정 61: 벨레스 진행·재개 규칙 PR01-PR07 채택

### 배경

사용자는 [PR01-PR07 선택표](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-15-veles-progression-resume/options.md)를 검토한 뒤 2026-11-15 다음과 같이 승인했다.

> 추천한 PR01–PR07과 공통 경계를 모두 채택할게. NG04에서 해당 범위를 정본에 반영하고 검토·커밋·푸시까지 진행해줘. 기존 원문·대안·보류는 유지하고 실제 UE 구현은 제외해줘.

[NG05 작성 독립 검토](../Narrative/Reviews/2026-11-15-veles-progression-resume-review.md)는 표현 두 곳 보완 뒤 PASS이며 사용자 승인과 구분한다. 이번 승인은 일곱 추천의 범위·효과·비용과 공통 경계에 한정한다. TR01-TR11·C01-C06·RT01-RT12, 조건 판정·중단 시점·재개 방식 표 전체를 구현 상태나 전체 경로 지원 목록으로 승격하지 않는다.

### 결정

[결정 53](0053-scene-continuity-adoption.md)의 실제 정보·인수 시점, [결정 57](0057-veles-information-delivery-adoption.md)의 정보 전달·누락 확인, [결정 58](0058-veles-chapter-continuity-adoption.md)의 첫 장 통합·미완료 연결, [결정 60](0060-world-journey-connections-adoption.md)의 성과와 현재 조건 구분을 첫 장의 진행·재개 판단으로 구체화한다. 기존 중심을 번복하지 않는다. 이전의 진행·재시도 보류 중 아래 의미·경계만 채택하며 정확한 입력·저장 데이터·수치·실행은 계속 보류한다.

|---|---|---|

각 행의 채택 문장·효과·비용과 공통 경계는 [Scenario](../Narrative/Scenario.md#벨레스-첫-장의-진행과-재개)가 소유한다. World 법칙·IB 관계, NC·VR·VB·CP·JC와 이전 확정을 유지한다. 모든 무기 선택, 선택적인 야외 조우와 실내 직접 대응·바르툴 직접 전투, 생존·해방·이격, 실제 정비·하류·인수·새 아침의 구분을 지킨다. 지식 누락으로 방어를 잠그거나 과거 구조를 재연하지 않으며 필수 사냥·레벨·새 동료·보상·자동 수리·무한 비축·숨은 파국 타이머를 넣지 않는다.

[결정 5](0005-run-modes-and-respawn.md)의 개별 재스폰과 [결정 21](0021-server-issued-player-identity.md)의 신원·등록 플레이어 복원 및 늦은 참가자 유지 예외는 바꾸지 않는다. 같은 세계의 성과 보존과 명시적 저장 시점 복원은 서로 다른 동작이다. 첫 장의 상세 상태가 실제 저장·복원된다고 주장하지 않으며 새 저장점·자동 되감기·원자적 실패 처리·다인 정보 공유·보상 규칙은 선택하지 않는다. 인수 누락을 아침에 찾았으면 현재 시각에서 부족한 인수·준비와 관련 새 점검을 잇고 저녁 재연·하루 추가 대기를 강제하지 않는다. 실제 다음 아침의 점검은 유지하며 시간·배편 세부는 보류한다.

PRA01-PRA02는 미채택 대안, PRH01-PRH06은 세부 보류로 유지한다. 기존 H·WH·CH·PH·FH·SH·VH·BH·RH·NH·IH·JH 원문도 보존하며 채택된 의미·경계 밖의 상세·다른 지역·실제 실행을 함께 해제하지 않는다. NG05 묶음과 조건·사례·재개·선택표 다섯 원문에는 상단 채택 안내만 추가한다. 원문·대안·보류·지도·좌표·분포·성장 수치를 삭제·덮어쓰지 않는다. 삭제 후보와 실제 삭제는 없다.

### 트레이드오프

실제 성과와 현재 유효성을 나누면 중단 뒤 완료한 일을 되감지 않으면서 달라진 조건만 확인할 수 있다. 반면 각 판단의 근거·대상·변화와 남은 일을 별도로 표현해야 하며, 접근·물량·시간이 없으면 정상 운영이나 재개 성공을 보장할 수 없다. 정확한 입력·대사·저장 대응과 무기별 실제 공간 검증은 후속 작업으로 남는다.

PRA01의 축소 채택은 정상 원고를 먼저 정리할 수 있지만 중단·저장 규칙을 다시 선택해야 한다. PRA02의 작업 묶음 단위 재확인은 세부 영향 추적 부담을 줄이지만 변하지 않은 조건까지 확인해 반복·지연이 늘 수 있다. 사용자는 일곱 추천과 관련 조건만 재확인하는 공통 경계를 함께 채택했으며 두 대안은 비교 자료로 보존한다.

이번 결정과 정본 반영 검토는 서사 판단·문서 일치의 범위다. 실제 UE 구현·실행, 전 경로·전체 상태 조합, 정보 인지·통행·재고·전투·저장 실패·동시 플레이 검증이나 제작 범위 확대를 뜻하지 않는다.
