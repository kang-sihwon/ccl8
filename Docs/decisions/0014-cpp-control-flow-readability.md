# 2026-10-06 — 결정 14: CPP 제어문과 처리 단계의 가독성

### 배경

사용자는 한 줄로 붙인 조건문과 실행문 때문에 CPP 코드의 가독성이 낮다고 지적했다. `UCCLDuelHitRule::Resolve`를 중괄호 블록으로 펼치고 판정 단계 사이에 빈 줄을 넣은 예시를 제시했다.

### 결정

CPP의 제어문은 단일 실행문도 중괄호로 감싸고 본문을 별도 줄에 쓴다. 독립된 검증·분기와 처리 단계 사이를 빈 줄 하나로 구분한다. 조건식, 실행 순서와 반환값을 보존하며 프로젝트 CPP에 같은 기준을 적용한다. 세부 기준과 예시는 [Coding](../Coding.md)이 소유한다.

### 트레이드오프

짧은 제어문도 여러 줄을 차지하지만 분기의 실행 범위와 조기 반환을 확인하기 쉬워진다. 연속된 선언·호출마다 빈 줄을 넣지는 않고 같은 작업 단위로 묶는다.
