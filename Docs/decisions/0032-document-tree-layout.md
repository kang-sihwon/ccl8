# 2026-10-31 — 결정 32: 문서 트리의 폴더 배치

### 배경

[결정 30](0030-document-cleanup-and-map-tree.md)은 나뉜 부모와 하위 군을 폴더로 삼기로 했지만 부모의 위치는 정하지 않았다. 정리를 마친 뒤 사용자가 미뤄 둔 질문에 답했다.

### 결정

나뉜 문서의 부모는 원래 경로에 두고 하위는 부모와 같은 이름의 폴더에 둔다. `EnvironmentPlan`의 하위인 환경 문서는 `Docs/EnvironmentPlan/` 아래로 옮기고, 영양 문서는 생태 문서의 하위로 둔다. 로그 경로만 뺀 큰 기록과 줄 단위로 검토하지 않은 사양서는 해당 시스템을 다루는 작업에서 같은 기준으로 정리한다.

### 트레이드오프

부모를 원래 경로에 두면 링크가 안정되지만 부모가 자기 폴더 밖에 있다. 환경 군을 옮기면 최상위 문서가 줄고 부모와 하위의 관계가 경로에 드러나지만, 해당 링크를 모두 고쳐야 한다. 큰 기록을 나중에 정리하면 지금의 비용을 아끼는 대신 낡은 서술이 그 문서를 열 때까지 남는다.
