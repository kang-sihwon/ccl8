# 2026-11-19 — 결정 72: `auto` 사용 범위

### 배경

`CCLLoadoutComponent.cpp` 한 파일에 `auto`가 52곳 있다. Epic C++ Coding Standard는 람다, 반복자, 긴 템플릿 타입 외에는 타입을 적도록 권하지만 프로젝트 규칙은 이를 정하지 않았다. 사용자는 Epic 기준을 따르는 안을 골랐다.

### 결정

`auto`는 다음에만 쓴다.

- 람다를 담는 변수
- 반복자
- 이름이 긴 템플릿 타입
- `Cast<T>`, `FindFragment<T>`처럼 오른쪽에 타입이 드러나는 결과

그 밖의 지역 변수는 타입을 적는다. 바꾸는 줄에만 적용하고, 기존 코드를 이 규칙만으로 일괄 수정하지 않는다. 세부 규칙은 [Coding](../Coding.md#코드-관례)이 소유한다.

### 트레이드오프

리뷰에서 값과 참조, 포인터의 구분이 줄만 보고 보인다. 대신 타입 이름이 긴 줄이 늘고, 한동안 기존 코드와 새 코드의 표기가 섞인다. 검사기는 이 규칙을 보지 않으므로 리뷰가 지킨다.
