# 2026-10-08 — 결정 18: 실제 자원과 경험으로 누적되는 Agent의 삶

### 배경

사용자는 같은 직업의 Agent가 성격·생활 기반·목표·경험·관계의 차이로 다른 삶을 살아가는 설계의 구현을 승인했다. 성격 목록을 늘리는 것보다 행동 결과가 다음 선택을 바꾸는 연결을 요구했다.

### 결정

성격 6개와 가치관 3개로 시작한다. 개인 특성·삶·경험과 관계·현재 상태를 선택적 Feature로 등록한다. 계정·인벤토리·의무 기록을 실제 자원의 원본으로 사용하고 장기 목표는 실제 결과에서 진행을 계산한다. 공통 판단 커널과 서버 실행 계약을 Actor와 소규모 Mass 시험에 함께 사용한다. 전체 계약과 검증 기준은 [AgentFoundation](../AgentFoundation.md)이 소유한다.

### 트레이드오프

숫자만 달리하는 AI보다 거래 원자성·저장 일관성·시간 진행과 실패 처리를 검증하는 비용이 크다. 대신 성격 차이와 실제 생활 조건의 영향을 분리해 설명할 수 있다. 모든 인간 특성이나 도시 경제를 구현하는 대안은 초기 범위에서 제외한다. 정의된 시설 단계와 작성된 마을·시험 시나리오에서 먼저 검증한다.
