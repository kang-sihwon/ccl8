# 2026-11-15 — 결정 58: 벨레스 첫 장 통합 흐름 NC01-NC04 채택

### 배경

사용자는 [NC01-NC04 묶음 선택표](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent/2026-11-15-veles-chapter-options.md)를 검토한 뒤 2026-11-15 다음과 같이 승인했다.

> 추천한 NC01-NC04와 공통 경계를 모두 채택할게. NG04에서 해당 범위를 정본에 반영하고 검토·커밋·푸시까지 진행해줘.

[NG01 독립 검토 PASS](../Narrative/Reviews/2026-11-15-veles-chapter-review.md)와 사용자 승인은 별개다. 이번 승인으로 선택표의 네 항목과 장면별·공통 경계를 채택한다. NC01이 인용한 [VR01-VR10 선택표](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent/2026-11-15-veles-familiar-route-options.md)의 흐름·강조와 장면별·공통 경계도 원래 범위대로 포함한다. NA·RA 대안이나 NH·RH 세부, 두 비교 원문 전체를 승인한 것으로 확대하지 않는다.

### 결정

[결정 54](0054-veles-scene-actions-adoption.md)의 행동·장면 강조와 [결정 57](0057-veles-information-delivery-adoption.md)의 정보 전달을 정상 흐름과 누락 사례의 연결·강조로 구체화한다. 기존 사건·정보 선후·인물 관계·무기 선택·실제 복구·출항 조건을 번복하지 않는다. 채택 문장과 경계의 정본은 [Scenario](../Narrative/Scenario.md#벨레스-첫-장의-통합-흐름과-미완료-연결)가 소유한다.

| 항목 | 채택한 중심 | 범위 |
|---|---|---|
| NC01 정상 흐름의 설명 배분 | 작업실은 원인·계획, 전투는 현재 변화, 복구는 실제 결과, 마을은 인수·여행 의사·새 점검으로 나눈다. | VR01-VR10 흐름·강조와 장면별·공통 경계를 포함한다. GB03·G04와 동쪽 왕복은 조건부 사례이며 고정 조우·통행 성공을 확정하지 않는다. |
| NC02 조사 공백의 연결 | 곰의 결박 관찰과 아직 모르는 차단 계획을 구분한다. 기존 작업실에서 빠진 연결만 처음 대조하고 공동의 현재 상태로 잇는다. | 조사 여건이 없으면 미완료다. 전투 면제·안전한 철수·무적 설명·동작 재연·자동 지식을 만들지 않는다. |
| NC03 미완료 귀환의 선택 | 주인공이 실제 끝낸 범위와 못 한 일을 먼저 밝히고 주민은 비상 운영의 현재 부담을 확인한다. | 해방·분리 성과와 남은 작업을 구분한다. 도움 수용을 정상 복구·출항으로 바꾸지 않고 강제 귀환·자동 수리·재고 보장·새 담당·지연 일수를 추가하지 않는다. |
| NC04 인수의 지식 차이 | 담당자의 질문을 이미 확인한 근거와 맞춰 답하고 주인공도 모르는 사실은 해당 자리의 실제 확인으로 남긴다. | 인수 뒤 저녁 의사·아침 새 결과를 잇는다. 담당자 지정·기록 배부만으로 인수를 끝내거나 늦게 발견한 누락을 전날 완료로 소급하지 않는다. |

선택적 야외 단서 생략, 작업실 조사 공백, 정비 미완료, 담당자 이해 부족을 구분한다. 실제 관찰·전달·작업이 있어야 다음 판단의 근거가 생긴다. 미완료 귀환은 허용하지만 정상 출항으로 세지 않는다. 현장 정비·하류 사용 점검·현재 재고와 예정 보충·담당자의 이해와 동의·다음 아침 점검을 갖춰야 한다. 시간 경과나 보고만으로 자동 해결하지 않는다.

직접 실내 대응·바르툴 전투와 모든 무기 선택, 몸·외부 결박·정상 설비의 구분, 바르툴 생존과 추격 중지를 유지한다. 전투 중 상태 변화 사이에 장치 설명을 끼워 위협을 멈추거나 끝난 결박을 되감지 않는다. 일반 동물은 생태로 남고 고블린 약탈은 사고 공모의 증거가 아니다. 서쪽 방문·전 개체 처치·늑대전 경험을 진행 조건으로 만들지 않는다.

해방·송수·마을 사용·숲 전체 회복은 다르다. 선택한 귀환로에서 실제 본 것만 보고하며 잔존 위협에 먼저 대응한다. 전투·분리 성과를 무효화하거나 정지시킨 기체를 되살리지 않는다. 귀환로·관찰·철수의 안전은 보장하지 않는다.

주민에게 처음 필요한 보고·질문·답변·동의는 남긴다. 저녁은 도움 수용·기록 분리·개인 여행 의사, 아침은 담당자의 새 점검 결과를 믿는 행동으로 구분한다. 첫 신뢰가 후속 약점까지 없애지 않는다. 린은 벨레스 나루에 남고 스승·마렌을 합치거나 마렌·이르의 현장 합류·원격 보고를 만들지 않는다. 첫 장은 예정 운송 배편에서 세계수 상부 수관을 보는 데서 닫는다.

NA01-NA02·RA01-RA02는 미채택 대안, NH01-NH05·RH01-RH06은 세부 보류로 유지한다. RH03·RH04에서 다룬 서사 사례 비교·강조가 정확한 조사 판정·재작업·재시도 규칙의 해제를 뜻하지 않는다. BA·BH·VA·VH·SA·SH·FA·FH·PA·PH·CA·CH·WA·WH와 첫 장의 나머지 대안·보류도 보존한다.

정확한 대사·소품·기록 수단·UI·조작·카메라·수치·저장·재시도·배편 재조정·비축 지속·실패 결과·후속 신상·원문 전체·지도·모든 경로 지원·제작은 채택 대상이 아니다. C01-C06 상태표·짧은 장면·통합표 전체를 정본으로 옮기지 않는다. 후보 네 편에는 채택 안내만 더하고 본문을 보존한다. World의 법칙과 [결정 1](0001-production-scope.md)의 제작 범위는 유지한다.

### 트레이드오프

정상과 누락 사례에서 지금 아는 사실·끝낸 일·남은 부담을 나누면 탐색 선택을 유지하면서 전투와 생활 복구의 성취를 연결할 수 있다. 반면 조사 재접근·필요한 주민 설명은 이동·대화 부담을 남긴다. 설명을 줄이더라도 실제 확인·작업·인수를 생략하지 않는다.

주민의 비상 부담 질문부터 보고를 여는 NA01은 생활 영향을 먼저 드러내지만 주인공이 자발적으로 한계를 인정하는 강조가 약해진다. 기록 일부를 함께 대조하는 NA02·RA01은 인수 내용을 분명히 보여 주지만 작업실 설명을 반복할 수 있다. 진입 때 G04를 정지하는 RA02는 다른 조건부 조우 사례로 남긴다. 이 대안들은 이번에 채택하지 않는다.

이번 결정은 서사 흐름·강조의 채택이다. 실제 정보 인지·통행·철수·전투 피로·무기 도달성·운영 여유·공학·운항·AI·UE를 검증한 결과가 아니다.
