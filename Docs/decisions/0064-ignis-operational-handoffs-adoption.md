# 2026-11-16 — 결정 64: 로덴·세르나·하르덴 운영과 인계 HO01-HO06 채택

### 배경

사용자는 [HO01-HO06 선택표](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-16-ignis-operational-handoffs/options.md)의 추천과 공통 경계를 검토한 뒤 2026-11-16 다음과 같이 승인했다.

> 추천한 HO01–HO06과 공통 경계를 모두 채택할게. NG04에서 해당 범위를 정본에 반영하고 검토·커밋·푸시까지 진행해줘. 기존 원문·대안·보류·도안·좌표·수치는 유지하고 실제 UE 구현·실행은 제외해줘.

[NG08 작성 독립 검토](../Narrative/Reviews/2026-11-16-ignis-operational-handoffs-review.md)는 PASS이며 잔여 지적은 없다. 작성·검토 완료와 사용자 채택은 구분한다. 이번 승인은 여섯 추천의 중심·이점·비용과 공통 경계이며 전체 원고·상세 표·수치·실제 실행의 승인이 아니다.

### 결정

[결정 53](0053-scene-continuity-adoption.md)의 SC02-SC04, [결정 59](0059-ignis-background-relations-adoption.md)의 IB, [결정 60](0060-world-journey-connections-adoption.md)의 JC를 로덴·세르나·하르덴 한 연결의 운영 판단에 구체화한다. [결정 61](0061-veles-progression-resume-adoption.md)의 실제 성과·현재 조건, [결정 62](0062-veles-validation-design-adoption.md)의 시점별 운영·증거 구분, [결정 63](0063-veles-manuscript-delivery-adoption.md)의 계획/수행·미완료 보고·현재 인수 확인을 적용한다. 첫 장의 개별 사건·매체·아침·공간을 후속 지역의 필수 절차로 확대하지 않는다.

| 항목 | 채택한 중심 |
|---|---|
| HO01 물량·자료·답변의 분리 | 발송·실제 수령·회신 수신·담당자의 인수 동의·현지 적용 결과를 따로 드러낸다. 세르나 첫 허가 화물, 후속 상행편 일반 화물, 하르덴 자료·부품을 구분한다. |
| HO02 현재량과 보충 계획의 시점별 대조 | 자원별 현재 사용 가능량과 예정 보충을 나누고, 생활·작업·운반의 실제 소모와 필요한 시점의 여유로 운영을 판단한다. 입력이 없는 경우와 부족이 확인된 경우를 구분한다. |
| HO03 불완전 첫 운송의 후속 인수 | 회신 지연은 마지막 확인 구간과 실제 수령 여부를 확인하고, 일부 부족은 품목·용도·현재 운영 영향을 나눠 지원·이동을 다시 협의한다. 실제 받은 몫과 구조·수리 성과는 보존한다. |
| HO04 북행 판단과 적용 성공의 분리 | 하르덴 현지 협의·제한 시험·정비 인수와 북부 출처 연결 뒤, 로덴 담당자의 인수 동의·현재 운영·보충 조건을 확인해 북행을 판단한다. 로덴 적용 성공은 이후 자기 현장 측정·시험으로만 판정한다. |
| HO05 담당 범위와 남은 비용의 인수 | 운송 선주의 적재·운항, 로덴의 수령·운영·시험, 린의 수리·운항, 하르덴 공방과 물 이용자의 협의 권한을 나누고 미합의 비용·교육·정비 부담을 남긴다. |
| HO06 조건 변화와 실제 전달 뒤 대응 | 북행 전 조건 변화는 영향받는 인수·운영만 다시 확인하고, 북행 뒤 로덴 시험 실패는 현지에서 가능한 운영을 맡으며 실제 전달 뒤 재시험·추가 운송·선택 재방문을 비교한다. |

여섯 항목의 전체 중심·이점·비용과 공통 경계는 [Scenario](../Narrative/Scenario.md#로덴세르나하르덴의-운영과-인계)가 소유한다. 물자 도착과 회신의 도착을 구분하고 실제 인수량만 현재량으로 인정한다. 일부 수령을 전량 이행으로 보지 않으며 부족 품목의 용도·현재 운영 영향을 확인해 지원·이동을 협의한다. 정상 S4 출발의 실제 수령 회신을 생략하지 않는다.

SC04의 현지 협의·제한 시험·정비 인수·북부 출처와 로덴 인수 동의·운영 여유를 유지한다. 로덴 시험이 미완료여도 그 조건에 근거가 있으면 북행을 판단할 수 있고, 운영이 버티지 못하면 미룬다. 근거가 없는 경우는 미확인으로 남긴다. 발송·담당자 지정만으로 성공을 선언하지 않으며 실제 로덴 적용은 자기 현장 측정·시험으로 판단한다.

기존 성과·현지 권한·유한 자원·실제 전달과 남은 비용을 유지한다. 예비선의 첫 허가 화물, 후속 S4 일반 화물, 하르덴 자료·부품, G1 해외 선실을 구분한다. 하르덴 상류 취수·켈바 하류 영향·윗샘의 추가 공급/보수도 유지한다. 린의 세르나·로덴 운송 잔류, 현지 인수 뒤 마렌 동행, 북부 이르 합류와 무기 자유를 바꾸지 않는다.

HOA01-HOA02·HOH01-HOH06과 기존 79행·PRA/PRH·VDA/VDH·IWA/IWH·JA/JH 및 이전 원문·대안·보류·도안·좌표·수치를 보존한다. OF01-OF09·OV01-OV10·HC01-HC08과 상세 표·변수명·수지식·정확한 문장·매체·계약·UI·모든 사례 지원을 정본이나 구현 사양으로 일괄 승격하지 않는다. 기존 원천 기록·작성 검토는 당시 근거로 유지하고 삭제·덮어쓰기를 하지 않는다.

새 직책·조직·대표권·국경·세율·형벌·면책·보상·필수 전투·자동 복원·즉시 통신·무한 자원·숨은 파국 시간표는 추가하지 않는다. G4·G5 상세와 실제 제작은 별도 요청이며 실제 UE 구현·실행은 이번 범위에서 제외한다.

### 트레이드오프

물자·답변·현지 시험을 분리하면 인물의 지식과 실제 운영 상태를 구별하고, 미완료와 조건 변화의 다음 행동을 드러낼 수 있다. 반면 당사자별 전달·답변·비용과 운영 여유의 근거를 표현해야 한다. 정량 입력이 없으므로 물량·운송 기간·운임·충분성을 확정할 수 없다.

HOA01의 짧은 핵심 답변은 설명 반복을 줄이지만 지연·부족의 원인과 부담이 덜 보일 수 있다. HOA02의 선택 재방문 상세는 현지 차이·책임을 직접 보여 주지만 왕복·부재 비용과 추가 집필·검증 부담이 생긴다. 두 대안은 비교 자료로 보존한다. 사용자는 HO01-HO06·공통 경계를 함께 채택했으며 재방문 강제나 회신 생략을 선택하지 않았다.

문서 반영·검토는 실제 정보 인지·항행·재고·현지 시험·전투·성장·UE 동작의 성공 증거가 아니다.
