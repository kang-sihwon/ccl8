# 2026-10-31 — 결정 31: 문서 정리의 일괄 승인

### 배경

[결정 30](0030-document-cleanup-and-map-tree.md)은 뺄 항목과 나눌 경계를 문서마다 승인받게 했다. `EnvironmentWater` 정리안을 승인한 뒤 사용자는 수락 없이 마지막까지 단계별로 진행하고 애매한 것은 나중에 한 번에 묻도록 정했다.

### 결정

결정 30의 문서별 승인을 대체한다. 승인된 정리 기준으로 문서를 끝까지 정리하고 문서마다 커밋한다. 기준으로 정할 수 없는 항목은 되돌리기 쉬운 쪽으로 처리하거나 그대로 두고, [작업 지도](../Work/README.md)의 "나중에 물을 것"에 모아 마지막에 한 번에 묻는다.

### 트레이드오프

진행이 빨라지고 사용자의 검토 부담이 줄어든다. 대신 잘못 뺀 내용을 문서마다 확인할 기회가 없다. 태그 `docs-tree-v0`, 문서별 커밋, `preserve.cjs` 대조로 되돌릴 수 있는 범위에 둔다.
