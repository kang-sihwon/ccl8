# 2026-11-03 — 결정 36: 모험 플롯 구성과 이전 후보 보존

### 배경

사용자는 현재 대화에서 “실제로 컨텐츠를 제작할 것은 아니고 플롯만 짜두려고 하는거야”라고 목적을 밝혔다. 이어 “내말은 갈등 요소가 있다, 주인공이 스토리 진행에 따라서 발전 및 진행되게 되는 스토리 흐름들 구성하고 싶어, 그리고 판타지니까 사람들의 갈등 말고도 몬스터들과의 전투 요소가 중요해”라고 방향을 지정했다.

지역별 상세 후보와 결정 순서를 본 뒤 사용자는 “오케이 차례대루 구성해줘”라고 요청했다. 2026-11-03 문서화 요청은 다음과 같다.

> 문서로 일단 다 남겨주고 수정되면 수정내용으로 고치고 이전 내용은 일단 남겨서 나중에 확정되면 불필요한 내용 다 정리하도록하자. 현재 세션에서 기록 안된 내용 전부 기록해줘

### 결정

현재 작업은 지역의 갈등과 몬스터 전투를 통해 주인공의 능력·관계·목표가 발전하는 장기 플롯을 구성한다. 실제 콘텐츠 제작, 기존 제작 범위 확대와 코드·에셋 구현은 이번 요청에 포함되지 않는다. 전쟁 확대안도 비교 자료로 남기되 전쟁이 반드시 일어나는 정본으로 채택하지 않는다.

대화의 미기록 제안과 미정을 후보 문서에 남긴다. 현재안은 수정 내용으로 갱신하고 의미가 달라지는 수정 전에는 이전안을 날짜가 있는 별도 문서로 보존한다. 작업 지도에서 현재안과 비교용 이전안을 구분한다. 최종 확정 후 정본 반영 범위, 남길 대안·폐기 이유와 불필요한 자료를 확인해 정리하며 지금은 삭제하지 않는다.

이 결정은 작업 목적과 기록·보존 방식에 대한 승인이다. 사용자 반응 “좋네”와 순차 구성 요청을 개별 인물·몬스터·사건 또는 World·Scenario 정본의 승인으로 확대하지 않는다. 고유 서사의 정본 반영은 기존 서사 작업 절차를 따른다.

### 트레이드오프

이전안을 파일로 남기면 판단을 되짚고 수정 전후의 의미를 비교하기 쉽지만 중복과 오래된 설정이 늘어난다. 현재안의 진입점을 하나로 유지하고 이전안의 상태를 표시해야 한다. 최종 확정 전 정리를 미루므로 문서 수는 늘지만 제안과 미정을 잃지 않는다. 이 보존 방식은 이번 서사 후보군에 적용하며 다른 문서 전체의 이력 규칙을 바꾸지 않는다.
