# 2026-11-14 — 결정 56: 지도 제작 자료의 도안 중심 정리

### 배경

사용자는 정리 범위로 “지도 작업 전체 정리: 도안·원본 좌표·필수 참조만 보존”을 선택했다.

### 결정

결정 55의 이전 제작 자료 일괄 보존을 필요한 도안·좌표·열람 참조 보존으로 대체한다. 이미지 제작 중단은 유지한다. 현재 도안과 좌표 원본을 변경하지 않고 임시 생성 작업 폴더, 중간 입력·출력, 제작·실험 스크립트와 대체된 뷰어를 제거한다. 최종 뷰어가 참조하는 이전 버전 이미지는 기존 경로에 남긴다.

문서에서 비교하는 그림과 검사 결과는 근거 자료로 보존한다. 과거 생성 기록의 경로는 당시의 출처이며 현재 파일 존재나 재생성 가능성을 보장하지 않는다. 실제 삭제 목록과 보존 검사 결과는 소유 문서의 정리 기록에서 확인한다. Git 이력·LFS 저장소는 정리 범위에 포함하지 않는다.

### 트레이드오프

도안 열람에 필요 없는 파일과 작업 폴더 용량을 줄인다. 이전 생성 과정을 현재 작업 트리에서 그대로 재실행할 수는 없으며, 보존된 검사 결과는 당시 범위의 증거로만 사용한다.
