# 2026-11-10 — 결정 47: 지도 제작 도안의 최소 상세 수준

### 배경

사용자는 현재 지도 작업을 실제 게임에 적용할 도안을 만드는 단계로 이해했다. 이어 세계수 관리도시 일대 이미지를 제시하며 적어도 해당 화면처럼 보여야 보고 작업할 수 있다고 요구했다. 첨부 이미지와 보관 중인 [M01 시안](../ArtDirection/EtherWorldMap/Atlas/Ignis-v1/M01.png)은 1,672×941px RGB 픽셀이 동일함을 확인했다.

### 결정

상세 제작 도안은 M01 참고 화면의 가독성을 최소 기준으로 삼는다. 개별 건물과 건물 사이 길, 도시 진입로, 주변 밭과 숲길을 구분하고 시설 사이의 배치 관계를 읽을 수 있어야 한다. 파일의 픽셀 수 증가나 업스케일만으로 이 기준을 충족했다고 판단하지 않는다.

대륙도는 전체 지형·거점 배치 기준으로 사용하고, 작업에 필요한 상세 범위는 같은 좌표와 경계 연결을 이어받는다. 기존 정착지 상세 36장을 이어진 타일로 간주하지 않는다. 기존 50개 대륙 타일은 상세 제작 도안 완료로 판정하지 않는다.

이번 결정은 도안의 용도와 최소 가독성을 구체화한다. 결정 46의 화풍·UI 기준은 유지한다. 참고 이미지의 개별 건물 배치·실거리·시설 치수나 게임의 최대 확대 배율을 확정하지 않는다. 플레이용 지도는 실제 월드의 지형·건물·길을 반영해 별도로 검증한다.

### 트레이드오프

상세 도안이 있으면 제작자가 건물·길·주변 지형의 관계를 직접 보며 작업할 수 있다. 대륙 바탕보다 많은 상세 제작과 경계 검토가 필요하며, 전체 합본의 크기만으로 완성도를 판단할 수 없다.

기존 M01을 참고하면 가독성 목표를 공유하기 쉽다. 다만 생성 이미지의 세부를 실제 게임 배치로 오인하지 않도록 확정 좌표와 새 시각 후보를 구분한다.
