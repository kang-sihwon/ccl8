# 2026-11-13 — 결정 49: 전투 연결과 인물 선택 CL01-CL12 채택

### 배경

2026-11-13 사용자는 [전투 연결 선택표](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-13-combat-connection-options.md)의 CL01-CL12를 다음과 같이 승인했다.

> 좋아. CL01\~CL12 추천안으로 채택하고 대안과 보류 항목은 그대로 남겨줘. 결정 문서랑 Scenario에 반영해줘.

선택표는 [독립 검토 PASS](../Narrative/Reviews/2026-11-13-combat-connection-options-review.md)를 받았다. 승인 범위는 전투 사이 학습의 연결, 인물 선택에서 드러낼 감정과 대가, 결과 장면의 중심이다. 검토 통과와 사용자 승인은 별개이며 이번 발언을 정본 반영의 근거로 삼는다.

### 결정

[결정 48](0048-five-continent-core-plot.md)의 주인공 성장·현지 권한 존중·전투 목표 구분을 CL01-CL12로 구체화한다. 기존 핵심 여정·G1-G6·동료 동행과 잔류·첫 장의 끝은 유지한다. Scenario에 다음 범위를 반영한다.

| 항목 | 채택 범위 |
|---|---|
| CL01 | 앞선 관찰·공격 중지 판단을 다음 전투에서 먼저 실행하고 새 예고·조건에 응용한다. 북부는 겨울지기 고유의 재잠금 종료를 읽는 응용이다. |
| CL02 | G1 방문 유무와 관계없이 G2 이후 현장 관찰·합의로 아르베나 본편 판단이 성립한다. 선행 방문 전용 필수 정보·기술을 두지 않는다. |
| CL03 | 공격 중지·미완료 철수·목표 달성 뒤 이탈·남은 작업을 동료 행동과 현장 상태로 구분한다. |
| CL04 | 착지·재상승, 측풍·사선, 남은 부위 공격, 여러 공격 방향과 마른 땅, 낙하 뒤 퇴로 등 관찰 대상을 달리한다. 결말에는 현재 전장에 필요한 판단을 결합한다. |
| CL05 | 로덴의 확인 생략·즉시 인정과 세르나의 계획 이해 뒤 구출 집착을 구분한다. 줄 고정의 손실은 남기고 하르덴부터 배운 분담을 먼저 실행한다. |
| CL06 | 하르덴 현지 협력에서 이르의 조건부 신뢰로 관계를 넓힌다. 아르베나에서는 현지 선장의 판단을 처음부터 존중한다. |
| CL07 | 북부의 통행 기회, 아르베나의 자료 확보 속도·회수 물량, 니베르의 증언 강요 수단처럼 구조에서 감수하는 대가를 달리한다. 자료·화물 손실은 매번 강제하지 않는다. |
| CL08 | 주인공은 직접 싸워 접근을 열고 현지인의 시험·운항·물 사용·통행·정비 판단을 존중한다. 결과를 확인하며 맡기고 위험을 제기할 수 있다. |
| CL09 | 벨레스 담당자 점검, 로덴 이송, 세르나 구조와 배·일감 손실, 하르덴 현지 제한 시험으로 초기 결과를 보여 준다. 시험 실패를 강제하지 않는다. |
| CL10 | 이르의 길 정보 제공, 중앙의 시민·공급 확인, 아르베나 항만 구조자와 회수 준비, 오르다스 시험 도선·운반으로 중반 결과를 보여 준다. |
| CL11 | 세라디온의 합의한 숲 작업·유지되는 취수·중지된 시험 확대, 니베르 책임자의 보온과 별도 조사 뒤 증언·현장 불일치를 보여 준다. |
| CL12 | 직접 전투·실제 심부 분리 뒤 다음 교대의 운영 결과를 확인하고 현지에 맡기는 행동으로 본편을 닫는다. |

중앙의 준비와 아르베나·니베르의 구조 인수는 해당 후속 전투보다 앞에 남긴다. 결과 장면을 모두 보스 처치 뒤로 옮기거나 짧은 표현을 이유로 실제 구조·분리·시험·인수를 생략하지 않는다. 니베르 귀환은 G6와 독립이며 결말의 현지 준비·전투·심부 분리·운영 인수·다음 교대를 유지한다.

CA01-CA06은 미채택 대안, CH01-CH08은 세부 보류로 원문 그대로 보존한다. WA01-WA10·WH01-WH08과 첫 장의 기존 보류도 유지하며, 이전 상세 원고는 삭제하지 않는다. 상세 후보 가운데 이번에 확정한 것은 CL의 연결·선택·결과 중심뿐이다. 구체 종·보스 명부·공격 패턴 전체·수치·공간·인원·대사·연출·저장 정책·실제 귀향은 함께 확정하지 않는다. World의 세계 법칙과 결정 1의 제작 범위도 바꾸지 않는다.

관찰 대상의 대표 이름은 후보를 식별하는 예시로 유지한다. CL04를 채택해도 대표 종·개체의 최종 명부나 기술별 공격 창이 확정되지는 않는다. 무기 자유·필드 생활권·일반 동물 구분을 유지하며 고정 전투 횟수·필수 관찰 시험·강제 피격·잘못된 조작을 요구하지 않는다.

### 트레이드오프

앞선 판단을 다음 현장에서 실행하면 성장과 신뢰가 이어지고, 지역별 결과가 전투의 의미를 남긴다. 반면 모든 연결을 말로 설명하면 모험이 늘어질 수 있으므로 행동과 현장 변화를 중심에 둔다. 자발적 발견에 더 맡기는 CA01, 방문별 도입을 두는 CA02, 안내 대사를 앞세우는 CA03, 감정 대화를 늘리는 CA04, 보고·일상으로 압축하는 CA05, 마렌의 관찰로 결말을 강조하는 CA06은 비교 자료로 보존한다.

정본 채택은 플롯의 방향과 인과를 고정한다. 실제 재미·난도·시간 비중·무기별 도달성·AI·UE 실행의 검증을 뜻하지 않으며 상세 연출과 구현은 보류 범위에서 별도로 다룬다.
