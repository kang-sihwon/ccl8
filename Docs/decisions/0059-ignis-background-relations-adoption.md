# 2026-11-15 — 결정 59: 이그니스 배경 관계 IB01-IB06 채택

[배경 작성 독립 검토 PASS](../Narrative/Reviews/2026-11-15-ignis-background-review.md)는 후보의 문서·좌표 정합 검토이며 사용자 승인과 구분한다. 이번 승인으로 추천 여섯 항목의 관계·효과·제한과 공통 경계를 채택한다. 36곳 비교표·정치 제도·종과 성장 표·상세 원문 전체를 승인한 것으로 확대하지 않는다.

각 행의 유지할 효과와 제한을 포함한 채택 문장은 [World](../Narrative/World.md#이그니스의-공급권한생활권)와 [Scenario](../Narrative/Scenario.md#벨레스-공급과-후속-사건의-시점)가 소유한다. 정확한 취수점·유량·양수·새 수로·원격 조작, 정기편·운송량·즉시 구조, 국호·국경·제도·인구·군사 동원, 종·파생형·레벨·개체 수, 자동 복구·출항·확정 실패 시간표는 함께 채택하지 않는다.

공통 경계는 다음과 같다. 기존 36곳의 해안·ID·이름·좌표를 유지하고, 새 국경·역사·인구·자원량·생물 수를 만들지 않는다. 원문·대안·보류·도안을 보존한다. 정착망 표의 좌표·생활 풍습·국가 제도·종 명부·성장 표 전체를 이번 핵심 선택으로 일괄 승격하지 않는다. 확정 NC·VR·FC·SC와 World의 유한 자원·성과 보존이 우선한다. 이미지·실제 지형·UE·AI·게임 규칙 제작은 별도다.

IA01-IA02는 미채택 대안, IH01-IH05는 세부 보류로 유지한다. 이전 H·WH·CH·FH·NH와 나머지 대안·보류도 해당 결정의 채택 범위 외에는 유지한다. 배경 묶음·정착망·생활권·선택표 네 원문에는 채택 안내만 추가한다. 지리·첫날 상황·여정 인계의 이전 충돌 문장은 보존하며 현재 판단에는 정본을 우선한다. 삭제 후보와 실제 삭제는 없다.

### 트레이드오프

공급 방향과 교역 규모·권한·사건 시점을 구분하면 기존 좌표와 첫 장 성과를 유지하면서 대륙 배경을 설명할 수 있다. 반면 장거리 협의·운송·주민의 실제 부담을 서술해야 하며 수급량·통행·생태 검증은 계속 필요하다.

IA01처럼 비교만 유지하면 새 확정은 줄지만 서부 물 설명과 장거리 교역의 해석이 계속 갈린다. IA02처럼 지역별로 나누면 당장의 검토량은 줄지만 전체 여정 연결 때 같은 관계를 다시 선택해야 한다. 사용자는 여섯 항목을 함께 채택했으며 두 대안은 비교 근거로 남긴다.

이번 결정과 [정본 반영 검토](../Narrative/Reviews/2026-11-16-adoption-summary.md#결정-59)는 서사 문서의 채택·대조 범위다. 실제 물류·수문·생태·통행·공학·운항·플레이·AI·UE 검증을 뜻하지 않는다.
