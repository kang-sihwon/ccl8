# 2026-10-31 — 결정 33: 큰 문서의 내용 정리를 앞당김

### 배경

[결정 32](0032-document-tree-layout.md)는 로그 경로만 뺀 큰 기록과 줄 단위로 검토하지 않은 사양서를 해당 시스템을 다룰 때 정리하기로 했다. 정리를 끝낸 뒤 측정하니 하위 문서 가운데 62KB와 56KB 문서가 남아 있었다. 23KB가 대략 1만 자 이상이라는 점을 확인한 사용자가 지금 정리하도록 정했다.

### 결정

결정 32의 정리 시점을 바꾼다. 큰 문서부터 크기 순으로 내용을 직접 읽어 불필요하거나 중복된 내용을 정리한 뒤, 내용상 나눌 수 있으면 항목별로 나눈다. [결정 30](0030-document-cleanup-and-map-tree.md)의 정리 기준과 [결정 31](0031-document-cleanup-without-per-document-approval.md)의 일괄 승인을 그대로 쓴다. 기계적으로 경로만 빼는 방식은 쓰지 않는다.

### 트레이드오프

정리 비용을 지금 치르는 대신 해당 문서를 여는 작업의 읽기량이 바로 줄어든다. 문서를 직접 읽고 현재 코드와 대조하므로 한 문서에 드는 시간이 앞선 기계적 정리보다 길다. 문서별 승인이 없으므로 잘못 뺀 내용은 태그 `docs-tree-v0`, 문서별 커밋, `preserve.cjs` 대조로 되돌릴 수 있는 범위에 둔다.
