# 2026-11-09 — 결정 45: 이그니스 기준 지도 화풍과 지명 표기 통일

### 배경

사용자는 벨레스·이그니스·에테르의 최종 시안을 함께 비교한 뒤 화풍과 UI의 차이를 지적했다. 이름 주변의 점선·연결 표시가 있는 곳과 없는 곳, 선의 형식이 제각각이라며 이그니스를 기준으로 통일할 부분을 짚고 수정하도록 요청했다.

### 결정

이그니스의 화풍을 세 지도에서 공유하는 기준으로 삼는다. 색·지표 질감·UI 글꼴·상하단 바·범례·표식의 역할을 맞추되 벨레스의 수직 시점과 각 축척의 정보량은 유지한다. 기존 지형 자료와 표시 좌표를 지명 가독성을 이유로 옮기지 않는다.

이름이 있는 도시·시설 등의 지점은 위치 표식과 동일한 실선 연결 규칙을 적용한다. 대륙·숲·강처럼 영역을 뜻하는 이름은 점과 연결선 없이 표시한다. 현재 위치는 청록색 원, 정착지·장소는 중성색 원, 주요 장소는 황색 사각형으로 구분한다. 선 길이는 글자와 지점의 거리에 따라 달라져도 색·굵기·불투명도·끝 처리의 기준은 공유한다.

결정 43과 44의 시각 기준을 구체화한다. 통일 수정안 v2와 공통 UI 값·표식 좌표·검사 자료는 [지도 제작 기준](../ArtDirection/EtherWorldMap/MapPresentation.md#최종-시안-v2)에 둔다. 기존 v1 채택 파일은 보존한다. 이번 요청은 통일 방향과 수정 작업의 승인으로 기록하며, 아직 보지 않은 v2 결과를 사용자가 최종 채택한 것으로 처리하지 않는다.

### 트레이드오프

모든 지점 이름에 같은 연결 형식을 적용하면 표식과 글자의 관계가 분명해진다. 지점이 밀집한 곳에서는 선이 늘어나므로 축척에 따라 표시 항목을 줄이고 이름을 분산해야 한다. 위치점을 이동해 겹침을 해결하지 않는다.

같은 UI를 사용하면 지도 사이에서 기호를 다시 배울 필요가 줄어든다. 특정 축척에 보이지 않는 종류도 공통 범례에 남으므로 화면의 모든 범례 항목에 실제 표식이 항상 존재하는 것은 아니다.
