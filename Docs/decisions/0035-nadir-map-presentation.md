# 2026-11-01 — 결정 35: 지도 바탕의 수직 시점과 평면 표현

### 배경

2026-11-01 사용자는 넓어진 벨레스 지도에서 “아니 지도면 하늘 높은 곳에서 밑으로 찍은 것 마냥 평면으로 나와야지...”라고 시점을 지적했다. 산 측면을 등고선으로, 숲과 건물을 윗면으로 바꾼 수직 시점 수정안을 본 뒤 “좋아 앞으로 이런 방식으로 하고”라고 이후 제작 방향을 지정했다.

### 결정

결정 34의 평면 도면형 지도 방향을 수직 시점으로 구체화한다. 지도 바탕은 지표를 수직으로 내려다보는 정사영으로 표현한다. 비스듬한 산봉우리·건물 정면·나무 줄기의 묘사를 피하고 산은 등고선과 음영, 숲과 건물은 수관과 지붕의 윗면으로 그린다. 지도만 검토하며 UI 제작은 뒤로 미룬다는 기존 요청을 유지한다.

벨레스 주변 지도 수직 시점 수정안은 표현 참고다. 해당 생성물의 해안·수계·등고선·거리·건물 수를 실측값이나 서사 정본으로 승인한 것은 아니다. 색감·선 굵기·등고선 간격과 지도 확대 단계는 후속 검토 대상이다. 기존 개념도는 보존하고 새 지도 바탕 제작에 이 기준을 적용한다.

### 트레이드오프

수직 시점은 길·물길·건물의 위치 관계를 일정하게 읽기 쉽지만 산과 도시의 측면 실루엣은 사라진다. 고도 차이는 등고선·음영으로 구분해야 한다. 생성한 등고선은 실제 지형의 계산 결과가 아니므로 인게임 지도 제작 때 지형 데이터와 다시 맞춰야 한다.
