# 2026-11-17 — 결정 66: 벨레스 B안 화풍 채택과 지도 위치를 반영한 장소별 콘셉트

### 배경

사용자는 리소스를 선별하기 전에 목표 화면을 정하도록 요청했다. 현실감 중심 A, 서정적인 반실사 B, 형태 중심 C를 비교한 뒤 B를 선택하고 같은 느낌의 공방 근경·나루 전경·숲 진입부 제작을 요청했다. 작업할 때 지도 위치를 반영할 것도 명시했다.

### 결정

[B 원본](../ArtDirection/VelesConcepts-2026-11-17/B-lyrical.png)의 자연광, 정돈된 목재·석재·직물, 읽히는 큰 색면과 약간 강조한 건축 비례를 벨레스의 후속 환경 콘셉트 기준으로 사용한다. 붉은 지붕, 청록 덧문, 겨자 천막과 황금빛 숲의 조합을 유지한다.

공방 근경·나루 전경·숲 진입부는 기존 지도·배치 자료의 장소 좌표, 강안, 물길과 연결로를 먼저 읽고 카메라를 정한다. B 원본에 압축된 시설 간 거리·큰 계단·단차를 새로운 배치로 채택하지 않는다. 현재 제작 기준은 [보관 도안](../ArtDirection/EtherWorldMap/IgnisSharedTerrain.md#제작-도안-보관과-사용)과 [블록아웃](../Work/VelesBlockout.md)을 대조한다. 초기 서사 배치의 고도와 현재 지형 자료의 고도 차이는 생성 이미지로 해결하거나 덮어쓰지 않는다.

승인 대상은 B안의 화풍과 후속 제작 방향이다. 새로 생성한 세 장소의 세부 건축·인물·설비, 정확한 치수·지형과 UE 최종 결과까지 승인한 것은 아니다. 지도 화풍·UI에 대한 기존 결정과 지도 추가 제작 중단 범위는 바꾸지 않는다. 이번 산출물은 지상 시점 환경 콘셉트다.

### 트레이드오프

반실사는 물성을 유지하면서 잔질감을 줄여 공간을 읽기 쉽게 할 수 있다. 기존 스캔 리소스도 색·거칠기·형태를 통일하는 작업이 필요하다. 정지 시안에서 성립한 색면과 분위기가 플레이 시점·전투·다른 조명에서도 유지되는지는 UE에서 별도로 확인해야 한다.

지도 관계를 우선하면 한 화면에 모든 시설을 가까이 모을 수 없다. 장소별 장면과 시선 방향을 나누어 연결을 설명하며, 생성 이미지의 치수와 거리감은 정밀 배치 검증을 대신하지 않는다.
