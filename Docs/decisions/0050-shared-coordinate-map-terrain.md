# 2026-11-13 — 결정 50: 이그니스 공통 좌표 기반 상세 배경 제작

### 배경

사용자는 정착지 사이 연결 지형과 외곽도 같은 상세도로 제작해 이그니스 전체를 완성하도록 요청했다. 기존 세계 격자를 정착지 수준의 개별 생성 PNG로 모두 채우는 방법은 현재 제작 환경의 처리·저장 범위를 넘는다. 계산 근거와 기존 방식의 완료 범위는 [공통 지형 상세 배경](../ArtDirection/EtherWorldMap/IgnisSharedTerrain.md)에 둔다.

사용자는 2026-11-13 선택 질문에 “기존 좌표 유지: 공통 지형 데이터와 반복 가능한 재질·식생으로 상세 배경을 만드는 방식으로 전환하고 먼저 연결 구간의 품질 검증”을 선택했다.

### 결정

기존 해안·수계·정착지의 좌표와 세계 격자를 유지한다. 정착지 사이와 외곽의 상세 배경은 공통 지형 데이터에 반복 가능한 재질과 식생을 적용하는 방식으로 제작한다. 대륙을 압축하거나 거점 사이 거리를 줄이지 않는다.

먼저 정착지 연결 구간에서 확대 가독성, 재질 반복, 경계 연속성과 기존 정착지 도안의 접합을 검증한다. 결과를 검토한 뒤 대륙 전체에 적용한다. 결정 47의 건물·길·주변 토지 이용 식별 기준과 결정 46의 화풍·UI를 유지한다. 절차적으로 채웠다는 사실만으로 전체 도안의 품질이 검증된 것으로 처리하지 않는다.

기존 자료에 없는 고도·식생 분포·길과 강의 폭은 제작 후보로 구분한다. 색을 분석한 바탕을 측량 고도 자료라고 설명하지 않는다. 기존 정착지 도안과 서사 정본은 보존하며 실제 UE 지형·플레이 검증과 구분한다.

### 트레이드오프

같은 세계 좌표에서 같은 재질과 식생을 재현하면 화면 이동과 분할 출력 사이의 연결을 유지할 수 있다. 모든 상세 픽셀을 개별 PNG로 미리 저장할 필요도 줄어든다.

재질 재사용에는 반복과 균질화의 위험이 있다. 지역별 지형·식생 조건, 주요 장소의 고유 형태와 정착지 접합을 별도로 조정해야 한다. 기존 그림의 과장된 길·강 폭을 자연스럽게 이어도 실제 시설 치수나 통행 가능성을 검증한 결과는 아니다.
