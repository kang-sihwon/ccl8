# 2026-11-19 — 결정 71: 코드 주석 언어

### 배경

AGENTS.md는 코드 주석을 영어로 쓰라고 하지만, [C++ 배치 규칙](../Coding/CppLayout.md#헤더-배치)의 예시와 헤더 32개는 `// 내 클래스 함수` 같은 한국어 영역 주석을 쓴다. 다음 작업자가 어느 쪽을 따를지 정할 수 없었다. 사용자는 설명은 한국어로 쓰고, 문장에서 영어가 더 맞는 용어(class, interface 같은 코딩 용어)는 영어로, 한국어로 써도 되는 용어는 한국어로 쓰도록 정했다.

### 결정

- 코드 주석의 설명 문장은 한국어로 쓴다. 영역 주석도 같다.
- 식별자, 엔진 API 이름, 영어로 쓰는 편이 정확한 용어는 영어로 쓴다. 클래스, 인터페이스처럼 한국어로 써도 뜻이 같은 용어는 한국어로 쓸 수 있다.
- 새로 쓰거나 고치는 주석에만 적용한다. 기존 영어 주석을 이 결정 때문에 일괄 번역하지 않는다.
- 식별자와 커밋 메시지는 계속 영어로 쓴다.

AGENTS.md의 언어 규칙을 이 결정에 맞춘다. 세부 규칙은 [Coding](../Coding.md#코드-관례)이 소유한다.

### 트레이드오프

설명을 사용자가 바로 읽을 수 있고, 배치 규칙 예시와 지침이 일치한다. 대신 한 파일 안에 영어 주석과 한국어 주석이 한동안 섞인다. 영어만 읽는 외부 기여자나 도구에는 불리하지만 현재 그런 기여자는 없다.
