# 2026-11-01 — 결정 34: 개념 지도와 인게임 지도 UI의 용도 구분

### 배경

2026-11-01 사용자는 기존 이그니스 생성 지도를 모바일 게임 같은 느낌의 개념화로 평가하고, 도시·마을 단위 이동을 보여줄 때 활용하면 좋겠다고 설명했다. 실제 플레이에서 열어 보는 지도에 대해서는 “실제 인게임에서 사용하는 UI에 나오는 지도는 붉은사막, 원신 같은 도면 지도를 말하는거야”라고 방향을 명확히 했다.

### 결정

기존 이그니스 생성 지도는 대륙의 분위기와 거점 관계를 보여주는 개념도다. 도시·마을 사이 이동 화면에서의 활용 후보로 보존한다. 실제 인게임 지도 UI는 지형과 위치 관계를 읽는 평면 도면형 지도로 제작한다. 사용자가 언급한 두 게임은 방향 참고이며 어느 한 작품의 화면을 그대로 재현하거나 두 작품의 표현을 동일하게 간주하지 않는다.

거리·수관·가림을 계산한 제작용 설계도는 별도 자료다. 그 도면 자체가 완성 UI 시안은 아니다. 지도 UI의 색감·질감·지형 표현·아이콘·확대 단계와 기능은 후속 시안으로 구체화한다. 이번 결정은 지도 표현과 용도에 한정하며 세계관 수치나 이동 시스템의 구현 범위를 확정하지 않는다.

### 트레이드오프

개념도는 분위기와 거점의 인상을 전달하기 쉽고, 평면 지도는 길과 위치 관계를 일관되게 읽기에 적합하다. 두 표현을 유지하려면 같은 지리 기준에서 도시·물길·길의 위치를 맞추는 관리가 필요하다. 기존 생성 이미지의 과장된 기호와 픽셀 간격은 인게임 좌표로 직접 사용할 수 없다.
