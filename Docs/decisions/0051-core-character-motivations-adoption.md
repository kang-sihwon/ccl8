# 2026-11-13 — 결정 51: 핵심 인물 동기와 관계 변화 CP01-CP12 채택

### 배경

2026-11-13 사용자는 [인물 선택표](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-13-core-character-options.md)의 추천안을 다음과 같이 승인했다.

> 좋아. CP01\~CP12 추천안으로 채택하고 대안과 보류 항목은 그대로 남겨줘. 결정 문서랑 Scenario에 반영해줘.

선택표는 [독립 검토 PASS](../Narrative/Reviews/2026-11-13-core-character-options-review.md)를 받았다. 사용자 발언을 정본 반영의 근거로 삼으며 검토 통과와 승인을 구분한다. 채택 범위는 네 사람의 욕망·두려움·성장 방향과 기존 사건에서 확인할 관계 변화 중심이다.

### 결정

[결정 48](0048-five-continent-core-plot.md)의 동행·잔류와 성장, [결정 49](0049-combat-connection-adoption.md)의 인물 선택·신뢰 확대·결과 장면을 CP01-CP12로 구체화한다. 두 결정이 남긴 WH04·CH05의 개인 서사 보류 가운데 아래 중심만 해제하며 나머지 보류는 유지한다. Scenario에 다음 범위를 반영한다.

| 항목 | 채택 범위 |
|---|---|
| CP01 | 주인공은 낯선 공방·생물·도시에서 자기 가능성을 시험하고 싶다. 필요 없는 사람이 될까 두려워 해결을 앞세울 수 있지만 가고 싶은 마음을 인정하고 맡긴 뒤 떠나는 법을 배운다. 호기심·용기를 유지하며 모든 도움을 인정 욕구의 계산으로 보지 않는다. |
| CP02 | 린은 자기 배와 판단으로 먼 물길을 선택하고 싶다. 친구에게 운항 판단을 빼앗길까 경계하면서도 도움과 결정권 양도를 구분한다. 구조를 손익만으로 판단하지 않는다. |
| CP03 | 마렌은 잘못을 인정한 뒤에도 경험을 다른 장인이 확인·개선할 수 있게 남기며 현장에서 일하고 싶다. 모든 판단이 무가치해질까 두려워 확인을 붙잡다가 상호 검토·현지 인계를 배운다. 고의 은폐나 면책으로 바꾸지 않는다. |
| CP04 | 이르는 주민에게 외지 일정에 종속되지 않는 이동·생활 선택을 남기고 싶다. 뒤에 남을 위험을 경계하며 협력 범위·우려를 먼저 설명하는 쪽으로 변한다. 주민 전체를 대표하거나 생명에 필요한 길을 숨겨 시험하지 않는다. |
| CP05 | 주인공은 벨레스 담당자를 믿고 떠나고 린은 마을 역할을 맡는다. 타르넬에서는 린 자신의 화물·하역 일로 합류하며 서로의 삶이 상대 여정에 딸린 것은 아님을 받아들인다. |
| CP06 | 로덴에서 주인공은 확인을 생략한 조작을 즉시 밝히고 마렌은 우회 승인·도면 누락을 인정한다. 불편함과 사실을 나눌 신뢰가 함께 남는다. 붕괴는 조작 이전이며 각자의 책임·전투·분리 작업을 유지한다. |
| CP07 | 세르나에서 린은 손실과 판단 침해에 상처받는다. 수리만으로 해결되지 않으며 시험 운항의 신호를 기다리는 행동으로 업무상 신뢰부터 회복한다. 린은 결정권을 유지하며 운송에 남고 일감 손실은 남는다. 린·마렌은 부품·비용·운항 조건을 함께 맞추며 마렌은 H03에 있다. |
| CP08 | 하르덴의 도움 요청에서 해외의 상호 검토로 발전한다. 마렌은 성급한 의미 연결의 근거를 나누고 주인공은 과도한 확인 대신 지금 관찰할 범위를 제안한다. 현지 권한을 유지하며 새 필수 실패·손실·지연을 만들지 않는다. |
| CP09 | 이르는 조건을 밝히고 협력하며 구조로 놓친 통행 기회를 주민 탓으로 돌리지 않는 주인공을 보고 더 많은 길 정보와 판단을 나눈다. 마렌과 장치·열 공급·길·피난 조건을 대조한다. 전적인 신뢰가 즉시 생기지는 않는다. |
| CP10 | 중앙에서는 서로 보이지 않는 자리도 맡기고 실제 인수 결과를 확인한다. 주인공의 접근 돌파, 마렌의 현지 기술 확인, 이르의 시민 인계, 린의 운송 연결을 유지한다. 이르의 잔류는 관계 실패가 아니다. |
| CP11 | 니베르에서 마렌은 자기 과거와 닮았다는 이유로 책임자를 면책·단죄하지 않는다. 주인공과 구조·협조를 분리하고 구조 뒤 증언·장치를 대조한다. 같은 범행·공모나 구조자 재상륙·발견의 즉시 적용을 만들지 않는다. |
| CP12 | 직접 전투·실제 분리 뒤 다음 교대 결과를 받아들인다. 주인공은 떠나도 되는 사람으로, 마렌은 잘못을 인정하고도 협력할 수 있는 사람으로 변한다. 과거 손실·불안·책임이 전부 해소되지는 않는다. |

관계 변화 여덟 묶음은 기존 CE01-CE12를 모두 가리킨다. CP08은 하르덴과 해외를 묶은 관계 발전이며 사건의 시간 순서를 바꾸지 않는다. 린·이르의 직접 만남·친분·즉시 통신·해외 재합류를 만들지 않는다. 첫 장의 끝, G1-G6, 구조와 후속 조사, 결말의 전투·실제 분리·운영 인수·다음 교대는 유지한다.

PA01-PA06은 미채택 대안, PH01-PH08은 세부 보류로 선택표 원문 그대로 보존한다. WH04·CH05에서 채택한 위 중심 외에는 기존 WH·CH·WA·CA와 첫 장의 보류를 유지한다. 최종 신상·가족사·연애·생사·완전한 화해 시점·정확한 대사·연출·꿈의 구체적 성과·개인 의뢰·호감도·AI·장비·수치·귀향·후일담과 원문 전체는 함께 확정하지 않는다. 후보 이름은 식별용으로 유지한다.

이전 인물 상세·CE 식별자·선택표·검토 기록은 보존한다. 모든 무기 선택과 생활권 기반 필드 전투·우회·왕복 탐색을 유지하고 관계 사건을 필수 대화 뒤 전투가 열리는 연속 단계로 만들지 않는다. World의 법칙과 결정 1의 제작 범위는 바꾸지 않는다.

### 트레이드오프

현재의 일과 선택 안에서 관계를 바꾸면 각 인물에게 독립된 목적을 주면서 기존 여정을 깊게 할 수 있다. 다만 책임·협의만 반복하면 성격의 즐거움과 친밀함이 약해질 수 있으므로 내면을 모든 장면의 설명으로 쓰지 않는다. 구체적인 일상 장면·대사는 보류한다.

호기심·자립·기술의 즐거움·공동체의 적극성을 더 강조하는 PA01-PA04, 지역 사이 대화 비중을 높이는 PA05, 개인 의뢰를 더하는 PA06은 비교 자료로 남긴다. 특히 PA06은 동선·동행·보상·제작 범위 검토가 필요하다. 정본 채택은 실제 플레이·독자 반응·동료 AI·UE 검증을 뜻하지 않는다.
