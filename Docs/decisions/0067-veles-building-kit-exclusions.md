# 2026-11-18 — 결정 67: 벨레스 건축 키트 9종 제외

### 배경

사용자는 B안용 건축 키트 비교표를 검토한 뒤 K05, K04, K06, K08, K10, K12, K14, K15, K16이 아트풍이나 시대배경에 맞지 않는다며 제외와 문서 반영을 요청했다.

### 결정

[결정 66](0066-veles-b-art-direction.md)의 B안 기준을 건축 키트 선별에 구체화한다. 다음 9종을 벨레스의 공방·주택과 부속 시설 활용 후보에서 제외한다. 부분 부재 활용과 원경·블록아웃 대안도 추천하지 않는다.

| ID | 상품 |
|---|---|
| K04 | Advanced Village Pack |
| K05 | Stylized Village Fatpack |
| K06 | Stylized Windmill Valley Environment |
| K08 | Stylized Harvest Farm Environment |
| K10 | Modular Building Set |
| K12 | Stylized - Clay Forest Village Pack |
| K14 | Modular House |
| K15 | Storage House Set |
| K16 | Watermills / Nature Environment |

제외 근거는 사용자가 판단한 아트풍·시대배경 불일치다. 상품별 기술적 사용 불가나 라이선스 제한을 뜻하지 않는다. 원래 상세·이미지 관찰과 이전 제안은 조사 데이터에 보존하고 현재 추천과 구분한다.

남은 K01·K02·K03·K07·K09·K11·K13은 기존의 후보·보류 상태를 유지한다. K01 우선 시험과 K02 조립 대안은 제안이며, 나머지 7종을 일괄 채택한 결정은 아니다. 실제 UE 임포트·조립·충돌·성능 검증과 지도 배치는 바꾸지 않는다.

### 트레이드오프

보유 키트의 활용 범위는 줄지만 B안의 화풍과 시대배경을 맞추는 기준이 명확해진다. 특히 K05의 부분 활용 제안을 철회하므로 지붕·덧문·천막 등 부족한 부재는 남은 후보나 맞춤 제작으로 해결해야 한다.
