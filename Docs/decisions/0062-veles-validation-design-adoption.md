# 2026-11-15 — 결정 62: 벨레스 공간·운영·전투 검증 기준 VD01-VD06 채택

### 배경

사용자는 [VD01-VD06 선택표](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-15-veles-validation-design/options.md)를 검토한 뒤 2026-11-15 다음과 같이 승인했다.

> 추천한 VD01–VD06과 공통 경계를 모두 채택할게. NG04에서 해당 범위를 정본에 반영하고 검토·커밋·푸시까지 진행해줘. 기존 원문·대안·보류·도안·좌표·수치는 유지하고 실제 UE 구현·실행은 제외해줘.

[NG06 작성 독립 검토](../Narrative/Reviews/2026-11-15-veles-validation-design-review.md)는 PASS이며 사용자 승인과 구분한다. 이번 승인은 여섯 추천의 검증 범위·판단 기준·이점·부담과 공통 경계다. 문서 검토 통과를 실제 검사 성공으로 바꾸지 않는다.

### 결정

[결정 37](0037-unrestricted-protagonist-weapons.md)의 모든 무기 선택, [결정 58](0058-veles-chapter-continuity-adoption.md)의 첫 장 통합 흐름·미완료 연결, [결정 61](0061-veles-progression-resume-adoption.md)의 실제 성과·현재 조건·진행과 재개를 첫 장의 검증 범위와 판단 기준으로 구체화한다. 기존 확정은 번복하지 않으며 실제 무기·공간·수치·실행 보류도 해제하지 않는다.

| 항목 | 채택한 중심 | 정본 소유 |
|---|---|---|
| VD01 기존 참조의 제한된 연결 | 동쪽 진입·지하 작업실·공동·같은 길 귀환·마을 인수·출항을 첫 검증 범위로 쓰고 도안별 역할·층·좌표·실제 여유를 구분한다. | Scenario |
| VD02 경로와 중단 사례 분리 | 적은 조우·통상 탐색·조사 누락·복구 전 귀환·부분 전투/작업·인수 부족을 서로 다른 시작 상태로 검사한다. | Scenario |
| VD03 각 무기의 도달성과 공격 창 | 실제 지원 목표의 모든 무기·행동·장비 조건을 명부에 연결하고 도달·가림·준비/접촉/회복·대응·생존 이격을 검사한다. | Scenario |
| VD04 시점별 운영 판단 | 실제 자원별 재고·생활 소비·운반·재작업·보충 시점을 기록하고 필요한 순간의 사용 가능량을 대조한다. | Scenario |
| VD05 경로 성장과 무기 시험 분리 | 같은 출발에서 적은 조우/통상 탐색의 실제 획득·소모를 비교하고, 무기 도달성은 별도 명시한 통제 상태에서 시험한다. | Scenario |
| VD06 단계별 실행 증거 | 필요한 최소 공간·계측·선행 미결·실행 순서와 각 검사 증거를 준비하고 문서 대조·실제 실행 결과를 분리한다. | Scenario |

각 행의 채택 문장·이점·부담과 공통 경계는 [Scenario](../Narrative/Scenario.md#벨레스-첫-장의-공간운영전투-검증-기준)가 소유한다. PR01-PR07과 NG01-NG04의 확정, 같은 세계의 실제 성과 보존과 명시적 저장 복원의 구분을 유지한다. 동쪽 왕복은 첫 비교 사례이며 모든 플레이의 필수 길이 아니다. 필수 야외 사냥·레벨·새 무기·동료·보상을 요구하지 않고 실내 직접 대응·바르툴 직접 전투·생존·이격·실제 정비를 유지한다.

기존 원문·대안·보류·도안·좌표·수치는 보존한다. 새 위치·층 구조·길·치수가 필요하면 원본을 유지한 별도 후보와 영향·선택 범위를 먼저 제시한다. 이미지 제작을 재개하거나 v5 전체를 실제 플레이 공간으로 확정하지 않는다. 평면 거리·시야·픽셀·문서 검사와 실제 통행·추격·전투·사용·원경을 구분한다. 운영·성장·재접근의 입력이 없으면 미확인으로 남기며 무한 자원·순간 이동·자동 수리·숨은 파국 시간표·자동 레벨 보정·강제 사냥으로 빈칸을 채우지 않는다.

현재 프로토타입의 수치·무기·처치/승리·저장 지원은 첫 장 전체 지원의 근거가 아니다. 새 구현·UI·스키마·전체 다인 플레이·전 대륙 검증은 별도 요청 범위다. 실제 UE 구현·실행은 이번에 하지 않는다.

VDA01-VDA02·VDH01-VDH06과 기존 79행·PRH를 포함한 모든 원문·대안·보류를 보존한다. SP·GX·WC·OP, 최소 제작 인계의 표·검사 ID·실행용 가정·좌표·수치 전체를 정본 상태나 구현 사양으로 승격하지 않는다. NG06 묶음·공간·검사·운영·인계·선택표 여섯 원문에는 상단 채택 안내만 추가한다. 기존 source-audit와 작성 검토 기록은 당시 근거로 유지한다. 삭제 후보와 실제 삭제는 없다.

### 트레이드오프

제한된 연결과 경로·무기별 검사를 함께 쓰면 연속 통행·운영의 실패와 개별 전투의 실패를 나눌 수 있다. 반면 초기 상태·실제 무기 명부·자원 시각·계측·증거를 각각 준비해야 한다. 대표 무기·한 장면·한 모드의 성공으로 전체를 통과시킬 수 없고 실제 입력이 없으면 판정 불가가 남는다.

VDA01의 공동·작업실 시험장 우선은 전투 공간 문제를 먼저 좁히지만 마을·귀환·재고·출항을 검증하지 못한다. VDA02의 동쪽·서쪽 동시 비교는 경로 차이를 일찍 확인하지만 초기 제작·측정 범위가 커진다. 사용자는 VD01-VD06과 공통 경계를 함께 채택했으며 두 대안은 비교 자료로 보존한다.

이번 채택·정본 반영은 검증 설계의 범위를 확정한다. 실제 검사 GX·WC의 결과는 모두 미실행이며 문서 PASS로 실제 정보 인지·통행·전투·운영·성장·저장·전체 경로 지원을 주장하지 않는다. 다음 집필과 별도 제작에서도 이 미확인을 유지한다.
