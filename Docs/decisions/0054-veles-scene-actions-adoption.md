# 2026-11-14 — 결정 54: 벨레스 장면 행동 VS01-VS12 채택

### 배경

2026-11-14 사용자는 [VS01-VS12 선택표](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent/2026-11-14-veles-scene-options.md)를 검토한 뒤 다음과 같이 승인했다.

> 좋아. VS01\~VS12 추천안과 공통 경계를 모두 채택하고 대안과 보류 항목은 그대로 남겨줘. 결정 문서랑 Scenario에 반영해줘.

선택표의 [독립 검토 PASS](../Narrative/Reviews/2026-11-14-veles-scene-options-review.md)와 사용자 승인은 별개다. 이번 발언을 근거로 표의 새 행동 배치·장면 강조와 장면별 경계, 공통 경계를 모두 채택한다. 기존 기준 열의 확정 사건을 번복하거나 첫 장 개요·소품·전체 교전·동선을 일괄 승인한 것으로 확대하지 않는다.

### 결정

[결정 40](0040-opening-core-settings.md)의 첫 장, [결정 41](0041-field-exploration-combat.md)·[결정 42](0042-goblin-territories-and-forest-wildlife.md)의 필드·생태, [결정 49](0049-combat-connection-adoption.md)의 전투 연결, [결정 51](0051-core-character-motivations-adoption.md)의 인물 변화, [결정 52](0052-regional-conflict-adoption.md)의 갈등, [결정 53](0053-scene-continuity-adoption.md)의 정보 연결을 구체 행동으로 드러낸다. 기존 CH·PH·FH·SH에서 이 행동 중심에 해당하는 부분만 보류에서 해제한다. 사건·동행·정보 범위·대가·필드 전투·제작 범위는 유지한다. 전체 채택 문장은 [Scenario의 벨레스 첫 장 행동](../Narrative/Scenario.md#벨레스-첫-장의-행동과-장면-강조)이 소유한다.

| 항목 | 채택한 행동·강조의 중심 |
|---|---|
| VS01 아침 | 주인공의 작은 수리와 린의 적재, 밀린 일을 먼저 말하는 반응과 등불·급수의 차이를 보여 준다. |
| VS02 역할 분담 | 남을 담당자가 자기 일을 밝히고, 주인공은 린의 물통 운반을 보며 조사 장비·철수 조건을 챙긴다. |
| VS03 숲 생활권 | 일반 동물의 생활과 결빙 관찰을 분리하고 고블린 흔적을 읽으며 접근·교전·이격을 고른다. |
| VS04 물가·작업 구역 | 후퇴하는 한 대상뿐 아니라 다른 접근 방향·정상 배관을 보고, 곰 흔적과 자신의 상태로 접근을 판단한다. |
| VS05 작업실 | 관찰과 미확인을 기록하고 복구 계획을 세운 뒤 조작부 접근의 방해를 확인한다. |
| VS06 공동 관찰 | 물러나려다 결박에 붙잡히는 곰을 보고 몸·외부 결정·정상 설비를 구분해 전투 목표를 잡는다. |
| VS07 바르툴 전투 | 체중·앞발·바닥 결박을 읽고 해방 단계에 따라 위치·공격 기회를 다시 고르며 해방 뒤 추격을 멈춘다. |
| VS08 현장 복구 | 위험한 연결에 새 동력을 넣지 않고 실제 결과·남은 정비를 기록한다. 곰의 호흡과 물소리로 긴장을 낮춘다. |
| VS09 귀환 | 조건이 허락하면 기존 서쪽 후보에서 다른 흔적·생활권을 살핀다. 바뀐 물길과 지속되는 생태를 함께 보며 익숙한 진입로 회항도 남긴다. |
| VS10 주민 인수 | 주민의 질문에 답하고 남은 정비를 숨기지 않는다. 주민은 실제 부담을 이해하고 인수한다. |
| VS11 저녁·밤 | 공동 식탁·장비 도움을 받고 타인의 일을 성과로 인정한다. 마을용 기록·가져갈 자료를 나누며 개인 여행 욕구를 인정한다. |
| VS12 다음 아침 | 담당자 결과에 필요한 질문만 하고 일을 다시 혼자 맡지 않는다. 짐의 위치·운항 판단을 따르며 린은 남고 상부 수관을 주인공 관점에서 본다. |

VS 번호는 개요 순서이며 필수 대화·전투 수업·퀘스트·적 생성 조건이 아니다. 일반 동물과 고블린은 사고 전부터 생활하며 거점 전멸·모든 조우를 요구하지 않는다. 약탈 흔적만으로 범인을 단정하지 않고 야외 조우를 건너뛰어도 작업실·공동에서 필요한 정보를 얻는다. 모든 무기 선택과 직접 전투, 바르툴 생존·추격 중지를 유지한다. 강제 실패·피격·특정 기술을 이해 조건으로 삼지 않는다.

정보는 실제 확인·전달받은 순서로 제한한다. 스승과 마렌을 합치거나 마렌·이르를 첫 장에 넣지 않고, 린은 마을에 남아 운반·적재·출항을 돕는다. 즉시 원격 보고·첫 출항 동행을 추가하지 않는다. 전투 뒤 실제 채취 해제·분리·파편 회수·정상 송수와 하류 점검, 현재 재고·예정 거래의 구분·동의를 유지한다. 서쪽 귀환은 선택 사례이며 새 기하·무전투·안전 구역·자동 재생성을 확정하지 않는다.

VS10의 이해·동의와 VS12의 실제 다음 점검은 구분한다. 주인공의 모든 친절을 인정 욕구로 설명하지 않고 첫 출항으로 후속 약점을 없애지 않는다. VS11의 공동 식탁·장비 도움은 행동 중심으로 채택하되 정확한 음식·수리 부위·대사·길이는 정하지 않는다. 밤의 결심만으로 출항하지 않고 다음 아침 이상이 있으면 연기한다. 세계수 최초 발견·전체 원경·타르넬 도착·새 인물 합류로 끝을 바꾸지 않는다.

VA01-VA02 대안과 VH01-VH06 보류는 그대로 남긴다. 기존 SA·SH·FA·FH·PA·PH·CA·CH·WA·WH와 첫 장의 나머지 항목도 자동 채택·폐기하지 않는다. 정확한 표현·소품·대사·전달 장치·게임 규칙·수치·운영 상세·신상·제도·새 후속 사건·후일담·원고 전체·실제 제작은 범위 밖이다. 기존 두 후보에는 채택 안내만 더하고 본문을 보존한다. World의 법칙과 결정 1의 제작 범위도 유지한다.

### 트레이드오프

관찰·전투·복구와 주민 인수를 행동으로 연결하면 수원을 살린 성취와 타인을 믿는 변화가 함께 보인다. 반면 관찰과 정비 설명이 길어지면 전투의 흐름이 끊기고, 인수와 다음 아침 점검이 같은 대화처럼 보일 수 있다. 짧은 현장 행동·확인 결과를 쓰고 두 장면의 목적을 나눈다. 저녁을 압축하는 VA01과 준비·인수의 설명보다 행동을 강조하는 VA02는 미채택 비교 자료로 보존한다.

서면 정합성과 사용자 채택은 실제 재미·독자 반응·전투와 설명의 비중·모든 탐색 순서의 정보 접근·무기 도달성·설비 공학·운항·AI·UE 검증을 뜻하지 않는다.
