# 2026-10-06 — 결정 4: 헤더의 불리언 멤버 타입

### 배경

사용자는 멀티플레이 기본 흐름 구현을 준비하면서 헤더의 불리언 선언에 `uint8`을 사용하고 문서에 명시하라고 지시했다. 이후 적용 범위를 멤버 변수로 한정했으며, `.cpp`의 지역 변수에는 `bool`을 허용했다.

### 결정

헤더의 클래스·구조체 불리언 멤버 변수만 `uint8`을 사용한다. 함수 반환값·매개변수와 `.cpp` 지역 변수는 `bool`을 유지한다. 엔진 오버라이드와 외부 인터페이스의 함수 시그니처도 원래 타입을 유지한다. 규칙 정본은 [Coding](../Coding.md)이다.

### 트레이드오프

모든 위치에서 `bool`을 사용하는 대안보다 멤버 저장 타입과 함수 인터페이스를 구분한다. `uint8`은 정수 타입이므로 불리언 멤버에 저장하는 값을 0 또는 1로 제한해야 한다.
