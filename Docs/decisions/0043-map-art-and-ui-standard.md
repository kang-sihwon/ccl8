# 2026-11-09 — 결정 43: 지도 화풍과 공통 UI 기준 채택

### 배경

사용자는 기존 지도 그림의 아기자기한 표현이 현실에 가까운 게임 그래픽과 어울리지 않는다고 지적했다. 벨레스 항공 지형도 후보에서는 나무와 동굴의 측면을 없애고 글씨와 아이콘을 단순화한 수정안을 골랐다. 이그니스에서는 산맥의 입체감이 남은 첫 번째 시안을 선호했고, 그 화풍과 UI를 유지한 도시 표기 보정본을 확인했다.

2026-11-09 사용자는 이 화풍과 UI를 앞으로의 지도 제작 기준으로 문서에 반영하고 벨레스와 이그니스 최종 시안을 정리하도록 요청했다. 채택한 파일은 [지도 제작 기준과 채택 시안](../ArtDirection/EtherWorldMap/MapPresentation.md#이전-v1-비교-자료)이 식별한다.

### 결정

이후 지도는 채택 시안의 사실적인 지표 질감과 절제된 색을 따른다. UI는 얇은 짙은 회색 상·하단 바, 장식 없는 고딕체, 작은 위치점과 단순한 장소 표식으로 구성한다. 장식적인 글씨, 보석 형태의 아이콘, 미니어처 도시와 개별 나무 모형을 기본 표현으로 쓰지 않는다.

지역 지도는 벨레스의 수직 항공 시점을 기준으로 삼는다. 나무는 수관, 건물은 지붕으로 읽으며 동굴의 정면 아치는 그리지 않는다. 대륙 지도는 이그니스 선택안의 산맥·고원·분지 질감과 입체감을 유지한다. 이그니스 시안은 엄밀한 수직 정사영이 아니므로 이후 대륙 시안을 일률적으로 평탄화하지 않는다.

결정 35의 UI 제작 보류를 해제한다. 모든 축척에서 산의 측면을 배제하던 부분은 위의 지역·대륙별 표현 기준으로 대체한다. 지역 지도의 수직 시점과 기존 지리 자료의 우선순위는 유지한다. 결정 34의 개념 지도·인게임 지도·제작용 도면의 용도 구분도 유지한다.

지명과 도시 위치는 기존 이름·좌표 자료에서 가져와 지도 바탕과 분리한다. 글자가 겹치면 이름과 연결선을 옮기고 위치점은 유지한다. 생성 이미지의 해안·수계·픽셀 간격을 새로운 지리 기준으로 쓰지 않는다.

이번 채택은 시각 기준과 최종 참고 이미지에 한정한다. 실제 게임 UI 구현, 엔진 글꼴 자산, 탐색 공개 방식, 확대 단계와 해금 규칙은 확정하지 않는다. 서사 정본과 기존 좌표 자료도 변경하지 않는다.

### 트레이드오프

항공 지표 질감은 사실적인 게임 공간과 연결하기 쉽지만 복잡한 배경에서 길과 표식이 묻힐 수 있다. 작은 표식과 글자 대비를 따로 조정해야 한다. 단색 측량도는 정보 구분에 유리하지만 사용자가 선택한 지표 표현과는 다르다.

대륙의 산맥 입체감은 넓은 지형을 읽는 데 도움이 되지만 실제 고도·거리·정사영을 보장하지 않는다. 그림과 좌표를 별도로 관리하면 정확한 지명을 유지할 수 있으나 두 자료를 연결하는 검사가 필요하다.
