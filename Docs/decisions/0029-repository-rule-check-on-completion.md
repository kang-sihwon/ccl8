# 2026-10-28 — 결정 29: 코드 작업 완료 때 저장소 전체 C++ 규칙 검사

### 배경

2026-10-25에 기록한 기존 C++ 규칙 위반 183건을 2026-10-28에 모두 정리해 저장소 전체 검사가 0건이 됐다. 그때까지 코드 작업의 완료 검사는 바꾼 줄의 clang-format 검사(`cpp-rules.cjs format`)와 바닥선 검사(`floor-guard.cjs`)뿐이었다. 그래서 한 줄 블록, 빈 줄, 헤더 `bool` 멤버 같은 규칙의 새 위반은 누가 직접 `cpp-rules.cjs check`를 돌려야만 드러났다. 사용자가 이 검사를 완료 검사에 넣기로 정했다.

### 결정

결정 12의 완료 검증에 `node Tools/Agent/cpp-rules.cjs check --summary`를 더한다. 이 검사는 저장소 전체를 보고 0건이어야 한다. 완료 보고에는 프로젝트 파일 생성, 빌드와 세 검사의 결과를 각각 적는다. 절차의 정본은 [Coding](../Coding.md#코드-작업-완료-검증)이다.

### 트레이드오프

검사가 저장소 전체를 보므로, 이번 작업과 무관한 파일에 위반이 생겨도 작업을 마칠 수 없다. 대신 위반이 0건인 지금 상태를 유지하고, 새 위반이 생긴 작업에서 바로 고칠 수 있다. 검사 시간은 1초 안쪽이다.
