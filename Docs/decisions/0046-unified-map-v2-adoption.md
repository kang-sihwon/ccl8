# 2026-11-09 — 결정 46: 통일한 지도 v2 최종 채택과 후속 제작 기준 확정

### 배경

사용자는 이그니스를 기준으로 화풍·UI·지명 표기를 통일한 벨레스·이그니스·에테르 v2 세 장을 확인했다. 2026-11-09 세 장을 최종 시안으로 확정하고 앞으로 지도 제작에도 같은 기준을 사용하도록 문서 반영을 요청했다.

### 결정

[최종 시안 v2](../ArtDirection/EtherWorldMap/MapPresentation.md#최종-시안-v2)의 PNG 세 장과 대응 SVG를 이후 지도 제작의 최종 참고 파일로 채택한다. 검토 당시의 파일명과 이미지 내용을 유지하고 보관 목록의 상태를 승인으로 갱신한다.

지도 제작은 이그니스 기준의 사실적인 지표 질감과 절제된 색, 공통 UI 글꼴·상하단 바·아이콘·범례를 따른다. 지역의 수직 시점과 대륙·세계 축척의 정보량을 구분한다. 이름이 있는 지점은 위치 표식과 동일한 실선 연결 규칙을 사용하고 대륙·숲·강 등의 영역 이름은 점과 연결선 없이 표시한다. 세부 값과 제작 절차는 소유 문서에 둔다.

결정 43과 44에서 채택한 v1의 최종 참고 파일 지위를 v2로 대체한다. 이전 결정의 사실적인 화풍, 축척별 표현, 지리 자료 우선 원칙은 유지한다. v1 파일과 제작·검사 자료는 이전 비교 자료로 보존한다. 결정 45의 통일 방향을 유지하며 v2가 검토 중이던 상태를 이번 최종 채택으로 확정한다.

새 지도의 해안·수계·지명·도시 위치는 기존 자료를 따르고, 글자의 가독성을 위해 위치점을 옮기지 않는다. 이번 승인은 시각 기준과 참고 시안에 한정하며 생성된 내부 지형의 지리 정본화나 실제 게임 UI 구현 완료를 뜻하지 않는다.

### 트레이드오프

공통 화풍과 UI를 재사용하면 지역·대륙·세계 지도 사이의 표현 차이를 줄일 수 있다. 축척에 따라 정보량은 달라지므로 글자 겹침과 표식 밀도를 따로 점검해야 한다.

v1을 보존하면 선택 과정과 지형 보정 근거를 다시 확인할 수 있지만 기준을 혼동할 수 있다. 현행 제작 기준은 v2로 명시하고 v1은 비교 자료로 구분한다.
