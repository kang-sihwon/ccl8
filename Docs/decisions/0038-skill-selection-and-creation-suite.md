# 2026-11-04 — 결정 38: 게임 제작 스킬 확장과 작업 전 선택 확인

### 배경

2026-11-04 사용자는 게임에 도움이 되는 Jenova 도구의 분야별 추천을 보고 C++ Coding Assistant를 제외한 언급 도구를 전부 스킬로 만들고 사용법을 문서화하도록 요청했다. 이후 작업 요청에는 사용할 스킬을 제안하고 괜찮은지 물으며 관련 스킬도 함께 보여 달라고 지시했다.

### 결정

기존 Worldbuilding Studio·Map Maker와 신규 13개를 제작·조사 스킬 15개로 안내한다. 비교 대상으로 언급된 Graphic Designer와 후순위로 소개한 Roleplay Game Master·Religion Creator·Conlang Creator도 포함한다. C++ Coding Assistant는 만들지 않고 기존 CCL의 UE 설계·검토·검증 절차를 유지한다. 범위와 각 호출 이름은 [사용 안내](../AgentContextTools/SkillUsage.md)가 소유한다.

새 스킬은 Jenova 공개 설명의 작업 방식을 참고한 로컬 지침이다. 내부 프롬프트 복제, 서비스 연결, 자동 기억·API 기능의 구현으로 취급하지 않는다. 정본은 `.agents/skills/`에 두고 Claude용 사본을 동기화한다.

결정 28의 협업 체계를 스킬 선택 단계에서 구체화한다. 새로운 작업에 사용할 스킬·각 역할·산출물과 관련 선택 스킬을 보여 주고 사용자의 선택을 기다린다. 선택을 위한 읽기 전용 확인은 먼저 할 수 있다. 스킬 발견은 자동으로 하되 본 작업의 생성·수정·실행은 확인 뒤에 한다.

직접 지정한 스킬은 선택 동의로 다룬다. 승인한 같은 조합·범위의 후속 작업에는 반복 확인하지 않고, 새로운 과제나 산출물 확대·전문 스킬 추가·교체가 있을 때 다시 묻는다. 무응답을 동의로 취급하지 않는다. 관련 후보를 보여 준 것만으로 사용 승인을 얻은 것으로 보지 않는다. 스킬 선택은 원래의 삭제·전송·정본 승인 등 권한 경계를 바꾸지 않는다.

이 지침은 CCL 프로젝트의 기존·신규·세션 스킬 선택에 적용한다. 전역 설정이나 다른 프로젝트를 바꾸는 결정은 아니다. 과거 결정 본문과 서사 후보는 이 변경으로 수정하지 않는다.

### 트레이드오프

사용자는 작업에 사용할 방법을 선택하고 관련 기능을 반복해서 볼 수 있다. 대신 새 작업의 시작에 확인 한 번이 더 필요하다. 자동 실행 방식보다 시작은 느리지만 선택을 기억하기 쉽다. 스킬을 직접 지정하거나 같은 작업을 이어갈 때 재질문을 생략해 반복 부담을 줄인다.
