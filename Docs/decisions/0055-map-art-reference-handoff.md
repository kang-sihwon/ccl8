# 2026-11-14 — 결정 55: 지도 이미지 제작 중단과 제작 도안 정리

### 배경

사용자는 실제 월드를 만든 뒤 지도 이미지를 추출해야 한다는 점을 확인하고 “그럼 이미지 작업은 여기서 멈추고 도안으로 정리해줘”라고 요청했다. 기존 결과는 2D 합성 이미지와 배치·고도 후보이며 실제 UE 플레이 공간을 구현한 결과가 아니다.

### 결정

지도 이미지의 추가 생성·보정과 이웃 구역·대륙 전체로의 상세 이미지 확장을 중단한다. 결정 50의 연결 구간 검토 후 대륙 전체에 상세 배경을 적용하는 후속 작업은 중단으로 대체한다. 같은 결정의 기존 좌표 보존과 공통 지형 데이터의 활용 원칙은 유지한다.

벨레스 상세 도안은 v5를 마지막 제작본으로 보관한다. v1부터 v4까지의 비교 자료, 이그니스 공통 지형 원본, 정착지 상세 자료와 검사 기록도 보존한다. 이는 v5의 모든 건물·도로 형태나 미검증 영역을 최종 승인한다는 뜻이 아니다. 결정 46의 통일 v2 세 장은 화풍·UI 기준으로 유지하고, 결정 47의 건물·골목 가독성은 도안을 읽는 기준으로 유지한다.

자료별 용도와 원본 경로, 미검증 범위는 소유 문서의 제작 도안 목록에서 확인한다. 새 게임 제작을 진행할 때는 기존 좌표 자료를 배치 초안으로 삼고 실제 월드에서 크기·길 폭·이동 동선을 검증한다. 플레이용 지도는 구현한 월드를 기준으로 추출·가공하고, 지명·아이콘·플레이어 위치는 실제 좌표에 연결하는 별도 표시로 다룬다. 추출 도구·해상도·갱신 주기·구현 방식은 아직 정하지 않는다.

이번 작업은 자료 정리까지다. UE 블록아웃이나 지도 기능 구현을 시작하지 않는다. 서사 정본과 기존 해안선·도시 위치도 변경하지 않는다.

### 트레이드오프

생성 이미지를 계속 다듬는 비용과 실제 월드 제작 시 다시 맞추는 일을 줄인다. 반면 대륙 전체의 건물·골목 수준 그림은 미완료로 남으며, 기존 도안의 통행성·시설 치수·경사와 공간 배치는 실제 제작 과정에서 검증해야 한다.
