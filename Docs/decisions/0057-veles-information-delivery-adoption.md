# 2026-11-15 — 결정 57: 벨레스 정보 전달 VB01-VB06 채택

### 배경

사용자는 [VB01-VB06 선택표](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent/2026-11-14-veles-information-options.md)를 검토한 뒤 다음과 같이 승인했다. 이 승인을 2026-11-15 결정과 정본에 반영한다.

> 좋아. VB01\~VB06 추천안과 공통 경계를 모두 채택하고 대안과 보류 항목은 그대로 남겨줘. 결정 문서랑 Scenario에 반영해줘.

선택표의 [독립 검토 PASS](../Narrative/Reviews/2026-11-14-veles-information-options-review.md)와 사용자 승인은 별개다. 이번 발언으로 여섯 항목의 전달 중심·장면별 경계와 공통 경계를 모두 채택한다. VI01-VI08·VT01-VT10과 원문 전체, 모든 전달 수단·재전달 분기·통행 가능성을 함께 승인한 것으로 확대하지 않는다.

### 결정

[결정 53](0053-scene-continuity-adoption.md)의 정보 선후와 [결정 54](0054-veles-scene-actions-adoption.md)의 벨레스 행동을, 필요한 사실을 확인하고 누락을 다시 연결하는 전달 중심으로 구체화한다. 기존 SH·VH에서 이 중심에 해당하는 부분만 보류에서 해제한다. 사건·행동·동행·직접 전투·실제 복구·출항 조건은 번복하지 않는다. 전체 채택 문장은 [Scenario의 정보 전달과 누락 확인](../Narrative/Scenario.md#벨레스의-정보-전달과-누락-확인)이 소유한다.

| 항목 | 채택한 전달 중심 |
|---|---|
| VB01 출발 | 분담 뒤 조사할 공급선과 돌아와 도움을 구할 상황을 짧게 확인한다. 조사 목적과 실제 길찾기를 구분한다. |
| VB02 작업실 | 현재 연결을 대조한 뒤 멈출 연결·보존할 회로·전투 뒤 할 일을 자기 기록에 묶는다. 놓친 연결은 기존 조사 공간에서 다시 살필 기회를 둔다. |
| VB03 곰과 전투 | 결박에 막힌 퇴각, 앞다리 해방 뒤 커진 이동·가슴 연결, 해방 뒤 이격을 현재 움직임으로 전달한다. 현재 상태 재관찰을 사건 되감기로 바꾸지 않는다. |
| VB04 복구 결과 | 실제 송수 확인과 하류 사용 확인 대기를 기록하고 못 한 작업은 미완료로 남긴다. 먼저 돌아온 경우에도 그 상태로 보고한다. |
| VB05 귀환 | 선택한 길에서 실제 본 상태만 보여 준다. 물길을 못 봤다면 현장 송수 확인과 마을 점검으로 성과를 전달하고 남은 위협에 대응한다. |
| VB06 인수·출항 | 주민이 이해하지 못한 부분만 질문·재설명한다. 저녁의 기록 분리·개인 여행 욕구와 다음 아침 담당자의 새 점검 결과를 구분한다. |

장소 도착·적 처치·설명 생략과 실제 확인은 다르다. 주인공은 관찰·전달받은 범위만 알고 플레이어의 실제 인지는 별도로 검증한다. 미관찰 흔적의 회상·미확인 기록 자동 습득·미방문 장소 보고를 추가하지 않는다. 여섯 항목은 강제 설명 여섯 번이나 게임 상태 판정 규칙이 아니다.

야외 조우가 없어도 작업실·공동에서 핵심 정보를 확인할 수 있는 인과를 유지한다. 모든 무리·거점 전멸·단서 수집을 요구하지 않고 실내 대응·직접 보스전을 면제하지 않는다. 모든 무기 선택과 몸·외부 결정·정상 설비 구분, 바르툴 생존·추격 중지를 유지한다. 풀린 다리를 다시 묶거나 무적 정지·강제 피격·실패·고정 카메라로 이해를 강요하지 않는다. 일반 동물은 생태로 남고 약탈 흔적은 공모의 확증이 아니다.

조사·복구·인수 누락은 실제 확인과 작업이 남았다는 뜻이다. 미완료 귀환을 금지하지 않지만 정상 복구·사용·출항과 구분한다. 기록·시간 경과·마을 점검이 미완료 현장을 자동 수리하지 않는다. 주인공 직접 복구, 하류 점검, 현재 재고와 예정 거래의 구분, 다음 보충·교체·동의, 다음 아침 점검을 유지한다. 재작업 담당·시점·비축 지속·재시도는 보류한다.

서쪽 귀환은 선택이며 생략한 길을 강제로 재생하지 않는다. 새 통로·잠금 해제·안전 구역·무전투·자동 적 생성을 추가하지 않는다. G04 같은 잔존 위협에 대한 바깥 대응·이격·길 판단이 먼저이며, 관찰 자리 접근·발견·철수·추격 중 기록 열람의 안전을 보장하지 않는다. 전투·복구 성과와 남은 위험을 함께 유지한다.

린은 마을의 운반·적재·출항 지원 뒤 나루에 남는다. 스승과 마렌을 합치거나 마렌·이르의 현장 합류·원격 즉시 보고를 만들지 않는다. VS10의 실제 인수, VS11의 전달 목적·개인 욕구, VS12의 새 점검을 합치지 않는다. 주민이 보지 않은 원인을 모두 알거나 새 이상을 완료로 세지 않으며 첫 장은 상부 수관에서 닫고 후속 약점은 남긴다.

BA01-BA02 대안과 BH01-BH06 보류는 그대로 남긴다. VA·VH, SA·SH·FA·FH·PA·PH·CA·CH·WA·WH와 첫 장의 나머지 대안·보류도 자동 채택·폐기하지 않는다. VB02 기록·VB04 완료와 미완료 구분·VB06 질문과 답변은 중심에 포함하되 정확한 표현·소품·재전달 시점·UI·판정·조작·분기·게임 규칙·수치·운영·후속 사건·원문 전체·제작은 범위 밖이다. 기존 후보 두 편에는 채택 안내만 더하고 본문을 보존한다. World의 법칙과 결정 1의 제작 범위는 유지한다.

### 트레이드오프

현장에서 필요한 사실과 새 결과만 확인하면 야외 탐색 선택을 유지하면서 조사·전투·복구·출항의 이유를 연결할 수 있다. 반면 반복 확인이 길어질 수 있고 전투 중 관찰 기회가 있어도 실제로 알아차리는지는 보장할 수 없다. 처음 본 사실과 달라진 결과를 구분하고, 이미 끝난 행동을 되돌리지 않는다. 출발 설명을 강화하는 BA01과 기존 기록 재확인을 강조하는 BA02는 미채택 비교 자료로 남긴다.

이번 채택은 정보 전달의 중심을 정한다. 실제 정보 인지·통행·전투와 설명 비중·무기 도달성·철수·재고 지속·재시도·공학·운항·AI·UE 검증을 뜻하지 않는다.
