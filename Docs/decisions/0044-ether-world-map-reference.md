# 2026-11-09 — 결정 44: 에테르 월드맵 최종 참고 시안 채택

### 배경

사용자는 벨레스·이그니스에서 채택한 화풍과 UI를 에테르 전체 월드맵에도 적용하되 기존 다섯 대륙의 배치와 해안선을 유지하도록 요청했다. 2026-11-09 완성본을 확인한 뒤 에테르 월드맵도 최종 시안으로 문서에 함께 정리하도록 요청했다.

### 결정

기존 세계지도 v3의 해안 좌표에 사실적인 지표 질감과 결정 43의 공통 UI를 적용한 완성본을 채택한다. 최종 PNG·SVG와 제작·검사 자료는 [에테르 월드맵](../ArtDirection/EtherWorldMap/MapPresentation.md#에테르-월드맵)에서 식별하고 벨레스·이그니스와 함께 관리한다.

다섯 대륙의 배치와 해안선을 유지한다. 지도 영역은 기존 2:1 비율을 따르며 UI를 포함한 전체 화면은 3,200×1,800이다. 세계 축척에서는 다섯 대륙 이름과 현재 위치 예시를 표시한다. 제작 중간의 지표 질감 이미지는 최종 지도에 포함되는 재료이며 채택 파일을 대신하지 않는다.

채택 범위는 지도 제작의 시각 기준과 최종 참고 이미지다. 생성된 내부 산맥·식생·설원을 새로운 지리·기후 정본으로 확정하지 않는다. 현재 위치 표시는 예시이며 실제 게임 UI·입력 동작의 구현을 뜻하지 않는다.

### 트레이드오프

기존 해안선을 그대로 사용하면 생성 과정에서 대륙의 배치나 외곽이 달라지는 것을 막을 수 있다. 지표 질감은 별도로 합성하므로 산맥·수계·기후의 세부 정합은 추가 작업이 필요하다.

세계 축척에서 표식을 줄이면 대륙의 형태와 이름을 읽기 쉽다. 개별 도시와 경로는 대륙·지역 지도에서 확인해야 한다.
