# 2026-11-16 — 결정 63: 벨레스 집필 표현과 정보 전달 IW01-IW06 채택

### 배경

사용자는 [IW01-IW06 선택표](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-15-veles-integrated-manuscript/options.md)를 검토한 뒤 2026-11-16 다음과 같이 승인했다.

> 추천한 IW01–IW06과 공통 경계를 모두 채택할게. NG04에서 해당 범위를 정본에 반영하고 검토·커밋·푸시까지 진행해줘. 기존 원문·대안·보류·도안·좌표·수치는 유지하고 실제 UE 구현·실행은 제외해줘.

[NG07 작성 독립 검토](../Narrative/Reviews/2026-11-16-veles-integrated-manuscript-review.md)는 C05 표현 두 곳 보완 뒤 PASS이며 사용자 승인과 구분한다. 이번 승인은 여섯 추천의 표현·수단·적용 조건·이점·비용과 공통 경계다. 전체 원고·정확한 대사·실제 정보 인지·게임 지원을 함께 확정하는 승인이 아니다.

### 결정

[결정 57](0057-veles-information-delivery-adoption.md)의 정보 전달, [결정 58](0058-veles-chapter-continuity-adoption.md)의 정상·미완료 연결, [결정 61](0061-veles-progression-resume-adoption.md)의 실제 정보·성과·현재 조건과 [결정 62](0062-veles-validation-design-adoption.md)의 검증 경계를 집필 표현과 작업 기록에 구체화한다. 기존 인물·사건·진행·검증 기준을 번복하지 않는다.

각 행의 표현·수단·적용 조건·이점·비용과 공통 경계는 [Scenario](../Narrative/Scenario.md#벨레스-첫-장의-표현과-작업-기록)가 소유한다. PR·VD와 NC·VR·VB·CP·IB·JC의 확정을 유지한다. 인물은 실제 관찰·전달받은 범위만 알며 등장·처치·대화 종료로 정보·작업·인수·출항을 자동 완료하지 않는다. 플레이어의 이해와 인물 지식을 구분한다.

야외 관찰·교전·동쪽 왕복·G04·GB03을 필수 순서로 삼지 않는다. 실내 직접 대응·바르툴 직접 전투·모든 무기 선택·해방·생존 이격을 유지하며 설명을 위해 위협을 멈추거나 과거 결박을 재연하지 않는다. 기록이 실제 수행을 대신하지 않는다. C03-C06은 실제 근거·접근·재고·인수·현재 점검이 있을 때만 성공 흐름으로 잇는다. 자동 복구·무한 자원·임의 시한·무상 회복은 넣지 않는다.

같은 세계의 성과 보존과 명시적 저장 복원은 기존 계약을 따른다. 새 저장 필드·자동 되감기·다인 정보 공유·보상·전체 경로 지원은 이번 집필 채택으로 확정하지 않는다. 린은 부두에 남고 스승과 마렌은 별개다. 마렌·이르의 현장/원격 합류, 새 인물·신상·혈통·연애·후일담·보상은 추가하지 않는다. 첫 장은 실제 출항 뒤 상층 수관에서 닫는다.

IW02는 접어 휴대하는 작업 기록과 계획/수행/남은 확인·마을 운영용/로덴 전달용의 구분을 채택한다. 정확한 규격·도식·필수 읽기·UI·자동 갱신·인벤토리 아이템화는 보류한다. IW04의 보고는 완료와 미완료의 차이를 먼저 말하는 표현 중심을 채택한 것이며 고정 대사·문답 시험은 아니다.

IWA01-IWA02·IWH01-IWH06과 기존 79행·PRA/PRH·VDA/VDH·BA/BH·NA/NH·RA/RH를 보존한다. MS01-MS10·C03-C06·C03-R·C06-M·VI01-VI08, 상세 표·조건부 성공·정확한 대사·전체 원고를 정본 상태나 구현 사양으로 승격하지 않는다. 통합 묶음·원고·대체 장면·정보·인물·선택표 여섯 원문에는 상단 채택 안내만 추가한다. source-audit와 작성 검토 기록은 당시 근거로 유지하며 원문·대안·보류·도안·좌표·수치를 덮어쓰지 않는다. 삭제 후보와 실제 삭제는 없다.

### 트레이드오프

짧은 대화와 휴대 작업 기록을 함께 쓰면 개인 욕구·주민의 질문과 실제 수행 내역을 연결할 수 있다. 반면 기록의 형태와 현재 근거를 구분해 보여 주어야 한다. 누락된 근거·접근·운영 값은 문장만으로 채울 수 없으며 정확한 대사·매체 세부·실제 인지는 후속 선택과 검증으로 남는다.

IWA01의 대화 축소·행동 서술 중심은 흐름을 빠르게 읽게 하지만 개인 여행 욕구와 담당자의 불명확한 질문을 독자가 추론해야 한다. IWA02의 인수 때 기록 일부 대조는 질문의 근거를 분명히 하지만 장면이 길어지거나 현장 원인을 전부 다시 설명할 위험이 있다. 사용자는 여섯 추천과 공통 경계를 함께 채택했으며 두 대안은 비교 자료로 보존한다.

문서 검토는 실제 인지·전투 피로·공간·운영·재미·UE 실행의 증거가 아니다. 실제 UE 구현·실행은 이번 범위에서 제외한다. 상세 스토리보드·음성·이미지와 실제 제작·실행은 별도 요청이다.
