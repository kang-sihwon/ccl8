# 에테르 첫 장 MJ 시안 제작 목록

벨레스의 아침부터 바르툴전, 급수 복구와 다음 날 출항까지 YouArt의 Midjourney(MJ)로 탐색할 시안을 정리한다. 디자인 40항목과 장면 38항목, 총 78항목을 제안한다. 항목 수는 아래 두 목록의 합계이며 생성 횟수나 최종 이미지 장수는 아니다. 상태별 시안과 재시도는 별도로 센다.

이 문서는 제작용 참조 목록이다. 시나리오의 사건은 [첫 장 상세 시나리오](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-first-chapter.md), 고유 설정은 [에테르 전체 구상](../Narrative/Drafts/2026-10-31-ether-taiga-dawn.md), 공통 시각 방향은 [ArtDirection](../ArtDirection.md)이 소유한다. 시안의 구성·구도·화면비·프롬프트는 제안이고 고유 서사와 최종 디자인은 아직 미승인이다. 이미지 생성은 시작하지 않았다.

| 도입부터 출항까지 사건별 화면을 만들 때 | [장면 시안 38항목](EtherFirstChapter/Scenes.md) |
| 과거 YouArt 시험 설정과 결과를 참고할 때 | [2라운드 프롬프트](../ConceptImageToolTest/Prompts/Round2.md), [화풍 잇기 결과](../ConceptImageToolTest/Results/StyleChain.md) |

## 전체 범위

| 분류 | 항목 ID | 수 | 용도 |
|---|---|---:|---|
| 인물과 생물, 바르툴 결박 | D01-D09 | 9 | 주인공·주민·적의 외형과 상태 구분 |
| 자원·도구·설비·생활 소품 | D10-D24 | 15 | 수리의 원인과 해결을 화면으로 설명 |
| 환경 구성 부품 | D25-D27 | 3 | 마을·숲·동굴의 재질과 형태 통일 |
| 공간과 원경 | E01-E08 | 8 | 장소 배치, 규모, 빛, 이동 방향 |
| 효과와 상태 변화 | X01-X05 | 5 | 에테르 소모, 냉기, 결박 파괴, 급수 회복 |
| 이야기 장면 | S01-S38 | 38 | 사건과 감정, 전투, 결말의 화면 구성 |

D는 피사체 디자인, E는 공간, X는 효과, S는 장면을 구분하는 식별자다. 하위 문서의 각 ID는 하나의 제작 의도를 뜻한다. 같은 ID 안에 여러 상태가 있으면 상태마다 별도 이미지를 만들고 같은 디자인인지 비교한다. 하나의 화면에 모든 상태를 억지로 넣지 않는다.

## 먼저 만들 시안

첫 묶음은 아래 12항목을 제안한다. 공통 색과 주인공·곰의 비례, 설비의 구조를 먼저 비교하면 나머지 장면을 다시 만드는 일을 줄일 수 있다.

| 순서 | 항목 | 먼저 판단할 내용 |
|---|---|---|
| 1 | E01 벨레스, E04 숲길, E07 수원 공동, E08 세계수 원경 | 밝은 타이가, 생활 공간, 동굴의 명도, 세계 규모 |
| 2 | D01 주인공, D08 바르툴, D09 결박 | 장인과 야생 곰의 실루엣, 두 결박의 위치 |
| 3 | D10 에테르, D11 검은 결정, D12 도끼 | 정상 자원·소모·손상의 구별과 주인공의 도구 |
| 4 | D18 채취부, D25 마을 구성 부품 | 고대 설비와 생활 기술의 차이, 건축 재질 |

이후 D02-D07로 인물과 일반 적을 정하고, 남은 소품·설비·공간·효과를 만든다. 장면은 참조할 디자인을 고른 뒤 S01부터 이야기 순서로 진행한다. 보스전의 핵심인 S16-S23은 다른 장면보다 먼저 시험해도 된다.

각 항목을 한 번에 완성하려 하기보다 먼저 후보를 비교하고 한 안을 선택한다. 시안 후보를 몇 장씩 뽑을지는 생성 비용과 첫 결과를 보고 정한다. 78항목 전체를 한꺼번에 생성하는 예산 승인을 뜻하지 않는다.

## 공통 시각 기준

현재 시나리오에 맞춘 기준은 다음과 같다. [ArtDirection의 제안](../ArtDirection.md#시각-기준제안)과 함께 적용한다.

| 대상 | 유지할 요소 | 피할 결과 |
|---|---|---|
| 전체 | 자연스러운 빛, PBR 재질을 이해할 수 있는 표면, 큰 색면과 명확한 실루엣 | 모든 물체가 금빛으로 발광해 형태가 사라짐 |
| 벨레스 | 목재 기둥 위 집, 붉은 지붕, 청록 덧문, 겨자색 천막, 넓은 판자길 | 금속 배관으로 뒤덮인 대도시, 새로운 성이나 궁전 |
| 숲 | 황금빛 침엽, 붉은 이끼, 청록 개울, 햇볕 속 국소적인 서리 | 숲 전체가 한겨울 설원이나 암흑 지대가 됨 |
| 동굴 | 뿌리·돌·얼음·옛 설비, 천장 틈의 햇빛, 읽히는 바닥 | 전투 공간과 조작부가 검은 실루엣에 묻힘 |
| 에테르 | 내부 금빛이 있는 정상 조각, 소모된 투명 조각 | 소모된 조각도 계속 빛남 |
| 검은 결정 | 탁한 결정과 접촉부의 냉기, 불규칙한 힘의 흔적 | 악마 문양, 의지를 가진 저주나 새로운 적처럼 표현 |
| 동물 전투 | 결정 손상, 통증과 경계, 탈출·거리 확보 | 피투성이 사체, 길든 반려동물, 갑옷을 입은 곰 |
| 복구 | 채취 정지, 급수 재가동, 남은 결정과 거목 손상 | 숲 전체의 즉시 정화, 곰의 부활이나 괴물 변신 |

기존 T0은 닫힌 수문과 긴 겨울의 후보 세계를 대상으로 했다. 그 이미지의 선택 이력은 에테르 세계의 승인으로 보지 않는다. 화풍 참조 후보로 검토할 수 있지만 설원, 수문, 얼음 채취인의 장비가 이번 시안으로 따라오면 제외한다. 이번 목록에서는 방패, 왕관, 새로운 마법 무기, 별도의 인간 보스도 추가하지 않는다.

## 프롬프트 조립

하위 문서의 영어 문장은 아직 실행하지 않은 프롬프트 초안이다. 아래 공통 문장 뒤에 해당 항목의 영어 문장을 붙인다. 화면비는 표의 제안값을 YouArt 화면에서 지정한다. 여러 상태가 적힌 항목은 상태를 하나 골라 문장을 작성한다.

```text
Fantasy action RPG concept art for Ether: Dawn of the Taiga. Natural light, physically grounded wood, stone, cloth, metal and fur, readable large color masses, clear silhouettes, lived-in craftsmanship. No text, no logo, no watermark, no interface overlay.
```

인물과 소품 단독 시안에는 다음 문장을 덧붙이는 것을 제안한다.

```text
Single subject, fully visible, simple neutral background, clear construction and material separation.
```

장면에는 다음 문장을 덧붙이는 것을 제안한다.

```text
One cinematic frame, clear foreground and background, readable action and spatial relationships.
```

첫 탐색에서 나온 얼굴, 나이, 체형, 복식은 후보로 다룬다. 주인공·스승·친구의 성별은 원문에서 정하지 않았다. 선택한 이미지의 얼굴·옷·장비를 짧은 외형 문장으로 기록하고 이후 프롬프트에 같은 문장을 붙인다. 원문에 없는 직업·혈통·민족 설정을 이미지에서 역으로 확정하지 않는다.

YouArt의 현재 MJ 버전, 지원 옵션과 참조 방식은 이 문서 작성 때 재검증하지 않았다. 과거 시험 설정은 위 링크의 시점 기록이며 현재 기본값으로 단정하지 않는다. 프롬프트에 버전 번호나 미확인 명령어를 넣지 않는다. 스타일 참조와 피사체의 동일성은 별도로 검사한다. 이미지가 비슷한 화풍이라고 인물·소품의 구조까지 같다고 보지 않는다.

## 상태와 결과 관리

결과는 ID에 상태와 후보 번호를 붙여 구분하는 방식을 제안한다. 예를 들어 `D12-base-v01`, `D12-repaired-v01`, `S18-v01`로 적는다. 결과를 남길 때 아래 서식을 복사해 사용한다. 최초 상태는 모든 항목이 `대기`다.

| ID·상태 | 생성 상태 | 결과 이미지·YouArt 결과 식별자 | 선택한 참조 ID | 모델·설정 | 사용한 프롬프트 | 판단·재시도 이유 |
|---|---|---|---|---|---|---|
| 기입 | 대기 / 생성 / 수정 필요 / 선택 | 미생성 | 미선택 | 실행 시 기록 | 실행한 원문 보관 | 미검토 |

대안 후보 중 한 장을 골랐다는 뜻의 `선택`과 서사·최종 아트 승인은 구분한다. 정확한 구조도, 연결도, 글자, 3면도와 제작 치수는 이 시안의 결과만으로 확정하지 않는다. 설비 연결과 전투 공간은 원문·배치 계획에 대조하고 필요한 설명을 사람이 별도로 붙인다.

## 검수 기준

- 각 장면에서 보이는 인물, 공간, 소품이 연결된 디자인 ID와 일치하는지 확인한다.
- 같은 장소의 전후 시안은 카메라와 기준물을 맞춰 비교한다. 건물, 뿌리, 조작부, 수로가 새 위치로 옮겨지면 수정한다.
- 바르툴은 같은 몸을 유지한다. 앞다리 결박 파괴 뒤에는 그 결박과 충격파가 사라지고 가슴 연결만 남는다.
- 채취부를 멈춰도 정상 에테르로 보온·송수 기능을 복구할 수 있는 구성이 읽혀야 한다.
- 큰 강의 흐름과 식수 수로의 고장을 혼동하지 않는다. 귀환 이후에도 결정 잔재, 쓰러진 파수꾼, 거목의 손상이 남는다.
- 출항은 기존 나루터와 배를 재사용한다. 하류 도시, 항해 전투, 새 동료와 두 번째 보스를 그리지 않는다.
- 효과 시안은 정지 화면의 방향 제안이다. 공격 예고 시간, 실제 애니메이션, UI와 플레이 중 가독성이 검증됐다고 기록하지 않는다.
