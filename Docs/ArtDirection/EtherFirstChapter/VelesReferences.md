# 벨레스 공간 참조 이미지

사용자가 보관 대상으로 지정한 벨레스 시안 두 장이다. 공방·급수대·나루터의 관계와 마을 중심부를 검토할 때 사용한다. 전체 전경과 최종 디자인은 미확정이며, 이미지의 건물 배치나 설비 구조를 서사 설정으로 확정하지 않는다.

상위 목록은 [에테르 첫 장 시안](../EtherFirstChapter.md), 관련 항목은 [디자인 목록의 공간](Designs.md#공간)에 있는 E01 벨레스 전체, E02 공방 앞과 내부, E03 나루터와 강변이다.

## 공방·급수대·나루터 관계

![벨레스 공방·급수대·나루터 관계 시안](Images/veles-workshop-water-quay.png)

왼쪽 앞의 공방, 중앙의 원형 수조, 오른쪽 나루터와 배가 보인다. 세 장소를 가까이 배치하고 주민의 생활 공간을 연결하는 참고로 사용한다. 붉은 지붕, 청록 덧문, 겨자색 천막과 목재·석재의 질감도 참고한다.

식수 수로와 배출구는 명확하지 않다. 오른쪽 급류와 정박지의 관계, 배관처럼 보이는 배경 구조물은 그대로 채택하지 않고 별도 배치에서 검토한다.

## 마을 중심부

![벨레스 마을 중심부 시안](Images/veles-village-center.png)

앞쪽 작업 공간에서 중앙의 열린 길을 따라 마을 안쪽을 바라보는 구성이다. 주민의 작업과 운반, 건물 사이 여유 공간, 잔잔한 물가와 정박한 배를 참고한다.

마을 경계와 숲으로 나가는 길, 별도의 식수 공급 경로는 확인되지 않는다. 이 이미지는 중심부 참고이며 마을 전체를 담은 조감도가 아니다.

## 다음 배치 검토

두 이미지는 서로 다른 후보이므로 건물과 수로의 위치가 일치한다고 가정하지 않는다. 전체 배치는 공방, 공동 급수대, 나루터, 숲 출입구를 표시한 간단한 조감도나 평면 스케치로 먼저 정리하는 것을 제안한다. 식수 수로는 큰 강과 구별하고, 배가 머무는 곳은 급류에서 벗어난 물가로 검토한다.
