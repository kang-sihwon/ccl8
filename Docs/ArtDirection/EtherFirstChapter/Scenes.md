# 첫 장 장면 시안

도입부터 다음 날 출항까지 38개 장면을 제안한다. 각 장면은 하나의 핵심 행동이나 결과를 담는다. [디자인 목록](Designs.md)의 인물·공간·소품을 선택한 뒤 조합하며, 생성 상태와 공통 프롬프트는 [부모 문서](../EtherFirstChapter.md)를 따른다.

화면비는 모든 장면에 16:9를 제안한다. 표의 영어 초안 앞에 공통 문장과 선택한 인물·공간의 외형 문장을 붙인다. 참조 ID는 필요한 디자인의 목록이며 YouArt에 그 수만큼 이미지를 동시에 입력하라는 뜻이 아니다. 실제 입력 방식은 실행 화면에서 확인한다.

구도와 렌즈 느낌은 제안이다. 대사·효과음·시간 경과를 이미지 한 장으로 증명하려 하지 않는다. 그 정보는 장면 설명과 실제 연출에서 다룬다. 검수할 때는 아래 연결된 시나리오의 사건 순서를 기준으로 삼는다.

## 시나리오 대조표

첫 장의 아홉 장면을 모두 포함한다. 장면 시안에서 다루지 않는 상태 변화는 연결된 디자인의 상태 시안으로 보완한다.

| 원문 장면 | 시안 범위 | 놓치지 않을 연결 |
|---|---|---|
| 1 시작 | S01-S04 | 유한한 에테르, 친구의 예정된 배, 단수 |
| 2 출발 | S05-S07 | 마을의 역할 분담, 정상 동력통 지급 |
| 3 숲 | S08-S12 | 세 적의 다른 대응, 곰의 흔적 |
| 4 동굴 | S13-S15 | 같은 파수꾼, 세 설비의 구분, 복구 계획 |
| 5 대면 | S16-S17 | 도망치지 못하는 곰, 막힌 조작부 |

새로 만들지 않는 시안은 신들의 기원·대혹한 도입 영상, 추가 인간 보스, 바르툴 변신·소환수, 보스전 이후 재료 수집, 숲 전체 정화, 후속 도시와 항해 플레이 구간이다. HUD, 아이콘, 메뉴와 정확한 모델링 제작도는 이번 이야기 시안 목록의 범위 밖이다.
