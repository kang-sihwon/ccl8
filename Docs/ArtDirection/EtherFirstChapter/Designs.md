# 첫 장 디자인 시안

인물·생물 9항목, 자원·소품·설비 15항목, 환경 부품 3항목, 공간 8항목, 효과 5항목을 만든다. 총 40항목이며 모두 시안 제안이다. 제작 순서와 공통 프롬프트는 [부모 문서](../EtherFirstChapter.md), 실제 등장 화면은 [장면 목록](Scenes.md)을 따른다.

표의 영어 문장 앞에 부모 문서의 공통 프롬프트를 붙인다. `상태·필수 요소`에 적힌 상태는 각각 별도 생성 대상으로 다룬다. 비교표가 필요한 경우 별도 생성한 이미지를 나란히 놓는다. 후보의 외형을 선택한 뒤 같은 대상의 다음 상태로 진행한다.
