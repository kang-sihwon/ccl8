# 벨레스 Megascans 상세·이미지 선별

**전체 2,387개 중 2,386개 판정 완료, 1개 미검토다.** 공방·나루·숲에 맞는 실제 외형을 확인한 결과만 아래 추천표에 넣었다. 2026-11-18 사용자 승인에 따라 접근 제한 1개를 미확인 예외로 남기고 조사를 종료했다. 미검토 행은 추천하지 않는다. 상세·이미지 조회 기준일은 2026-11-17이다.

B안 26개 우선 선별 이후 남은 2,096개 중 접근 가능한 2,095개의 상세 설명과 대표 이미지 판정을 마쳤다. 앞선 291개와 합쳐 총 2,386개를 판정했다. 수집과 실제 이미지 판정은 별도로 집계한다. 0316 Wooden Cigar Box는 공개 페이지가 `Mature content hidden for user`를 반환해 상세·이미지 미확인으로 남겼다. 접근 설정은 변경하지 않았다.

[26개 재검토·20개 추천 배치표](QuixelMegascansReview/B-selection-2026-11-17.md)는 첫 도입 묶음의 기록이다. 아래 누적표와 검색표에 접근 가능한 전체 후보의 B안 대조 결과를 정리했다. 모든 추천을 한 장면에 함께 넣으라는 뜻은 아니다.

상품마다 상세 설명의 크기·열린/닫힌 메시·포맷을 읽고, Fab에서 표시된 대표 이미지를 원본 크기로 확보해 비교했다. 여러 변형이 보이는 소개 이미지를 여러 메시 제공의 증거로 해석하지 않는다. 작은 미리보기만 잡힌 경우 원본을 다시 확인하기 전에는 판정하지 않는다. 이미지의 뒤쪽·바닥·내부가 보이지 않으면 해당 부분은 미확인이다. 대표 이미지 외 모든 갤러리·3D 뷰어를 검토했다는 뜻은 아니다.

공통으로 UE 5.8.3 임포트·실행, 실제 폴리곤·LOD·Nanite·충돌·NavMesh·성능, 재질의 실제 품질, 리그·애니메이션은 미검증이다. 열린/닫힌 메시와 물리 치수는 제공자의 설명이며 축을 임의로 바꾸지 않았다. 무료 표시는 조회 시점 표시이고 최신 라이선스·파일·사용 범위는 도입 직전에 다시 확인한다.

## 이미지 검토에서 달라진 판단

목재·도구라는 이름만으로는 벨레스 적합성을 정할 수 없다. 전쟁 망치는 제작용 망치에서 제외했고, 궁전용 조각 천장·장식 문·현대적인 탁자·파손된 작업 가구도 기본 구성에서 제외했다. 모루는 받침 포함 여부, 밧줄은 실제 크기, 선반은 벽 고정 여부, 줄기는 수관이 없는 조각인지를 나누어 기록했다. 같은 역할의 변형은 보류해 첫 도입 묶음이 불필요하게 커지지 않게 했다.
