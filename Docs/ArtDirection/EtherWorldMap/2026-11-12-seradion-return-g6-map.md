# 세라디온 귀항 인계·G6 준비 지도

[세라디온 귀항·G6 후보](../../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-12-seradion-return-g6.md)의 운송·책임 인계와 수원 주변 준비·대피·결말 경계를 나누어 표시한다. 기존 [수원 좌표](2026-11-10-seradion-waterworks-map.md)와 [남부항 좌표](2026-11-10-seradion-polar-departure-map.md)를 보존하며 서로 다른 국소 좌표를 하나의 지리도로 합치지 않는다. [최종 제작 도안](MapPresentation.md#제작-도안의-최소-상세-수준) 아트는 별도다.

[SVG](Images/seradion-return-handoffs-v1.svg). 화살표는 배편과 인수의 순서이며 거리·방위·일수·동시 이동을 뜻하지 않는다. 8명 생존자와 14명 승무원은 남부항에 남고 주인공·마렌만 별도 연안편으로 이동한다. G6 준비 인수 뒤 공개·점거·외곽 정찰로 연결된다.

![기존 수원을 보존한 G6 준비·주민 대피·심부 접근](Images/seradion-g6-waterworks-v1.png)

[SVG](Images/seradion-g6-waterworks-v1.svg). 기존 SE-P01에 Q01-Q16을 더했다. 파랑은 현재 대조·정찰, 녹색은 대피, 주황은 다른 귀환, 올리브는 선택 탐색, 보라는 후속 돌파·철수 후보다. 보라 경로는 이번에 돌파를 마친 경로가 아니다. 이전 호수·주민 배관·장소를 보존하며 WG6는 추천 처치 상태를 유지한다.

## 자료와 한계

Q13-Q12-Q11은 현재 선택 탐색과 후속 철수가 공유하는 후보 구간이다. 올리브 실선 위 보라 점선으로 두 역할을 함께 표시한다. 현재 선택 탐색이 가능하다는 뜻이며, 후속 점거·전투 이후에도 안전한 철수로라고 보장하지 않는다.

[배치 자료](Data/seradion-return-g6-v1.json)와 [계산 검사](Data/seradion-return-g6-v1-validation.json)는 원본 보존·16장소·7개체·경비 8명·후속 방어체 1기, 인원·성장·경로·SVG 위치를 대조한다. 대피로 폭은 계산 후보이며 실제 지형·경사·시야·군중·수용·수질·항행·AI·전투·UE 실행은 미검증이다. 구조자 구호와 주민 대피의 명부를 합산하지 않는다. G6 준비 완료와 결말 전투 완료는 별개다.
