## 좌표·축척·원본

[대륙 좌표](Data/ignis-continent-georeference-v1.json)를 수정하지 않는다. 원본 강·산맥·도로를 패널 범위로 잘라 그리며 확대도 원점에 로컬 m/1,000을 더한다. 가로·세로 배율은 같고 위쪽은 투영 격자 북쪽이다. 현지 진북·구면 지표 거리·DEM·눈 깊이·하폭으로 해석하지 않는다.

운송도는 원본 육상 회랑과 백풍 산맥을 보여 주는 부분 도면이며 해안·대륙 윤곽을 재작성한 지도가 아니다. 원본 강선과 도로가 겹치는 곳은 같은 계곡 회랑이지 수면 위 도보다. 네르바 본류 횡단의 교량·나루, 기존 R4의 교량과 모든 장거리 숙박·보급은 실행 미검증이다.

NP01은 D01의 원래 절점 2-3 위 X=-240km에 놓은 새 후보이며 Y=1473.711655km다. 구조권 원점은 남쪽 (-240,1467)km, 유적 접근점은 북쪽 (-240,1482)km다. 새로 그린 접근선의 경사·통과 고도·바람·적설을 검증했다고 주장하지 않는다. 일반 도시·마을을 북쪽 유적 안으로 옮기지 않는다.

## 표기와 검사 범위

확대도의 파랑은 진입, 주황은 귀환, 초록은 선택·피난, 보라는 거수 이동이다. 연보라는 몬스터의 활동 동선, 갈색 원은 잠재 생활권, 보라 원은 별도 구조체다. 운송도의 주황은 R4 역행, 파랑은 기존 북행, 보라는 새 고개 접근 후보다. 원의 중첩이 실제 동시 교전 수를 뜻하지 않는다.

정문 A02-A03의 붉은 X는 점유·결빙으로 이용하지 않는 연결이다. A06-A07은 방어 차단 해제 뒤 열린다. A07-A08의 주황 원은 기록실 안쪽에서 수동 해제하는 정비문으로, 처음부터 양방향 통행 가능한 선이 아니다. 본편은 동쪽 작업길로 들어가 기록실에 도착한 뒤 서쪽 귀환을 연다.

RG1은 R05-R06으로, 피난민은 R04-R05-R07-R08-R01로 이동한다. 두 경로는 R05 분기를 공유한다. 거수가 먼저 서쪽으로 이동한 뒤 사람이 R05에서 남쪽으로 돌아가는 시간차 조건과, 분기 이후의 경로 분리를 대조한다. 피난 개시 전 실제 동물 방향과 잔여 포식종은 별도 확인해야 한다.

R02-R03의 주황 표식은 파손턱의 보행 전용 접근이다. 정찰자의 역행과 들것 피난을 같은 통행 조건으로 보지 않는다. 현재 들것으로 이 연결을 사용할 수 없으므로 거수가 R05를 비워야 부상자를 포함한 전체 피난이 가능하다. 실제 폭·지지·등반·들것 하중은 후보 검증 범위 밖이다.

좌표 검사·그림 검토와 실제 지형·유량·기후·포식·AI·전투·경험치·UE 실행을 구분한다. 자세한 결과는 검사 JSON과 검토 문서가 소유한다.

작성자의 계산 검사 191항목은 원본·형태·수량·실제 SVG·길이·축척·고개와 남북 패널·들것 통행·유도 전후·기록실 단계별 접근을 통과했다. PNG 4장을 직접 확인했으며, 경로 연결 성공은 실제 보행·전투·하중 검증을 뜻하지 않는다.
