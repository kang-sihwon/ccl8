# 중앙 생활권 좌표 기준도

대륙 전체와의 연결은 [36곳 좌표 정합 후보](2026-11-07-continent-coordinate-map.md)에서 이어진다. 아래 도면의 중앙 좌표는 그대로 유지하고, 새 전역 원점 후보와 외곽 27곳을 추가했다. 아래 검증·남은 범위는 이 중앙 도면 자체에 대한 기록이다.

중앙 생활권의 대도시 2곳·일반 도시 3곳·마을 4곳을 기존 좌표로 다시 그렸다. 벨레스 주변 네 마을을 별도로 확대해 방향과 간격을 읽을 수 있게 했다. [이전 생성 지도](2026-11-01-ignis-all-settlements-nadir.md)의 가로로 늘어난 중앙 확대도를 대신해 좌표 관계를 확인할 때 사용한다.

| 자료 | 용도 |
|---|---|
| [PNG](Images/ignis-central-coordinate-map-v2.png) | 같은 글꼴과 배치로 바로 열어 볼 때 |
| [SVG](Images/ignis-central-coordinate-map-v2.svg) | 지점·강선·라벨을 좌표 그대로 편집할 때 |
| [검증 결과 JSON](Data/ignis-central-coordinate-map-v2-validation.json) | 좌표 역산, 표시 개수·축척·거리 대조와 파일 해시를 확인할 때 |
| [기준 좌표 JSON](Data/worldtree-settlement-basis-v1.json) | 세계수 원점의 지역 좌표와 제안 강선 원본을 볼 때 |

## 표현과 확인 범위

Codex가 기존 지역 좌표에서 새 SVG·PNG를 생성했다. 두 출력은 같은 도형·문자 배치에서 그렸고 PNG는 맑은 고딕을 사용한다. SVG는 보는 환경의 글꼴에 따라 글자 폭이 달라질 수 있다. 이미지 크기는 2,000×1,480이다.

| 항목 | 표시·계산 기준과 결과 |
|---|---|
| 본도 | X -25부터 180km, Y -55부터 175km. 가로·세로 모두 5px/km. 50km 축척 막대는 250px |
| 벨레스 확대도 | X 136부터 158km, Y 133부터 155km. 가로·세로 모두 25px/km. 5km 축척 막대는 125px |
| 정착지 | 본도 대도시 2·일반 도시 3·마을 4. 확대도는 같은 마을 4곳의 재표시이며 정착 수에 중복 합산하지 않음 |
| 시설 | 중앙 환적장은 사각형으로 표시. 도시·마을 수에 포함하지 않음 |
| 세계수 | 수관 지름 18km를 본도 지름 90px로, 상주 제한 반경 12km를 반경 60px로 표시 |
| 벨레스 이웃 | 솔숨 (+4,+6)km, 들보리 (-10,-8)km, 숲곁 (-7,-2)km. X는 동쪽, Y는 북쪽 |
| 강선 | 본도 17개 절점을 원본과 대조. 확대도는 같은 강선을 화면 범위로 잘라 표시 |
| 거리 대조 | 본도·확대도에 표시된 지점의 모든 쌍을 역산. 최대 평면 거리 오차는 각각 약 2.85×10⁻¹⁴km, 1.78×10⁻¹⁵km |

좌표 역산은 SVG의 실제 원 중심·시설 사각형 중심과 강선 절점을 읽어 수행했다. 기준 데이터의 의미 해시는 UTF-8 JSON을 키 정렬·공백 없는 구분자·한글 보존으로 직렬화한 SHA-256이다. SVG 해시는 UTF-8/LF로 정규화하고 PNG 해시는 원시 바이트로 계산했다. 결과와 해시 방법은 검증 JSON에 기록했다.

## 독립 검토

별도의 읽기 전용 검토자가 기준 JSON, SVG 좌표·반경·축척 막대와 PNG를 직접 대조했다. 최초 지적은 확대도의 솔숨 이름 위로 강선이 지나는 한 건이었다. 라벨을 강 왼쪽 빈 공간으로 옮긴 뒤 PNG와 SVG를 다시 확인해 최종 `PASS`를 보고했다. 좌표 검사도 다시 통과했다.

검토자는 중앙 정착지 9곳과 환적장, 확대도 마을 4곳의 좌표 표시 14개, 본도 강선 17절점, 두 화면의 동일 가로세로 배율과 세계수 두 반경을 확인했다. 글자 겹침 수정 뒤 남은 지적은 없다.

## 남은 범위

이 자료는 기존 지역 설계 좌표를 정확히 표시한 도면이다. 세계지도 위경도와 중앙 지역도의 정합, 실제 지형·수계·항행·이동 시간은 검증 전이다. 강선의 굵기와 정착지 기호 크기는 가독성을 위한 표현이다. 직선거리 대조는 지역 투영 평면 기준이며 구면 최단거리와 구분한다.

외곽 정착지 27곳과 대륙 전체 생성도의 기호·해안·지형은 이번 도면에 포함하지 않았다. 기존 전체 시안은 비교 자료로 보존하고, 중앙의 위치·방향·축척 확인은 이 자료를 우선한다. 전체 36곳의 생활권과 상대 지형은 [서사 지리 후보](../../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent/geography.md)를 따른다.
