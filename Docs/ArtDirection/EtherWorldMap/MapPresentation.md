# 지도 제작 기준과 채택 시안

**지도 이미지의 추가 제작은 중단했다.** [결정 55](../../decisions/0055-map-art-reference-handoff.md)에 따라 기존 결과는 실제 월드 제작용 참고 도안으로 보존한다. 아래 화풍·UI와 가독성 기준은 유지하며, [도안 목록과 사용 범위](IgnisSharedTerrain.md#제작-도안-보관과-사용)를 먼저 확인한다. 실제 플레이용 지도는 구현한 월드를 기준으로 별도 제작·검증한다.

벨레스·이그니스·에테르 월드맵의 통일한 v2 세 장을 최종 참고 시안으로 사용한다. 사용자가 2026-11-09 최종 채택하고 이후 지도 제작에도 적용하도록 확정한 근거는 [결정 46](../../decisions/0046-unified-map-v2-adoption.md)이다. 앞으로의 지도는 이 문서의 화풍·공통 UI·지명 표기 규칙과 v2 파일을 기준으로 제작한다. 최종 시안은 제작의 참고 이미지이며 실제 게임 화면이나 확정된 지리 데이터라는 뜻은 아니다.

이그니스 기준 통일 방향은 [결정 45](../../decisions/0045-unified-map-presentation.md)를 따른다. [결정 43](../../decisions/0043-map-art-and-ui-standard.md)과 [결정 44](../../decisions/0044-ether-world-map-reference.md)로 앞서 채택한 v1 파일은 이전 비교 자료로 보존한다. v1과 v2의 UI·표식 규칙을 섞어 사용하지 않는다.

상위 문서는 [에테르 세계지도 시안](../EtherWorldMap.md)이다. 해안·정착지 위치는 [대륙 좌표 기준](2026-11-07-continent-coordinate-map.md), 세계의 면적과 투영은 [지도 제작 기준표](../../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-map-production-basis.md)를 따른다.

## 화풍과 축척

사실적인 지표 질감과 지형의 큰 형태를 먼저 읽게 한다. 숲·암석·물·설원의 색은 절제하고, 지형의 특징을 장식적인 나무나 도시 모형으로 대신하지 않는다. 아래 기준은 결정 43의 화풍을 구체화한 결정 45와 최종 채택 결정 46을 따른다.

| 범위 | 표현 기준 |
|---|---|
| 지역 지도 | 벨레스처럼 지표를 수직으로 내려다보는 항공사진 느낌을 쓴다. 나무의 수관과 건물 지붕을 표시하고 줄기·건물 정면·동굴의 정면 아치를 배제한다. |
| 대륙 지도 | 이그니스 선택안처럼 산맥·고원·분지의 입체감과 사실적인 지표 질감을 유지한다. 산맥을 평탄화한 후속 후보를 기준으로 바꾸지 않는다. |
| 세계 지도 | 에테르 월드맵처럼 기존 다섯 대륙의 배치·해안선을 유지하고 사실적인 지표 질감을 그 안에 적용한다. 대륙 이름과 현재 위치를 중심으로 표시한다. |
| 축척에 따른 생략 | 대륙에서는 숲을 식생 영역으로 읽고 개별 나무·집을 그리지 않는다. 지역에서는 필요한 길·건물·강변을 구분한다. |
| 지형 색과 재질 | 자연스러운 녹색 식생, 회갈색 암석, 낮은 채도의 물과 눈을 사용한다. 양피지·금빛 장식·동화풍 윤곽선을 기본 화풍으로 쓰지 않는다. |
| 위치 기준 | 해안·수계·도시의 기존 자료를 먼저 정한다. 그림에서 잘 보이게 하려고 도시 위치나 강의 연결을 옮기지 않는다. |

이그니스의 채택 화풍에는 산봉우리 측면과 강조된 고도감이 남아 있다. 이를 엄밀한 수직 정사영이나 위성 실측 자료로 설명하지 않는다. 지역 지도의 수직 시점과 대륙 지도의 채택된 입체 표현을 구분한다.

## 제작 도안의 최소 상세 수준

상세 제작 도안은 아래 [세계수 관리도시 M01 시안](Atlas/Ignis-v1/M01.png)처럼 건물과 길을 보고 배치 작업을 할 수 있어야 한다. 2026-11-10 사용자가 제시한 첨부 화면과 보관된 M01의 RGB 픽셀이 동일함을 확인했으며, 이 화면을 최소 가독성 기준으로 지정한 근거는 [결정 47](../../decisions/0047-map-working-drawing-detail.md)이다.

![상세 제작 도안의 최소 가독성 참고](Atlas/Ignis-v1/M01.png)

| 확인 대상 | 상세 도안에서 읽혀야 하는 것 |
|---|---|
| 건물 | 개별 지붕과 건물 사이 빈 공간을 구분할 수 있다 |
| 길 | 골목과 도시 진입로, 주변 숲길의 흐름을 따라갈 수 있다 |
| 시설 | 주요 시설의 위치와 주변 길·건물의 관계를 확인할 수 있다 |
| 주변 지형 | 밭·공터·숲·암반의 영역과 마을 경계를 구분할 수 있다 |
| 연결 | 인접 상세 범위와 상위 지도에서 공통 지형·길·거점의 위치와 연결이 유지된다 |

위 표는 사용자 요구를 제작 시 확인할 항목으로 풀어 쓴 것이다. 참고 화면은 1,672×941px이며, 출력 픽셀 수보다 실제 작업 화면에서의 식별 여부를 우선한다. 작은 원본을 확대하거나 선명화한 것만으로 통과 처리하지 않는다. 필요한 세부를 가진 상세 원본을 제작하고 원본 크기와 출력 크기를 구분해 기록한다.

대륙 합본은 배치와 연결을 보는 용도다. 상세 도안을 대신하지 않으며 작업할 범위는 공통 좌표를 유지해 상세화한다. M01의 개별 건물·골목은 시각 후보이고, 이번 기준 지정으로 실거리나 실제 게임의 최대 확대 배율이 확정되는 것은 아니다. 현재 대륙 50개 타일과 기존 정착지 36장의 연결·검증 범위는 [고정 픽셀 섹터](WorldSectorPlan.md)와 [연속 지역 지도](IgnisConnectedAtlas.md)에서 구분한다.

## 공통 UI

채택 시안의 간결한 UI를 유지하고 지형 바탕과 표기 레이어를 분리한다. 최종 엔진 글꼴 자산과 화면 크기별 수치는 아직 미정이다.

| 요소 | 제작 기준 |
|---|---|
| 화면 틀 | 얇은 짙은 회색 상·하단 바를 사용한다. 큰 장식 테두리와 불필요한 패널을 넣지 않는다. |
| 글씨 | 장식 없는 고딕체를 사용한다. 지명은 기울임·붓글씨·세리프 없이 수평으로 읽게 한다. |
| 현재 위치 | 작은 청록색 점과 짧은 방향 표시를 사용한다. 큰 보석이나 입체 화살표로 바꾸지 않는다. |
| 도시·일반 장소 | 작은 중성색 점으로 표시한다. 축척에 따라 이름을 생략해도 위치점을 임의로 벌리지 않는다. |
| 주요 장소 | 황색 사각형을 사용한다. 동굴 입구와 세계수에 같은 의미로 적용하며 목적지라는 뜻으로 혼용하지 않는다. |
| 지점 이름 | 표시한 도시·시설은 모두 위치 표식, 얇은 회색 실선 연결선, 이름으로 구성한다. 점선은 사용하지 않는다. |
| 영역 이름 | 대륙·숲·강은 영역 위에 이름만 둔다. 대표점이나 연결선을 붙이지 않는다. 현재 위치 점은 영역 이름과 별개다. |
| 지명 충돌 | 위치점은 좌표에 고정하고 글자만 옮긴다. 연결선은 기점에서 꺾임 한 곳을 거쳐 글자 앞에 수평으로 끝나는 공통 형식이다. 지점과 글자의 거리에 따라 길이만 달라진다. |
| 범례 | 현재 위치, 정착지·장소, 주요 장소의 순서와 의미를 세 지도에서 동일하게 사용한다. 해당 축척에 보이지 않는 종류도 공통 범례에 남긴다. |
| 안내 | 지역명, 간단한 북쪽 표시, 닫기, 범례와 짧은 입력 안내를 둔다. 그림 속 입력 안내는 동작 구현의 증거가 아니다. |

통일한 v2의 글자는 모두 별도 SVG 레이어이며 `Malgun Gothic, sans-serif`를 사용한다. 이는 시안의 렌더링 설정이며 게임에서 사용할 글꼴을 확정한 것은 아니다. 앞선 v1에서는 이그니스 SVG만 이 설정을 사용했고 벨레스의 글자는 생성 이미지에 포함돼 실제 사용 글꼴을 식별하지 못했다.

## 최종 시안 v2

아래 세 PNG와 대응 SVG가 결정 46으로 확정한 최종 참고 파일이다. 파일명은 검토 때의 `unified-v2`를 유지하며, 승인 상태는 [보관 목록](Data/map-ui-unified-v2-assets.json)에 기록한다. 비교판과 생성 입력문은 보조 자료이고 세 지도 파일이 제작 기준이다.

이그니스 v1의 차분한 올리브색 식생·회갈색 암석·짙은 청록색 물을 세 지도의 기준으로 삼았다. 벨레스의 수직 시점과 이그니스의 산맥 입체감은 축척별로 유지한다. 벨레스와 에테르의 지표 질감은 기본 제공 `image_gen`으로 보정하고, 이그니스의 기존 지형 바탕은 그대로 재사용했다. UI와 이름·표식은 하나의 공통 SVG 생성 규칙으로 구성했다.

| 비교 항목 | 앞선 시안의 차이 | v2 적용 |
|---|---|---|
| 화풍 | 벨레스는 밝은 항공사진 느낌, 에테르는 더 선명한 녹색이었다. | 이그니스 기준으로 색과 명암을 보정했다. 지역의 수관·지붕 시점은 유지했다. |
| 화면·글자 | 출력 크기, 글자 크기와 굵기, UI 간격이 달랐다. | 세 화면을 1,672×941로 맞추고 상·하단 바 50px, 지점 이름 18px, 영역 이름 20px를 공통으로 사용했다. |
| 연결선 | 일부 지점만 연결선이 있었고 색·굵기·끝 위치도 달랐다. | 이름이 있는 지점은 모두 1px 실선, 불투명도 0.85, 같은 색과 끝 간격을 사용한다. 영역 이름은 선이 없다. |
| 표식·범례 | 사각형을 목적지·주요 장소로 혼용했고 세계 범례의 대륙 점은 본문 표기와 달랐다. | 청록색 원은 현재 위치, 중성색 원은 정착지·장소, 황색 사각형은 주요 장소다. 세 범례가 동일하다. |
| 대륙의 정보량 | 이름 없는 작은 도시 점들이 중앙에 모여 있었다. | v2에서는 일반 도시 12곳의 작은 점을 숨겼다. 데이터는 보존하고 표시한 주요 도시·벨레스·세계수의 위치는 유지했다. |

위 픽셀 수치는 [공통 UI 값](Data/map-ui-unified-v2-tokens.json)에 있는 1,672×941 참고 화면의 기준이다. 이후 시안에서는 같은 값을 재사용하고, 다른 출력 크기에서는 화면 크기에 비례해 함께 조정한다. UE 화면 크기별 값이나 접근성 설정으로 확정한 것은 아니다.

검사에서 벨레스의 지점 5곳과 이그니스의 지점 10곳에 각각 연결선 하나가 대응했다. 영역 이름은 벨레스 2개·에테르 5개이며 연결선과 대표점이 없다. 세 SVG의 공통 글자·선 스타일과 세 PNG의 하단 범례·북쪽 표시·닫기 영역은 각각 동일했다. 이그니스의 기존 지형 레이어와 표시한 10지점 좌표, 에테르의 해안 꼭짓점 32,129개도 유지했다. 에테르의 지도 영역은 1,672×836으로 2:1이다.

벨레스의 시설 표식은 v1 화면 위치를 사용하고 마을 표식은 기존 마을 영역에 추가했다. 강·마을·숲의 큰 관계는 화면으로 대조했으나 생성 도구가 보정한 지표의 픽셀 동일성이나 측량 좌표 정합은 보장하지 않는다. 에테르도 해안 외곽만 좌표로 보존했으며 생성된 내부 산맥·수계·기후의 정확도는 미검증이다.

## 이후 지도 제작 절차

1. 범위에 맞는 v2 PNG·SVG와 공통 UI 값을 먼저 읽는다. 지역·대륙·세계 축척에 맞춰 정보를 생략하되 화풍과 표식의 의미는 유지한다.
2. 해안·수계·지명·정착지의 기존 자료를 확인하고 바탕과 표기 레이어를 분리한다. 생성 이미지의 지형을 새 지리 기준으로 삼거나 글자 배치를 위해 위치점을 이동하지 않는다.
3. 지점 이름에는 같은 실선 연결 규칙을 적용하고 영역 이름에는 점과 연결선을 두지 않는다. 글꼴·아이콘·범례·선의 색과 굵기는 공통 UI 값을 사용한다.
4. 출력 후 지명 철자·표식 개수·좌표·글자 겹침·범례 일치와 해안·수계 보존을 대조한다. 화면 확인과 좌표 검사를 구분해 기록하고, 미검증 지형·실제 게임 동작은 별도로 표시한다.

## 이전 v1 비교 자료

### 이그니스

![이그니스의 채택된 지도 화풍과 도시 표기](Images/ignis-map-ui-approved-v1.png)

기존 좌표도의 서안항·동안항·세르나를 선택한 그림의 세 항구에 맞추는 아핀 변환으로 표시 좌표를 계산했다. 원본의 낡은 표식 자리는 이미지 도구로 보정한 부분만 사용하고, 새 이름과 점은 SVG 레이어로 배치했다. 전체 지형을 다시 생성한 결과를 최종 바탕으로 사용하지 않았다.

화면의 이름은 주요 도시인 세계수 관리도시·로덴·세르나·하르덴·서안항·동안항·북부 관문도시·남동 평야도시와 벨레스·세계수다. 일반 도시의 이름과 대부분의 마을 표식은 이 축척에서 생략했다. 세계수는 대륙 크기의 나무 모형 대신 작은 위치 기호로 표시한다.

### 에테르 월드맵

![에테르의 채택된 다섯 대륙 월드맵과 공통 UI](Images/ether-world-map-ui-approved-v1.png)

기존 [세계지도 v3 해안 좌표](Data/ether-world-map-land35-precise-v3.json)를 그대로 사용해 이그니스 타이가·아르베나·오르다스·세라디온·니베르를 배치했다. 지표 질감은 각 대륙의 해안 내부에만 적용하고 바다와 지명·공통 UI를 별도 레이어로 구성했다. 하단 전체에 이어지는 니베르와 오르다스의 내해·해협도 기존 해안 형상을 따른다.

최종 PNG는 3,200×1,800이며, 상·하단 UI 사이의 지도 영역은 3,200×1,600으로 기존 2:1 비율을 유지한다. SVG는 지표 이미지를 내부에 포함하므로 별도 질감 파일 없이 열 수 있다. 세계 축척에서는 도시 표식을 생략하고 다섯 대륙 이름과 벨레스 좌표에 놓은 현재 위치 예시를 표시한다. 현재 위치는 게임에서 읽은 값이 아니다.

제작 중 생성한 `terrain-plate.png`는 해안 안을 채우기 위한 중간 질감 이미지다. 바다·다섯 대륙의 외곽·UI를 합성하기 전의 자료이며 최종 월드맵으로 사용하지 않는다. 생성된 산맥·식생·설원 등의 내부 표현은 시각 제안으로, 기존 세부 지형이나 기후 자료와 정합을 검증한 결과가 아니다.

v1 시안 보관본은 원본 작업 파일과 SHA-256이 같다. 파일 대응과 해시는 [벨레스·이그니스 보관 목록](Data/approved-map-assets-v1.json)과 [에테르 월드맵 보관 목록](Data/ether-world-map-ui-approved-v1-assets.json)에 둔다. 원래 생성 입력문은 제작 당시 표현을 그대로 보존하므로 현재 기준과 다른 미채택 보정 지시가 포함될 수 있다. 후속 제작의 기준은 이 문서의 최종 시안 v2다.

2026-11-09 작업 파일 검사에서 주요 도시 8곳·일반 도시 12곳·벨레스의 표식 21개와 이름 10개가 표시 좌표 자료에 일치했다. 세계수 기호는 정착지 21개와 별도다. 상·하단 UI는 화풍을 선택한 원본과 픽셀이 같고, 전체 픽셀의 약 97.09%가 원본과 같았다. 수치의 근거는 위 검사 결과이며, 정본 좌표나 실제 게임에서 실행한 검증으로 해석하지 않는다.

표시 좌표의 일치는 아핀 변환 뒤의 SVG 좌표를 확인한 결과다. 그림의 해안·물길·고도와 지리 좌표가 모두 정합한다는 뜻은 아니다. 작은 지역의 위치점이 가까이 보이는 것은 대륙 축척의 결과이며, 상세 배치는 기존 좌표 자료를 따른다.

에테르 월드맵은 원본 해안 꼭짓점 32,129개를 모두 유지했고, 정규화 좌표의 최대 오차는 0이었다. 다섯 대륙의 해안 클립 참조와 이름, 지도 영역 비율, 출력 PNG 크기도 검사했다. 이 결과는 해안 외곽의 보존을 확인한 것이며 생성된 내부 지형의 정확도를 보장하지 않는다.

새 시안을 만들 때는 채택 이미지로 화풍과 UI를 맞춘 뒤 지명·위치점을 기존 좌표에서 배치한다. 편집 후에는 이름, 점의 위치, 글자 겹침과 수정 영역 밖의 변화를 대조한다. 실제 고도 자료 연결, 탐색 공개, 확대 단계, 입력 동작과 UE 화면 검증은 후속 작업이다.
