# 니베르 첫 탐색·상륙과 본선 귀환 지도

[니베르 첫 상륙 후보](../../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-11-niber-first-landing.md)의 관측·접안·보행·생활권·대체 귀환을 NI-L01 국소 좌표로 비교한다. 기존 세계 해안·남부항 위치를 바꾸지 않는다. 좌표 검토와 공간 후보이며 [최종 제작 도안 기준](MapPresentation.md#제작-도안의-최소-상세-수준)의 채택 화풍·시설 상세를 완료한 아트는 아니다.

## 첫 조사와 생활권

![니베르 해안 포식권·첫 보급소·선택 위험과 다른 귀환](Images/niber-first-survey-v1.png)

[SVG](Images/niber-first-survey-v1.svg). 새 20장소·5형태·6생활 단위·11개체를 표시했다. 파랑은 접근, 주황은 다른 귀환, 녹색은 포식권 우회, 보라는 선택·대체 경로다. N18로 향하는 옅은 선은 후속 수색 방향이며 이번 탐색 완료 경로가 아니다. 먹이터와 매개 물건에 묶인 범위를 구분하며 모든 원을 실제 감지 반경으로 해석하지 않는다.

## 상륙과 회수

![첫 상륙과 서쪽 대체 승선·본선 회수 동선](Images/niber-landing-return-v1.png)

[SVG](Images/niber-landing-return-v1.svg). N17 옛 접근점은 해빙 때문에 제외한다. 주 상륙 N02와 대체 N12는 현지 재관측이 필요하다. 선박 경로는 수면, 보행은 육지로 구분하며 육해 경계의 실제 승하선은 미검증이다. 본선 10명·소형정 2명·해안조 4명으로 나누고 귀환 시 같은 6명이 이동한다. 본선 복귀는 세라디온 귀항 완료와 다르다.

## 자료와 확인 범위

[배치 JSON](Data/niber-first-landing-v1.json)과 [계산 검사](Data/niber-first-landing-v1-validation.json)에서 원본 보존·형태 범위·인원·성장·보행과 보트·우회·SVG 좌표를 확인한다. 지붕·가림벽·덮개와 암반은 새 공간 후보이며 실제 고도·수심·해빙·시야·통신·구조·AI·전투·UE 실행은 미검증이다. G5는 유지하지만 구조 성공·실패 원인·G6를 완료하지 않는다.
