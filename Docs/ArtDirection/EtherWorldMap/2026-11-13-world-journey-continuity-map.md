# 5대륙 전체 여정 진행 관계도

[전체 여정 통합 점검](../../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-13-world-journey-continuity.md)을 한 장으로 읽는 비지리 관계도다. 이그니스 환승·세라디온 귀항을 생략하지 않고, G1 선택 왕래와 G2 본편을 구분한다. 기존 세계지도·항구·지역 좌표는 수정하지 않는다.

![이그니스부터 세라디온 결말까지 해금·성장·인계 관계](Images/world-journey-continuity-v1.png)

[SVG](Images/world-journey-continuity-v1.svg). 위쪽 왼쪽에서 오른쪽, 아래쪽 오른쪽에서 왼쪽으로 본편이 이어진다. 화살표는 진행·수송 조건이며 거리·방위·시간·항행 가능성을 뜻하지 않는다. 하단의 G1 선택 방문은 S3 이후 아르베나 공개 구역을 왕래하고 S4로 돌아오는 별도 경로다.

[통합 자료](Data/world-journey-continuity-v1.json)는 성장 28지점과 도감·배치 대조 범위 및 원천을 기록한다. [계산 검사](Data/world-journey-continuity-v1-validation.json)는 성장 연결·배치 범위·종 분류의 검사 결과다. 지도 그림의 지리 정확도나 모든 지역의 실제 통행을 검사한 자료는 아니다.

G4는 동안항 원양 계약 뒤, G5는 남부항 개조·보급·피난 인수 뒤다. T6 귀항은 G6와 독립이고 G6 이후에도 보스 전투·실제 분리·주민 인계가 남는다. 기본 종료 60과 선택 +2 종료 62는 비교값이며 최고 레벨이 아니다. [최종 지도 제작 도안 기준](MapPresentation.md#제작-도안의-최소-상세-수준)은 별도 적용 대상이다.
