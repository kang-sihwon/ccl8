# 에테르 세계지도 계산 보정 검증

계산 보정본(v3)은 행성 둘레 40,000km인 구면에서 육지 35%와 이그니스 2,000만 km²를 충족했다. 기준점, 본토 외곽, 격자, 대륙 분리, 니베르의 좌우 이음과 오르다스 내해 연결을 검사했다. 이 결과는 지도 제작 수치에 대한 검증이며 지형·기후·항행 가능성이나 서사 정본 승인을 뜻하지 않는다.

상위 문서는 [세계지도 시안](../EtherWorldMap.md)이다. 목표 수치는 [지도 제작 기준표](../../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-map-production-basis.md)가 소유한다. 측정 근거는 [해안 좌표](Data/ether-world-map-land35-precise-v3.json)와 [검증 결과 JSON](Data/ether-world-map-land35-precise-v3-validation.json)이다. 검증은 Codex가 수행했으며 별도 검토자의 독립 검토는 아니다.

## 면적과 위치

| 번호·대륙 | 외곽 기준점 | 보정한 구면 육지 면적 |
|---|---|---:|
| 1 이그니스 타이가 | 55°N, 0° | 20,000,000km² |
| 2 아르베나 | 25°N, 105°W | 40,000,000km² |
| 3 오르다스 | 35°S, 65°W | 35,000,000km² |
| 4 세라디온 | 5°S, 115°E | 73,253,536.263km² |
| 5 니베르 | 남극 포함 | 10,000,000km² |
| 합계 | 행성 표면적 509,295,817.894km² | 178,253,536.263km², 35% |

세라디온은 기존 반올림 목표 73,250,000km²에 3,536.263km²를 더해 합계를 정확히 35%로 맞췄다. 차이는 약 0.0048%이며 나머지 네 대륙의 면적은 유지했다. 별도 섬은 이번 도형에 포함하지 않았다. 이후 섬을 추가하면 해당 대륙의 본토 면적을 그만큼 줄여 합계를 유지해야 한다.

기준점은 외곽 사각형의 중심이며 육지 무게중심이 아니다. 네 본토의 동서남북 극점은 기준표의 반올림 전 좌표에 맞췄다. 외곽을 바꾸지 않고 그 안의 해안 폭을 조절했으므로 기준 동서 폭·남북 길이도 유지된다.

## 형태와 계산 방식

사용자가 선택한 [생성 시안(v2)](Images/ether-world-map-land35-v2.png)에서 네 본토와 남극 해안을 추출했다. 북쪽 중앙·서쪽·남서쪽·동쪽·하단이라는 구도, 이그니스 남쪽 만, 아르베나 동쪽 반도, 오르다스 내해, 세라디온의 긴 남북 형태를 유지했다. 면적을 맞추기 위해 해안의 국소 폭과 굴곡 간격은 달라졌고 작은 장식 섬은 생략했다.

네 본토는 각 외곽 안의 상대 좌표 `t`에 `t - a × sin(2πt)`를 적용했다. 경계와 중앙을 고정하는 단조 변환이며, 대륙별 계수 `a`를 이분법으로 찾아 목표 면적을 맞췄다. 니베르는 하단에 연결된 육지 성분만 추출해 해안 높이를 화면 세로 89-92% 안에서 보정했다. 좌우 끝의 높이와 접선도 맞췄다.

좌표 자료는 지구 WGS84가 아닌 가상 구면 모델이다. 경도·위도는 각각 `360x - 180`, `90 - 180y`로 얻는다. 면적은 `R² × |∮ sin(위도) d경도|`로 계산하며 삼각함수에는 라디안을 쓴다. 선분은 위경도 공간에서 직선으로 정의하고 대권 경로로 해석하지 않는다. 따라서 SVG의 직선 해안과 계산 대상이 같다. 고위도 확대가 있는 지도이므로 화면의 육지 픽셀 비율 자체를 35%로 맞추지는 않는다.

## 검증 결과

| 검사 | 결과 |
|---|---|
| SVG를 다시 읽은 면적 검산 | 생성에 쓴 해석 적분과 별도로 5점 가우스 구적법 적용. 대륙별 목표 차이 0.001km² 미만 |
| 전체 육지 비중 | SVG 검산값 34.99999999999634%. 계산 정밀도 안에서 35% |
| 별도 픽셀 근사 | 7,200×3,600 픽셀 중심을 육지와 대조하고 위도별 구면 면적으로 가중. 34.99918048% |
| 좌표와 외곽 | SVG 좌표와 원본 도형의 정규화 좌표 차이 0.000000000001 미만. 네 기준점과 본토 외곽 일치 |
| 격자 | 내부 세로선 11개·가로선 11개. 경도 30°·위도 15°. 3,600×1,800 지도에서 격자 한 칸 300×150픽셀 |
| 대륙 분리 | 다섯 도형 유효. 본토끼리 겹치는 면적 0 |
| 니베르 | 해안 세로 89-92%, 남극까지 연속 육지. 좌우 해안 높이·끝 접선 일치 |
| 오르다스 내해 | 내해 안쪽에서 해협을 거쳐 외해로 나가는 검사 경로가 육지를 통과하지 않음 |
| 교역 연결 | 지정한 세 연결만 존재. 육지 내부를 통과하지 않으며 양 끝이 해안에 닿음 |
| 화면 확인 | PNG에서 번호·십자·격자·해안·교역선과 전체 구도를 확인 |

PNG의 안티앨리어싱과 해안선 두께는 면적의 기준이 아니다. 이후 편집과 면적 계산은 SVG 또는 좌표 JSON을 사용한다. SVG에는 `land`, `graticule`, `trade-connections`, `reference-points`, `labels` 그룹이 있어 요소별로 편집할 수 있다. 내해 연결 검사는 수로의 존재만 확인하며 수심이나 선박의 통과 가능성을 보장하지 않는다.

## 남은 판단

이 해안은 수치 검증을 마친 검토용 초안이다. 최종 형태 승인, 이그니스 내부 거점 재배치, 항구와 기항지, 항해 거리·시간, 해류·기후·식생, 니베르 탐사 출발지는 별도 작업이다. 교역선의 해안 접점은 임시 연결점이며 항구 좌표로 승격하지 않는다.
