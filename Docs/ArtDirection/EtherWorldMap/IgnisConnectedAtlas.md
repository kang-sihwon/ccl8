# 이그니스 연속 지역 지도

확정된 [지도 제작 기준 v2](MapPresentation.md)를 사용해 대륙 전체 권역도, 주요 도시 8곳의 권역도, 36개 정착지 상세도를 함께 제작한다. 사용자는 2026-11-09 세 범위를 모두 요청했다. 새 이미지의 지형·시설 표현은 검토 후보이며 기존 시안과 지리 자료를 보존한다.

## 지도집 열기

현재 제작 방식은 [세계지도 고정 픽셀 섹터](WorldSectorPlan.md)를 따른다. 이그니스의 육지 포함 39칸을 새로 생성하고 바다 배경 11칸을 더해 2,048px 타일 50장과 20,480×10,240px 합본을 제작했다. [새 섹터 지도 뷰어](Atlas/IgnisSectors-v1/index.html)에서 경계를 켜고 확대해 연결 상태를 확인한다. [제작본과 검증 범위](WorldSectorPlan.md#이그니스-제작본)를 함께 읽는다. 새 결과는 검토 후보이며 에테르 세계 전체 제작은 다른 대륙의 설정이 정해진 이후로 보류한다.

아래 지도집과 정착지 상세 36장은 이전 방식의 비교 자료다. 새 섹터 지도에 합쳐진 타일로 취급하지 않는다.

앞서 요구한 **정착지 상세지도 36장 자체가 서로 맞물리는 전체 지도**는 미완료다. 현재 36장은 각각 제작한 이미지여서 이 조건을 충족하지 못한다. 대륙 바탕을 나눈 9구역의 연결 검증을 상세지도 36장의 연결 검증으로 대신할 수 없다.

[36장 원본 조립본](Atlas/Ignis-v1/provenance/detail-puzzle-v1/ignis-36-details-assembled.png)과 [이름·접합선 표시본](Atlas/Ignis-v1/provenance/detail-puzzle-v1/ignis-36-details-seams.png)은 UI를 제외한 기존 이미지 영역을 빈틈없이 붙인 검사 자료다. 기존 좌표의 동서·남북 순서를 참고해 6×6 칸에 임시 배치했으며, 정확한 지리 배치나 맞물리는 퍼즐의 정답 배치가 아니다. 강·해안·도로가 경계에서 끊기는 곳이 보인다. 지형 추가나 경계 보정은 하지 않았다. [배치 자료](Atlas/Ignis-v1/provenance/detail-puzzle-v1/layout.json)와 [원본 36장 확인 기록](Atlas/Ignis-v1/provenance/detail-puzzle-v1/verification.json)을 보관한다. 연결된 상세 전체 지도의 완성 상태는 미완료다.

[이그니스 지도집](Atlas/Ignis-v1/index.html)에서 전체 연결도, 도시 권역, 정착지 상세를 선택한다. 이름 검색, 도시 표식 선택, 소속 권역 복귀, 인접 구역 이동, 확대·축소를 지원한다. PNG는 바로 볼 수 있고 SVG는 같은 폴더의 지형 이미지와 함께 열어야 한다.

## 제작 결과

| 단계 | 구성 | 현재 상태 |
|---|---|---|
| 전체 연결 | 전체 연결도 1장 + 3×3 연속 구역 9장 | 공통 지형·좌표를 사용하며 인접 경계 12곳이 맞닿는다 |
| 주요 도시 권역 | 주요 도시 8곳과 주변 정착지의 권역도 8장 | 확대 지형 시안과 공통 바탕의 연결 기준본을 함께 제공한다 |
| 정착지 상세 | 대도시 8·일반 도시 12·마을 16의 지도 36장 | 벨레스 v2 재사용 + 신규 바탕 35장, 기존 시설 좌표 표기 |

기본 지도는 총 54장이다. 권역별 연결 기준본 8장은 비교 자료로 별도 보관했다. 신규 이미지는 **제작·검증을 마친 검토 후보**이며, 승인된 벨레스·이그니스·에테르 v2의 최종 시안 지위를 바꾸지 않는다.

## 좌표와 지형의 연결 범위

[대륙 좌표 자료](Data/ignis-continent-georeference-v1.json)의 36정착지·하천 14개·노선 24개와 [세계지도 해안](Data/ether-world-map-land35-precise-v3.json)의 이그니스 해안 꼭짓점 6,156개를 사용했다. 전체 연결도와 연속 구역 9장은 하나의 지형 바탕을 공유한다. 하천·노선과 정착지 표식은 원자료 좌표에서 변환하며 원자료는 수정하지 않았다.

도시 권역 8장은 대륙 바탕을 확대했을 때 생기는 흐림을 줄이기 위해 별도로 지형을 보강했다. 각 권역의 **연결 기준본과 비교** 버튼으로 같은 좌표 범위의 공통 바탕을 볼 수 있다. 보강한 숲·암반·물가가 인접 지도와 픽셀 단위로 같다는 뜻은 아니다.

정착지 상세 36장은 각 정착지 좌표에 연결한 별도의 확대 시안이다. 시설 좌표가 있는 7곳은 기존 상세 자료를 사용하고, 그 밖의 건물·골목·식생은 새 시각 후보로 구분했다. 표식 좌표는 원자료와 일치하지만 생성된 건물이나 부두가 모든 표식 아래에 정확히 놓였다는 보장은 없다. 벨레스는 승인된 v2 이미지를 그대로 재사용했으며 기존 화면 내 위치를 실측 좌표로 바꾸지 않았다.

대륙 바탕의 원본 래스터는 1,774×887이고 좌표 캔버스는 3,840×1,920이다. 지도 UI 출력은 1,672×941이다. 캔버스 확대를 원본 해상도 증가로 간주하지 않는다. 지역 상세 사이를 빈틈없이 덮는 연속 지표, 실제 게임 이동·전투·고도·시설 축척은 미검증이다.

## UI와 검증

글꼴·상하단 바·아이콘·색상은 [v2 기준](MapPresentation.md)을 사용한다. 모든 이름이 있는 점 표식은 같은 굵기의 실선 연결선 두 구간을 사용하며 점선 연결선을 넣지 않았다. 지형 이름과 점 표식은 구분한다.

[검증 결과](Atlas/Ignis-v1/verification.json)는 PASS다. 지도 54장의 PNG 크기와 표식 좌표, 정착지 36곳의 누락 여부, 연속 구역의 경계 12곳, 공통 하단 UI, 승인 파일 12개의 해시 보존을 확인했다. 브라우저에서 장소 이름 210개의 잘림·겹침이 없음을 검사했고, 검색·상세 이동·소속 권역 복귀·확대·Esc 복귀·연결 기준본 비교도 확인했다. 생성 지형과 시설 좌표의 완전 일치나 UE 실행을 통과했다는 의미는 아니다.

생성 과정에서 관리도시의 불필요한 강, 서안항의 하천 누락, 북부 관문도시의 합류 방향, 바람재 풍차의 측면 표현을 수정했다. 신규 지형의 세부 형태와 화풍에 대한 사용자 검토는 남아 있다.

파일 구성과 표시 좌표는 [지도 목록](Atlas/Ignis-v1/atlas-manifest.json), 제작 입력은 [상세 지도 계획](Atlas/Ignis-v1/provenance/detail-plans.json), [상세 생성 기록](Atlas/Ignis-v1/provenance/generation-records.json), [권역 생성 기록](Atlas/Ignis-v1/provenance/region-generation-records.json)에 있다.
