# 이그니스 대륙과 36개 정착지 좌표 정합

중앙 9곳의 지역 좌표를 유지하고 외곽 27곳을 같은 구면 좌표계에 연결했다. 세계지도 v3의 해안, 세계수, 산맥 분수계, 주요 하천과 교역 회랑을 두 도면에서 대조할 수 있다. 외곽 위치와 전역 원점은 새 설계 후보이며 정본 승인이 아니다.

지형·정착 이유는 [통합 지리 후보](../../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent/geography.md), 제도·현재 갈등·몬스터는 [현재 상황 후보](../../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent/present-world.md)가 소유한다. 이 문서는 그 관계를 좌표로 옮기는 기준을 소유한다. [결정 35](../../decisions/0035-nadir-map-presentation.md)의 평면 표현과 [결정 39](../../decisions/0039-opening-scenario-and-continent-context.md)의 배경 상세화 범위를 따른다.

## 유지한 기준과 새로 제안한 위치

세계지도 해안과 중앙 지역의 상대 배치는 이동하지 않았다. 외곽 27곳은 기존 생성 이미지의 픽셀 위치를 측량한 값이 아니라, 같은 역할과 지형 관계를 만족하도록 새로 정한 좌표다. 기존 시안·후보와 서사 정본은 보존한다.

| 구분 | 적용한 기준 |
|---|---|
| 해안 | [세계지도 v3 JSON](Data/ether-world-map-land35-precise-v3.json)의 이그니스 해안 6,156절점을 그대로 사용한다. 다른 네 대륙도 수정하지 않는다. |
| 구면 | 기존 반지름 6,366.197723675814km를 사용한다. 지구 WGS84 좌표가 아니다. |
| 세계수 전역 위치 | 경도 -1°, 위도 54°를 새 후보로 제안한다. 기존 중앙 분지·호수군 남쪽·테른 본류 서쪽이라는 조건을 이어받는다. |
| 지역 좌표 | 세계수 중심 구면 방위정거도법이다. 원점에서 X는 동쪽, Y는 북쪽이고 추가 회전은 0°다. 중앙 9곳과 환적장 좌표, 본류 17절점을 [선행 JSON](Data/worldtree-settlement-basis-v1.json)에서 그대로 가져온다. |
| 첫 장 지역 | 벨레스 나루는 지역 좌표 (150,145)km다. 기존 마을 내부 미터 좌표를 1,000으로 나눠 더하는 변환을 유지한다. 출항 원경과 실제 보행·전투 검증은 별도다. |
| 외곽 정착지 | 일반 도시의 유역·교역 기능과 배후 마을의 관계를 우선한다. 마을을 대륙 그림의 빈 공간에 흩어 놓지 않는다. |
| 항구 | 주거·창고 중심 후보를 선택한 해안 절점에서 내륙 방향 3km에 둔다. 물가 하역점과 바다 쪽 12km의 항로 접속점은 별도다. 항만 시설 크기와 수심을 뜻하지 않는다. |
| 지형·수계 | 산맥 축 5개 선형, 연결 호수 표식 2곳, 하천 14개와 노선 24개를 제안한다. 정밀 등고선이나 실제 고도 모델에서 추출한 결과가 아니다. |

원점을 더 남쪽 해안 가까이 옮기면 중앙 9곳 전체가 이동하고, 세르나를 중앙 가까이 끌어오면 기존 해안과 하구 관계가 깨진다. 현재 후보는 중앙 분지의 여유 공간과 해안 보존을 우선한다. 그 결과 관리도시와 세르나 사이에는 긴 하류 생활권이 생긴다.

36곳은 이번에 설계한 대도시 8곳·일반 도시 12곳·마을 16곳의 목록이다. 대륙의 모든 거주지·농가가 정확히 36곳뿐이라는 인구 설정을 새로 확정하지 않는다. M01-M08은 도면에서 대도시를 찾기 위한 식별자다. 기존 T01-T12, V01-V16과 지명은 유지한다.

## 두 도면의 모양과 축척

![기존 세계지도와 같은 정거원통도법의 연결도](Images/ignis-world-registration-v1.png)

세계지도 연결도는 원본의 정거원통도법을 유지한다. 전체 좌표 도면은 중앙 지역과 같은 방위정거도법을 사용하므로 북쪽이 모여 보인다. 두 그림의 해안 절점과 도시의 경위도는 같다. 해안선을 다시 그려 대륙 모양을 바꾼 결과가 아니다.

| 도면 | 좌표 표시 기준 |
|---|---|
| 전체 좌표 도면 | 3,200×2,460px. 대륙 패널의 X는 -3,605부터 4,025km, Y는 -2,065부터 3,045km이고 가로·세로 배율은 0.295px/km다. |
| 중앙 확대 | X -25부터 180km, Y -55부터 175km. 가로·세로 2.35px/km다. |
| 벨레스 확대 | X 136부터 158km, Y 133부터 155km. 가로·세로 19px/km다. |
| 세계지도 연결도 | 2,400×1,470px. 해안 좌표의 경도·위도를 같은 각도 배율로 표시한다. |

방위정거도법에서 세계수 원점으로부터의 거리는 구면 최단거리와 일치한다. 원점 이외 두 지점 사이의 평면 거리와 면적은 왜곡되므로 구면 좌표로 다시 계산해야 한다. 패널의 같은 가로·세로 배율이 대륙 어디서나 지표 축척이 같다는 뜻은 아니다. 위쪽은 원점의 북쪽이고, 다른 지역의 진북은 경선 방향으로 읽는다.

정거원통 연결도에서는 고위도 동서 길이가 과장된다. 그 그림의 픽셀 간격으로 도시 간 실거리를 정하지 않는다. 변환된 해안 절점 사이는 SVG에서 직선으로 잇는 표시 근사이며, 원본의 경위도 선형 보간과 구면 면적 기준은 [세계지도 검증](2026-11-01-precision-validation.md)을 유지한다. 이번에는 대륙 면적을 다시 계산하지 않았다.

## 외곽 27곳이 지형에 연결되는 방식

배후 마을은 모도시의 고유 기능과 생활 공급 관계를 유지한다. 아래의 같은 묶음은 행정상 편입 확정을 뜻하지 않는다. 갈매·청그물은 독립된 연안 포구를 갖고, 여름뜰은 계절 집결지이므로 삼각형으로 표시한다.

| 지형권과 거점 | 배치 이유와 연결 |
|---|---|
| 하르덴·누마·바람재 | 하르덴은 서부 분수계 동쪽의 계곡 단이다. 누마는 북서 배후 고원, 바람재는 북동쪽 바람길 아래에 놓인다. 둘 다 하르덴 주변 수십 km 생활권으로 묶는다. |
| 켈바·윗샘 | 켈바는 하르덴보다 동쪽·하류의 진입부이고 윗샘은 그 북서쪽 상류 지선이다. H09가 H02에 합류하며 취수·경작·공방의 협의 관계를 유지한다. |
| 드라벤·서안항 | 하르덴에서 P01 고개를 육로로 넘어야 드라벤의 서향 유역에 들어간다. H03은 서안항으로 나가며 하르덴의 H02와 연결하지 않는다. |
| 살레크·갈매 | 남서 반도 바깥 해안의 서로 가까운 포구다. 구면 직선거리는 약 38.6km이고 해안 육로 B13으로 연결한다. 포구의 실제 피항 성능은 아직 미확인이다. |
| 세르나 | 테른 본류와 메르사 지선이 만나는 하구권이다. 주거·창고 중심, 물가 하역장, 바닷배 항로 접속점을 나눈다. |
| 메르사·씨앗골 | 세르나에서 만 동쪽 육지를 따라 평야로 들어가는 길에 둔다. 씨앗골은 메르사 북동쪽의 배후 경작지다. |
| 남동 평야도시·물나래 | 동부 분수계 남서쪽의 내륙 지선 유역이다. 물나래는 도시 남동쪽 하류 단이며 바다에 직접 면한 항구로 바꾸지 않는다. |
| 동안항·에스칼·긴솔 | 동부 분수계 동쪽의 별도 유역이다. 긴솔에서 에스칼로 목재를 내리고 동안항으로 보낸다. 에스칼은 B15 지선으로 R7과 연결한다. |
| 루세아·청그물 | 남동 반도 바깥 연안에 둔다. 청그물은 루세아와 동안항 사이 포구이며 B14 연안 지선이 연결한다. 두 곳의 담수 지선은 내륙 평야 수계와 분리한다. |
| 관문도시·케르딘·길목 | 백풍 산맥 남쪽 거주 계곡이다. 길목은 케르딘 아래 접근로, 케르딘은 높은 고개 아래에 둔다. 북쪽 옛 겨울 분지나 고개 정상에 일반 거주지를 옮기지 않는다. |
| 네르바·돌곡·새불 | 관문에서 중앙으로 내려가는 H04 계곡이다. 새불은 관문과 네르바 사이, 돌곡은 네르바 가까운 경작·저장 단이다. |
| 울렌·여름뜰 | 관문 서쪽 지선이다. 울렌 상류의 여름 집결지와 아래 시장을 연결하며 여름뜰을 연중 정주 도시로 표시하지 않는다. |

## 물길·분수계·통행

주요 수계는 바다 하나로 내려가는 가지 구조다. 하천 고도는 원천에서 하구까지 낮아지는 설계 절점값이며 실제 지형에서 계산한 경사나 수심이 아니다. H04의 호수 두 곳도 같은 물길에 놓인 표식이며 원형 해안과 면적이 확정된 호수는 아니다.

| 수계 | 이어지는 곳과 출구 |
|---|---|
| H01 테른 | 북동 산림 → 기존 17절점의 벨레스·타르넬·로덴·환적장 → 남쪽 하류 → 세르나 해안 |
| H02·H09 | 하르덴 동향 계곡과 윗샘 → 켈바 → 중앙 남쪽의 테른 합류점 |
| H03 | 서부 분수계 서쪽 → 드라벤 → 서안항 해안 |
| H04·H08 | 케르딘·울렌 지선 → 관문 → 네르바 → 중앙 호수군 → 테른 합류점 |
| H05 | 긴솔 → 에스칼 → 동안항 해안 |
| H06 | 동부 산지 남쪽 → 평야도시·물나래 → 남쪽 해안의 별도 하구 |
| H07 | 메르사 배후 → 메르사 → 세르나 하구권의 테른 합류점 |
| H10 | 백풍 산맥 북쪽 사면 → 북해안. 남쪽 거주 계곡과 강으로 연결하지 않음 |
| H11-H14 | 살레크·루세아·갈매·청그물의 짧은 담수 지선 → 각각의 해안 |

| 노선 | 좌표에 적용한 통과 조건 |
|---|---|
| R1·R2 | R1은 로덴에서 환적장을 거쳐 세르나로 내려가는 테른 회랑이다. 상류 강선은 벨레스까지 이어진다. R2는 관리도시에서 같은 서안의 환적장까지 10km 접속이다. |
| R3 | 중앙에서 산맥 남쪽 기슭을 따라 네르바·관문으로 간다. 강을 건너는 지점은 교량·나루의 후속 상세화가 필요하다. |
| R4·R5 | R4는 켈바·하르덴의 동향 계곡이다. R5는 P01의 분수계 틈을 넘어 드라벤·서안항으로 간다. 고개 위에 연속 하천이나 운하를 만들지 않는다. |
| R6 | 세르나에서 만 동쪽 육지를 거쳐 메르사·평야도시로 간다. 만을 직선으로 가로지르지 않는다. |
| R7·B15 | 평야에서 P02 낮은 고개를 넘어 동안항으로 간다. 에스칼은 별도 산림 지선 B15로 합류한다. 도로 합류점은 새 정착지로 세지 않는다. |
| R8·R9 | 바다 쪽 접속점 사이를 남서·남동 반도 바깥으로 연결한다. 접안 구간은 해안 절점까지 별도로 기록한다. |
| B01-B14 | 외곽 마을과 모도시, 북부 지선, 청그물의 연안 운송을 연결한다. B14는 해로이고 나머지는 육상 회랑이다. |

육상 선은 통행할 계곡·고개의 회랑이다. 강선과 겹치는 부분은 같은 계곡을 이용한다는 뜻이며 물 위에 도로가 놓였다는 뜻이 아니다. 도로의 어느 강안을 쓰는지, 교량 위치와 폭, 경사·홍수 우회로는 하위 축척에서 설계해야 한다. 바다 선도 수심·암초·바람을 검증한 항해 경로가 아니다.

## 생활권과 갈등에 미치는 영향

네 정치권과 기존 몬스터 역할을 바꾸지 않고, 통제할 수 있는 통로를 구체화했다. 도면 색은 기존 소속·협약·거래 생활권을 구분하는 표식이다. 전 대륙의 국경·과세권을 칠한 것이 아니며 벨레스의 정식 가입·과세 미정도 유지한다.

| 공간상의 병목 | 이어지는 기존 상황 |
|---|---|
| 하르덴의 동향 수로와 서향 고개 분리 | 취수·설비 가동 협의는 켈바 쪽, 고원 물산의 운임·판매권 갈등은 드라벤·서안항 쪽에서 작동한다. 비룡과 산지 포식종의 통행 위험도 고개·절벽 회랑에 연결할 수 있다. |
| 북부 계곡과 계절 지선 | 관문의 반출 제한이 울렌 이동 시기·네르바 비축·새불 수리에 전해진다. 백각 거수의 이동권을 국경선처럼 막아 두지 않는다. |
| 평야와 동안의 별도 유역 | 곡물·종자는 평야의 물 배분에, 조선목은 동안 계곡의 벌채 일정에 묶인다. 같은 왕국이어도 P02 통행과 납기 협의가 필요하다. |
| 세르나 하구와 반도 바깥 항로 | 강배·바닷배 환적과 대기 비용이 존재한다. 하구 갑각종·갈퀴등 해수의 활동은 항만 접속·연안 위험과 연결하되 대륙 전체 바다를 점유한다고 확대하지 않는다. |

새 좌표에서 관리도시·세르나의 구면 직선거리는 약 1,125.2km, 하르덴·켈바는 약 601.1km다. 벨레스·로덴 약 64.0311km의 기존 관계는 유지된다. 대륙 간선 거래와 마을 근교 왕래는 규모가 다르다. 이전 개념도의 픽셀 간격이나 후속 모험 후보의 장면 전환으로 이동 시간을 정하지 않는다. 이 거리들은 위 검증 JSON의 구면 계산값이며 도로·수운 거리나 여정 일수가 아니다.

## 검증 결과와 한계

계산 검증은 `PASS`다. 대도시 8·도시 12·마을 16의 고유 ID·지명, 전부 육지에 놓인 정착지, 기존 중앙 9곳·환적장·강선 보존, 전역 좌표 왕복 변환을 확인했다. 대륙 패널 27곳·중앙 패널 9곳·벨레스 재표시 4곳으로 SVG 표식 40개가 고유 거점 36곳을 나타낸다.

해안 절점은 두 SVG에서 원본으로 역산했다. 하천 14개의 설계 고도는 하류로 감소하고, 지류 합류점의 좌표·고도가 일치하며 바다까지 연결되는 순환 없는 구조다. 표시한 분수계를 강이 가로지르는 교차와 기록되지 않은 하천끼리의 교차는 없다. 노선 24개는 해안 경계를 가로지르지 않으며 육로·수운 절점은 육지 쪽, 해로 절점은 바다 쪽이다. 접안 구간은 별도 항만 자료로 구분했다.

전역 왕복 변환 최대 오차는 약 1.83×10⁻¹²km, SVG 정착지 역산 최대 오차는 약 2.26×10⁻⁷km다. 원본 투영 도면의 해안 역산 오차는 약 3.01×10⁻⁹도 이하이다. 이 값은 데이터와 표현의 내부 일치 오차이며 제안 위치의 지리 정확도를 뜻하지 않는다. 파일 해시는 검증 JSON에 SHA-256으로 기록했다. PNG는 원시 바이트, SVG·JSON은 BOM 없는 UTF-8과 LF 줄바꿈으로 정규화해 계산한다.

두 PNG를 직접 열어 확인했다. 전체 도면은 글자 경계상자 간 겹침과 이름 배경이 정착지 중심을 가리는지도 검사했다. SVG는 같은 도형·문자 배치로 만들었으나 환경별 글꼴 대체에 따른 폭 차이는 남는다. 해안 교차 계산은 선분의 관통 교차를 검사하고 끝점의 육해 상태를 함께 확인했다. 접선 접촉·공선 중첩, 물길 주변 실제 지형과 항행까지 보증하지 않는다.

[독립 검토](../../Narrative/Reviews/2026-11-07-continent-coordinate-review.md)는 `PASS`다. 검토자가 원본과 새 데이터·SVG를 독립 계산으로 대조하고 최종 PNG 두 장과 파일 해시를 확인했다. 남은 지적은 없다. 정밀 지형 고도, 홍수면·수심, 기후·식생, 인구·물류·통행 시간, UE 경사·보행·시야·전투는 미검증이다. 정착지 안의 주거·취수·하역장 고저차도 후보 조건이며 이번 대륙 축척에서 실측하거나 구현하지 않았다.
