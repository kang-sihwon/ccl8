# 이그니스 정착지 상세 도안

정착지 사이와 외곽의 자료는 [공통 지형 상세 배경](IgnisSharedTerrain.md)이 소유한다. 결정 55에 따라 이미지 추가 제작은 중단했다. 결정 56에 따라 아래 도안 뷰어·타일·좌표와 참고 자료를 보존하고 생성 안내 이미지·중간 합본·실험 스크립트를 제거했다. 검사 기록은 정리 전 제작본의 결과이며 현재 재생성 절차가 아니다.

이그니스 대륙 배경과 정착지 36곳을 하나의 [확대 뷰어](Atlas/IgnisSettlementDetails-v1/index.html)에서 확인한다. 정착지를 선택하면 해당 위치로 확대하고, `일대`는 기존 범위, `상세`는 새로 제작한 중심부를 보여 준다. `원본 비교`는 카메라 위치를 유지한 채 새 상세 타일을 숨긴다. 휠 확대·축소, 드래그 이동, 격자·이름·이동로 표시와 `Esc` 대륙 복귀를 지원한다.

이번 범위는 **대륙 전체의 정착지 중심부 1차 상세화**다. [관리도시 제작본](Atlas/IgnisM01Details-v1/index.html)의 기존 12칸을 재사용하고, 다른 35곳에 신규 138칸을 제작해 총 150칸을 조립했다. [36곳 비교 이미지](Atlas/IgnisSettlementDetails-v1/previews/settlements-36.png)와 [납품 목록](Atlas/IgnisSettlementDetails-v1/records/delivery.json)에서 범위를 확인한다. 외곽 전체와 정착지 사이의 모든 길을 같은 상세도로 완성했다는 뜻은 아니다.

## 제작 범위와 좌표

| 단계 | 범위 | 용도 |
|---|---|---|
| 대륙 배경 | 기존 L0 50칸 | 해안, 산맥, 큰 물길과 정착지 위치를 확인한다 |
| 정착지 일대 | 기존 배치 참고 36장 | 도시·마을의 전체 구성과 새 상세 구역의 위치를 비교한다 |
| 도시·읍 중심부 | L10 신규 74칸과 관리도시 기존 12칸 | 지붕, 골목, 창고, 나루와 중심 접근로를 확인한다 |
| 작은 마을 중심부 | L11 신규 64칸 | 좁은 원본 범위 안에서 집과 작은 길을 충분히 크게 확인한다 |

[분할 계획](Atlas/IgnisSettlementDetails-v1/records/plan.json)은 [세계 분할 기준](WorldSectorPlan.md)을 그대로 사용한다. 타일 파일은 2,048×2,048px, 생성 안내 영역은 사방 128px를 포함한 2,304×2,304px이다. 뷰어와 계획의 `worldPixelBounds`는 공통 L10 세계 좌표를 사용한다. 따라서 L10 타일의 좌표 폭은 2,048, L11 타일의 좌표 폭은 1,024이며, 저장 이미지의 폭은 둘 다 2,048px이다. 주소의 C·R은 해당 LOD의 정수 열·행이다.

기존 정착지의 국지 좌표와 원본 범위를 구면 AEQD에서 세계 정거원통 좌표로 변환했다. 각 타일의 작업 영역이 원본 안에 들어오는지 확인하고 인접한 칸을 선택한다. 원본 밖의 픽셀을 가장자리 색으로 늘려서 새 지형으로 취급하지 않는다. 뷰어는 정착지 확대 시 중심 위도의 코사인으로 화면 가로 비율을 보정하며 저장 좌표는 바꾸지 않는다.

## 표현과 조립

[결정 47](../../decisions/0047-map-working-drawing-detail.md)의 건물·골목 식별 기준과 [통일 UI 기준](MapPresentation.md)을 따른다. 내장 `image_gen`에 같은 좌표의 안내 이미지와 수직 시점 보정본을 넣어 지붕 재질, 골목, 마당, 적재장과 숲의 세부를 새로 만든다. 생성 원본의 실제 크기는 파일 검사 기록에 남기며 2,048px 출력 크기와 구분한다.

생성 원본은 1,254×1,254px이며 2,304px 작업 영역에 정렬한 뒤 2,048px 코어를 내보낸다. 파일 출력 크기를 실제 생성 세부의 해상도로 해석하지 않는다. 이웃의 중첩 영역에서는 픽셀 차이가 작은 경로를 찾아 연결하고 그 주변 16px를 합성한다. 넓은 중첩 합성에서 나타난 지붕 중복을 줄이기 위한 처리다. 제작 구역 바깥쪽 128px는 기존 참고 지형으로 전환한다. 기존 참고 이미지에 새 세부가 생겼다는 뜻은 아니며 확대하면 해상도 차이가 보인다.

숲 구역을 항구 참고 그림의 배치로 잘못 만든 T01·T11·V05의 각 1칸은 해당 지형 안내 이미지만 넣어 다시 생성했다. 여름뜰 V15의 끊긴 흙길 1곳은 [640px 국소 영역](Atlas/IgnisSettlementDetails-v1/records/V15-road-repair.json)을 보정했다. 보정 결과를 합본에 반영한 뒤 코어 타일을 다시 추출하므로 합본과 타일은 같은 픽셀을 사용한다. 여러 타일을 한 장의 대륙 그림으로 다시 생성하지 않는다.

지명과 시설 표식은 이미지에 굽지 않고 좌표 레이어로 표시한다. 이름이 있는 점은 같은 굵기의 실선 두 구간으로 연결하고, 글자가 겹치면 다른 방향을 찾거나 해당 축척에서 숨긴다. 확대하면 다시 표시한다. 대륙 이동로는 원자료의 육로·강·바다 이동을 구분하며 실제 도로 노면이나 항행 가능성의 검증 결과로 취급하지 않는다.

## 확인 범위와 남은 차이

- [조립 검사](Atlas/IgnisSettlementDetails-v1/records/assembly-verification.json) 835개가 통과했다. 정착지 주소 유지, 타일 ID·정수 경계·파일 크기·생성 원본, 합본과 코어 타일의 RGB 일치를 검사했다.
- 전체 36곳의 [뷰어 검사](Atlas/IgnisSettlementDetails-v1/records/viewer-verification.json) 47개가 통과했다. 이미지 로딩, 실제 드래그·휠 입력, 비교·표시 전환과 대륙 복귀를 확인했다.
- 신규 138장의 비교 시트와 정착지 35곳의 내부 경계 111곳을 화면으로 검토했다. [시각 검토 기록](Atlas/IgnisSettlementDetails-v1/records/visual-review.json)은 잘못 생성된 배치, 지붕 중복과 흙길 단절의 보정 및 남은 차이를 구분한다. 픽셀 일치는 모든 건물과 길의 지리적 정확성을 증명하지 않는다.
- 벨레스의 승인 그림에는 모든 시설을 동시에 맞추는 정확한 지리 등록이 없다. 이번 임시 정합은 나루와 동굴을 기준으로 하며 숲 입구는 기존 공간 후보 좌표와 약 140m 차이가 남는다. 뷰어에서 이를 표시하며 확정 정합으로 사용하지 않는다.
- 대륙 배경과 기존 정착지 일대는 동일한 게임 지형에서 추출한 이미지가 아니다. 새 타일 내부의 연결 확인과 대륙 배경까지의 지형 정합은 서로 다른 검사다. 중간 축척의 연결 지형, 도시 외곽 전체, 실제 시설 치수와 UE 이동 검증은 후속 범위다.

기존 채택 지도와 관리도시 제작본은 보존한다. 새 지붕·마당·시설 세부는 제작 후보이며 서사 정본이나 실제 게임 월드의 측량 자료로 사용하지 않는다.
