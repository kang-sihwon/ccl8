## 원본·변환·새 지형

[대륙 좌표 JSON](Data/ignis-continent-georeference-v1.json)과 [세계 해안 원본](Data/ether-world-map-land35-precise-v3.json)은 수정하지 않는다. 36정착지·전체 해안·H01 본류·R1 노선·M03 주거 기준점/해안 하역점/외항 접속점을 그대로 참조한다. 기존 해안 좌표를 기존 구면 방위정거도법으로 다시 투영해 패널에서 잘라 그렸다. 원본 해안을 직선 해변 후보로 대체한 결과가 아니다.

로컬 m는 M03의 투영 km에 더하며 추가 회전은 없다. 위쪽은 세계수 중심 투영 격자의 북쪽이다. 현지 진북·구면 지표 거리·정밀 수심으로 해석하지 않는다. R1의 평면 절점 합 1,270.17km는 실측 항행 거리·하루 이동 시간이 아니다.

새 갈대·조수 배수로·선착장·좌초선·작은 암반은 이번 후보 기호다. 근해 암반을 본토 해안의 원본 절점에 합치거나 대륙 면적을 다시 계산하지 않는다. 원본 대륙의 저해상도 지형만으로 구조 현장의 노출 암반·항행 수심을 검증할 수 없다.

파랑은 진입·전달, 주황은 귀환, 녹색은 우회·선택·상단 철수다. 보라는 배 접근이며 귀환 배편은 주황으로 표시한다. 연보라는 무리 이동이고 원은 잠재 생활권이다. 선 색만으로 걷기와 배를 혼동하지 않도록 H06-H07·H09-H10을 범례에 명시했다. H07-H09는 항만도에서 묶어 표시하고 구조 확대도에서 세 점을 각각 표시한다.

## 확인 범위

작성자는 PNG 4장을 직접 열어 좌표 격자·범례·지명·연결을 확인했다. [계산 검사](Data/roden-serna-exploration-v1-validation.json) 188항목은 원본 보존·축척·실제 SVG 역산·경로·수량·현행 S3 범위·만조 시 상단 탈출·길이와 생활권 교차를 통과했다. 구조 이동선이 실제 SVG의 갑판·임시 발판·암반 안에 드는지 0.25m 표본으로 확인했다. 도보·배 경로의 본토/바다 구분을 20m 이하 간격으로 대조하고, 짧은 잔교의 해안 밖 연결만 별도로 허용했다. 이 검사는 수심·항행·해저 암초를 검증하지 않는다. 공공 하역·주거·수리 길의 공백을 야외 전투 누락으로 세지 않으며, 수중 해수를 육상 접촉 표본에서 제외한다.

실제 조석·범람·파도·시야·발판 하중·들것·승선·배 접안·전투 난도·AI·먹이 수지·경험치와 UE 실행은 미검증이다. 그림과 계산이 맞는다는 사실을 플레이 검증 PASS로 사용하지 않는다.
