# 세계지도 고정 픽셀 섹터

세계지도 전체에 동일한 픽셀 격자를 두고, 이그니스에 해당하는 칸을 제작한다. 정착지 수로 구역을 나누지 않는다. 2026-11-10 사용자가 이 분할 설계에 따른 이그니스 제작을 요청했다. 이그니스의 육지 포함 39칸을 새로 생성하고 바다 배경 11칸과 함께 50개 타일 및 전체 합본으로 내보냈다. 새 결과는 검토 후보이며 채택된 v2 시안을 대체하지 않는다. 에테르 세계 전체의 제작은 나머지 대륙의 대략적인 설정이 정해진 이후로 보류한다.

## 크기와 개수

| 대상 | 지도 영역 크기 | 분할 | 개수 |
|---|---|---|---|
| 에테르 전체 기본 단계 L0 | 65,536×32,768px | 2,048×2,048px, 32열×16행 | 512칸 |
| 이그니스 전체 작업 사각형 | 20,480×10,240px | 같은 크기, 10열×5행 | 50칸 |
| 이그니스 육지가 포함된 칸 | 같은 격자 | 내륙 10칸·해안 29칸 | 39칸 |
| 작업 사각형 안에서 이그니스 육지가 없는 칸 | 같은 격자 | 외곽 배경 | 11칸 |

2,048px은 개별 이미지 확인과 합성에 사용할 작업 단위다. 세계 전체 크기는 기존 지도 비율 2:1을 유지하면서 이그니스를 수십 개의 섹터로 다룰 수 있도록 정했다. 이는 목표 캔버스 크기이며 기존 저해상도 지형에 실제 세부 정보가 늘었다는 뜻이 아니다. 전체 캔버스를 한 번에 생성하지 않고 섹터와 축소 합본으로 관리한다.

이그니스 범위는 세계 격자의 **C11–C20, R01–R05**다. 열·행 번호는 0부터 시작한다. 세계 픽셀 범위는 `[22528, 43008) × [2048, 12288)`이며, 50칸을 원래 주소대로 조립하면 20,480×10,240px이 된다. 정착지 36곳은 좌표를 바꾸지 않고 해당 칸에 배정했다. 같은 칸에 여러 정착지가 들어갈 수 있다.

![이그니스 고정 섹터](Atlas/WorldSectorPlan-v1/ignis-sector-layout.png)

[세계 전체 격자](Atlas/WorldSectorPlan-v1/ether-sector-layout.png), [섹터 목록 CSV](Atlas/WorldSectorPlan-v1/sectors.csv), [좌표·경계 자료 JSON](Atlas/WorldSectorPlan-v1/sector-plan.json)을 함께 사용한다. 배치도의 기존 지형은 위치 확인용이며 상세화 결과가 아니다.

## 좌표와 경계 규칙

- 기준은 기존 세계지도 정규화 좌표다. 좌상단 `(0, 0)`, 오른쪽이 동쪽, 아래쪽이 남쪽이다. `x = u × 65536`, `y = v × 32768`로 계산한다.
- L0 섹터 ID는 `L0-C열-R행`이다. 시작 픽셀은 `(열 × 2048, 행 × 2048)`이며 오른쪽·아래쪽 끝은 다음 칸에 속한다. UI와 이름 표기는 지형 픽셀에 포함하지 않는다.
- 해안·강·경로는 세계 좌표의 공통 선을 참조한다. 각 섹터에서 별도로 위치를 정하지 않는다. 인접 경계 85곳과 그 위의 지형·경로 교차 90건을 계산했다. 경로에는 육상로 외 이동 수단도 있으므로 모두 도로로 그리지 않는다.
- 제작 시 사방에 128px 문맥을 더한 2,304×2,304px 작업 영역을 사용한다. 이는 합성 규격이며 이미지 생성 도구가 해당 해상도로 출력한다는 보장은 아니다. 도구 출력은 작업 좌표로 정렬한 후 사용한다.
- 접합부는 양쪽 지형을 함께 보며 같은 세계 좌표의 중첩 영역을 합성한다. 현재 제작본은 256px 중첩 영역에 완만한 가중치를 적용하고, 모서리에는 인접 네 칸을 함께 반영했다. 마지막에 중앙 2,048×2,048px을 잘라 원래 픽셀 주소에 배치한다. 강·산맥의 위치가 어긋나 단순 합성으로 해결되지 않는 접합부는 양쪽을 포함한 띠를 함께 수정한 뒤 양쪽 타일에 나눠 반영한다.

고정 격자는 빈틈과 잘못된 배열을 막지만, 따로 생성한 지형의 연결을 자동으로 보장하지 않는다. 생성 후 공통 위치의 중첩 영역, 강 폭·흐름, 길과 해안의 경계 통과 지점, 색·식생 전환을 합본에서 확인해야 한다. 인접한 서로 다른 픽셀의 색이 같아야 한다는 검사로 대신하지 않는다.

## 확대 단계

L0는 대륙 지형용이다. 벨레스처럼 지붕과 시설을 보는 화면은 동일한 좌표 체계에서 하위 섹터로 상세화한다. 확대 단계가 하나 늘 때마다 부모 한 칸을 2×2 자식으로 나누고, 자식 한 장의 출력 크기는 계속 2,048×2,048px로 유지한다. 실제 생성은 필요한 범위에만 수행한다.

상세 도안은 [결정 47](../../decisions/0047-map-working-drawing-detail.md)의 [최소 상세 기준](MapPresentation.md#제작-도안의-최소-상세-수준)을 충족해야 한다. 관리도시 M01 화면처럼 건물·골목·진입로·주변 밭과 숲길을 읽는 수준이다. 현재 50개 L0 타일은 이 상세 기준을 충족한 결과가 아니며, 픽셀 조립 검사 통과를 상세 도안 완성으로 해석하지 않는다. 하위 섹터 제작 시 상위 좌표와 인접 지형·길의 연결을 유지한다.

기존 반지름 기준 세계 둘레는 약 40,000km이므로 L0의 남북 방향은 약 1.221km/px이다. 예를 들어 L8은 L0 대비 256배로, 남북 약 4.77m/px이고 한 칸 높이는 약 9.77km다. 동서 실거리는 위도에 따라 달라진다. 이 수치는 기본 격자가 시설 상세도와 다른 단계임을 설명하는 값이며, L8을 모든 지역의 제작 범위로 확정한 것은 아니다.

## 이그니스 제작본

[확대 뷰어](Atlas/IgnisSectors-v1/index.html)에서 전체 지도와 개별 타일을 같은 좌표로 탐색한다. 휠 확대·축소, 드래그 이동, 전체 보기, 섹터 경계 표시, 정착지 36곳 이름 표시를 지원한다. 지명 표식은 원자료 좌표에 고정하고 글자와 실선 연결선을 별도 레이어로 그린다. 세계수는 원자료의 경도 −1°, 위도 54°에 황색 사각형으로 표시한다.

![이그니스 50개 섹터 조립본](Atlas/IgnisSectors-v1/previews/ignis-ui-overview.png)

각 육지 타일은 기존 지형과 공통 하천을 해당 세계 좌표로 잘라 만든 안내 이미지, 승인된 벨레스 v2 화풍을 참조해 생성했다. 생성 원본 39장은 각각 1,254×1,254px이다. 이를 2,304px 작업 캔버스로 리샘플링하고 중첩 영역을 합성한 뒤 2,048px 타일로 잘랐다. 출력 크기를 원본 생성 해상도로 설명하지 않는다. 바다 배경 11칸은 동일한 단색으로 구성했다. 기존 해안 좌표로 만든 마스크는 생성 지형이 대륙 외곽으로 번지는 것을 제한한다.

합본은 내보낸 타일 50장을 10열×5행의 원래 위치에 붙인 결과다. 전체 대륙 이미지를 새로 생성한 후 분할한 결과가 아니다. 생성 원본·좌표 안내 이미지·해안 마스크와 합성 스크립트는 로컬 작업 폴더 `output/imagegen/ignis-sectors-20261110/`에 보존하며 Git에는 포함하지 않는다. 공유 생성 기록의 기기별 경로는 [경로 정리 기록](Atlas/path-portability.json)에 따라 자리표시자로 바꿨다. 기존 정착지 상세 시안 36장은 시설·화풍 참고로 보존하며 이번 50개 타일에 포함하지 않았다.

## 확인 결과와 남은 작업

[분할 검사](Atlas/WorldSectorPlan-v1/verification.json)에서 50개 ID 중복 없음, 정착지 36곳 배정, 이그니스 해안 전체 포함, 정수 픽셀 경계, 누락·중복 없는 분할, 인접 경계 85곳과 교차 위치 범위를 확인했다.

[합성 검사](Atlas/IgnisSectors-v1/records/assembly-verification.json)는 통과했다. 육지 생성 파일 39개와 출력 타일 50개의 ID·크기, 합본의 각 칸과 출력 타일의 RGB 픽셀 완전 일치, 인접 경계 85곳의 해안 마스크 중첩 일치, 정착지 36곳의 지도 범위 포함을 확인했다. 경계 색상 급변 선별 검사에서 표시된 경계는 없었다. 이는 모든 강·길·능선의 의미상 연속성을 자동으로 증명하는 검사가 아니다.

전체 미리보기와 85개 경계를 담은 확대 비교판 [1](Atlas/IgnisSectors-v1/previews/seams-1.png), [2](Atlas/IgnisSectors-v1/previews/seams-2.png), [3](Atlas/IgnisSectors-v1/previews/seams-3.png), [4](Atlas/IgnisSectors-v1/previews/seams-4.png), [5](Atlas/IgnisSectors-v1/previews/seams-5.png), [6](Atlas/IgnisSectors-v1/previews/seams-6.png)을 화면으로 확인했다. 이 검토 범위에서 큰 물길·해안·산맥의 단절은 발견하지 못했다. 중첩 합성부에는 질감이 부드러워지는 부분이 있으며, 작은 길과 개별 지형 전부를 정밀 대조한 것은 아니다.

[뷰어 검사](Atlas/IgnisSectors-v1/records/viewer-verification.json)에서 파일 로딩, 경계·정착지 표시 전환, 확대 시 고해상도 타일 로딩, Esc 전체 복귀와 실행 오류 없음을 확인했다. 마우스 드래그 입력도 전달했지만 카메라 이동량은 수치로 판정하지 않았다. 시설 상세 확대 단계와 UE 실행은 이번 범위에 포함하지 않았다. 남은 제작은 최소 상세 기준을 충족하는 하위 도안과 그 연결 검증이다. 대륙 조립본의 제작 완료와 상세 도안의 미완료 상태를 구분한다.
