# 세라디온 결말 접근·전장 지도

[결말 후보](../../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-13-seradion-finale.md)의 경비 돌파·중추 전투·분리·귀환을 보여 주는 좌표 검토 지도다. [G6 준비 지도](2026-11-12-seradion-return-g6-map.md)의 좌표와 생태를 보존한다. [최종 제작 도안](MapPresentation.md#제작-도안의-최소-상세-수준)의 화풍·지형 아트와 실제 전투 실행 검증은 별도다.

## 경비 통로와 중추 연결

![기존 Q계 좌표를 보존한 경비 접근·서쪽 진입·동쪽 귀환](Images/seradion-finale-connection-v1.png)

[SVG](Images/seradion-finale-connection-v1.svg). 파란 접근선 바깥의 주황선은 같은 길을 철수에도 쓸 수 있다는 뜻이다. 회색은 기존 선택·귀환 연결이며 북측 Q12에는 망령 위험이 남는다. Q15는 적 중심이다. 기존 목표 방향선을 중앙 몸체를 관통하는 보행로로 사용하지 않는다.

## 보스 발판과 정비 접근

![중앙 몸체를 돌아 싸우고 무력화 뒤 심부에 접근하는 전장](Images/seradion-finale-arena-v1.png)

[SVG](Images/seradion-finale-arena-v1.svg). E04는 외부 대기, E05-E08은 전투 발판, E09는 RC1 무력화 뒤 분리 위치다. M1은 중앙 구동 몸체, M2/M3은 낮은 엄폐 후보이며 W1/W2는 작업 배수로다. 녹색 작업선은 전투 중 안전 우회가 아니다. 도면의 원형 현장 범위가 실제 공격 범위를 확정하지 않는다.

## 근거와 미검증

[배치 JSON](Data/seradion-finale-v1.json)은 기존 자료 전체와 새 12장소·10경로·5시설·2작업 수면을 담는다. [계산 검사](Data/seradion-finale-v1-validation.json)는 원천 해시·인원·성장·경로 폭·생활권·지도 좌표를 대조한다. 지도는 국소 평면 후보이며 실제 경사·수문·시야·도달 거리·전투 난도·군중·AI·UE 실행을 검증하지 않는다. 기존 생물·동물을 새로 추가한 몬스터 수에 합산하지 않는다.
