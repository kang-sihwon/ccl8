## 반영한 설정

| 항목 | 설정 |
|---|---|
| 나이·직업 | 56세, 공방의 에테르 설비 장인 |
| 키·몸무게 | 178 cm, 69 kg |
| 체형 | 어깨가 완만하게 내려가고 팔다리가 길다. 호리호리하고 엄지 밑이 도톰하다. |
| 얼굴과 머리 | 긴 얼굴, 낮게 묶은 잿빛 머리, 짧게 친 회색 수염, 끝이 흰 눈썹, 웃으면 벌어지는 위 앞니 사이 |
| 의상 | 한쪽 무릎에만 천을 덧댄 긴 잿빛 모직 외투, 어두운 조끼, 리넨 셔츠, 가죽 벨트, 낡은 끈 장화 |
| 버릇 | 작은 고리를 끼울 때 눈을 가늘게 뜨고 물건을 등불 쪽으로 돌린다 |

## 만든 방법

2026-11-27에 Codex CLI 0.172.0의 내장 이미지 도구로 만들었다. 에이전트 모델은 `gpt-6.2-astra`다. 도구가 받는 인자는 `prompt`, `referenced_image_paths`, `num_last_images_to_include`, `transparent_background`뿐이다. 시드와 해상도는 지정할 수 없어서 같은 인물을 유지하려면 참조 이미지를 써야 한다.

1. 사용자가 고른 이전 시안의 외모를 단색 배경 얼굴 사진 R1로 옮긴다.
2. R1을 참조로 새 키와 체형의 전신 기준 S1을 단색 배경에서 만든다.
3. R1과 S1을 참조로 장면 S2를 만든다. 얼굴만 필요한 상반신 S3는 R1만 참조한다.

모든 실행에서 메모리를 끄고 지시문을 그대로 넘겼으며, 세션 기록과 대조해 확인했다. 한 장에 56~137초가 걸렸다.

## 이 방식에 이른 근거

이전 시안 여러 묶음을 비교해 얻은 사실이다. 비교에 쓴 이미지들은 성공작만 남기면서 지웠다.

| 문제 | 원인 | 해결 |
|---|---|---|
| 그림처럼 보인다 | 지시문의 `painterly`, `brushwork` 문구. 화풍을 지정하지 않으면 이 도구는 실사 쪽으로 간다. | 실사 사진으로 지시한다. |
| 영화 스틸이나 CG처럼 보인다 | 어두운 조명, 빛나는 판타지 소품, 다큐 사진 지시 | 밝은 낮빛의 폰 스냅, 민속촌에서 시대 의상을 입은 배우를 찍은 상황으로 지시한다. |
| 화면이 자글자글하다 | 낡은 나무, 공구, 자갈처럼 잔무늬가 많은 배경. `use marks`, `phone HDR` 같은 지시. 참조 이미지의 천 질감이 옮겨 온 것. | 매끈한 회반죽 벽과 마루의 빈방, `no HDR`과 잔무늬 금지 지시, 단색 배경의 깨끗한 참조만 쓴다. |
| 얼굴이 비슷한 미남형으로 몰린다 | 개인 메모리의 "얼굴을 매력적으로" 선호와 에이전트의 지시문 재작성 | `--disable memories`로 실행하고 지시문을 그대로 넘긴다. |
| 뽑을 때마다 다른 사람이 나온다 | 참조 없이 글만으로는 얼굴이 정해지지 않고, 시드를 지정할 수 없다. | 단색 배경 얼굴 기준 R1을 참조로 붙인다. |
| 같은 얼굴인데 키와 다리 비율이 달라진다 | 얼굴만 참조하면 몸 비율은 다시 무작위가 된다. | 키, 체중, 머리 수, 허리 위치를 글로 적고 전신 기준 S1을 함께 붙인다. |
| 참조가 배경과 구도까지 따라온다 | 참조 이미지는 인물만 골라 옮기지 않는다. | 참조는 단색 배경 사진으로만 만든다. |

같은 개인사 시안에서 오델, 하겐, 켈의 얼굴이 닮아 보였다. 세 사람도 이 방식으로 다시 만들 때 인물표의 구별점(짧은 목과 네모난 턱, 긴 목과 인중, 넓은 등과 갈라진 턱 끝)을 지시문에 넣는다.

## 확인한 결과

이미지를 직접 열어 확인했다.

- R1, S1, S2, S3가 같은 얼굴로 읽힌다.
- S1과 S2에서 완만한 어깨와 긴 팔다리의 호리호리한 체형이 나왔다.
- S2의 외투는 부드러운 모직으로 읽히고 배경에 잔무늬가 거의 없다.
- S3에서 눈을 가늘게 뜨고 손끝의 고리를 살피며, 엄지 밑 도톰한 살이 보인다.

머리, 벨트, 발 구간을 원본 해상도로 잘라 10px 눈금으로 몸 비율을 쟀다. 머리 높이는 정수리 머리카락부터 수염 끝까지다. 경계를 눈으로 읽었으므로 머리 수에 ±0.4쯤 오차가 있다.

| 이미지 | 머리 수 | 벨트 위치(정수리부터, 전신 대비) |
|---|---:|---:|
| S1 | 약 7.5 | 약 43% |
| S2 | 약 7.7 | 약 43% |

S2는 지시한 약 7.7등신에 맞고, 벨트 위치가 S1과 같아 전신 기준이 몸 비율을 붙잡았다.

## 남은 것

- S3는 고리를 등불 쪽이 아니라 얼굴 앞으로 든다. 등불을 얼굴과 손 사이에 두는 구도로 다시 지시하면 버릇이 더 분명해진다.
- 위 앞니 틈은 S2의 크기에서 확인되지 않는다. 얼굴 클로즈업으로 따로 확인해야 한다.
- S1 외투 옷깃에 옅은 무늬가 남았다.
- 생성 시안이므로 정면, 측면, 뒷면의 비례가 정확히 맞는다고 보장하지 않는다. 게임의 최종 얼굴과 체형은 MetaHuman으로 만들 때 정한다.
- 실사 시안은 [결정 66](../../../decisions/0066-veles-b-art-direction.md)의 반실사 B안 게임 화면과 질감이 다르다. 캐릭터 기준은 [ArtDirection](../../../ArtDirection.md)에서 아직 미정이다.
