# 중세 주거 건축 도감

유럽과 지중해 주변에서 사람이 살았던 건물 109곳을 골랐다. 농가 한 채부터 왕실 거처까지, 지붕선과 층수뿐 아니라 집이 길과 물가에 닿는 방식, 방이 마당을 둘러싸는 방식도 비교할 수 있다.

[사진으로 비교하기](index.html)

한 건물은 한 번만 실었다. 복합 유적에서는 이름을 적은 주거동이나 궁전이 한 사례다. 연대는 원형 또는 주요 건립 단계이며 사진은 현존 상태를 보여 준다. 복원·이축·후대 증층을 확인한 곳은 연대나 설명에 적었다. 치수는 출처가 제시한 측정 대상을 함께 적었고, 다른 사례는 층수와 동 배치로 규모를 표시했다.

## 발굴도와 평면을 더 볼 수 있는 자료

아래 자료는 위 건물 수에 더하지 않았다.

- 도판 7.4에는 푸스타트의 9세기 주택과 수로가, 7.5에는 페스의 중정 주택이 실려 있다. 도판 5.11은 그라나다의 집과 궁전을 같은 축척으로 놓았다. [모로코 페스와 이집트 푸스타트의 주택 평면](https://web.mit.edu/akpia/www/articlepulido.pdf)

- 모로코 문화부는 발굴한 궁전을 13–14세기로 잡는다. 같은 유적의 목욕장과 궁전은 건립 연대와 용도가 다르다. [모로코 아그마트 궁전](https://mjcs.gov.ma/fr/communique-de-presse/)

- 발굴 보고와 기록을 다시 검토한 건축사 논문이다. 북아프리카 파티마 왕조의 지방 궁전과 도판 출처를 찾을 때 본다. [리비아 아즈다비야의 파티마 궁전](https://ora.ox.ac.uk/objects/uuid:c06ef6f0-8581-4ffe-b2a1-6a83824d704e)

- 현장 배치도에서 Dar el-Bahr의 위치를 찾은 뒤 대학 자료의 궁전 평면을 보면, 방과 수조가 차지하는 영역이 구별된다. [알제리 호수 궁전의 상세 평면](https://elearn.univ-tlemcen.dz/pluginfile.php/128474/mod_resource/content/1/TD12-S4Le%20palais-du-lac.pdf)

사진과 도면에는 원본 파일의 저작자·이용 조건을 붙였다. 이 자료집에는 원본 비율을 유지한 위키미디어 축소본을 실었다.
