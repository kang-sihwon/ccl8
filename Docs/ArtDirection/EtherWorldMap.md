# 에테르 세계지도 시안

결정 39에 따라 다섯 대륙 외형과 플레이 대륙의 지형·36개 정착지를 서사 배경으로 연결한 결과는 [지형과 정착 정리](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-06-opening-and-continent/geography.md)에서 읽는다. 생성 지도 확대도에 남은 거리·방향 오차와 문서의 상대 배치 기준을 구분한다.

육지 35%와 이그니스 2,000만 km²를 맞춘 계산 보정본(v3)을 지리 검토용 지도로 사용한다. 사용자가 고른 두 번째 생성물(v2)의 구도를 바탕으로 해안선을 벡터로 옮기고 위치·외곽·구면 면적·격자를 보정했다. 이 해안선을 유지한 [에테르 월드맵 최종 참고 시안](EtherWorldMap/MapPresentation.md#최종-시안-v2)은 결정 46으로 채택한 통일 UI v2다. 결정 44의 [월드맵 v1](EtherWorldMap/MapPresentation.md#에테르-월드맵)은 이전 비교 자료다. 지표 질감의 채택과 서사 정본의 지리 확정은 구분한다.

상위 문서는 [아트 방향](../ArtDirection.md)이다. 수치와 투영 규칙은 [지도 제작 기준표](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-map-production-basis.md)가 소유한다.

## 지도 용도와 UI 방향

[동안항 환승·세라디온 진입 도면](EtherWorldMap/2026-11-10-seradion-arrival-map.md)은 T3-T5 수송 관계, 기존 R9의 루세아·동안항 구간, 세라디온 새 22장소·8생활 단위의 첫 탐색을 구분한 좌표 검토 자료다. 기존 항구·해안·항로를 보존하며 세라디온 국소 도면의 세계 해안 접속과 실제 항행·전투는 미검증이다.

[오르다스 고원·흰침 도면](EtherWorldMap/2026-11-10-ordas-highlands-map.md)은 기존 외항 좌표를 보존하고 새 26장소·15생활 단위와 수로 회복·고원 왕복·보스 접근 및 다른 귀환을 연결한 좌표 검토 자료다. 지도 3장의 국소 설계값이며 세계 해안 접속·실제 항행·전투 성능과 정본 채택은 확정하지 않는다.

[T2 출항·오르다스 외항 도면](EtherWorldMap/2026-11-09-ordas-arrival-investigation-map.md)은 연안 환승 관계와 외항·저수지·수로 외곽의 28장소, 생활권·봉쇄 관측·다른 귀환을 세 장에 담은 좌표 검토 자료다. 세계 해안 접속·내해 전체 개방과 실제 항행을 확정하지 않는다.

[아르베나 수색·G3 연결 도면](EtherWorldMap/2026-11-09-arvena-fleet-search-map.md)은 기존 도착항 26장소를 보존하고 새 28장소·15형태·16생활 단위와 숲·연안 왕복, 7명 구조·최종 대응을 연결한 좌표 검토 자료다. 현행 화풍·UI를 대체하지 않으며 세계 해안 접속과 실제 항행은 미검증이다.

[세르나–아르베나 출항·도착 도면](EtherWorldMap/2026-11-09-serna-arvena-passage-map.md)은 G1·G2 환승 관계, 세르나 기존 항만·외항, 아르베나 첫 탐색을 세 장에 담았다. 26장소·7형태·20개체와 구조체 1기, 두 교량 퇴로와 북쪽 우회를 연결한다. T1과 아르베나 국소 후보는 세계 해안에 접속한 해도로 취급하지 않는다.

[이그니스 연속 지역 지도](EtherWorldMap/IgnisConnectedAtlas.md)의 현재 제작본은 고정 픽셀 격자에 맞춘 타일 50장과 20,480×10,240px 조립본이다. [분할 기준과 검증 범위](EtherWorldMap/WorldSectorPlan.md)를 함께 읽는다. 이전 전체 연결도·연속 구역 9장·주요 도시 8권역·36정착지 상세는 비교 자료로 보존하며, 기존 상세 36장이 연속 지형이라는 뜻은 아니다. 새 제작본은 사용자 검토 후보이고 에테르 세계 전체 제작은 나머지 대륙의 설정 이후로 보류한다.

[이그니스 S1-S6 연결 도면](EtherWorldMap/2026-11-09-ignis-journey-map.md)은 전체 왕복 경로·동료와 설비 인계·벨레스 파생형 배정을 지도 3장에 정리한다. 기존 좌표·생활권을 유지하며 S3 첫 화물과 S4 후속편, 공공 통과와 S6 설비 접근, 선택 성장 보존을 구분한다. 인게임 지도 UI를 대체하지 않는 검토 자료다.

[중앙 S6 탐색 도면](EtherWorldMap/2026-11-09-central-exploration-map.md)은 북부 귀환·관리도시 준비·바깥 뿌리권·안쪽 설비의 최종 접근을 연결한다. 지도 4장과 좌표 JSON에 27장소·13생활 단위·34개체와 별도 구조체 5기·인간조 5명을 담았다. 원본 지리·세계수 반경을 유지하며 새 시설·생활권·공급 운용은 후보로 구분한다.

[지도 제작 기준과 채택 시안](EtherWorldMap/MapPresentation.md)이 이후 지도의 화풍·공통 UI·지명 표기와 벨레스·이그니스·에테르 월드맵 최종 참고 이미지를 소유한다. 현행 기준은 [결정 46](../decisions/0046-unified-map-v2-adoption.md)의 통일한 v2다. [결정 43](../decisions/0043-map-art-and-ui-standard.md)과 [결정 44](../decisions/0044-ether-world-map-reference.md)의 v1은 이전 비교 자료로 보존한다. 지리·탐색 설계도는 아래 자료에서 별도로 읽는다.

[결정 45](../decisions/0045-unified-map-presentation.md)에 따라 이그니스를 기준으로 세 지도의 색·공통 UI·지명 연결 규칙을 맞췄으며, 사용자가 [최종 시안 v2](EtherWorldMap/MapPresentation.md#최종-시안-v2)를 채택했다. 새 지도는 이 기준과 공통 UI 값을 재사용하고 축척에 맞춰 정보량을 조절한다.

[북부 탐색 도면](EtherWorldMap/2026-11-09-north-exploration-map.md)은 하르덴 공공 복귀·네르바·관문·새 고개·북사면 기록 유적을 연결한 후보다. 운송·네르바·남쪽 구조·보관소 4장과 좌표 JSON에 26장소·13생활 단위·34개체와 구조체 6기를 담았다. 원본 정착·수계·산맥을 유지하며 새 NP01과 접근 회랑은 미검증 후보로 구분한다.

[세르나–켈바–하르덴 도면](EtherWorldMap/2026-11-08-serna-harden-exploration-map.md)은 R1 상행·공공 환적·R2·R4와 두 지역 탐색을 연결한 후보다. 전체 운송·공공 환적장·켈바·하르덴·비룡 전투 단 5장에 30장소·17생활 단위·45개체와 구조체 1기를 담았다. 기존 정착지·해안·물길을 유지하고 새 국소 높이·생활권·귀환을 별도 데이터로 기록했다.

[로덴–세르나 하구·항만 도면](EtherWorldMap/2026-11-08-roden-serna-exploration-map.md)은 기존 R1·M03·해안에 25장소·12생활 단위와 도보·배 왕복을 연결한 후보다. 구간도·하구·항만·좌초선 확대도 4장과 좌표 JSON을 함께 읽는다. 다른 지역의 이전 그림까지 갱신한 것은 아니다.

현행 분포·레벨의 기준은 [세계 분포·성장 후보](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-08-world-distribution-and-leveling.md)다. 이를 적용한 [타르넬–로덴 구간도·탐색 확대도](EtherWorldMap/2026-11-08-tarnel-roden-exploration-map.md)에 두 생활권의 진입·귀환·철수와 22개 장소를 작성했다. 아래 v1·v2 안내와 수치는 이전 작업 기록이며, 새 S2 도면이 다른 지역의 옛 그림까지 갱신한 것은 아니다.

확장 몬스터 기준의 현재 분포·레벨 문서는 [생태·성장 v2](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-08-continent-ecology-progression-v2.md)다. v2는 문서 작업이며 아래 v1의 지도·JSON을 갱신하지 않았다. v1 그림은 기존 지형·경로의 참고이고 확장 종의 현행 배치도가 아니다.

대륙 메인 여정을 기존 좌표에 연결한 [이동·생태·성장 후보](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-08-continent-ecology-progression.md)에 전체 경로도·중앙 확대도·성장 곡선과 JSON을 추가했다. 36곳과 기존 해안·물길을 유지하고 여섯 메인 구간과 세 선택 탐색권을 구분한다. 새 접근점·레벨·지역 생태는 후보이며 그림의 색 표식은 기후 경계나 실제 스폰 영역이 아니다.

실제 인게임 지도 UI는 지형과 위치를 읽는 평면 도면형 지도로 제작한다. 기존 이그니스 생성 그림은 도시·마을 사이 이동을 보여주는 개념도로 활용할 수 있다. 근거는 사용자의 용도 구분을 기록한 [결정 34](../decisions/0034-concept-and-ingame-map-roles.md)다.

[결정 35](../decisions/0035-nadir-map-presentation.md)의 지역 지도 수직 시점은 유지한다. UI 제작 보류와 모든 축척의 엄격한 평면 표현은 결정 43으로 일부 대체했다. 지역은 벨레스의 수직 항공사진 느낌을, 대륙은 이그니스 선택안의 산맥 입체감과 지표 질감을 따른다.

[벨레스 지도만의 표현 3안과 첫 표현 유지본](EtherWorldMap/2026-11-01-veles-map-style-variants.md), [주변 생활권 지도와 수직 시점 수정안](EtherWorldMap/2026-11-01-veles-wider-region-map.md)은 이전 비교 자료로 보존한다. 현재 표현 기준은 위 채택 시안이며 이미지의 지형·축척·정착지 좌표를 확정한 것은 아니다. 일반 도시와 마을의 표시 이름·생활권은 [정착망 상세 설정](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-ignis-settlement-network.md#상세-설정)을 참조한다.

| 자료 | 용도와 현재 상태 |
|---|---|
| 기존 이그니스 생성 지도 | 대륙 분위기·거점 관계를 보는 개념도. 도시·마을 단위 이동 화면의 활용 후보 |
| 세계지도 좌표·세계수·정착지 설계도 | 면적·거리·배치·시야를 검토하는 제작 자료. UI 외형을 정한 시안이 아님 |
| 인게임 지도 UI | [벨레스·이그니스·에테르 월드맵 최종 시안 v2](EtherWorldMap/MapPresentation.md#최종-시안-v2)를 제작 기준으로 사용한다. [벨레스 첫 시안](EtherWorldMap/2026-11-01-veles-ingame-map-ui.md)은 이전 비교 자료이며 실제 게임 구현은 미검증이다. |

사용자는 붉은사막·원신을 인게임 지도의 방향 참고로 들었다. 두 작품의 세부 지도 기능이나 시각 요소를 조사·채택한 상태는 아니다. ccl8의 현행 기준과 남은 범위는 다음과 같다.

- 지형 바탕에는 강·호수·산지·절벽·숲·길과 건물 윤곽을 위에서 읽는 형태로 표현한다. 과장된 입체 도시 모형은 위치 기준으로 사용하지 않는다.
- 지명과 현재 위치·목표 등의 표식은 지형 바탕과 분리해 가독성을 검토한다. 실제 표시 항목은 기능 범위에 맞춰 정한다.
- 벨레스의 공방·급수대·나루·숲길·동굴 관계는 기존 지역 자료를 따른다. 채택 시안에서 급수대 이름을 생략한 것이 시설 설정을 없앤다는 뜻은 아니다. 같은 배치 기준을 지역 확대와 대륙 축소 표현에 연결한다.
- 색감·지표 질감·글씨·아이콘·지명 연결선은 결정 46의 최종 시안 v2와 제작 기준을 따른다. 양피지 질감과 등고선은 기본 화풍의 필수 요소가 아니다. 실제 고도 자료와 대륙 수계·위경도의 정합, 탐색 공개 방식과 확대 단계는 미확정이다.

## 이그니스 지역 확대

대륙 전체와 중앙 지역을 함께 맞춘 위치 기준은 [36개 정착지 좌표 정합 후보](EtherWorldMap/2026-11-07-continent-coordinate-map.md)다. 세계지도 v3 해안과 중앙 9곳을 유지하고 외곽 27곳, 주요 분수계·수계·교역 회랑을 같은 좌표계에 연결했다. 기존 세계지도와 같은 투영의 대조 도면도 함께 둔다. 새 전역 원점·외곽 위치·지형 선형은 미승인 설계 후보다.

중앙의 관리도시·로덴·벨레스와 주변 정착지의 위치·방향·축척은 [좌표 기준 보정본](EtherWorldMap/2026-11-07-central-coordinate-map.md)을 우선한다. 기존 데이터로 중앙 9곳과 환적장을 다시 그리고 벨레스 주변을 같은 축척 비율로 확대했다. 좌표 역산 검사와 독립 시각 검토를 통과했다.

대도시 8곳·일반 도시 12곳·마을 16곳의 이름과 위치는 위의 36곳 좌표 정합 도면에서 함께 읽는다. [이전 정착망 수직 평면 시안](EtherWorldMap/2026-11-01-ignis-all-settlements-nadir.md)은 등고선 중심의 표현 참고로 보존한다. 이전 시안의 중앙 확대도는 거리 비율과 벨레스 이웃 마을 방향에 오차가 있어 실제 좌표 기준으로 사용하지 않는다.

세계수의 실제 치수와 그 영향을 받는 도시·마을의 현재 작업 후보는 [세계수·정착지 설계도](EtherWorldMap/2026-11-01-worldtree-settlement-plans.md)에서 읽는다. 새 지역도는 관리도시·로덴·벨레스의 거리와 가림 조건을 정의한다. 아래 생성 이미지는 대륙의 큰 지형·정치 관계를 보는 개념도로 유지하며, 중앙 도시 표식의 실거리 배치로 사용하지 않는다.

현재 배치의 바탕은 [이그니스 전체 지형 시안](EtherWorldMap/2026-11-01-ignis-macro-terrain.md)이다. 대륙이 화면 대부분을 채우도록 확대한 뒤 산맥·고원·분지·평야·강·호수와 세계수를 표현했다. 사용자가 다음 단계로 이그니스의 큰 도시 배치를 요청해 [주요 도시 8곳의 후보](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-ignis-major-cities.md)를 추가했다. [도시 시안 제작 기록](EtherWorldMap/2026-11-01-ignis-city-prompts.md)에 입력·출력·프롬프트를 둔다.

세계수는 [중앙 분지의 본류 서쪽에 표시한 후보](EtherWorldMap/2026-11-01-ignis-macro-terrain.md#세계수-위치-후보)를 추가했다. 지도상의 수관은 가독성을 위해 강조한 상징이며 실제 치수의 작업 후보는 [세계수 규모](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-worldtree-scale.md)에 정리했다.

도시와 정치 관계를 지도에서 함께 볼 때는 [통치·생산·교역 배치안](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-ignis-governance-layout.md)을 읽는다. [통합 PNG](EtherWorldMap/Images/ignis-governance-production-trade-v2.png)에 정치권 4곳과 생산·공급 거점 8곳, 수운·육로·연안 해로를 표시했다. 입력·출력·프롬프트와 화면 확인 범위는 [제작 기록](EtherWorldMap/2026-11-01-ignis-governance-prompts.md)이 소유한다. 정밀 국경·면적·항행 조건을 검증한 지도는 아니다.

앞서 만든 [이그니스 거점 배치](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-ignis-spatial-layout.md)와 [벨레스·첫 장 동선](../Narrative/Drafts/2026-10-31-ether-taiga-dawn/2026-11-01-first-chapter-spatial-layout.md)은 비교 자료로 보존한다. 대륙 전체 지형을 고른 뒤 다시 검토하며 기존 좌표를 확정 조건으로 사용하지 않는다.

## 생성 시안에서 확인한 내용

- 이그니스가 넓은 북방 육지로 표현되고 남쪽 만이 보인다.
- 오르다스 북동쪽의 내해가 좁은 물길을 통해 바깥 바다와 이어져 보인다. 정확한 수로 폭과 항행 가능성은 미검증이다.
- 다섯 본토가 바다로 분리되고 니베르가 하단 전체에 이어진다.
- 세 교역 연결을 점선으로 표현했다. 세라디온과 니베르로 가는 선은 없다.

## 생성 시안의 오차와 미검증 항목

격자가 요구한 가로·세로 각 12등분과 일치하지 않고 적도도 세로 중앙에서 벗어나 보인다. 기준점과 본토 극점도 표의 좌표에서 일부 벗어난다. 해안의 작은 섬과 항로의 화살표 같은 끝 모양은 생략 요청과 다르다. 이 확인은 화면 관찰이며 정밀 픽셀 측정은 아니다.

해안선의 구면 면적을 계산하지 않았으므로 실제 육지 비중 35%와 이그니스 2,000만 km²의 충족은 미검증이다. 니베르 해안의 범위와 좌우 이음, 항로 끝의 정확한 접속도 추가 확인이 필요하다. 이 시안은 대륙의 존재감과 전체 형태를 고르는 데 사용하고, 선택한 형태를 좌표가 고정된 지도에 옮긴 뒤 면적을 검증한다.
