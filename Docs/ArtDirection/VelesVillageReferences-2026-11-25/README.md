## 벨레스의 기준

서쪽에는 경작지, 중앙에는 주거지, 동쪽에는 수리 공방과 작업 마당, 남쪽에는 나루가 있어. 공동 급수대와 샘물길을 지나는 주민은 큰 강에서 짐을 옮기는 사람과 다른 길을 써. 북동쪽 저장고에서 숲길로 넘어갈 때는 지붕이 뜸해지고 숲이 가까워져. [벨레스 구역별 지도와 기존 아트](../VelesConcepts-2026-11-17/B-village.md)

B안의 자연광, 서정적인 반실사, 붉은 지붕·청록 덧문·겨자색 천막·황금빛 숲을 기준으로 삼아. 미술 자료에서는 형태와 배치를, 게임 화면에서는 캐릭터가 그 공간에 들어갔을 때 보이는 범위를 골라봐. [벨레스 화풍 결정 66](../../decisions/0066-veles-b-art-direction.md) · [기존 마을과 공방 자료](../EtherFirstChapter/VelesReferences.md)

## 출처와 선택 방법

게임 화면은 개발사·배급사가 공식 상점에 올린 스크린샷이야. 콘셉트·환경 아트에는 손으로 그린 그림, 설계 시트, 제작자가 공개한 3D 환경 렌더와 트레일러 장면이 있어. 옛 그림은 작품 도판을 실었고, 뒤러와 브뤼헐처럼 중세 말이나 근세의 풍경도 포함했어. 카드에 적은 관찰점은 벨레스에 적용하기 위한 해석이야. 작품명과 출처는 카드의 ‘원문’에서 확인할 수 있어.

카드에서 ‘가까움’이나 ‘피하고 싶음’을 고른 뒤 ‘선택 정리’를 누르면 번호와 제목이 모여. 이전에 표시한 게임과 그림도 같은 브라우저에서 다시 볼 수 있어. 자료를 고른 뒤 벨레스 콘셉트 시안을 만들고, 시안 승인 뒤 레벨 제작으로 넘어가.
