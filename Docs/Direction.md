# ccl8 제작 방향

ccl8은 Orbis와 전체적인 작업 방향과 그래픽 스타일을 공유하는 소울라이크 RPG다. 마을에서 출발해 일반 적과 전투하고 보스에 도달하는 짧은 게임을 완성한다. 근거는 [결정 1](DesignLog.md)이며, 아래 확정 범위는 2026-10-05 사용자 지시를 따른다.

## 확정 범위

| 항목 | 기준 |
|---|---|
| 장르 | CCL 신청 계획서에 기재한 소울라이크 RPG를 유지한다 |
| 제작 기간 | 3-4개월 안에 완성한다. 실제 착수일과 제출일은 미기록이다 |
| 공간 | 마을 하나와 보스에게 도달하는 전투 구간을 만든다 |
| 적 | 보스 하나와 서로 다른 일반 몹 몇 종류를 만든다 |
| 인물·서사 | NPC 몇 명과 이 범위에서 끝나는 간단한 시나리오를 만든다 |
| 아트 | Orbis의 그래픽 스타일을 기준으로 한다. 구체적인 해석과 후보는 [ArtDirection](ArtDirection.md)이 소유한다 |
| 작업 시간 | 회사 업무 외 시간에 진행한다 |

CCL 지원 프로그램은 사용자 설명상 3개월이며, 게임 제작 목표 기간은 위와 같다. 네 번째 달을 제출 일정에 포함할 수 있는지는 확인되지 않았다. 일정 초안은 [StudyRoadmap](StudyRoadmap.md)에 있다.

## 역할

AI는 기획 초안, 아트 방향 제안, 구현, 통합, 검증과 문서화를 주도한다. 사용자는 결과를 검토하고 수정 사항과 방향을 지시한다. 사용자가 게임 코드를 직접 작성하는 것을 진행의 선행 조건으로 삼지 않는다. 파일 수정과 실행 경계는 [Coding](Coding.md)이 소유한다. 근거는 [결정 2](DesignLog.md)다.

AI는 검토 가능한 결과를 작은 작업 단위로 제공한다. 확정 범위 안의 세부 구현 선택은 이유를 기록하고 진행한다. 장르, 콘텐츠 범위, 핵심 경험을 바꾸는 선택은 대안과 영향을 정리해 사용자에게 제시한다.

## Orbis와의 관계

이번 지시는 전체 방향과 그래픽 스타일을 공유하라는 뜻으로 기록한다. Orbis의 천체 시뮬레이션, 항해, 세계 확장, 장기 학습 과제를 ccl8의 필수 구현으로 자동 편입하지 않는다. 필요한 요소는 이 게임의 경험과 제작 기간에 기여하는지 개별 판단한다.

Orbis 문서는 방향을 확인하는 참고 자료다. 게임 코드, 에셋, 고유 인물과 세계 설정, 과거 기록을 복사하는 것은 이번 정리의 범위에 없다. ccl8 문서만으로 후속 작업을 진행할 수 있게 유지한다.

## 제작 판단 기준

다음은 AI가 제안하는 제작 기준이며 사용자가 확정한 세부 사양은 아니다.

- 마을, 전투 구간, 보스와 결말을 먼저 연결해 전체 흐름을 플레이할 수 있게 한다.
- 일반 몹의 종류는 외형 수보다 서로 다른 공격 신호와 대응 행동으로 구분한다.
- 새 시스템은 이 짧은 플레이에서 실제로 쓰이는 경우에 도입한다.
- 완성 기준은 시작, 실패 후 재도전, 보스 격파와 종료까지 이어지는 실행 가능한 결과물로 잡는다.
- 범위가 커지면 부가 콘텐츠와 변형 수를 먼저 줄이고 필수 전투 흐름을 유지한다.

이 접근은 장기 확장성과 콘텐츠 다양성보다 기한 내 통합 검증을 우선한다. Orbis와 동일한 시스템 규모를 먼저 구축하는 대안은 재사용 여지가 있지만, 이번 제작 기간에는 실제 콘텐츠 완성을 늦출 위험이 있다.
