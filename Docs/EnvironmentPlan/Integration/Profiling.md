# 통합 계측

`run_environment_smoke.ps1`의 CPU, 메모리, 프레임 계측 방식과 측정값을 볼 때 읽는다. 측정이 끝나지 않은 범위는 [프레임 계측의 미완료 범위](../Integration.md#프레임-계측의-미완료-범위)에 있다.

## 프로세스 계측

`run_environment_smoke.ps1`은 직접 시작한 프로세스만 0.5초 간격으로 관측한다. CPU 누적 시간, 작업 집합·private bytes, 운영체제가 제공하는 최대 작업 집합과 같은 관측 회차의 작업 집합 합계를 로컬 결과에 기록한다. 각 표본에 프로세스 ID·역할·실제 경과 시간을 남긴다. 종료 사이에 얻지 못한 마지막 CPU 값은 추정하지 않으며, 표본 수가 없는 프로세스는 미측정으로 표시한다. 실패한 실행도 결과와 이미 얻은 표본을 보존한다.

이는 프로세스 비용의 첫 측정이며 프레임 CPU/GPU 시간이나 네트워크 대역폭을 대신하지 않는다. 반복 실행의 각 회차는 별도 결과를 유지한다. 실제 패키지에서 기능 통과와 계측 파일 생성을 확인한 뒤 측정값을 기록한다. 패키지 빌드와 실행을 동시에 수행한 값은 성능 기준으로 사용하지 않는다.

## 프레임 계측

프레임 비용은 선택적인 `-ProfileFrames` 실행으로 분리한다. 같은 실험장 맵을 자동 시험 조작 없이 실행하고, UE CSV profiler가 지정 프레임을 기록한 뒤 정상 종료한다. 렌더링 실행은 `-csvGpuStats`도 요청한다. 초기 로딩 이후의 실행 명령으로 캡처를 시작하지만, 측정 안의 초기 프레임에는 셰이더 준비·내비게이션 생성 등의 비용이 남을 수 있다. NullRHI 실행에는 GPU 측정값을 요구하지 않는다. 근거는 UE 5.8.3의 `<Engine>/Source/Runtime/Core/Private/ProfilingDebugging/CsvProfiler.cpp`다. 장시간 평균뿐 아니라 프레임 원본을 보존하며, 표본이 없는 지표를 0으로 보고하지 않는다.

CSV 요약은 요청한 프레임 수가 실제 파일의 표본 수와 같은지 확인한 뒤 첫 30프레임을 제외한다. 30프레임 이하의 짧은 진단은 마지막 한 프레임을 남긴다. 평균·중앙값·95/99백분위·최댓값과 원본을 보존하며, 백분위는 nearest-rank 방식을 쓴다. 월드의 완료 세계 시각·대기 게임 시간·아직 입력되지 못한 게임 시간도 초 단위의 별도 필드로 남긴다. CSV 출력의 정밀도는 저장·시간 경계 검증에 쓰지 않는다. `PROFILE PASS`는 계측 완료를 뜻하며 기능 검사나 프레임 예산 통과를 뜻하지 않는다.

### 프레임 예비 계측 결과

2026-10-10 UE 5.8.3, Ryzen 9 3950X·RTX 4070 Ti에서 Scenario의 렌더링·NullRHI를 각각 180프레임 기록하고 정상 종료했다. 서버 최초 빌드가 동시에 진행 중이었고, 이 실행 파일에는 아래 지형 경계 최적화가 들어 있지 않다. `summarize_environment_profile.py`로 실제 180개 표본과 첫 30프레임 제외 후 150개 표본을 확인했다.

| 실행 | 프레임 평균 | Tickable 평균 | GPU 평균 |
|---|---|---|---|
| 렌더링 1280×720 | 202.51ms | 189.69ms | 44.77ms |
| NullRHI | 212.87ms | 203.05ms | 미측정 |

기능 통과나 성능 목표 달성 결과가 아니다. 렌더링을 끄고도 큰 Tickable 비용이 남았고, 지형 질의가 청크와 만나지 않는 광선에도 모든 삼각형을 검사했다. 그래서 [청크 경계 검사](../Terrain/Verification.md#지형-질의-비용)와 단계별 계측을 추가했다. 빌드가 겹친 이 예비 실행과의 정확한 개선 비율은 계산하지 않는다.

안내·조작 화면을 읽을 수 있고 반 열림·열림의 문 폭이 다르다. 실험장 바깥의 검은 영역과 단순한 표면·생물 표현은 남아 있으며 최종 아트 통과로 기록하지 않는다.

## 지형 질의 수정 후 프레임 계측

2026-10-11 최종 지형 경계·서버 표현 수정의 생성·Editor 빌드 후 CCL 자동 검사 145/145를 통과했다. 이 절의 결과는 이후 구역 09 추가 전 소스 기준이다.

자체 빌드 프로세스가 없는 상태에서 Scenario를 각 600프레임 기록하고 첫 30개를 제외한 570개 표본을 요약했다. Ryzen 9 3950X·RTX 4070 Ti, 1280×720, 60fps 제한이다.

| 실행 | 프레임 평균 / 95백분위 | 게임 스레드 평균 | GPU 평균 | 대기 게임 시간 |
|---|---|---|---|---|
| 렌더링 | 16.6692 / 16.6765ms | 6.7047ms | 4.9195ms | 0.2399–0.2414초 |
| NullRHI | 16.6668 / 16.6752ms | 미측정 | 미측정 | 0.2487–0.2488초 |

두 실행 모두 아직 시계에 입력되지 못한 게임 시간은 0이었다. 렌더링의 세계 완료 시각은 60초에서 629초로 진행했다. 프레임 제한에서의 짧은 고정 시점 관측이며 대규모·장시간·전체 맵 프레임 보장이 아니다.

중첩된 exclusive CSV 구간은 자식 비용을 뺀다. 따라서 기존 Tickables와 비교하려면 새 Tickables·WorldAdvance·SurfaceAdvance·EcologyAdvance를 합산해야 한다. 이 합은 렌더링 평균 약 2.165ms, NullRHI 약 1.990ms였다. 지형 경계 검사 자체의 전체 비용 비중을 별도로 측정한 수치는 아니다.
