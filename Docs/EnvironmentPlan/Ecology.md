# 생태계·생애 구현과 검증

단계 8의 개체군·식생·부패·Agent 나이를 공통 세계 시간과 저장에 연결했고, Actor/Mass 전환, 첫·늦은 접속자 복제, 저장 복원, 실제 공간 경로를 검증했다. 이 문서는 단계 8의 값 모델, 시간순 생애 계산, 월드 진행·저장 연결과 영역별 설계·구현·검증 기록을 소유한다. 범위는 [환경 계획](../EnvironmentPlan/Design.md#생태계와-생애-주기)과 [결정 19](../decisions/0019-natural-environment-and-labs.md)를 따른다.

기능별 전용 레벨과 단일 종류·표본 수 선택은 [환경 실험장 사용법](Laboratories.md)을 따른다. 구역 06·07의 비교 배치 설명은 기존 통합 실험장 기준이다.

## 집계 생물의 에너지·기아 구현

연령군과 행동 없는 예약의 대사·섭식·기아를 공통 정수 세계초에 연결했다. 예약·반환에서 에너지를 이전하고 음식 소비 원장과 사망 사건을 검증한다. 생태 본문 형식 6의 저장 계약, 기존 코드와의 비교, 구역 06의 입력 조정과 규모 검사는 [집계 생물의 영양 상태](Ecology/Nutrition.md)가 소유한다.
