# 기능별 환경 실험장 사용법

`/Game/Maps/Tests`의 전용 레벨에서 시험 하나를 골라 실행한다. 생태계·식생·생애·부패는 종류 하나와 표본 수를 정한 뒤 새로 배치한다. 레벨마다 세계 시간과 초기 상태를 새로 만들고 0배속에서 시작한다. 기존 통합 실험장은 여러 기능을 함께 비교할 때 사용한다.

레벨 선택과 설정은 `Source/CCL/Environment/CCLExperimentLaboratoryScreen.cpp`, 서버 검증·이동은 `CCLExperimentLaboratory.cpp`, 레벨·종류 목록은 `CCLLaboratoryConfiguration.cpp`가 소유한다. 이 문서는 실험장의 사용법, 레벨과 표본, 실험용 리소스와 제출 범위, 후속 작업 기준과 검증 기록을 소유한다. 근거는 [결정 27](../decisions/0027-per-feature-environment-labs.md)이다.

## 하위 문서

| 문서 | 읽는 때 |

| [실험장 검증](Laboratories/Verification.md) | 전용 레벨의 검증 결과와 미검증 범위를 확인할 때 |

## 시작과 조작

1. 콘텐츠 브라우저에서 `/Game/Maps/Tests/Ecology` 등 원하는 레벨을 열고 Play를 누른다.
2. F7 실험 화면의 **전용 레벨 선택**에서 기능을 고른다. 이 조작은 새 레벨로 이동하며 이전 실험의 진행을 이어받지 않는다.
3. 생태계·식생·생애·부패는 **시험 종류**, **표본 수 (1-16)**를 정하고 **선택한 시험만 새로 배치**를 누른다.
4. 시간 배율을 입력하고 **배율 적용**을 누른다. 0은 정지, 1은 실시간, 60은 빠른 관찰이다. 천체 관측창이 열렸으면 해당 창의 관측 배율에 적용되므로 세계 시간을 바꿀 때는 관측창을 닫는다.
5. F7로 화면을 닫고 WASD로 이동해 표본을 본다. F7을 다시 열어 관측값과 조작 버튼을 확인한다.
6. **현재 실험 초기화**로 시간·표본을 시작 상태로 되돌린다. 저장 슬롯은 레벨·종류·수량별로 나뉜다.

에디터에서 기본값을 바꾸려면 `LaboratorySettings` 액터의 `LaboratoryVariant`, `LaboratoryCount`를 수정한다. 실행 중 종류·수량 변경에는 위 메뉴를 쓴다. 플레이어 바닥은 `LaboratoryFloor_BlockAll`의 충돌이 담당한다.

전용 레벨에서는 중복 구역 선택과 기존 맵 이동 메뉴를 숨긴다. 사용법·자동 검사·저장 / 불러오기는 접힌 제목을 눌러 연다. 저장·복원 레벨은 저장 버튼을 바로 표시한다. 초기화와 관찰 위치 이동은 메뉴 하단에 유지한다.

### 관찰 방법과 표시 범위

메뉴에서 환경 조건과 시간 배율을 정하고 장면의 변화를 관찰한다. 자동 검사는 별도 계산으로 즉시 결과를 내는 항목도 있으므로 장면의 시간 진행과 구분한다.

- 메뉴와 사용법 본문의 글씨를 확대했으며 긴 영역은 스크롤한다.
- 시간 조작과 천체 관측은 Celestial에서 사용한다. Clock 레벨과 쿠킹 항목은 제거했고 기존 구역 번호와 자동 검사 식별자는 보존했다.
- 물·지형 전용 레벨은 미리 채운 물 없이 시작한다. 비 버튼은 18 mm/h이며 높은 세계 배율에서는 누적 강수도 빨라진다. 눈 레벨의 초기 적설은 보행·압축 시험용이다.
- 날씨·눈·물·지형·식생·순환·화재·차폐 레벨에는 강수 표시가 있다. 식생의 겨울 입력은 강설을 지속하며 60배에서 적설·휴면 변화를 관찰한다.
- 식생 발화는 첫 표본이 마른 상태에서 가능하다. 가뭄과 60배를 적용하고 수분이 표시된 발화 기준보다 작아지면 발화한다. 젖은 표본은 실패 이유를 표시한다. 비·성장은 세계 시간을, 연소는 게임 시간을 따른다.
- 생태계 이동 관찰에는 1배를 권장한다. 물고기 수면은 내부를 볼 수 있는 반투명 진단 표시다. 전용 레벨의 Actor는 양·물고기·비둘기·개미의 Skeletal Mesh와 애니메이션을 사용한다.
- 차폐 실험은 문 쪽에서 관찰한다. 비·바람과 문을 조작하고 발화 후 실내 농도와 문 밖 연기를 비교한다. 배출 이펙트는 농도·문 개방·풍속을 나타내는 진단 표현이며 유체 해석 결과는 아니다.
- 환경 순환은 60배를 적용한 뒤 **순환 시작**을 누른다. 경사 상단의 적설·압축, 하단 유출·진흙, 결빙·건조를 두 번 진행하고 결과에 현재 단계를 표시한다.

조작 요청은 PlayerController RPC와 Director의 권한·실행 세대 검사를 거친다. 공통 환경 계산은 서버가 소유하고 표현 Actor는 복제 상태를 읽는다. 표현 전용 보간이나 이펙트는 저장 데이터에 반영하지 않는다.

## 레벨과 표본

아래 이름은 모두 `/Game/Maps/Tests/` 아래에 있다.

| 레벨 | 시험 내용 |
|---|---|
| `Celestial` | 세계 시간·배율과 천체 관측 |
| `Weather` | 자연 날씨·강제 강수 |
| `Snow` | 적설·압축·이동 |
| `Water` | 물 유입·유출 |
| `Terrain` | 영구 지형·충돌·경로 |
| `Ecology` | 지상 생물·물고기·새·곤충 중 하나 |
| `Vegetation` | 식생 9종 중 하나 |
| `Life` | 자연 노화·노화 보호·외부 피해 중 하나 |
| `Decay` | 노출·냉각·밀폐 보관 중 하나 |
| `Persistence` | 세계 저장·복원 |
| `Cycle` | 눈·융해·물·진흙·건조 순환 |
| `Fire` | 연소·강수·소화 |
| `Shelter` | 문·차폐·실내 공기 |

생태계 수량은 개체군의 전체 개체 수이며 초기에는 모두 Actor로 표시한다. Actor는 개체마다 별도 몸체가 있고, Mass는 같은 개체 상태를 데이터로 처리하며 구체로 위치를 표시한다. 전환 시 개체의 위치·에너지·섭취 기록을 유지하며 숨김 상태에서도 계산은 계속된다. 이동은 세계 시간을 따르므로 동작 관찰에는 1배를 사용한다. 전용 레벨은 실험용 동물 리그를 사용하며 최종 아트가 아니다. 리소스 프로필이 없는 기존 통합 맵은 도형 표시를 유지한다.

개체별로 다른 탐색 경로를 사용하며 지상 생물과 개미는 주기적으로 멈춘다. 가까운 이웃에서 벗어나는 방향을 탐색 목표에 더하고, 배고프면 먹이 탐색이 우선한다. 섭취를 시작한 개체는 에너지 95%까지 먹으려 하므로 경계값에서 이동·섭취를 반복하는 현상을 줄인다. Actor는 서버 위치 사이를 보간하고 방향을 부드럽게 바꾸며 이동 속도에 맞춰 애니메이션 속도를 조절한다. 0배에서는 애니메이션을 멈춘다. 먹이 지점에서의 개체 간 겹침 방지, 새의 착지·이륙, 발의 지형 맞춤과 동작 간 블렌딩은 아직 구현하지 않았다.

생태계의 서버 시뮬레이션은 개체별 탐색·휴식·먹이 접근을 결정하고 Actor와 Mass가 같은 결과를 사용한다. 표시 Actor는 위치·방향을 보간하고 Skeletal Mesh의 이동·정지 애니메이션을 재생한다. 별도 AI Controller나 StateTree가 같은 위치를 다시 쓰게 하지 않는다. 기존 결정론적 시간 진행·저장 복원 계약을 유지하기 위한 선택이며, 추후 전투 AI와의 전환은 별도 과제다.
식생 수량은 패치 수다. 나무는 Norway Maple, 풀·꽃·관목은 보유한 Fishermans_Cabin, 양치는 PN_Fern의 `fern_01_01` 메시를 사용한다. 성장량에 따라 크기가 바뀌고 휴면 때도 같은 메시를 유지한다. 고사는 기울어진 메시로 표시하며 전용 시듦·고사 재질은 없다. 이끼·조류·수생 식물·버섯은 아직 진단 도형이다. **20°C · 강수 중지**는 강수·가뭄을 끄고 기존 식물의 성장을 이어 가는 조건 입력이다. 식물 초기화 버튼이 아니다. 전용 표본의 수명은 7세계일이며, 기존 통합 맵의 단축 수명은 유지한다. 생애 수량은 마네킹 주민 수이며 수명 단축·보호·피해 버튼은 첫 표본에 적용한다.

부패 수량은 선택한 보관함 안의 음식 개수다. 음식 메시 하나가 해당 묶음을 나타내므로 수량만큼 메시를 늘어놓지 않는다. **건조·고온다습·냉각**은 선택한 보관함의 앞으로의 온습도를 바꾼다. 1배로 천천히, 60배로 빠르게 진행하면 신선도에 따라 빵 표면이 어두워지고 곰팡이 무늬가 퍼진다. 0배에서는 조건만 바꾸며 품질은 진행하지 않는다. 냉각은 이후 부패와 곰팡이 성장을 멈추지만 기존 손상을 복구하지 않는다. 밀폐의 부패 계수 0.2·곰팡이 노출 0은 유지한다. 바닥으로 꺼낸 음식은 위치의 환경을 사용한다.

부패 표본은 이미 보유한 Fishermans_Cabin의 `SM_Bread_01`을 사용한다. 필요한 원본 의존성을 `/Game/TestResources/Fishermans_Cabin`에 복사했으며, 진단 재질 `M_FoodProgress`가 빵 텍스처와 복제된 품질을 함께 사용한다. 재질의 녹색 피복은 곰팡이 비율을 설명하는 시각 표시이며 미생물 분포를 계산한 결과는 아니다. `Tools/Validation/update_food_presentation.py`로 누락 의존성과 재질을 만들 수 있다.
